🌟 Seaborn কী? কেন শিখব?

একদম শুরুর কথা

ধরো তুমি একটা বিশাল Excel sheet খুলেছ, হাজার হাজার সংখ্যা দেখছ। শুধু সংখ্যা দেখে কিছু বোঝা কঠিন, তাই না? ডেটা ভিজুয়ালাইজেশন মানে হলো এই সংখ্যাগুলোকে সুন্দর গ্রাফ ও চার্টে রূপান্তরিত করা, যাতে চোখের সামনেই বোঝা যায় ডেটায় কী লুকিয়ে আছে।

Seaborn হলো Python-এর একটি লাইব্রেরি যেটা দিয়ে খুব সহজে সুন্দর ও তথ্যপূর্ণ statistical গ্রাফ তৈরি করা যায়। এটা Matplotlib-এর উপর ভিত্তি করে তৈরি, কিন্তু অনেক বেশি সহজ এবং Pandas DataFrame-এর সাথে সরাসরি কাজ করে।

Seaborn → Matplotlib এর উপর নির্মিত, Pandas এর সাথে সরাসরি কাজ করে

📘 Notebook ১ — Univariate Distribution

একটি মাত্র ভেরিয়েবল বিশ্লেষণ করা

Univariate মানে হলো "একটি মাত্র ভেরিয়েবল"। ধরো তুমি শুধু জানতে চাও, NBA খেলোয়াড়দের বয়স কেমন? কতজন ২৩ বছরের, কতজন ৩০ বছরের? এই ধরনের প্রশ্নের উত্তর দেওয়ার জন্যই Univariate Analysis।

📊 2.1 — displot() ফাংশন (Histogram + KDE)

Histogram হলো সবচেয়ে বেশি ব্যবহৃত গ্রাফ যেকোনো সংখ্যার ভেরিয়েবলের জন্য। এটা দেখায় কোন মানের কতটি ডেটাপয়েন্ট আছে।

একটি বয়স-বিতরণের Histogram। প্রতিটি বার দেখায় ঐ বয়সে কতজন খেলোয়াড় আছে।

সবচেয়ে সহজ ব্যবহার:

sns.displot(df['age'])
plt.show()

বিস্তারিত প্যারামিটার সহ:

# kde=True মানে density curve দেখাও
# rug=True মানে নিচে ছোট ছোট দাগ দিয়ে ডেটাপয়েন্ট দেখাও
# bins=10 মানে ১০টি interval/bucket তৈরি করো
# color='red' মানে লাল রঙ
sns.displot(df['age'], kde=True, rug=True, bins=10, color='red')
plt.show()
kde=True/FalseKernel Density Estimation curve দেখাবে কিনা। এটা একটি মসৃণ বাঁকা রেখা যা বিতরণের আকার বোঝায়।
rug=True/Falseনিচে ছোট ছোট উল্লম্ব রেখা (|) দিয়ে প্রতিটি ডেটাপয়েন্ট দেখায়।
bins=nকতটি bucket/interval-এ ভাগ করবে। বেশি bins = বেশি বিস্তারিত কিন্তু noisy।
color='red'রঙ পরিবর্তন।
kind='hist'/'kde'/'ecdf'কোন ধরনের গ্রাফ দেখাবে তা নির্ধারণ করে।
🧠 গ্রাফ পড়ার ব্যাখ্যা: NBA dataset থেকে দেখা যায়: খেলোয়াড়দের বয়স ১৯ থেকে ৩৯ বছরের মধ্যে। ২৩-২৫ বছরের খেলোয়াড়ই সবচেয়ে বেশি। ৩৭-৩৯ বছরের খেলোয়াড় সবচেয়ে কম।

〰️ 2.2 — kdeplot() — শুধু Density Curve

KDE (Kernel Density Estimation) মানে হলো ডেটার উপর একটি মসৃণ বাঁকা লাইন যেটা দেখায় কোথায় ডেটা বেশি ঘন।

Histogram vs KDE — দুটোই বিতরণ দেখায়, কিন্তু KDE মসৃণ
# শুধু KDE curve দেখানো
# shade=True → curve এর নিচের অংশ রঙিন করে
# cut=0 → curve-এর শেষ দুই প্রান্ত কেটে দেয় (data range এর বাইরে না যেতে)
sns.kdeplot(df['age'], shade=True, cut=0)
plt.show()
💡 কখন KDE ব্যবহার করব? যখন histogram-এর সিঁড়িগুলো দেখতে ভালো লাগে না, এবং তুমি শুধু overall pattern বুঝতে চাও। বিশেষত যখন দুটো distribution তুলনা করতে হয়, KDE অনেক পরিষ্কার দেখায়।

📈 2.3 — ECDF (Empirical Cumulative Distribution Function)

ECDF একটু আলাদা। এটা দেখায়: "X মানের নিচে কতভাগ ডেটা আছে?"

ECDF গ্রাফ। লাল দাগের কাটাকাটি পয়েন্ট বলছে: ৫০% খেলোয়াড়ের বয়স ২৬ এর নিচে।
# kind='ecdf' দিয়ে ECDF দেখানো
sns.displot(df['age'], kind='ecdf')
plt.show()
✅ গ্রাফ পড়ার ব্যাখ্যা: এই গ্রাফ থেকে বোঝা গেল: ডেটাসেটের ৫০% এরও বেশি খেলোয়াড়ের বয়স ২৬ বছরের নিচে। সিঁড়ির মতো লাফ = এই বয়সে অনেক খেলোয়াড় একসাথে আছে।

📊 3 — countplot() — Categorical Variable বিশ্লেষণ

যখন ভেরিয়েবলটি সংখ্যা নয়, বরং category (যেমন: playoffs = "F", "NP", "FT"), তখন countplot ব্যবহার করা হয়। এটা প্রতিটি category-তে কতটি record আছে তা bar দিয়ে দেখায়।

# x-axis-এ playoffs, y-axis-এ count
sns.countplot(x="playoffs", data=df)
plt.show()

# hue দিয়ে আরও একটি ভেরিয়েবল যোগ করা
# এখানে প্রতিটি playoffs category-র মধ্যে pos-এর breakdown দেখাবে
sns.countplot(x="playoffs", hue="pos", data=df)
plt.show()
🔑 hue argument: এটা Seaborn-এর সবচেয়ে শক্তিশালী feature। hue মানে হলো আরেকটি categorical variable-অনুযায়ী রঙে ভাগ করা। যেকোনো Seaborn function-এ hue যোগ করলে গ্রাফে আরেকটি মাত্রা যোগ হয়।

🎯 Interview-Level Exercise — Notebook ১

প্রশ্ন ১: একটি DataFrame-এ 'salary' কলামের distribution দেখাও যেখানে: histogram-এ ১৫টি bin থাকবে, KDE curve থাকবে, color হবে 'steelblue', এবং গ্রাফের title হবে "Salary Distribution"।
sns.displot(df['salary'], bins=15, kde=True, color='steelblue')
plt.title("Salary Distribution")
plt.show()

প্রশ্ন ২: ML প্রজেক্টে তুমি একটি model train করার আগে target variable 'failure_count'-এর distribution check করতে চাও। কীভাবে করবে? এটা normal distribution কিনা বুঝবে কীভাবে?
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Histogram + KDE
ax1 = sns.histplot(df['failure_count'], kde=True, ax=axes[0])
axes[0].set_title('Distribution of failure_count')

# ECDF
sns.ecdfplot(df['failure_count'], ax=axes[1])
axes[1].set_title('ECDF of failure_count')

plt.tight_layout()
plt.show()

# Normal distribution হলে KDE curve টি bell-shaped (ঘণ্টার আকার) হবে
# Skewed হলে curve টি একদিকে লম্বা হবে (long tail)

সাক্ষাৎকারে ব্যাখ্যা করো: normal distribution check করা জরুরি কারণ অনেক ML algorithm (linear regression, etc.) assume করে target normal। যদি skewed হয়, log transformation প্রয়োজন হতে পারে।

📗 Notebook ২ — Multivariate Analysis Part 1

একাধিক ভেরিয়েবলের মধ্যে সম্পর্ক খোঁজা — relplot

এখন আমরা দুটো বা তার বেশি ভেরিয়েবলের মধ্যে সম্পর্ক দেখব। উদাহরণ: "বেশি সময় খেললে কি বেশি পয়েন্ট পায়?" — এই প্রশ্নের উত্তর দুটো ভেরিয়েবলের মধ্যে সম্পর্ক বিশ্লেষণ করে পাওয়া যায়।

⚫ 2.1 — Scatter Plot (Point Cloud)

Scatter plot দেখায় দুটো সংখ্যার ভেরিয়েবলের মধ্যে প্রতিটি জোড়া ডেটাপয়েন্টকে একটি বিন্দু হিসেবে। বিন্দুগুলোর pattern থেকে সম্পর্ক বোঝা যায়।

তিন ধরনের Correlation। সবুজ=ধনাত্মক, কমলা=সম্পর্কহীন, বেগুনি=ঋণাত্মক।
# সহজ scatter plot
sns.relplot(x="off_rebounds", y="pts", data=df)
plt.show()

# আরও বিস্তারিত — hue, style, size দিয়ে
sns.relplot(
    x="steals", 
    y="assists", 
    hue="pos",    # রঙ দিয়ে position দেখাও
    style="pos",  # আলাদা আকার দিয়ে position দেখাও
    data=df
)
plt.show()
Parameterকী করেউদাহরণ
hueরঙ দিয়ে category আলাদা করেhue="pos"
sizeবিন্দুর আকার দিয়ে variable দেখায়size="age"
styleবিন্দুর আকৃতি (circle/square/etc.) দিয়ে category দেখায়style="conf"
colকলাম অনুযায়ী আলাদা আলাদা গ্রাফcol="playoffs"
rowসারি অনুযায়ী আলাদা গ্রাফrow="conf"
kindscatter বা line plot নির্ধারণkind='scatter' বা 'line'

📉 2.2 — Line Plot

Line plot দেখায় দুটো continuous variable-এর মধ্যে trend। বিশেষত যখন x-axis সময় বা ক্রমানুসারে সাজানো কিছু হয়।

# kind='line' দিয়ে line plot
sns.relplot(x="age", y="min_played", kind='line', data=df)
plt.show()

# confidence interval ছাড়া (ci=None)
sns.relplot(
    x="games", y="pers_fouls", 
    kind="line", 
    ci=None,  # ছায়া অংশ সরাও
    data=df[df['games'] > 60]  # শুধু ৬০+ গেম খেলা খেলোয়াড়
)
plt.show()
💡 Confidence Interval কী? Line plot-এ ছায়া (shaded area) হলো confidence interval — এটা দেখায় যে average line আসলে কতটা নিশ্চিত। চওড়া ছায়া = বেশি অনিশ্চয়তা = কম ডেটা। ci=None দিলে এটা দেখাবে না।

🔲 2.3 — FacetGrid (col ও row দিয়ে একাধিক গ্রাফ)

FacetGrid হলো relplot-এর একটি বিশেষ ক্ষমতা — এটা একটি categorical variable অনুযায়ী একই গ্রাফ বারবার আঁকতে পারে। যেমন: তিনটি playoff category-র জন্য তিনটি আলাদা scatter plot।

col="playoffs" দিলে প্রতিটি playoff value-র জন্য আলাদা গ্রাফ তৈরি হয়
# col অনুযায়ী আলাদা column-এ গ্রাফ
sns.relplot(x="games", y="pers_fouls", col="playoffs", data=df)

📐 3.1 — lmplot() — Regression Line সহ Scatter

lmplot scatter plot আঁকে এবং সাথে একটি regression line (সরল রেখা) যোগ করে। এটা দিয়ে দুটো variable-এর মধ্যে linear সম্পর্ক আছে কিনা সেটা visually test করা যায়।

lmplot: সবুজ রেখা = regression line (linear relationship-এর সেরা fit)
# সহজ regression plot
sns.lmplot(x="min_played", y="pts", data=df)
plt.show()

# LOWESS regression (non-linear, smoother curve)
# যখন relationship সরল রেখা নয়
sns.lmplot(x="assists", y="turnover", lowess=True, data=df)
plt.show()

# Quadratic regression (বাঁকা রেখা)
sns.lmplot(x="age", y="pts", order=2, data=df)
plt.show()
📖 LOWESS কী? LOWESS (Locally Weighted Scatterplot Smoothing) হলো এমন একটি curve যেটা প্রতিটি অংশে আলাদাভাবে fit করে। এটা তখন ব্যবহার করো যখন সম্পর্কটা কখনো বাড়ে, কখনো কমে — সরল রেখা দিয়ে ব্যাখ্যা করা যায় না।

🌡️ 3.3 — Correlation Matrix ও Heatmap

Correlation (-১ থেকে +১) দেখায় দুটো variable কতটা একসাথে পরিবর্তিত হয়।

Correlation coefficient scale। |r| ≥ 0.5 হলে শক্তিশালী সম্পর্ক।
# Step 1: Correlation matrix বের করো
# iloc[:,1:13] → শুধু numerical columns select করা
cor = df.iloc[:, 1:13].corr()

# Step 2: Heatmap আঁকো
fig, ax = plt.subplots(figsize=(12, 12))
sns.heatmap(
    cor,
    annot=True,     # প্রতিটি cell-এ value দেখাও
    ax=ax,
    cmap="coolwarm", # নীল=negative, লাল=positive
    fmt=".2f",       # ২ decimal place
    vmin=-1, vmax=1  # scale -1 থেকে 1
)
plt.title('Correlation Matrix')
plt.show()
⚠️ গুরুত্বপূর্ণ সতর্কতা: Correlation ≠ Causation। দুটো variable correlate করলেই একটা আরেকটার কারণ নয়। যেমন: স্টেশনে বেশি প্ল্যাটফর্ম থাকলে বেশি যাত্রী হয় — এর মানে এই নয় যে প্ল্যাটফর্ম বাড়ালেই যাত্রী বাড়বে। Causation prove করতে statistical test দরকার।

🎯 Interview-Level Exercise — Notebook ৩

প্রশ্ন ১: ML Feature Selection-এ correlation matrix কীভাবে সাহায্য করে? একটি উদাহরণসহ কোড লেখো।
# High correlation feature pairs খোঁজা (multicollinearity)
cor_matrix = df.select_dtypes(include=['float64', 'int64']).corr()

# |correlation| > 0.85 হলে সেই pair গুলো feature selection-এ সমস্যা করতে পারে
high_corr = (cor_matrix.abs() > 0.85) & (cor_matrix != 1.0)

# Heatmap
fig, ax = plt.subplots(figsize=(10, 8))
sns.heatmap(
    cor_matrix, 
    annot=True, 
    cmap='coolwarm',
    center=0,
    fmt='.2f',
    ax=ax
)
plt.title('Feature Correlation Matrix\n(High correlation = potential multicollinearity)')
plt.show()

# কোন feature গুলো highly correlated?
for col in cor_matrix.columns:
    for idx in cor_matrix.index:
        if high_corr.loc[idx, col] and idx < col:
            print(f"High correlation: {idx} ↔ {col}: {cor_matrix.loc[idx,col]:.3f}")

সাক্ষাৎকারে ব্যাখ্যা: Multicollinearity তখন হয় যখন দুটো feature highly correlated হয়। এতে model-এর coefficients unstable হয়। যেমন: 'total_rebounds' এবং 'off_rebounds' highly correlated হলে model confused হবে কোনটা বেশি গুরুত্বপূর্ণ।

🎻 4.3 — Violin Plot

✅ Simple, পরিচিত, outlier দেখায়
❌ Distribution-এর shape দেখায় না (bimodal লুকিয়ে থাকে)

Violin Plot

❌ Complex, কম পরিচিত audience-এর কাছে

প্রশ্ন ১ 🔴 — Feature Engineering: Time Features

feat DataFrame থেকে নিচের features তৈরি করো: is_rush_hour (৭-৯টা বা ১৭-১৯টা হলে 1), is_weekend (শনি/রবি হলে 1), season (month থেকে 0=winter,1=spring,2=summer,3=autumn)। তারপর heatmap দিয়ে rush_hour ও severity-র সম্পর্ক দেখাও।

feat['is_rush_hour'] = (
    ((feat['hour'] >= 7)  & (feat['hour'] <= 9)) |
    ((feat['hour'] >= 17) & (feat['hour'] <= 19))
).astype(int)

feat['is_weekend'] = (feat['weekday'] >= 5).astype(int)

def get_season(m):
    if m in [12,1,2]:  return 0  # winter
    elif m in [3,4,5]:  return 1  # spring
    elif m in [6,7,8]:  return 2  # summer
    else:                return 3  # autumn
feat['season'] = feat['month'].apply(get_season)

pivot = feat.groupby(['is_rush_hour','severity']).size().unstack(fill_value=0)
plt.figure(figsize=(6, 3))
sns.heatmap(pivot, annot=True, fmt='d', cmap='YlOrRd')
plt.title('Rush Hour vs Accident Severity')

⑧ K-Nearest Neighbors — প্রতিবেশী দেখে সিদ্ধান্ত

📊 Algorithm Selection Guide

Algorithm সমস্যার ধরন কখন ব্যবহার সুবিধা অসুবিধা
Linear Regression Regression Linear সম্পর্ক, ব্যাখ্যাযোগ্যতা দরকার দ্রুত, সহজ, interpretable Non-linear ধরে না
Logistic Regression Classification Binary/multi-class, baseline model Probability দেয়, explainable Complex pattern ধরে না
Decision Tree Class./Regression Business rules দরকার, explainability Visualizable, no scaling Overfitting হয়
Random Forest Class./Regression Default go-to, tabular data Robust, feature importance ধীর prediction
Gradient Boosting Class./Regression High accuracy দরকার, competition সর্বোচ্চ accuracy (tabular) Slow training, many hyperparams
K-Means Clustering (Unsup.) Customer segmentation, grouping Simple, scalable K আগে জানতে হয়
PCA Dim. Reduction High-dim data, visualization Noise কমায় Interpretability কমে
KNN Class./Regression Small dataset, anomaly detection Simple, no training phase Slow prediction, scaling sensitive
SVM Classification Medium dataset, clear margin দরকার High-dim space-এ effective Large data-তে ধীর
Neural Network যেকোনো Large data, image/text/audio যেকোনো pattern শেখে Data বেশি লাগে, black box

    'Random Forest': RandomForestClassifier(n_estimators=100, n_jobs=-1),

}

from sklearn.model_selection import GridSearchCV, learning_curve

param_grid = {
    'n_estimators':    [50, 100, 200],
    'max_depth':       [3, 5, 7, None],
    'min_samples_leaf':[1, 10, 20],
}
rf_gs = GridSearchCV(
    RandomForestClassifier(random_state=42, n_jobs=-1),
    param_grid, cv=5, scoring='f1_macro', n_jobs=-1, verbose=1
)
rf_gs.fit(X_train, y_train)
print("Best Params:", rf_gs.best_params_)
print(f"CV F1: {rf_gs.best_score_:.4f}")
print(f"Test:  {rf_gs.best_estimator_.score(X_test, y_test):.4f}")

sizes, tr_sc, va_sc = learning_curve(
    rf_gs.best_estimator_, X_train, y_train,
    cv=5, train_sizes=np.linspace(0.1,1.0,10),
    scoring='f1_macro', n_jobs=-1)

plt.figure(figsize=(8, 5))
plt.plot(sizes, tr_sc.mean(axis=1), 'o-', color='#58a6ff', label='Train')
plt.plot(sizes, va_sc.mean(axis=1), 'o-', color='#3fb950', label='Validation')
plt.fill_between(sizes, tr_sc.mean(axis=1)-tr_sc.std(axis=1),
                 tr_sc.mean(axis=1)+tr_sc.std(axis=1), alpha=0.1, color='#58a6ff')
plt.fill_between(sizes, va_sc.mean(axis=1)-va_sc.std(axis=1),
                 va_sc.mean(axis=1)+va_sc.std(axis=1), alpha=0.1, color='#3fb950')
plt.xlabel('Training Size'); plt.ylabel('F1 (macro)')
plt.title('Learning Curve — Best Random Forest')
plt.legend(); plt.tight_layout(); plt.show()
