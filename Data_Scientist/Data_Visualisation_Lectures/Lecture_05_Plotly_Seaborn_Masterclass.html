🤔 ডেটা ভিজুয়ালাইজেশন কেন দরকার?

ধরো, তোমার কাছে হাজারো সংখ্যা আছে — যেমন গত ৩০ বছরের ভিডিও গেমের বিক্রয় তথ্য। শুধু সংখ্যা দেখলে তুমি সহজে কিছু বুঝতে পারবে না। কিন্তু সেই তথ্য যদি একটা গ্রাফ বা চার্টে দেখানো হয়, তাহলে মুহূর্তেই তুমি বুঝতে পারবে কোন বছরে সবচেয়ে বেশি বিক্রি হয়েছে, কোথায় পড়েছে।

🔧 Plotly কী এবং কীভাবে ব্যবহার করব?

Plotly হলো Python-এর একটা লাইব্রেরি যেটা দিয়ে ইন্টারঅ্যাক্টিভ গ্রাফ তৈরি করা যায়। মানে তুমি গ্রাফে মাউস নিয়ে গেলে তথ্য দেখাবে, জুম করা যাবে, ক্লিক করে ফিল্টার করা যাবে — এটাই Plotly-র সৌন্দর্য।

🌐 Plotly.js এর উপরে তৈরি
Plotly আসলে JavaScript-এর Plotly.js লাইব্রেরির উপরে বানানো। তাই এর গ্রাফগুলো Jupyter Notebook-এ, HTML ফাইলে, বা Dash অ্যাপে দেখানো যায়।

Plotly ইন্সটল করা

Terminal / Command Prompt
# Step 1: Terminal খোলো # Step 2: Python version চেক করো python --version # Step 3: Plotly ইন্সটল করো pip install plotly

🔎 বোঝার কথা: pip হলো Python-এর Package Manager। যেমন Android-এ Play Store দিয়ে app ইন্সটল করো, Python-এ pip দিয়ে library ইন্সটল করো।

Plotly ইমপোর্ট করা — দুটো প্যাকেজ

Python — import.py
import plotly.express as px import plotly.graph_objects as go
🟢 দুটো প্যাকেজ কেন?
plotly.express (px) → সহজ, দ্রুত গ্রাফ বানানোর জন্য। কম কোড লিখতে হয়। Masterclass-এ বেশিরভাগ কাজ এটা দিয়েই হবে।

plotly.graph_objects (go) → বেশি কাস্টমাইজেশনের জন্য। বেশি কোড, বেশি নিয়ন্ত্রণ।

# ধাপ ১: Figure (ক্যানভাস) তৈরি করো fig = go.Figure() # ধাপ ২: গ্রাফের ধরন বলো (এখানে Scatter = ডট চার্ট) fig.add_traces(go.Scatter(x='Variable_1', y='Variable_2')) # ধাপ ৩: শিরোনাম ও অক্ষের নাম দাও fig.update_layout( title="আমার গ্রাফের শিরোনাম", xaxis_title="X অক্ষ", yaxis_title="Y অক্ষ" ) # ধাপ ৪: গ্রাফ দেখাও fig.show()

🧪 Plotly — সব প্রশ্ন ও উত্তর বাংলায়

প্রশ্ন (a) — CSV ফাইল পড়া

question_a.py
import pandas as pd df = pd.read_csv('Game_sales.csv') df.head()

🔎 লাইন বাই লাইন ব্যাখ্যা:

  • ▸ import pandas as pd → pandas লাইব্রেরি আনো, সংক্ষেপে pd নাম দাও
  • ▸ pd.read_csv(...) → CSV ফাইলটা পড়ে একটা টেবিলে রাখো, সেটার নাম df (DataFrame)
  • ▸ df.head() → টেবিলের প্রথম ৫টা সারি দেখাও
📌 DataFrame কী?
DataFrame মানে একটা এক্সেল শিটের মতো টেবিল। সারি (rows) আর কলাম (columns) আছে। Python-এ pandas লাইব্রেরি দিয়ে এই টেবিল নিয়ে কাজ করা যায়।

প্রশ্ন (b) — সময়ের সাথে বিক্রির ট্রেন্ড (Line Chart)

প্রশ্ন: ১৯৮৫ থেকে ২০১৬ পর্যন্ত বৈশ্বিক ভিডিও গেম বিক্রির ট্রেন্ড দেখাও।

📈 কোন গ্রাফ ব্যবহার করব?
সময়ভিত্তিক ডেটার জন্য (time-series) সবচেয়ে ভালো হলো Line Chart (রেখা গ্রাফ)। এতে বছরের সাথে সাথে পরিবর্তন স্পষ্ট বোঝা যায়।
বিভিন্ন গ্রাফের ধরন ও ব্যবহার
question_b.py
# ধাপ ১: বছর অনুযায়ী গ্রুপ করে মোট বিক্রি হিসাব করো df_global_sales = df.groupby(['Year_of_Release']).agg({'Global_Sales': 'sum'}) # ধাপ ২: খালি Figure তৈরি fig = go.Figure() # ধাপ ৩: Scatter (line) trace যোগ করো fig.add_traces(go.Scatter( x=df_global_sales.index, y=df_global_sales['Global_Sales'] )) # ধাপ ৪: শিরোনাম ও লেবেল দাও fig.update_layout( title="Evolution of Global Video Game Sales between 1985 and 2016", xaxis_title="Year", yaxis_title="Sales" ) fig.show()

🔎 groupby(['Year_of_Release']).agg({'Global_Sales': 'sum'})

এটা বলছে: বছর অনুযায়ী ডেটা ভাগ করো, তারপর প্রতি বছরের সব বিক্রি যোগ করো। যেমন ২০০৮ সালে মোট কত বিক্রি হয়েছে।

🔎 df_global_sales.index → এটা বছরগুলোর তালিকা (X অক্ষের জন্য)

📊 ফলাফল থেকে কী বোঝা গেল?
গ্রাফ দেখলে বোঝা যায় বিক্রি ক্রমশ বাড়ছিল, ২০০৮ সালে চূড়ায় পৌঁছায়। এরপর থেকে কমতে শুরু করে। কেন? হয়তো ডেটায় নতুন প্ল্যাটফর্মের তথ্য নেই, অথবা সত্যিই বিক্রি কমেছে।

প্রশ্ন (c) — স্কোরের বিতরণ (Box Plot)

প্রশ্ন: বছরের সাথে ভিডিও গেমের স্কোরের ট্রেন্ড দেখাও।

📦 Box Plot কী?
Box Plot দেখায় ডেটা কতটা ছড়িয়ে আছে। মাঝের রেখা হলো মিডিয়ান (মধ্যমান), বাক্সটা হলো মাঝের ৫০% ডেটা, আর ডগাগুলো চরম মান।

ভাবো ৫০ জনের পরীক্ষার নম্বর — সবচেয়ে কম, সবচেয়ে বেশি, গড় কত — এটাই Box Plot এক ছবিতে দেখায়।

fig = go.Figure() fig.add_traces(go.Box( x=df['Year_of_Release'], # X অক্ষে বছর y=df['Critic_Score'] # Y অক্ষে স্কোর )) fig.update_layout( title="Evolution of score between 1985 and 2016", xaxis_title="Year", yaxis_title="Score" ) fig.show()

প্রশ্ন (d) — একই গ্রাফে একাধিক লাইন (Multi-line Chart)

প্রশ্ন: একই গ্রাফে Global, NA, EU, JP বিক্রির ট্রেন্ড দেখাও।

question_d.py
# একসাথে ৪টা কলামের যোগফল বের করো df_global_sales = df.groupby(['Year_of_Release']).agg({ 'Global_Sales': 'sum', 'NA_Sales': 'sum', 'EU_Sales': 'sum', 'JP_Sales': 'sum' }) fig = go.Figure() # একটা list-এ চারটা Scatter trace দাও fig.add_traces([ go.Scatter(name="Global", x=df_global_sales.index, y=df_global_sales['Global_Sales']), go.Scatter(name="NA", x=df_global_sales.index, y=df_global_sales['NA_Sales']), go.Scatter(name="EU", x=df_global_sales.index, y=df_global_sales['EU_Sales']), go.Scatter(name="JP", x=df_global_sales.index, y=df_global_sales['JP_Sales']) ]) fig.update_layout( title="Evolution of Video Game Sales between 1985 and 2016", xaxis_title="Year", yaxis_title="Sales" ) fig.show()

🔎 এখানে add_traces([ ... ])-এ একটা list দেওয়া হয়েছে, যেখানে ৪টা Scatter trace আছে। প্রতিটার আলাদা name থাকায় legend-এ আলাদা করে দেখাবে।

🌍 মজার তথ্য
গ্রাফ থেকে দেখা যায় উত্তর আমেরিকা (NA) বিশ্বের সবচেয়ে বড় ভিডিও গেম বাজার — এমনকি ইউরোপের থেকেও বেশি, যদিও ইউরোপে জনসংখ্যা ২০ কোটি বেশি!
💡 Plotly Tip — Legend-এ ডাবল-ক্লিক!
Legend-এ কোনো category-তে ডাবল-ক্লিক করলে শুধু সেটাই দেখাবে, বাকিগুলো লুকিয়ে যাবে। এটা Plotly-র ইন্টারঅ্যাক্টিভিটির সুবিধা।

প্রশ্ন (e) — Publisher-ভিত্তিক গেম সংখ্যা ও বিক্রি (Grouped Bar)

প্রশ্ন: প্রতিটা Publisher কত গেম বানিয়েছে এবং কত বিক্রি করেছে — একসাথে দেখাও।

question_e.py
# Publisher অনুযায়ী মোট বিক্রি global_sales = df.groupby(['Publisher']).agg({'Global_Sales': 'sum'}) # Publisher অনুযায়ী গেমের সংখ্যা global_games = df.groupby(['Publisher']).agg({'Name': 'count'}) # দুটো টেবিল জোড়া লাগাও, বিক্রির ক্রমে সাজাও, শীর্ষ ১৫ নাও global_sales = global_sales.join(global_games).sort_values( by='Global_Sales', ascending=False).head(15) fig = go.Figure() fig.add_traces([ go.Bar(name='Sales', x=global_sales.index, y=global_sales['Global_Sales']), go.Bar(name='Number of games', x=global_sales.index, y=global_sales['Name'], marker_color='orange') # রং নির্দিষ্ট করো ]) fig.update_layout(title="Number of games and global sales per Publisher") fig.show()
⚠️ সতর্কতা — স্কেলের পার্থক্য
এই গ্রাফে দুটো আলাদা জিনিস একসাথে দেখানো হয়েছে — বিক্রি (মিলিয়নে) এবং গেমের সংখ্যা (unit-এ)। এই দুটোর একক আলাদা, তাই সরাসরি তুলনা করা ঠিক নয়।

প্রশ্ন (f) — Scatter Plot: User Score vs Critic Score

প্রশ্ন: User Score এবং Critic Score-এর মধ্যে কোনো সম্পর্ক আছে? Scatter plot দিয়ে দেখাও।

📐 Correlation (সহসম্বন্ধ) কী?
দুটো variable-এর মধ্যে সম্পর্ককে Correlation বলে।
• +1 = পুরোপুরি ধনাত্মক সম্পর্ক (একটা বাড়লে অন্যটাও বাড়ে)
• -1 = পুরোপুরি ঋণাত্মক সম্পর্ক (একটা বাড়লে অন্যটা কমে)
• 0 = কোনো সম্পর্ক নেই

মনে রেখো: Correlation মানেই Causation নয়। দুটো জিনিস একসাথে পরিবর্তন হলেই বলা যায় না যে একটা অন্যটার কারণ।
Correlation-এর তিনটি ধরন
question_f.py
# Plotly Express দিয়ে Scatter Plot — অনেক কম কোড! fig = px.scatter( df, x="Critic_Score", # X অক্ষে সমালোচকের স্কোর y="User_Score", # Y অক্ষে ব্যবহারকারীর স্কোর range_y=[0, 10], # Y অক্ষ ০ থেকে ১০ range_x=[0, 100], # X অক্ষ ০ থেকে ১০০ hover_data=['Name', 'EU_Sales'] # hover করলে এই তথ্য দেখাবে ) # একটা reference line যোগ করো (যদি দুই স্কোর সমান হতো) fig.add_shape( type="line", x0=0, x1=100, y0=0, y1=10, line=dict(color="Red", width=2, dash="dash") ) fig.show()

🔎 hover_data মানে: মাউস point-এর উপর নিয়ে গেলে Name এবং EU_Sales দেখাবে।

🔎 add_shape(type="line") মানে: একটা রেখা আঁকো। এখানে লাল ড্যাশ রেখাটা দেখায় যদি User আর Critic স্কোর একই হতো তাহলে কোথায় থাকত।

৯. Distribution (বিতরণ) কী? — সহজ ব্যাখ্যা

Notebook-এ Distribution নিয়ে বিস্তারিত বলা হয়েছে। এটা বোঝাটা খুব জরুরি।

📊 Distribution কী — একটা উদাহরণ
ধরো তোমার ক্লাসে ৫০ জন ছাত্রের পরীক্ষার নম্বর আছে। এখন প্রশ্ন — বেশিরভাগ কত পেয়েছে? কতজন ৮০-৯০ এর মধ্যে, কতজন ৫০-৬০ এর মধ্যে?

এই বিস্তার বা ছড়িয়ে পড়াটাই Distribution। Histogram দেখায় কোন range-এ কতজন পড়ে।

Distribution-এর বৈশিষ্ট্য:
• Central tendency — গড় বা মধ্যমান কোথায়?
• Dispersion — ডেটা কতটা ছড়িয়ে আছে?
• Shape — বামে বেশি, ডানে বেশি, নাকি মাঝে বেশি?

🧠 চূড়ান্ত পরীক্ষা

তুমি জাপানের রেস্তোরাঁর রেটিং ডেটা বিশ্লেষণ করছো। তোমাকে দেখাতে হবে: প্রতি শহরে গড় রেটিং কত এবং রেটিংগুলো কতটা ছড়িয়ে আছে। কোন গ্রাফ ব্যবহার করবে?

উত্তর দেখো

Box Plot সবচেয়ে উপযুক্ত! কারণ এটা একসাথে দেখায়: median (গড়ের কাছাকাছি), IQR (ছড়িয়ে পড়া), এবং outlier (অস্বাভাবিক মান)। X অক্ষে শহর, Y অক্ষে রেটিং দিলেই হবে।

Plotly: px.box(df, x="city", y="rating")
Seaborn: sns.boxplot(x="city", y="rating", data=df)

🧠 চূড়ান্ত পরীক্ষা ২

df.groupby('Publisher').agg({'Name': 'count'}) — এটা কী করে?

উত্তর দেখো

প্রতিটা Publisher কতটা গেম বানিয়েছে সেটা গণনা করে। groupby('Publisher') মানে Publisher অনুযায়ী ভাগ করো, আর agg({'Name': 'count'}) মানে Name কলামে কতটা সারি আছে গণনা করো — সেটাই গেমের সংখ্যা।
