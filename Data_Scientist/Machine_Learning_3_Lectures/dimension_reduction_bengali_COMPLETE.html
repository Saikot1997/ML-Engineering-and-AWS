মডিউল ০ — প্রসঙ্গ: মুখের ছবি চেনার সিস্টেম 🎭

ধরো, ফ্রান্সের সরকার তোমাকে বলল — "আমাদের একটা সিস্টেম বানাও যেটা ভিডিও ক্যামেরার ছবি দেখে বিপজ্জনক মানুষদের চিনতে পারবে।"

তোমার কাছে আছে:

  • প্রতিটি ছবি ৬২ × ৪৭ = ২৯১৪টি পিক্সেল (grayscale)
  • প্রতিটি পিক্সেল = একটি feature
  • মোট ২৯১৪টি feature প্রতিটি ছবির জন্য
এই পুরো মডিউলে আমরা শিখব কীভাবে ২৯১৪টি feature থেকে মাত্র কয়েকটি গুরুত্বপূর্ণ feature বেছে নেওয়া যায়, কিন্তু তারপরেও accuracy কমে না। এটাই হল Dimensionality Reduction।

🎯 লক্ষ্য কী ছিল?

  • ১কমপক্ষে ৬০% accuracy — মানুষ চেনার ক্ষেত্রে
  • ২দ্রুত কাজ করবে — real-time video surveillance-এ ব্যবহার হবে
  • ৩শেষে পাওয়া গেল: ২৯১৪ → ৮২ features, accuracy ৭০%+

🏠 সহজ উদাহরণ দিয়ে বোঝা যাক

ধরো তুমি একটা বাড়ি বিক্রি করতে চাও। বাড়ির তথ্য আছে:

  • দাম (টাকায়)
  • দাম (ডলারে)
  • ঘরের সংখ্যা
  • বাথরুমের সংখ্যা
  • এলাকা (বর্গফুটে)
  • এলাকা (বর্গমিটারে)

লক্ষ্য করো — "দাম টাকায়" এবং "দাম ডলারে" আসলে একই তথ্য, শুধু unit আলাদা। একইভাবে বর্গফুট আর বর্গমিটার। সুতরাং এদের একটি রাখলেই চলে।

Dimensionality Reduction হল এমন একটি প্রক্রিয়া যেখানে আমরা ডেটার features কমাই, কিন্তু গুরুত্বপূর্ণ তথ্য হারাই না। এটি correlated বা অকার্যকর features বাদ দেয়।

📊 "Curse of Dimensionality" — মাত্রার অভিশাপ

এটা ML-র একটা বিখ্যাত সমস্যা। ধরো তোমার কাছে ১০০টি উদাহরণ আছে। যদি features ১০০০টি থাকে, তাহলে প্রতিটি উদাহরণ থেকে থেকে অনেক দূরে। Model শিখতে পারে না।

মডিউল ১ — Feature Selection: তিনটি পদ্ধতি 🔬

Boston শহরের বাড়ির দাম predict করার dataset নিয়ে কাজ করব। Dataset-এ ১৩টি আসল feature আছে, ১০টি random number, এবং শেষ ৫টি constant।

Feature Selection = কোন features রাখব, কোনটা ফেলব — এটা বেছে নেওয়া। তিনটি ধরন আছে: Filter, Wrapper, Embedded।

২.১ Filter Methods — ছাঁকনি পদ্ধতি 🧹

এই পদ্ধতিতে আমরা ML model ছাড়াই features বিশ্লেষণ করি। শুধু statistics দেখি।

পদ্ধতি ক: VarianceThreshold — শূন্য variance বাদ দাও

ধারণা: যে feature সব observation-এর জন্য একই value দেয়, সে feature কোনো তথ্য বহন করে না। যেমন সব বাড়ির জন্য একটা column সবসময় "1" — এটা বাদ দাও।

from sklearn.feature_selection import VarianceThreshold
import pandas as pd
import numpy as np

# Dataset লোড করো
df = pd.read_csv("real_estate_boston.csv", sep=";")

# Target আলাদা করো
X = df.drop('medv', axis=1).drop('ID', axis=1)
y = df['medv']

# VarianceThreshold তৈরি করো
# threshold=1e-6 মানে: variance যদি ১e-6 এর কম হয়, বাদ দাও
sel = VarianceThreshold(threshold=1e-6)
sel.fit(X)

# কোন features টিকল?
mask = sel.get_support()  # True/False array
print("টিকে থাকা features:", X.columns[mask].tolist())
print("বাদ গেল:", X.columns[~mask].tolist())

# Transform করো
X_filtered = sel.transform(X)
print("নতুন shape:", X_filtered.shape)

পদ্ধতি খ: SelectKBest — সেরা K টা বেছে নাও

ধারণা: প্রতিটি feature এবং target variable-এর মধ্যে statistical relationship পরিমাপ করো। যাদের সম্পর্ক সবচেয়ে শক্তিশালী, তারাই থাকবে।

f_regression ব্যবহার করো regression problem-এ (continuous target)। mutual_info_regression non-linear সম্পর্কও ধরতে পারে। 
from sklearn.feature_selection import SelectKBest, f_regression, mutual_info_regression
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# পদ্ধতি ১: F-test (linear সম্পর্ক পরিমাপ করে)
sel_f = SelectKBest(score_func=f_regression, k=13)
sel_f.fit(X_train, y_train)
print("F-test দিয়ে বেছে নেওয়া features:", X.columns[sel_f.get_support()].tolist())

# পদ্ধতি ২: Mutual Information (non-linear সম্পর্কও ধরে)
sel_mi = SelectKBest(score_func=mutual_info_regression, k=13)
sel_mi.fit(X_train, y_train)
print("MI দিয়ে বেছে নেওয়া features:", X.columns[sel_mi.get_support()].tolist())

# Transform training এবং test set
X_train_sel = sel_f.transform(X_train)
X_test_sel  = sel_f.transform(X_test)
Classification problem-এ regression test ব্যবহার করা যাবে না! classification-এর জন্য f_classif বা chi2 ব্যবহার করো।

২.২ Wrapper Methods — আবরণী পদ্ধতি 🎁

ধারণা: একটা ML model-কে "judge" হিসেবে ব্যবহার করা হয়। বিভিন্ন feature combination চেষ্টা করে দেখা হয় কোনটা সবচেয়ে ভালো score দেয়।

from sklearn.feature_selection import RFE, RFECV
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import KFold

# প্রথমে StandardScaler দিয়ে normalize করো
# (LinearRegression data magnitude-sensitive, তাই জরুরি)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled  = scaler.transform(X_test)

# RFE — নিজে number of features বলো
lm  = LinearRegression()
rfe = RFE(estimator=lm, step=1, n_features_to_select=13)
rfe.fit(X_train_scaled, y_train)
print("RFE ranking:", rfe.ranking_)  # 1 = selected

# RFECV — cross-validation দিয়ে automatically সেরা সংখ্যা বেছে নেয়
crossval = KFold(n_splits=5, random_state=2, shuffle=True)
rfecv = RFECV(estimator=lm, cv=crossval, step=1)
rfecv.fit(X_train_scaled, y_train)
print("Optimal features:", rfecv.n_features_)

২.৩ Embedded Methods — অন্তর্নিহিত পদ্ধতি 🧬

Filter এবং Wrapper-এর মাঝামাঝি পদ্ধতি। Training-এর সময়েই feature selection হয়ে যায়। L1 regularization (LASSO) ব্যবহার করে।

LASSO (Least Absolute Shrinkage and Selection Operator): এটি এমন একটি Linear Regression যেখানে model training-এর সময় কম গুরুত্বপূর্ণ feature-এর coefficient স্বয়ংক্রিয়ভাবে শূন্য (0) হয়ে যায়।
Loss = MSE + λ × ||coefficients||₁

এখানে λ (lambda) বড় হলে বেশি coefficient শূন্য হয় → কম features বাকি থাকে।

from sklearn.linear_model import Lasso
from sklearn.feature_selection import SelectFromModel
from sklearn.model_selection import GridSearchCV

# LASSO দিয়ে feature selection
lasso = Lasso(alpha=1)  # alpha = λ (regularization strength)
sel   = SelectFromModel(estimator=lasso, threshold=1e-10)
sel.fit(X_train_scaled, y_train)
print("LASSO-selected features:", X.columns[sel.get_support()].tolist())

# সেরা alpha খোঁজো GridSearch দিয়ে
alpha_grid = {'alpha': [1/i for i in range(1, 10)]}
grid = GridSearchCV(estimator=Lasso(), param_grid=alpha_grid,
                    cv=crossval, scoring='neg_mean_squared_error')
grid.fit(X_train_scaled, y_train)
print("সেরা alpha:", grid.best_params_)

# সেরা model দিয়ে feature selection
sel_best = SelectFromModel(estimator=grid.best_estimator_,
                            threshold=1e-10, prefit=True)
X_train_emb = sel_best.transform(X_train_scaled)
X_test_emb  = sel_best.transform(X_test_scaled)

🎯 ইন্টারভিউ-স্তরের Exercise — Feature Selection

প্রশ্ন ১ (কোডিং): তোমার কাছে ৫০০ features সহ একটি customer churn prediction dataset আছে। আগে VarianceThreshold দিয়ে constant features বাদ দাও, তারপর RFECV দিয়ে optimal features খোঁজো এবং final model accuracy রিপোর্ট করো।
উত্তর দেখো

এই ধরনের pipeline ML engineering-এ খুব common:

from sklearn.pipeline import Pipeline
from sklearn.feature_selection import VarianceThreshold, RFECV
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler

pipe = Pipeline([
    ('var', VarianceThreshold(threshold=1e-6)),
    ('scale', StandardScaler()),
    ('rfe', RFECV(LogisticRegression(max_iter=200),
                   cv=5, scoring='roc_auc')),
    ('clf', LogisticRegression(max_iter=200))
])
pipe.fit(X_train, y_train)
print(pipe.score(X_test, y_test))
প্রশ্ন ২ (Theory): LASSO এবং Ridge Regression-এর মধ্যে feature selection-এর দৃষ্টিকোণ থেকে পার্থক্য কী?
উত্তর দেখো

LASSO (L1): কিছু coefficients সম্পূর্ণ শূন্য করে → feature selection করে।
Ridge (L2): সব coefficients ছোট করে কিন্তু কখনো শূন্য করে না → feature selection করে না।
তাই Dimensionality Reduction-এর জন্য LASSO preferred।

প্রশ্ন ৩ (Coding Challenge): তোমার ML pipeline production-এ আছে। নতুন data আসলে feature selection step কীভাবে handle করবে?
উত্তর দেখো

Training set-এ fit() করো, তারপর test/production data-তে শুধু transform() করো। fit_transform() কখনো test data-তে করবে না — এটা data leakage তৈরি করে। sklearn Pipeline ব্যবহার করলে এটা automatically সঠিকভাবে হয়।

মডিউল ২ — PCA: প্রিন্সিপাল কম্পোনেন্ট অ্যানালাইসিস 📐

🌟 PCA কী — একদম সহজ ভাষায়

ধরো তোমার কাছে একটা ছায়ার মতো সমস্যা আছে। সূর্য থেকে আলো পড়লে ৩D object-এর ২D ছায়া পড়ে। যদি তুমি সঠিক কোণে ছায়া ফেলাও, তাহলে সেই ছায়া দেখেই object বুঝতে পারবে।

PCA ঠিক এটাই করে — সঠিক দিক খুঁজে বের করে যেখানে data project করলে সবচেয়ে বেশি information বজায় থাকে।

🔑 PCA-র মূল বৈশিষ্ট্য

  • ১Unsupervised — target variable দরকার নেই। PCA data structure নিজেই বোঝে।
  • ২Principal Components (PC) — নতুন তৈরি অক্ষগুলো। PC1 সবচেয়ে বেশি variance ধরে, PC2 দ্বিতীয় সর্বোচ্চ, ইত্যাদি।
  • ৩Orthogonal (লম্ব) — সব PC একে অপরের সাথে perpendicular। তাই এদের মধ্যে কোনো correlation নেই।
  • ৪Linear Transformation — পুরোনো features-এর linear combination দিয়ে নতুন features তৈরি হয়।

📊 Explained Variance Ratio — কতটুকু তথ্য রাখলাম?

Explained Variance Ratio বলে, একটা PC কতভাগ তথ্য "ধরে রেখেছে"। যদি PC1-এর EVR = 0.84, মানে মোট variance-এর ৮৪% PC1-এ আছে।

Cumulative Explained Variance = PC1_var + PC2_var + ... + PCk_var
লক্ষ্য: ≥ 0.90 (৯০% variance রাখা)

def biplot(pca, data_2d, feature_names, targets=None):
    fig, ax = plt.subplots(figsize=(10, 8))
    # Data points
    scatter = ax.scatter(data_2d[:,0], data_2d[:,1],
                         c=targets, cmap='tab10', alpha=0.4, s=10)
    # Feature arrows (scaled)
    scale = 3 * np.sqrt(pca.explained_variance_)
    for i, name in enumerate(feature_names):
        ax.arrow(0, 0,
                 pca.components_[0,i]*scale[0],
                 pca.components_[1,i]*scale[1],
                 color='red', head_width=0.1)
        ax.text(pca.components_[0,i]*scale[0]*1.1,
                pca.components_[1,i]*scale[1]*1.1,
                name, color='red', fontsize=9)
    ax.set_xlabel('PC1'); ax.set_ylabel('PC2')
    ax.set_title('PCA Biplot')
    plt.show()

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np

# ─── Full PCA Pipeline ───
class PCATransformer:
    def __init__(self, variance_threshold=0.90):
        self.scaler = StandardScaler()
        self.pca    = PCA(n_components=variance_threshold)

    def fit_transform(self, X_train, X_test):
        X_tr_s = self.scaler.fit_transform(X_train)
        X_te_s = self.scaler.transform(X_test)
        X_tr_p = self.pca.fit_transform(X_tr_s)
        X_te_p = self.pca.transform(X_te_s)
        print(f"Reduced: {X_train.shape[1]} → {self.pca.n_components_} features")
        print(f"Variance retained: {self.pca.explained_variance_ratio_.sum():.2%}")
        return X_tr_p, X_te_p

    def plot_variance(self):
        cumvar = np.cumsum(self.pca.explained_variance_ratio_)
        plt.plot(cumvar)
        plt.axhline(0.9, c='r', ls='--')
        plt.xlabel('Components'); plt.ylabel('Cumulative Variance')
        plt.title('PCA Cumulative Explained Variance')
        plt.show()

# Use:
transformer = PCATransformer(variance_threshold=0.90)
X_train_pca, X_test_pca = transformer.fit_transform(X_train, X_test)
transformer.plot_variance()

📌 Theory প্রশ্ন

Q1: PCA apply করার আগে কেন standardization জরুরি?
উত্তর

PCA variance maximize করার চেষ্টা করে। যদি একটা feature-এর range 0-10,000 এবং আরেকটার 0-1 হয়, তাহলে PCA প্রথম feature-কে dominant মনে করবে — শুধু বড় scale-এর কারণে। StandardScaler সব features-কে mean=0, std=1 করে দেয়, তাই PCA সঠিকভাবে true variance বুঝতে পারে।

# সঠিক পদ্ধতি:
pipe = Pipeline([('scale', StandardScaler()), ('pca', PCA(n_components=0.9))])
X_tr = pipe.fit_transform(X_train)
X_te = pipe.transform(X_test)
Q2: PCA এবং SVD (Singular Value Decomposition) কীভাবে সম্পর্কিত?
উত্তর

PCA আসলে covariance matrix-এর eigendecomposition। sklearn-এর PCA internally SVD ব্যবহার করে কারণ এটা numerically stable। SVD: X = UΣVᵀ। Principal components হল V-এর columns, এবং eigenvalues হল Σ-এর diagonal values squared divided by (n-1)।

Q3: কতটা PCA component রাখবে — কীভাবে decide করবে?
উত্তর

তিনটি উপায়: (১) Scree plot — explained variance কোথায় "elbow" করে সেখানে কাটো। (২) Cumulative variance threshold — সাধারণত 90-95% variance রাখো: PCA(n_components=0.90)। (৩) Downstream task performance — cross-validation করে দেখো কতটা component-এ model best perform করে।

Q4: "Data Leakage" কী এবং PCA-তে কীভাবে এড়াবে?
উত্তর

Data leakage মানে test data-র information training-এ ঢুকে যাওয়া। PCA-তে leakage হয় যদি তুমি সব data (train+test) দিয়ে fit() করো। সঠিক পদ্ধতি: শুধু training data-তে fit(), তারপর test data-তে শুধু transform()। sklearn Pipeline এটা automatically enforce করে।

Q5: PCA কি classification accuracy সবসময় উন্নত করে?
উত্তর

না, সবসময় না। PCA variance maximize করে কিন্তু class-discriminating information সর্বোচ্চ করে না। কখনো কখনো discriminative information কম-variance component-এ থাকতে পারে। তাই সবচেয়ে ভালো হলো downstream task-এ evaluate করে দেখা। তবে: (১) overfitting কমায়, (২) training দ্রুত করে, (৩) noise কমায় — এগুলো সাধারণত accuracy উন্নত করে।

Q6: LASSO এবং Ridge Regression-এ feature selection-এর পার্থক্য কী?
উত্তর

LASSO (L1): Loss + λ||w||₁ → অনেক coefficient সম্পূর্ণ শূন্য হয় → sparse solution → feature selection করে।
Ridge (L2): Loss + λ||w||₂² → সব coefficient ছোট হয় কিন্তু কখনো শূন্য হয় না → feature selection করে না।
Elastic Net: উভয়ের combination — both sparsity এবং group selection।

Q7: LDA-র সর্বোচ্চ output features কেন (c-1)?
উত্তর

LDA between-class scatter matrix (S_B) কে maximize করে। S_B হল class mean vectors দিয়ে তৈরি, এবং c টা class-এর মধ্যে c-1 টা linearly independent direction আছে। গণিতগতভাবে: rank(S_B) ≤ c-1। তাই LDA-র output space সর্বোচ্চ (c-1) dimensional।

🌐 Isomap কী — Manifold Learning

PCA data-কে একটা সমতল (flat) plane-এ project করে। কিন্তু real-world data অনেক সময় বাঁকানো (curved) surface-এ থাকে। Isomap সেই বাঁকানো surface-কে সমান করে। এটাকে বলে Manifold Learning।

Geodesic Distance: সরলরেখায় দূরত্ব নয়, বক্ররেখা বরাবর দূরত্ব। পিঁপড়া যদি একটা আপেলের উপর দিয়ে হাঁটে, তাহলে তার পথ = geodesic। Isomap এই geodesic দূরত্ব ব্যবহার করে।

🧠 মুখ চেনার Dataset-এ Isomap কী বলে?

Face dataset-এ Isomap apply করলে দেখা গেল:

  • X-axis (Component 1): মুখের brightness — ডানদিকে উজ্জ্বল, বামে অন্ধকার মুখ
  • Y-axis (Component 2): মুখের দিক — উপরে বামদিকে তাকানো, নিচে ডানদিকে তাকানো

এর মানে হল — Isomap এই দুটো "variance factor" নিজেই আবিষ্কার করেছে, আমরা বলিনি!

PCA-র গণিত — ভয় নেই, ধাপে ধাপে বুঝি 🧮

এই section-এ গণিত আছে, কিন্তু প্রতিটি ধাপ বাংলায় ব্যাখ্যা করা হয়েছে। ML Engineer হিসেবে এটা বুঝলে interview-এ অনেক এগিয়ে থাকবে।

🔢 PCA কীভাবে কাজ করে — ৫ ধাপে

  • ১ Standardize করো: সব feature-এর mean = 0, std = 1 করো।
    X_scaled = (X - mean) / std
    কেন? বড় scale-এর feature যাতে PCA-কে mislead না করে।
  • ২ Covariance Matrix তৈরি করো:
    C = (1/n) × Xᵀ × X (n = sample সংখ্যা)
    কেন? এটা বলে কোন features একসাথে বাড়ে/কমে (correlated)।
  • ৩ Eigendecomposition: Covariance matrix ভাঙো।
    C × v = λ × v
    এখানে v = eigenvector (direction), λ = eigenvalue (সেই direction-এ কতটা variance)।
    কেন? eigenvector-গুলোই principal components।
  • ৪ Sort by eigenvalue: বড় eigenvalue = বেশি variance = বেশি গুরুত্বপূর্ণ।
    শীর্ষ k টা eigenvector রাখো।
  • ৫ Project করো:
    X_pca = X_scaled × W
    এখানে W = শীর্ষ k eigenvectors-এর matrix (shape: n_features × k)।

💻 PCA হাতে-কলমে (sklearn ছাড়া)

import numpy as np

def pca_from_scratch(X, n_components):
    """PCA manually implement করা — numpy দিয়ে"""

    # Step 1: Standardize
    mean   = X.mean(axis=0)
    std    = X.std(axis=0)
    std[std == 0] = 1           # zero std হলে division by zero এড়াও
    X_sc   = (X - mean) / std

    # Step 2: Covariance matrix
    C = np.cov(X_sc.T)             # shape: (n_features, n_features)

    # Step 3: Eigendecomposition
    eigenvalues, eigenvectors = np.linalg.eigh(C)

    # Step 4: Sort (descending order — সবচেয়ে বড় eigenvalue আগে)
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues  = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    # Step 5: Top k eigenvectors নাও
    W = eigenvectors[:, :n_components]  # (n_features, k)

    # Step 6: Project
    X_pca = X_sc @ W                    # (n_samples, k)

    # Explained variance ratio
    evr = eigenvalues[:n_components] / eigenvalues.sum()

    return X_pca, W, evr

# ════════════════════════════════════════════════════════════
# Production-Grade ML Pipeline with Dimensionality Reduction
# ════════════════════════════════════════════════════════════
import numpy as np
import pandas as pd
import joblib
import logging
from pathlib import Path

from sklearn.pipeline import Pipeline
from sklearn.feature_selection import VarianceThreshold
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.metrics import classification_report, roc_auc_score

logging.basicConfig(level=logging.INFO,
                    format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger('DimRedPipeline')


class DimensionalityReductionPipeline:
    """
    Production-ready Dimensionality Reduction + Classification Pipeline
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Features:
      - Variance threshold filtering
      - StandardScaler normalization
      - PCA dimension reduction
      - RandomForest classification
      - GridSearchCV hyperparameter tuning
      - Model persistence (save/load)
      - Prediction with confidence scores
    """

    def __init__(self, variance_threshold=1e-6, pca_variance=0.90,
                 model_dir="models"):
        self.variance_threshold = variance_threshold
        self.pca_variance       = pca_variance
        self.model_dir          = Path(model_dir)
        self.model_dir.mkdir(parents=True, exist_ok=True)
        self.pipeline           = None
        self.is_fitted          = False

    def build_pipeline(self):
        """Pipeline তৈরি করো"""
        self.pipeline = Pipeline([
            ('var_filter', VarianceThreshold(threshold=self.variance_threshold)),
            ('scaler',     StandardScaler()),
            ('pca',        PCA(n_components=self.pca_variance, random_state=42)),
            ('clf',        RandomForestClassifier(n_jobs=-1, random_state=42))
        ])
        logger.info("Pipeline built successfully")
        return self

    def tune_hyperparameters(self, X_train, y_train):
        """GridSearchCV দিয়ে best hyperparameters খোঁজো"""
        param_grid = {
            'pca__n_components':  [0.85, 0.90, 0.95],
            'clf__n_estimators':  [100, 200, 300],
            'clf__max_depth':     [None, 10, 20],
            'clf__min_samples_leaf': [1, 2, 4]
        }

        cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
        gs = GridSearchCV(
            self.pipeline, param_grid,
            cv=cv, scoring='accuracy',
            n_jobs=-1, verbose=1, refit=True
        )
        gs.fit(X_train, y_train)

        self.pipeline  = gs.best_estimator_
        self.is_fitted = True

        logger.info(f"Best params: {gs.best_params_}")
        logger.info(f"Best CV score: {gs.best_score_:.4f}")

        n_pca = self.pipeline.named_steps['pca'].n_components_
        n_orig = X_train.shape[1]
        logger.info(f"Dimension reduction: {n_orig} → {n_pca} ({n_orig/n_pca:.1f}x)")

        return gs.cv_results_

    def fit(self, X_train, y_train):
        """Simple fit (GridSearch ছাড়া)"""
        self.pipeline.fit(X_train, y_train)
        self.is_fitted = True
        return self

    def evaluate(self, X_test, y_test):
        """Comprehensive evaluation"""
        if not self.is_fitted:
            raise RuntimeError("Model not fitted yet. Call fit() first.")

        y_pred  = self.pipeline.predict(X_test)
        y_proba = self.pipeline.predict_proba(X_test)
        accuracy = self.pipeline.score(X_test, y_test)

        results = {
            'accuracy':  accuracy,
            'report':    classification_report(y_test, y_pred, output_dict=True),
            'n_components': self.pipeline.named_steps['pca'].n_components_,
            'original_features': X_test.shape[1]
        }
        logger.info(f"Test Accuracy: {accuracy:.4f}")
        return results

    def predict(self, X):
        """Prediction with confidence"""
        predictions = self.pipeline.predict(X)
        probabilities = self.pipeline.predict_proba(X)
        confidence = probabilities.max(axis=1)
        return pd.DataFrame({
            'prediction': predictions,
            'confidence': confidence,
            'high_confidence': confidence >= 0.8
        })

    def save(self, filename="dim_red_pipeline.pkl"):
        """Model সংরক্ষণ"""
        path = self.model_dir / filename
        joblib.dump(self.pipeline, path)
        logger.info(f"Model saved to {path}")
        return str(path)

    def load(self, filename="dim_red_pipeline.pkl"):
        """সংরক্ষিত model লোড"""
        path = self.model_dir / filename
        self.pipeline  = joblib.load(path)
        self.is_fitted = True
        logger.info(f"Model loaded from {path}")
        return self

# PCA দিয়ে drift detect করা যায়!

from scipy.stats import ks_2samp
import warnings

def detect_pca_drift(X_reference, X_new, pca, threshold=0.05):
    """
    PCA component distribution-এ drift আছে কিনা দেখো।
    Kolmogorov-Smirnov test ব্যবহার করে।
    """
    ref_pca = pca.transform(X_reference)
    new_pca = pca.transform(X_new)

    drift_detected = False
    results = []

    for i in range(ref_pca.shape[1]):
        stat, p_value = ks_2samp(ref_pca[:, i], new_pca[:, i])
        drifted = p_value < threshold
        results.append({'component': i, 'statistic': stat,
                         'p_value': p_value, 'drift': drifted})
        if drifted:
            drift_detected = True

    drift_df = pd.DataFrame(results)
    drifted_pcs = drift_df[drift_df['drift']]

    if drift_detected:
        warnings.warn(
            f"⚠️ DRIFT DETECTED in {len(drifted_pcs)} PCA components!"
            f" Consider retraining the model."
        )
    return drift_df, drift_detected

এটা বলে — একটা principal component মোট data variance-এর কতভাগ "ধরে রেখেছে"। যদি PC1-এর EVR = 0.84, মানে আসল data-র ৮৪% information PC1-এ encode আছে। Cumulative EVR = সব রাখা PC-র EVR যোগ। সাধারণত ≥0.90 (90%) target করা হয়।

🟡 Intermediate Level

I1: তুমি PCA apply করলে এবং test score training score-এর চেয়ে অনেক বেশি হল — কী সমস্যা হতে পারে?
উত্তর

সম্ভবত Data Leakage। যদি PCA সব data (train+test) দিয়ে fit করা হয়, তাহলে test data-র statistical properties training-এ ঢুকে যায়। এটা artificially test score বাড়িয়ে দেয়। সমাধান: PCA শুধু training data-তে fit করো, test-এ শুধু transform।

I2: Multicollinearity আছে এমন dataset-এ PCA কেন ভালো কাজ করে?
উত্তর

Multicollinearity মানে কিছু features highly correlated — তারা duplicate information বহন করে। PCA correlated features-কে uncorrelated principal components-এ transform করে। Covariance matrix decomposition করলে correlated features-গুলো একই PC-তে উচ্চ loading দেখায়, তাই effectively একটা PC-তে তাদের information consolidate হয়। এটা linear regression, neural networks-এর training stability উন্নত করে।

I3: কোন পরিস্থিতিতে PCA use না করা ভালো?
উত্তর

① Interpretability জরুরি হলে — financial/medical domain-এ "কেন এই prediction?" জানাতে হয়, PCA-র নতুন features-এর মানে বোঝা কঠিন। ② Non-linear relationships — PCA শুধু linear structure ধরে। ③ Sparse data — text data, one-hot encoding-এ Truncated SVD ব্যবহার করো। ④ Very few features ইতিমধ্যে থাকলে — overhead worth না।

I4 (Coding): একটা custom transformer বানাও যেটা sklearn Pipeline-এ ব্যবহার করা যাবে এবং PCA + Feature Selection combine করবে।
সম্পূর্ণ সমাধান 
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.decomposition import PCA
from sklearn.feature_selection import VarianceThreshold
from sklearn.preprocessing import StandardScaler
import numpy as np

class SmartDimReducer(BaseEstimator, TransformerMixin):
    """
    Combined Feature Selection + PCA Transformer
    sklearn Pipeline-compatible
    """
    def __init__(self, variance_thresh=1e-6, pca_components=0.9):
        self.variance_thresh = variance_thresh
        self.pca_components  = pca_components

    def fit(self, X, y=None):
        self.var_sel_ = VarianceThreshold(threshold=self.variance_thresh)
        self.scaler_  = StandardScaler()
        self.pca_     = PCA(n_components=self.pca_components)

        X_var    = self.var_sel_.fit_transform(X)
        X_scaled = self.scaler_.fit_transform(X_var)
        self.pca_.fit(X_scaled)
        return self

    def transform(self, X):
        X_var    = self.var_sel_.transform(X)
        X_scaled = self.scaler_.transform(X_var)
        return self.pca_.transform(X_scaled)

    def get_reduction_info(self):
        return {
            'n_components': self.pca_.n_components_,
            'total_variance': self.pca_.explained_variance_ratio_.sum(),
            'after_var_filter': self.var_sel_.get_support().sum()
        }

# Use in Pipeline:
from sklearn.pipeline import Pipeline
from sklearn.svm import SVC

pipe = Pipeline([
    ('dim_red', SmartDimReducer(pca_components=0.90)),
    ('clf',     SVC(kernel='linear'))
])
pipe.fit(X_train, y_train)
print(pipe['dim_red'].get_reduction_info())
print(f"Score: {pipe.score(X_test, y_test):.4f}")

from sklearn.preprocessing import StandardScaler, LabelEncoder
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression

🌀 Manifold Learning — Non-linear Dimensionality Reduction

🎓 প্রথমে বুঝি: Manifold কী?

কল্পনা করো একটা কাগজের শিট। সেটা 3D space-এ ভাঁজ করে একটা Swiss Roll (জেলি রোল কেক) বানালে। কাগজটা আসলে 2D — কিন্তু 3D-তে দেখাচ্ছে। Manifold Learning-এর কাজ হলো সেই "ভাঁজ খুলে" কাগজটাকে আবার flat করা। এটা PCA পারে না কারণ PCA শুধু সরলরেখায় (linear) চিন্তা করে।

Manifold: একটি complex, curved structure যেটা আসলে কম মাত্রায় বিদ্যমান কিন্তু বেশি মাত্রায় represent হচ্ছে। যেমন পৃথিবীর surface হলো একটি 2D manifold যেটা 3D space-এ আছে।

🔹 Swiss Roll — Manifold Learning-এর ক্লাসিক উদাহরণ

Swiss Roll হলো sklearn-এর একটি বিখ্যাত synthetic dataset। এটা 3D-তে একটা spiral shape — কিন্তু আসলে 2D। PCA এটাকে unroll করতে পারে না, কিন্তু Isomap পারে। 

from sklearn.datasets import make_swiss_roll
from sklearn.decomposition import PCA
from sklearn.manifold import Isomap
import matplotlib.pyplot as plt
import numpy as np

# 1. Swiss Roll তৈরি করো
n_samples = 5000
X, color = make_swiss_roll(n_samples, random_state=42)
print(f"Swiss Roll shape: {X.shape}")  # (5000, 3) — 3D

# 2. PCA দিয়ে 2D-তে নামাও (কাজ করবে না ভালোভাবে)
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

fig, axes = plt.subplots(1, 2, figsize=(14, 6))
axes[0].scatter(X_pca[:,0], X_pca[:,1], c=color, cmap='Spectral', s=5)
axes[0].set_title("PCA — Swiss Roll (ব্যর্থ)")

# 3. Isomap দিয়ে 2D-তে নামাও (সফল!)
isomap = Isomap(n_neighbors=12, n_components=2)
X_iso = isomap.fit_transform(X)

axes[1].scatter(X_iso[:,0], X_iso[:,1], c=color, cmap='Spectral', s=5)
axes[1].set_title("Isomap — Swiss Roll (সফল! ভাঁজ খুলে গেছে)")
plt.show()

# plot_components function — images দেখায়
from matplotlib import offsetbox

def plot_components(data, model, images=None, ax=None,
                     thumb_frac=0.05, cmap='gray_r', prefit=False):
    ax = ax or plt.gca()
    if not prefit:
        proj = model.fit_transform(data)
    else:
        proj = data
    ax.plot(proj[:, 0], proj[:, 1], '.b')
    if images is not None:
        min_dist_2 = (thumb_frac * max(proj.max(0) - proj.min(0))) ** 2
        shown_images = np.array([2 * proj.max(0)])
        for i in range(data.shape[0]):
            dist = np.sum((proj[i] - shown_images) ** 2, 1)
            if np.min(dist) < min_dist_2:
                continue
            shown_images = np.vstack([shown_images, proj[i]])
            imagebox = offsetbox.AnnotationBbox(
                offsetbox.OffsetImage(images[i], cmap=cmap), proj[i])
            ax.add_artist(imagebox)

# t-SNE দিয়ে শুধু Coat visualize করো
fig, ax = plt.subplots(figsize=(10, 10))
plot_components(
    data=data_mant,
    model=TSNE(n_components=2, method='barnes_hut', random_state=42),
    images=data_mant.values.reshape((-1, 28, 28)),
    ax=ax, thumb_frac=0.1, cmap='gray_r'
)
ax.set_title("t-SNE — Coat class structure (ছোট ছবি দেখাচ্ছে)")
plt.show()
t-SNE visualization-এ ছবিগুলো দেখলে বোঝা যায়: উপরে গাঢ় রঙের coat, নিচে হালকা রঙের। বামে ছোট coat, ডানে লম্বা coat। এটাই manifold learning-এর মূল কথা — visual pattern আবিষ্কার করা।

from sklearn.datasets import make_swiss_roll

from sklearn.manifold import Isomap, TSNE, LocallyLinearEmbedding

# Data
X, color = make_swiss_roll(2000, random_state=42)

methods = {
    'PCA':    PCA(n_components=2),
    'LLE':    LocallyLinearEmbedding(n_neighbors=12, n_components=2),
    'Isomap': Isomap(n_neighbors=12, n_components=2),
    't-SNE':  TSNE(n_components=2, random_state=42),
}

fig, axes = plt.subplots(1, 4, figsize=(20, 5))

for ax, (name, method) in zip(axes, methods.items()):
    t0 = time.time()
    X_2d = method.fit_transform(X)
    elapsed = time.time() - t0
    ax.scatter(X_2d[:,0], X_2d[:,1], c=color, cmap='Spectral', s=5)
    ax.set_title(f"{name}\n({elapsed:.1f}s)")
    ax.set_xticks([]); ax.set_yticks([])

plt.suptitle("Swiss Roll: PCA vs LLE vs Isomap vs t-SNE", fontsize=14)
plt.tight_layout()
plt.show()

সবচেয়ে জরুরি Interview Q&A:

Q: t-SNE কি production ML pipeline-এ ব্যবহার হয়?
A: সাধারণত না। t-SNE-এর কোনো transform() method নেই — মানে নতুন data আসলে আবার পুরো algorithm চালাতে হয়। UMAP-এর transform() আছে।

Q: UMAP আর t-SNE-এর মূল পার্থক্য?
A: UMAP দ্রুত, global structure ধরে, transform() আছে। t-SNE ধীর, cluster separation ভালো, global structure দুর্বল।

Q: n_neighbors কীভাবে choose করব?
A: কোনো mathematical metric নেই। ৫, ১৫, ৩০, ৫০ try করে visually ভালোটা নাও।

📌 Manifold Learning — মনে রাখার মূল বিষয়গুলো

  • 🔹 PCA linear → curved data ঠিকভাবে handle করতে পারে না
  • 🔹 Manifold learning non-linear → curved structure unroll করে
  • 🔹 LLE: local neighbor দেখে, দ্রুত, কিন্তু global structure কম
  • 🔹 Isomap: geodesic distance ব্যবহার করে, Swiss Roll fix করে
  • 🔹 t-SNE: class separation সবচেয়ে ভালো, কিন্তু ধীর, no transform()
  • 🔹 UMAP: fastest, global+local, transform() আছে → production-friendly
  • 🔹 এগুলো unsupervised — target দেখে না, তবু class আলাদা করে!
  • 🔹 কোনো metric নেই algorithm compare করার — visual judgment করতে হয়
  • 🔹 সব feature standardize করো nearest-neighbor based method-এর আগে
  • 🔹 Production pipeline: PCA + classifier → Manifold শুধু visualization-এ
