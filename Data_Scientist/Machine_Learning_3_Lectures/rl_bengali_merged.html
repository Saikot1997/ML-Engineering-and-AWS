💼 INTERVIEW Module 01 — জব ইন্টারভিউ প্রশ্নোত্তর
Q1 Supervised, Unsupervised, এবং Reinforcement Learning-এর মূল পার্থক্য কী?
উত্তর: Supervised-এ labeled data থেকে শেখা হয় (input→output mapping)। Unsupervised-এ unlabeled data-র structure বোঝা হয়। RL-এ কোনো labeled data নেই — agent environment-এর সাথে interact করে, action নেয়, reward পায় এবং সেই reward থেকে শেখে। RL-এর মূল বৈশিষ্ট্য হলো sequential decision making এবং delayed reward।
Q2 RL-এর real-world application-এ সবচেয়ে বড় চ্যালেঞ্জ কী?
উত্তর: (১) Sample efficiency — লক্ষ লক্ষ episode লাগে শিখতে। (২) Reward shaping — সঠিক reward define করা কঠিন। (৩) Sim-to-real gap — simulation-এ শেখা real world-এ কাজ নাও করতে পারে। (৪) Safety — training-এর সময় agent ক্ষতিকর কাজ করতে পারে।
Q3 RL কখন ব্যবহার করা উচিত নয়?
উত্তর: যখন labeled data প্রচুর আছে (Supervised better হবে), যখন environment simulate করা সম্ভব নয়, যখন real-time interaction অনেক expensive বা বিপজ্জনক, এবং যখন simpler rule-based বা optimization approach কাজ করে।

Environment, Agent, State, Episode — মূল উপাদানগুলো

RL-এর সবচেয়ে গুরুত্বপূর্ণ ধারণাগুলো একটা একটা করে বুঝবো, GridWorld দিয়ে।

🤖 Agent

যে সিদ্ধান্ত নেয়। মানুষের মস্তিষ্কের মতো — পরিবেশ দেখে action বেছে নেয়।

উদাহরণ: Chess player, Robot arm, গেমের character

🌍 Environment

যে দুনিয়ায় Agent থাকে। Agent-এর action-এ react করে।

উদাহরণ: Chess board, শহরের রাস্তা, GridWorld grid

📍 State (s)

Agent এখন কোথায় / পরিস্থিতি কী। Environment-এর একটা snapshot।

উদাহরণ: Grid-এর কোন cell-এ আছি, Chess board-এর বর্তমান অবস্থান

🎮 Action (a)

Agent কী করতে পারে। উপরে, নিচে, বামে, ডানে যাওয়া।

উদাহরণ: {up, down, left, right}, {buy, sell, hold}

🏆 Reward (R)

Action-এর পর পাওয়া পুরস্কার বা শাস্তি। + হলে ভালো, - হলে খারাপ।

উদাহরণ: সোনা পেলে +100, গর্তে পড়লে -100

📺 Episode

শুরু থেকে শেষ পর্যন্ত একটা পুরো খেলা। শেষ হয় goal পেলে বা মরলে।

উদাহরণ: একটা Chess game, GridWorld-এ একবার সোনা খোঁজা

GridWorld — RL-এর সবচেয়ে জনপ্রিয় Training Ground
State → Action → Reward চক্র
📌 মনে রাখো: এই চক্রটা বারবার চলে — একটা episode মানে এই চক্র বহুবার চলা। প্রতিবার agent দেখে → action নেয় → reward পায় → নতুন state-এ যায়।

🧠 Policy (π) — কীভাবে সিদ্ধান্ত নেয়?

Policy হলো agent-এর "বুদ্ধি" — কোন state-এ কী action নেবে সেই নিয়ম। এটাই হলো RL-এর main লক্ষ্য: সেরা policy খুঁজে বের করা।

❌ Random Policy

যেকোনো direction-এ random যায়। কোনো learning নেই। 1000 step-এ gold পাওয়ার সম্ভাবনা খুবই কম।

    return np.random.choice(['up','down','left','right'])

💼 INTERVIEW Module 02 — Environment & Agent প্রশ্নোত্তর
Q1 MDP (Markov Decision Process) কী? RL-এ কেন দরকার?
MDP হলো RL সমস্যার mathematical framework। এতে আছে: State (S), Action (A), Transition probability P(s'|s,a), Reward R(s,a), Discount factor γ। RL ধরে নেয় পরিবেশ MDP follow করে — মানে শুধু current state এবং action দিয়েই next state নির্ধারণ করা যায়, পুরো history লাগে না। এই assumption-কে বলে Markov Property।
Q2 Policy কী এবং optimal policy বলতে কী বোঝায়?
Policy (π) হলো state থেকে action-এ mapping: π(s) → a। Deterministic policy সরাসরি action দেয়, stochastic policy action-এর probability দেয়। Optimal policy (π*) হলো যেটা follow করলে expected cumulative reward সবচেয়ে বেশি হয়।
Q3 Observation আর State-এর পার্থক্য কী?
State হলো environment-এর পুরো সত্যিকার অবস্থা। Observation হলো agent কতটুকু দেখতে পাচ্ছে। Fully observable environment-এ observation = state। Partially observable environment-এ (POMDP) agent পুরো state দেখতে পায় না — যেমন poker-এ অন্যের cards দেখা যায় না।
Q4 Sparse reward সমস্যা কী?
যখন reward শুধু episode-এর শেষে পাওয়া যায় (যেমন only শেষে gold পেলে +1), তখন agent কোন action ভালো ছিল সেটা বুঝতে পারে না। Solution: reward shaping (intermediate reward দেওয়া), curiosity-driven exploration, বা hindsight experience replay।

MODULE ০৩

RL-এর গণিত — Reward, Return, Value Function

ভয় পেয়ো না! প্রতিটা সূত্র সহজ উদাহরণ দিয়ে বোঝাবো।

📊 Reward (R) বনাম Return (G)

🎁 Reward (R_t)

শুধু এই মুহূর্তে পাওয়া পুরস্কার। একটা step-এর পরিণাম।

পরীক্ষায় প্রতিটা প্রশ্নের নম্বর = Reward। প্রতিটা প্রশ্ন = এক step।

💰 Return (G_t)

এই মুহূর্ত থেকে episode শেষ পর্যন্ত সব reward-এর যোগফল (discounted)।

পরীক্ষার মোট নম্বর = Return। সব প্রশ্নের নম্বর মিলিয়ে।

Return-এর সূত্র:

G_t = R_t + γ·R_(t+1) + γ²·R_(t+2) + ... = Σ γⁱ · R_(t+i)

γ (gamma) — Discount Factor কী?

γ একটা সংখ্যা যা 0 থেকে 1-এর মধ্যে থাকে (যেমন 0.8, 0.9, 0.99)। এটা দিয়ে বলা হয়: "ভবিষ্যতের reward এখনকার চেয়ে কম মূল্যবান।"

ধরো আজ ১০০ টাকা পাবে নাকি ১ বছর পর পাবে — আজকেরটা বেশি মূল্যবান, তাই না? এটাই discount factor-এর কাজ। γ=0.9 মানে পরের step-এর reward-এর মূল্য 90%, তার পরের step-এর 81% (0.9²), এভাবে কমতে থাকে।

🧮 Return হিসেব — হাতে-কলমে উদাহরণ

ধরো একটা episode-এ 4টা reward পেলে: R₀=-1, R₁=-1, R₂=-1, R₃=+100। γ=0.8

Python — Return Calculation
import numpy as np

rewards = [-1, -1, -1, 100]
gamma   = 0.8

# G_t = R_t + γ*R_{t+1} + γ²*R_{t+2} + ...
# G_0 = -1 + 0.8*(-1) + 0.64*(-1) + 0.512*(100)
#      = -1 - 0.8 - 0.64 + 51.2 = 48.76

def compute_returns(rewards, gamma):
    T = len(rewards)
    gammas = np.array([gamma**i for i in range(T)])
    # G_t = dot product of rewards[t:] with gammas[0:T-t]
    returns = [np.dot(rewards[i:], gammas[:len(rewards)-i]) 
               for i in range(T)]
    return returns

G = compute_returns(rewards, gamma)
print(f"G_0 = {G[0]:.2f}")  # G_0 = 48.76
print(f"G_1 = {G[1]:.2f}")  # G_1 = 62.20
print(f"G_2 = {G[2]:.2f}")  # G_2 = 79.00
print(f"G_3 = {G[3]:.2f}")  # G_3 = 100.00

🗺️ Value Functions — V(s) এবং Q(s,a)

V(S) — State Value Function
V(S) = E[ G_t | s_t = S ]

একটা state-এ থাকলে policy π follow করে মোট কত reward পাওয়া যাবে তার প্রত্যাশিত মান।

Chess-এ একটা position কতটা ভালো তার মান = V(s)। King safe আছে, piece বেশি → V(s) বেশি।

Q(S,A) — Action-Value Function
Q(S,A) = E[ G_t | s_t=S, a_t=A ]

State S-এ action A নিলে এবং তারপর policy π follow করলে মোট কত reward পাওয়া যাবে।

Chess-এ একটা নির্দিষ্ট move নেওয়ার পর কতটা ভালো = Q(s,a)। এটাই RL-এর সবচেয়ে গুরুত্বপূর্ণ function!

⚖️ Exploration বনাম Exploitation

RL-এ সবচেয়ে বড় দ্বিধা: নতুন কিছু চেষ্টা করবো (explore) নাকি যা জানি তাই ব্যবহার করবো (exploit)?

💼 INTERVIEW Module 03 — Mathematics প্রশ্নোত্তর
Q1 Discount factor (γ) বড় বা ছোট হলে কী পার্থক্য হয়?
γ=0 হলে agent শুধু immediate reward দেখে (myopic)। γ→1 হলে দূরের reward-ও equally মূল্যবান (far-sighted)। γ বড় হলে agent দীর্ঘমেয়াদী পরিকল্পনা করে কিন্তু convergence ধীর। γ ছোট হলে fast convergence কিন্তু shortsighted। Practical-এ 0.9-0.99 ব্যবহার হয়।
Q2 V(s) এবং Q(s,a)-এর সম্পর্ক কী?
V(s) = Σ_a π(a|s) · Q(s,a) — মানে V(s) হলো Q(s,a)-এর policy-weighted average। Optimal policy-তে: V*(s) = max_a Q*(s,a)। Q function বেশি useful কারণ এটা দিয়ে সরাসরি action choose করা যায় (model-free)।
Q3 Bellman Equation কী?
Bellman equation বলে current state-এর value = immediate reward + discounted next state value।
V(s) = R(s,a) + γ · V(s')
এটা recursive — V(s) নির্ভর করে V(s')-এর উপর। সব RL algorithm কোনো না কোনোভাবে এই equation solve করে।
Q4 Exploration-Exploitation tradeoff কীভাবে handle করা হয়?
প্রধান পদ্ধতি: (১) ε-greedy: ε probability-তে random, বাকি greedy। (২) Boltzmann/Softmax exploration: temperature দিয়ে কতটা explore করবে নিয়ন্ত্রণ। (৩) UCB (Upper Confidence Bound): কম দেখা actions বেশি try করে। (৪) Thompson Sampling: Bayesian approach।

Monte Carlo Learning — Episode শেষে শেখা

Monte Carlo পদ্ধতিতে agent পুরো episode শেষ করার পরে শেখে। সহজ কিন্তু সীমাবদ্ধতা আছে।

Monte Carlo কীভাবে শেখে? ভাবো তুমি একটা অন্ধকার maze-এ আছো। তুমি random ঘোরো, যদি বের হতে পারো — তাহলে পুরো path মনে রেখে বিশ্লেষণ করো: "কোন মোড়গুলো ঠিক ছিল?"। পরের বার সেই মোড়গুলোতে একটু বেশি আস্থা রাখো। যদি বের হতে না পারো — সেই episode থেকে কিছুই শেখো না।

Monte Carlo Policy Iteration — কীভাবে কাজ করে
🔄 Q Update Formula — ধাপে ধাপে বোঝো
Q(s,a) ← Q(s,a) + (G_t - Q(s,a)) / N(s,a)

এই formula টা আসলে running average!

  • G_t = এই episode-এ (s,a) থেকে পাওয়া actual return
  • Q(s,a) = এখন পর্যন্ত average estimate
  • N(s,a) = (s,a) কতবার দেখেছি
  • (G_t - Q) / N = average কতটা update হবে

উদাহরণ: পরীক্ষায় 3টা result: 70, 80, 90।
Average = (70+80+90)/3 = 80।
Running style-এ: avg = 70, তারপর avg = 70 + (80-70)/2 = 75, তারপর avg = 75 + (90-75)/3 = 80। Same result!

Python — Monte Carlo Agent
import numpy as np
from gridworld.agents import Agent

class MonteCarloAgent(Agent):
    def __init__(self, prefix='MC_GLIE', grid_size=(5,5)):
        self.prefix = prefix
        self.set_of_actions = ['up', 'down', 'left', 'right']
        self.EPSILON = 1.0      # শুরুতে সব random
        self.GAMMA   = 0.8      # discount factor
        
        # Q matrix: (row, col, action) → expected return
        self.Q_function = np.random.uniform(
            size=(grid_size[0], grid_size[1], len(self.set_of_actions))
        )
        self.N = np.zeros(
            shape=(grid_size[0], grid_size[1], len(self.set_of_actions))
        )
        
        self.position = (0, 0)
        self.states  = []    # episode-এর state history
        self.actions = []    # episode-এর action history
        self.rewards = []    # episode-এর reward history
        self.episode = 0

    def act(self):
        # এখনকার position save করো
        self.states.append(self.position)
        
        # ε-greedy: ε সম্ভাবনায় random, বাকি greedy
        if np.random.uniform() < self.EPSILON:
            action = np.random.choice(self.set_of_actions)
        else:
            action = self.set_of_actions[
                np.argmax(self.Q_function[self.position[0], 
                                          self.position[1]])
            ]
        
        self.actions.append(action)
        return action

    def observe(self, agent_position, reward, breeze, smell, 
                 end_episode, info):
        # শুধু reward ও position save করো — শেখা হবে reset()-এ
        self.rewards.append(reward)
        self.position = agent_position

    def reset(self):
        """Episode শেষে ডাকা হয় — এখানে শেখা হয়"""
        
        # ১. Episode counter বাড়াও
        self.episode += 1
        
        # ২. সব timestep-এর Return (G_t) হিসেব করো
        rewards     = np.array(self.rewards)
        episode_len = len(rewards)
        gammas      = np.array([self.GAMMA**i for i in range(episode_len)])
        
        # G_t = Σ γⁱ R_{t+i} (step t থেকে শেষ পর্যন্ত)
        returns = [
            np.dot(rewards[i:], gammas[:len(rewards)-i]) 
            for i in range(episode_len)
        ]
        
        # ৩. Q function update করো
        for idx, (r, c) in enumerate(self.states):
            G_t    = returns[idx]
            a_idx  = self.set_of_actions.index(self.actions[idx])
            
            # N(s,a) += 1
            self.N[r, c, a_idx] += 1
            
            # Q(s,a) += (G_t - Q(s,a)) / N(s,a)  ← running average
            self.Q_function[r, c, a_idx] += (
                (G_t - self.Q_function[r, c, a_idx]) / 
                self.N[r, c, a_idx]
            )
        
        # ৪. ε decay: GLIE condition — ε = 1/episode → 0 হয়ে যাবে
        self.EPSILON = 1 / self.episode
        
        # ৫. History reset করো নতুন episode-র জন্য
        self.states  = []
        self.actions = []
        self.rewards = []


# Training

💼 INTERVIEW Module 04 — Monte Carlo প্রশ্নোত্তর
Q1 First-visit MC এবং Every-visit MC-র পার্থক্য কী?
একটা episode-এ একই state বহুবার দেখা যেতে পারে। First-visit MC: শুধু প্রথমবার দেখা হলেই update করে — unbiased। Every-visit MC: প্রতিবার দেখা হলেই update করে — biased কিন্তু বেশি data। Asymptotically দুটোই সঠিক। নোটবুকের implementation every-visit।
Q2 GLIE কী এবং MC convergence-এর জন্য কেন দরকার?
GLIE = Greedy in the Limit with Infinite Exploration। দুটো condition: (১) প্রতিটা state-action জোড়া infinite বার explore হবে (N→∞)। (২) Policy ধীরে ধীরে greedy হবে (ε→0)। যদি ε=1/k হয়, তাহলে দুটো condition-ই পূরণ হয় এবং Q → Q* (optimal) converge করে।
Q3 Monte Carlo কেন high variance?
Return G_t = R_t + γR_{t+1} + γ²R_{t+2} + ... — এটা অনেক random variable-এর যোগফল। প্রতিটা step stochastic হলে G_t-এর variance অনেক বেশি হয়। Temporal Difference (TD) methods এই variance কমায় bootstrapping-এর মাধ্যমে।

MODULE ০৫

SARSA — Temporal Difference Learning

Monte Carlo-র সমস্যা সমাধান করে TD Learning। প্রতিটা step-এই শেখে — episode শেষের জন্য অপেক্ষা করে না।

TD vs MC তুলনা: MC মানে পুরো পরীক্ষা শেষে পড়া দেখে grade দেওয়া। TD মানে প্রতিটা প্রশ্নের পরেই আংশিক grade দেওয়া। TD বলে: "আমি এখনকার reward এবং পরের step-এর Q-estimate দিয়ে এখনই update করবো — পুরো episode শেষের অপেক্ষা নেই।"

🔤 SARSA মানে কী?

Action (a)
নেওয়া সিদ্ধান্ত

SARSA update করে (s, a)-এর Q value দেখে: reward R পেয়ে s'-তে গেলাম, সেখানে a' action নেবো — সেই Q(s', a') দিয়েই estimate করি।

📐 SARSA Update Rule

Q(s,a) ← Q(s,a) + α [ R + γ·Q(s',a') − Q(s,a) ]

প্রতিটা অংশ কী করে?

অংশনামঅর্থ
α (alpha) Learning rate কতটা দ্রুত update হবে। 0→1। Robbins-Monro: α_n = 1/(n+1)
R Immediate reward এই step-এ পাওয়া reward
γ·Q(s',a') Bootstrapped future value পরের state-action-এর discounted estimate — এটাই TD-র বিশেষত্ব!
R + γQ(s',a') − Q(s,a) TD Error (δ) আমার এখনকার estimate কতটা ভুল ছিল

TD Error বোঝো সহজে: তুমি ভাবলে পরের city-তে যেতে 2 ঘণ্টা লাগবে (estimate)। আধঘণ্টা পর GPS বললো আর 2 ঘণ্টা বাকি — মানে মোট 2.5 ঘণ্টা। তোমার estimate ছিল ভুল, TD error = 0.5 ঘণ্টা। পরের বার এই route-এর estimate update করবে।

SARSA Algorithm — Step by Step Flow
📏 Robbins-Monro Condition — α কীভাবে decay করবে?
Σ αₙ = ∞     এবং     Σ αₙ² < ∞

এই দুটো condition নিশ্চিত করে Q optimal-এ converge করবে। সহজ solution: αₙ = 1/(n+1) যেখানে n হলো step number।

প্রথম condition: learning কখনো পুরোপুরি বন্ধ হবে না (infinite sum)। দ্বিতীয় condition: একসময় learning rate এত ছোট হবে যে stable হবে (finite squared sum)।

Python — SARSA observe() — এটাই শেখার জায়গা
class SarsaAgent(Agent):
    def __init__(self, prefix='SARSA', grid_size=(7,10),
                 starting_position=(3,0), gold_position=(3,7),
                 epsilon=0.5, gamma=0.8, holes_positions=[]):
        self.set_of_actions   = ['up', 'down', 'right', 'left']
        self.starting_position = starting_position
        
        # Q random init, terminal states = 0
        self.Q_function = np.random.uniform(
            size=(grid_size[0], grid_size[1], len(self.set_of_actions))
        )
        self.Q_function[gold_position[0], gold_position[1]] = 0
        for hole in holes_positions:
            self.Q_function[hole[0], hole[1]] = 0
        
        self.ALPHA   = 1
        self.GAMMA   = gamma
        self.EPSILON = epsilon
        
        # SARSA-র জন্য current ও previous state/action/reward track করতে হয়
        self.current_action   = None
        self.previous_action  = None
        self.current_reward   = None
        self.previous_reward  = None
        self.current_position = starting_position
        self.previous_position = None
        self.step_number = 0

    def act(self):
        # previous action save করো
        self.previous_action = self.current_action
        
        # ε-greedy action choice
        if np.random.uniform() < self.EPSILON:
            action = np.random.choice(self.set_of_actions)
        else:
            idx    = np.argmax(self.Q_function[self.current_position[0],
                                               self.current_position[1]])
            action = self.set_of_actions[idx]
        
        self.current_action = action
        self.step_number   += 1
        self.ALPHA          = 1 / self.step_number  # Robbins-Monro
        return action

    def observe(self, agent_position, reward, breeze, smell,
                 end_episode, info):
        """এখানেই SARSA update হয় — প্রতিটা step-এ"""
        
        # A' = current action index (পরের step-এর action, ইতিমধ্যে act() বেছে নিয়েছে)
        current_action_idx = self.set_of_actions.index(self.current_action)
        
        # শুধু previous action থাকলেই update (প্রথম step-এ নয়)
        if self.previous_action is not None:
            prev_action_idx = self.set_of_actions.index(self.previous_action)
            
            # Q(S, A) — আগের state-action-এর current estimate
            q_s_a   = self.Q_function[self.previous_position[0],
                                       self.previous_position[1],
                                       prev_action_idx]
            
            # Q(S', A') — পরের state-action-এর estimate (bootstrapping!)
            q_sp_ap = self.Q_function[self.current_position[0],
                                       self.current_position[1],
                                       current_action_idx]
            
            # SARSA update: Q(s,a) = (1-α)Q(s,a) + α(R + γQ(s',a'))
            update = (1 - self.ALPHA) * q_s_a + \
                      self.ALPHA * (self.current_reward + self.GAMMA * q_sp_ap)
            
            self.Q_function[self.previous_position[0],
                             self.previous_position[1],
                             prev_action_idx] = update
        
        # State/reward history update করো
        self.previous_position = self.current_position
        self.current_position  = agent_position
        self.previous_reward   = self.current_reward
        self.current_reward    = reward
        
        # Episode শেষ হলে → last Q update (terminal state reward দিয়ে)
        if end_episode:
            self.Q_function[self.previous_position[0],
                             self.previous_position[1],
                             current_action_idx] = \
                (1 - self.ALPHA) * self.Q_function[self.previous_position[0],
                                                     self.previous_position[1],
                                                     current_action_idx] + \
                 self.ALPHA * reward

    def reset(self):
        # Episode শেষে সব reset — MC-র মতো শেখে না এখানে!
        self.previous_action   = None
        self.previous_reward   = None
        self.previous_position = None
        self.current_action    = None
        self.current_reward    = None
        self.current_position  = self.starting_position

💼 INTERVIEW Module 05 — SARSA & TD Learning প্রশ্নোত্তর
Q1 SARSA on-policy কেন? Q-Learning-এর সাথে পার্থক্য কী?
SARSA on-policy কারণ Q(s',a') estimate করার সময় যে a' সে actually নেবে সেটাই (ε-greedy policy থেকে) ব্যবহার করে। Q-Learning off-policy: update-এ max_a Q(s',a) নেয় — behaviour policy যাই হোক। SARSA safe path শেখে (cliff এড়িয়ে চলে), Q-Learning optimal path শেখে (cliff-এর ধার দিয়ে)।
Q2 TD Error কী এবং এটা কেন গুরুত্বপূর্ণ?
TD Error (δ) = R + γQ(s',a') − Q(s,a)। এটা হলো "আমার আগের estimate কতটা ভুল।" TD Error ≈ 0 মানে Q converge হয়েছে। Neuroscience-এ দেখা গেছে মানুষের brain-ও TD Error-এর মতো signal ব্যবহার করে শিখতে — dopamine neuron-এর firing pattern!
Q3 n-step TD কী? SARSA এবং MC-র মাঝামাঝি কীভাবে?
1-step TD (SARSA): Q update-এ শুধু পরের state দেখে। n-step TD: n steps দেখার পর update করে। MC: infinite steps (episode শেষে) দেখার পর update। n বাড়লে → বেশি actual reward দেখে → কম bias কিন্তু বেশি variance। n=1 → TD, n=∞ → MC। TD(λ) এই পুরো spectrum একসাথে cover করে।
Q4 Cliff Walking-এ SARSA vs Q-Learning কোনটা better?
CliffGridWorld-এ Cliff-এর ধার দিয়ে সোজা path optimal কিন্তু risky। Q-Learning optimal path শেখে (cliff-এর পাশ দিয়ে) কিন্তু training-এ প্রায়ই পড়ে যায়। SARSA safe path শেখে (cliff থেকে দূরে) — ε-greedy-র কারণে fall risk জানে। Production-এ safety matter করলে SARSA ভালো।

n-step SARSA-র সমস্যা: সঠিক n কত? TD(λ) বলে — "সব n-step return একসাথে নাও, কিন্তু বড় n-কে কম গুরুত্ব দাও!"

qᵗλ = (1 − λ) · Σₙ₌₁∞ λⁿ⁻¹ · q⁽ⁿ⁾ₜ যেখানে λ ∈ (0, 1)

🔍 Eligibility Trace — "কোন State এই Reward পাওয়ার যোগ্য?"

🧠 Eligibility Trace কী?

TD(λ)-র practical implementation-এর জন্য Eligibility Trace E(s,a) ব্যবহার করি। এটা প্রতিটা state-action pair-কে একটা "credit score" দেয়।

ক্রেডিট কার্ড analogy: তুমি শপিং করলে। যে দোকানে সবচেয়ে সম্প্রতি গেছো, সে সবচেয়ে বেশি credit পায়। আগেরগুলো কম। Eligibility Trace ঠিক এটাই করে — সম্প্রতি visit করা (s,a)-গুলো বেশি credit পায়।

E(s,a) ← E(s,a) + 1    (যখন (s,a) visit হয়)
E(S,A) ← γ·λ·E(S,A)    (সব state-action, প্রতি step-এ decay)
Eligibility Trace — Goal পাওয়ার পর backward credit assignment

⚙️ SARSA(λ) Algorithm — ধাপে ধাপে

SARSA(λ) Algorithm — Backward View (Eligibility Trace)
INITIALIZE: Q(s,a) = random;  Q(terminal, .) = 0;  E(s,a) = 0

WHILE k < total_episodes:
E(s,a) = 0  ← প্রতি episode শুরুতে trace clear করো
s ← initial state;  a ← ε-greedy(Q, s)

WHILE s is not terminal:
Take a → observe R, s'
a' ← ε-greedy(Q, s')  ← পরের action বেছে নাও

δ ← R + γ·Q(s',a') − Q(s,a)  ← TD Error
E(s,a) ← E(s,a) + 1  ← current state credit দাও

FOR ALL (S,A):  ← সব state-action একসাথে!
Q(S,A) ← Q(S,A) + α·δ·E(S,A)
E(S,A) ← γ·λ·E(S,A)  ← decay

s ← s';  a ← a'
k += 1
🔑 SARSA vs SARSA(λ) মূল পার্থক্য: SARSA-তে শুধু current (s,a) update। SARSA(λ)-তে সব (S,A) একসাথে update হয় — trace weighted। এজন্য SARSA(λ) অনেক দ্রুত শেখে!
λ = 0 হলে?

E ← γ·0·E = 0 → শুধু current (s,a) update হয়।
SARSA(0) = Regular SARSA!

λ=0 → 1 step → pure TD
λ = 1 হলে?

Trace কখনো decay হয় না → পুরো episode credit পায়।
SARSA(1) ≈ Monte Carlo!

λ=1 → ∞ steps → MC-like

import numpy as np

class SarsaLambdaAgent:
    """SARSA(λ) — Eligibility Trace সহ। PDF-এর observe() completed."""
    def __init__(self, grid_size=(10,10), gold_position=(9,9),
                 holes=[], epsilon=0.5, gamma=0.8, lambda_=0.9):
        self.actions = ['up','down','right','left']
        rows, cols = grid_size
        # Q function: random শুরু, terminal states = 0
        self.Q = np.random.uniform(size=(rows, cols, 4))
        self.Q[gold_position] = 0
        for h in holes: self.Q[h] = 0
        # Hyperparameters
        self.ALPHA, self.GAMMA, self.EPSILON = 1.0, gamma, epsilon
        self.lambda_ = lambda_
        # ★ Eligibility Trace — Q-র মতো shape, সব 0
        self.E = np.zeros_like(self.Q)
        # State tracking
        self.cur_a = self.prev_a = self.cur_r = None
        self.cur_s = (0, 0); self.prev_s = None
        self.step = 0

    def act(self):
        """ε-greedy policy"""
        self.prev_a = self.cur_a
        self.step += 1
        self.ALPHA = 1.0 / self.step  # alpha decay
        r, c = self.cur_s
        if np.random.uniform() < self.EPSILON:
            action = np.random.choice(self.actions)
        else:
            action = self.actions[np.argmax(self.Q[r, c])]
        self.cur_a = action
        return action

    def observe(self, new_pos, reward, end_episode):
        """
        ★★★ মূল SARSA(λ) update ★★★
        প্রতি step: δ → E update → সব Q update → E decay
        """
        cur_ai = self.actions.index(self.cur_a)

        if self.prev_a is not None:
            prev_ai = self.actions.index(self.prev_a)
            # Q(S,A) এবং Q(S',A')
            q_sa   = self.Q[self.prev_s[0], self.prev_s[1], prev_ai]
            q_spap = self.Q[self.cur_s[0],  self.cur_s[1],  cur_ai]
            # ★ TD Error
            delta = self.cur_r + self.GAMMA * q_spap - q_sa
            # ★ Eligibility update: current state-action credit
            self.E[self.prev_s[0], self.prev_s[1], prev_ai] += 1
            # ★ সব Q update (trace-weighted)
            self.Q = self.Q + self.ALPHA * delta * self.E
            # ★ সব trace decay
            self.E = self.GAMMA * self.lambda_ * self.E

        # State update
        self.prev_s = self.cur_s
        self.cur_s  = new_pos
        self.cur_r  = reward

        if end_episode:
            # Terminal: Q(S',A')=0 → δ = R − Q(S,A)
            delta = self.cur_r - self.Q[self.prev_s[0], self.prev_s[1], cur_ai]
            self.E[self.prev_s[0], self.prev_s[1], cur_ai] += 1
            self.Q = self.Q + self.ALPHA * delta * self.E
            self.E = self.GAMMA * self.lambda_ * self.E

    def reset(self):
        """Episode শেষে — trace অবশ্যই clear করো!"""
        self.prev_a = self.prev_s = self.cur_a = self.cur_r = None
        self.cur_s = (0,0); self.step = 1
        self.E *= 0  # ★ প্রতি episode শুরুতে trace clear!

💼 INTERVIEW Module 06 — TD(λ) & SARSA(λ) Interview প্রশ্নোত্তর
Q1 TD(λ) কী এবং কেন দরকার? λ=0 এবং λ=1 কী বোঝায়?
উত্তর: TD(λ) হলো MC এবং TD Learning-এর combination। qᵗλ = (1−λ)·Σ λⁿ⁻¹·q⁽ⁿ⁾ₜ — সব n-step return-এর weighted average। λ=0 → pure TD (SARSA), λ=1 → pure MC। দরকার কারণ: MC-তে Low Bias কিন্তু High Variance, TD-তে উল্টো। TD(λ) λ দিয়ে balance করে। Backward view-এ Eligibility Trace দিয়ে efficiently implement।
Q2 Eligibility Trace কী? Mathematical formulation কী?
উত্তর: E(s,a) — প্রতিটা (s,a) pair-কে credit score দেয়। Visit-এ E(s,a) += 1, প্রতি step-এ E(S,A) ← γλE(S,A) (decay)। Q update: Q(S,A) ← Q(S,A) + α·δ·E(S,A) — trace যত বেশি, তত বেশি update। সুবিধা: একটা TD error দিয়ে পুরো trajectory update হয়, O(|S||A|) per step।
Q3 SARSA(0) vs SARSA(λ) — কোনটা কখন?
উত্তর: SARSA(0): stable env, computation limited, fast convergence চাইলে। SARSA(λ): long path, sparse reward, দ্রুত শিখতে হলে। λ=0.9 সাধারণত সেরা। SARSA(λ) সাধারণত কম episode-এ converge করে কারণ পুরো path থেকে শেখে।
Q4 [Hard] Production-এ SARSA(λ) implement করলে কী কী সতর্কতা?
উত্তর: (1) Episode reset: প্রতি episode-শুরুতে E=0 — না করলে trace leak হবে। (2) Memory: E table Q-র মতোই বড় — large state space-এ function approximation লাগে। (3) Lambda tuning: Optuna/GridSearch দিয়ে tune করো। (4) Alpha decay: 1/step বা cosine schedule। (5) Monitoring: MLflow-এ δ distribution, E norm track করো।
Q5 n-step SARSA আর TD(λ)-র পার্থক্য কী?
উত্তর: n-step SARSA একটা fixed n নেয়, n steps buffer রাখতে হয়, implement কঠিন। TD(λ) = সব n-step returns-এর weighted sum — mathematically equivalent কিন্তু backward view (eligibility trace) দিয়ে efficiently implement করা যায়। Same result, অনেক সহজ implementation — তাই practice-এ TD(λ) ব্যবহার করা হয়।

def epsilon_greedy(state, Q, actions, epsilon):
    r, c = state
    if np.random.uniform() < epsilon:
        # Explore: random
        return np.random.choice(actions)
    else:
        # Exploit: greedy
        return actions[np.argmax(Q[r, c])]

# reset() এ চলে — episode শেষে
def mc_update(states, actions, rewards,
              Q, N, gamma, actions_list):
    T = len(rewards)
    G = np.zeros(T)
    G[-1] = rewards[-1]
    for t in range(T-2, -1, -1):
        G[t] = rewards[t] + gamma * G[t+1]
    for t, (r, c) in enumerate(states):
        a = actions_list.index(actions[t])
        N[r, c, a] += 1
        Q[r, c, a] += (G[t] - Q[r, c, a]) / N[r, c, a]

# observe() এ চলে — প্রতি step-এ
def sarsa_update(Q, s, a, r, s_next, a_next,
                  alpha, gamma, actions):
    ai  = actions.index(a)
    ai_ = actions.index(a_next)
    q_sa    = Q[s[0], s[1], ai]
    q_sp_ap = Q[s_next[0], s_next[1], ai_]
    td_error = r + gamma * q_sp_ap - q_sa
    Q[s[0], s[1], ai] += alpha * td_error
    return Q

def qlearning_update(Q, s, a, r, s_next,
                       alpha, gamma, actions):
    ai  = actions.index(a)
    q_sa = Q[s[0], s[1], ai]
    # SARSA: Q(s',a') যেখানে a' ε-greedy থেকে
    # Q-Learning: max_a Q(s',a) — সেরাটা নাও!
    max_q_sp = np.max(Q[s_next[0], s_next[1]])
    td_error  = r + gamma * max_q_sp - q_sa
    Q[s[0], s[1], ai] += alpha * td_error
    return Q

"""
Monte Carlo RL Agent — Production Ready
ব্যবহার: GridWorld বা যেকোনো discrete action space environment
"""
from __future__ import annotations
import numpy as np
from dataclasses import dataclass, field
from typing import List, Tuple, Dict, Optional
import logging

logger = logging.getLogger(__name__)


@dataclass
class MCConfig:
    """Monte Carlo Agent configuration"""
    grid_rows:    int   = 10
    grid_cols:    int   = 10
    gamma:        float = 0.9   # discount factor
    epsilon_init: float = 1.0   # শুরুর epsilon
    epsilon_min:  float = 0.01  # সর্বনিম্ন epsilon
    decay_type:   str   = "glie" # "glie" | "linear" | "exp"
    seed:         Optional[int] = None


class MonteCarloPolicyIteration:
    """
    Monte Carlo Policy Iteration with GLIE epsilon decay.
    On-policy, every-visit MC control.
    """

    ACTIONS = ["up", "down", "left", "right"]

    def __init__(self, config: MCConfig):
        self.cfg = config
        if config.seed is not None:
            np.random.seed(config.seed)

        # Q(s, a) এবং N(s, a) matrix
        shape = (config.grid_rows, config.grid_cols, len(self.ACTIONS))
        self.Q = np.zeros(shape)
        self.N = np.zeros(shape, dtype=int)

        self.epsilon = config.epsilon_init
        self.episode = 0

        # Episode trajectory buffer
        self._states:  List[Tuple[int, int]] = []
        self._actions: List[str]             = []
        self._rewards: List[float]           = []

        # Metrics tracking
        self.metrics: Dict[str, List] = {
            "episode_returns": [],
            "episode_lengths": [],
            "epsilons": [],
        }

    # ──────────────────────────────────────────────
    # Action selection
    # ──────────────────────────────────────────────
    def select_action(self, state: Tuple[int, int]) -> str:
        """ε-greedy action selection"""
        r, c = state
        self._states.append(state)

        if np.random.uniform() < self.epsilon:
            action = np.random.choice(self.ACTIONS)
        else:
            action = self.ACTIONS[np.argmax(self.Q[r, c])]

        self._actions.append(action)
        return action

    def record_reward(self, reward: float):
        """প্রতিটা step-এর reward record করো"""
        self._rewards.append(reward)

    # ──────────────────────────────────────────────
    # Episode-end update (reset করলে চলে)
    # ──────────────────────────────────────────────
    def end_episode(self) -> Dict[str, float]:
        """Episode শেষে Q update এবং ε decay"""
        self.episode += 1

        # ১. Discounted returns compute
        T       = len(self._rewards)
        returns = self._compute_returns(self._rewards, self.cfg.gamma)

        # ২. Q update (every-visit MC)
        for t in range(T):
            r, c  = self._states[t]
            a_idx = self.ACTIONS.index(self._actions[t])
            self.N[r, c, a_idx] += 1
            alpha = 1.0 / self.N[r, c, a_idx]
            self.Q[r, c, a_idx] += alpha * (returns[t] - self.Q[r, c, a_idx])

        # ৩. ε decay
        self.epsilon = self._decay_epsilon()

        # ৪. Metrics log
        ep_return = float(np.sum(self._rewards))
        self.metrics["episode_returns"].append(ep_return)
        self.metrics["episode_lengths"].append(T)
        self.metrics["epsilons"].append(self.epsilon)

        # ৫. Buffer clear
        self._states.clear()
        self._actions.clear()
        self._rewards.clear()

        return {"return": ep_return, "length": T, "epsilon": self.epsilon}

    # ──────────────────────────────────────────────
    # Helper methods
    # ──────────────────────────────────────────────
    @staticmethod
    def _compute_returns(rewards: List[float], gamma: float) -> np.ndarray:
        T = len(rewards)
        G = np.zeros(T)
        G[-1] = rewards[-1]
        for t in range(T - 2, -1, -1):
            G[t] = rewards[t] + gamma * G[t + 1]
        return G

    def _decay_epsilon(self) -> float:
        if self.cfg.decay_type == "glie":
            eps = 1.0 / self.episode
        elif self.cfg.decay_type == "exp":
            eps = self.epsilon * 0.995
        else:  # linear
            eps = self.epsilon - 0.001
        return max(eps, self.cfg.epsilon_min)

    def greedy_action(self, state: Tuple[int, int]) -> str:
        r, c = state
        return self.ACTIONS[np.argmax(self.Q[r, c])]

    def get_policy_grid(self) -> np.ndarray:
        """প্রতিটা cell-এ optimal action কোনটা সেটা return করো"""
        symbols = {0: "↑", 1: "↓", 2: "←", 3: "→"}
        policy = np.argmax(self.Q, axis=2)
        return np.vectorize(symbols.get)(policy)

    def save(self, path: str):
        np.savez(path, Q=self.Q, N=self.N)
        logger.info(f"Model saved to {path}")

    @classmethod
    def load(cls, path: str, config: MCConfig) -> "MonteCarloPolicyIteration":
        agent = cls(config)
        data  = np.load(path)
        agent.Q, agent.N = data["Q"], data["N"]
        return agent


# ──────────────────────────────────────────────
# Training loop example (GridWorld-এর সাথে)
# ──────────────────────────────────────────────
def train_mc(env, n_episodes: int = 5000) -> MonteCarloPolicyIteration:
    config = MCConfig(grid_rows=10, grid_cols=10, gamma=0.9, seed=42)
    agent  = MonteCarloPolicyIteration(config)

    for ep in range(n_episodes):
        state = env.reset()  # (row, col) tuple
        done  = False

        while not done:
            action          = agent.select_action(state)
            next_state, reward, done, _ = env.step(action)
            agent.record_reward(reward)
            state = next_state

        metrics = agent.end_episode()

        if ep % 500 == 0:
            print(f"Ep {ep:4d} | Return: {metrics['return']:7.1f} | "
                  f"ε: {metrics['epsilon']:.4f}")

    return agent

"""
SARSA Agent — Temporal Difference On-Policy Control
প্রতিটা step-এ Q update হয় — Episode শেষের অপেক্ষা নেই।
"""
import numpy as np
from dataclasses import dataclass
from typing import Tuple, Optional, Dict, List


@dataclass
class SarsaConfig:
    grid_rows:   int   = 10
    grid_cols:   int   = 10
    gamma:       float = 0.9
    epsilon:     float = 0.5
    alpha_init:  float = 1.0  # Robbins-Monro: 1/step
    terminal_states: List[Tuple] = None
    seed: Optional[int] = None


class SarsaTDAgent:
    """
    SARSA: State-Action-Reward-State-Action
    Update rule: Q(s,a) ← (1-α)Q(s,a) + α[R + γQ(s',a')]
    """

    ACTIONS = ["up", "down", "right", "left"]

    def __init__(self, config: SarsaConfig):
        self.cfg = config
        if config.seed:
            np.random.seed(config.seed)

        shape   = (config.grid_rows, config.grid_cols, len(self.ACTIONS))
        self.Q  = np.random.uniform(low=0, high=0.01, size=shape)

        # Terminal states-এ Q = 0
        if config.terminal_states:
            for r, c in config.terminal_states:
                self.Q[r, c] = 0.0

        # SARSA state tracking
        self._s:     Optional[Tuple] = None  # previous state
        self._a:     Optional[str]  = None  # previous action
        self._r:     Optional[float]= None  # previous reward
        self._s_cur: Optional[Tuple] = None  # current state
        self._a_cur: Optional[str]  = None  # current action
        self._step   = 0
        self.epsilon = config.epsilon

        self.metrics = {"td_errors": [], "episode_rewards": []}
        self._ep_rewards: List[float] = []

    def begin_episode(self, initial_state: Tuple) -> str:
        """Episode শুরুতে — প্রথম action বেছে নাও"""
        self._s     = None
        self._a     = None
        self._r     = None
        self._s_cur = initial_state
        self._step  = 1
        self._ep_rewards.clear()
        self._a_cur = self._epsilon_greedy(initial_state)
        return self._a_cur

    def step(self, next_state: Tuple, reward: float,
              done: bool = False) -> str:
        """
        Environment-এর response পেয়ে Q update করো।
        পরের action return করো।
        """
        self._ep_rewards.append(reward)
        self._step += 1
        alpha = 1.0 / self._step  # Robbins-Monro condition

        # a' বেছে নাও (পরের state-এ)
        next_action = self._epsilon_greedy(next_state)

        # SARSA update: Q(s,a) ← Q(s,a) + α[R + γQ(s',a') - Q(s,a)]
        s, a   = self._s_cur, self._a_cur
        si, ai = s[0], s[1]
        a_idx  = self.ACTIONS.index(a)

        if done:
            # Terminal: Q(s',.) = 0
            td_target = reward
        else:
            na_idx    = self.ACTIONS.index(next_action)
            q_sp_ap   = self.Q[next_state[0], next_state[1], na_idx]
            td_target = reward + self.cfg.gamma * q_sp_ap

        td_error = td_target - self.Q[si, ai, a_idx]
        self.Q[si, ai, a_idx] += alpha * td_error
        self.metrics["td_errors"].append(abs(td_error))

        # Advance state/action
        self._s_cur = next_state
        self._a_cur = next_action

        if done:
            ep_ret = sum(self._ep_rewards)
            self.metrics["episode_rewards"].append(ep_ret)

        return next_action  # caller-কে পরের action জানাই

    def _epsilon_greedy(self, state: Tuple) -> str:
        r, c = state
        if np.random.uniform() < self.epsilon:
            return np.random.choice(self.ACTIONS)
        return self.ACTIONS[np.argmax(self.Q[r, c])]

    def greedy_action(self, state: Tuple) -> str:
        r, c = state
        return self.ACTIONS[np.argmax(self.Q[r, c])]

def train_sarsa(env, n_episodes: int = 1000) -> SarsaTDAgent:
    config = SarsaConfig(
        grid_rows=7, grid_cols=10,
        gamma=0.9, epsilon=0.5,
        terminal_states=[(3, 7)],  # gold position
        seed=42
    )
    agent = SarsaTDAgent(config)

    for ep in range(n_episodes):
        state  = env.reset()
        action = agent.begin_episode(state)
        done   = False

        while not done:
            next_state, reward, done, _ = env.step(action)
            action = agent.step(next_state, reward, done)

        if ep % 200 == 0:
            recent = agent.metrics["episode_rewards"][-50:]
            avg    = np.mean(recent) if recent else 0
            print(f"Ep {ep:4d} | Avg Return (last 50): {avg:7.2f}")

    return agent

"""
SARSA(λ) Production Agent
Features: Eligibility Trace, alpha decay, configurable λ
"""
from __future__ import annotations
import numpy as np
from dataclasses import dataclass
from typing import List, Tuple, Optional
import logging

logger = logging.getLogger(__name__)


@dataclass
class SarsaLambdaConfig:
    grid_rows:    int   = 10
    grid_cols:    int   = 10
    gamma:        float = 0.9
    lambda_:      float = 0.9   # eligibility trace decay
    epsilon_init: float = 1.0
    epsilon_min:  float = 0.01
    alpha_init:   float = 0.5
    alpha_decay:  str   = "step"  # "step" | "cosine"


class SarsaLambdaProductionAgent:
    """
    SARSA(λ) Agent — Production Ready
    Backward View Eligibility Trace implementation
    """
    def __init__(self, cfg: SarsaLambdaConfig,
                 gold: Tuple[int,int]=(9,9),
                 holes: List[Tuple]=[] ):
        self.cfg = cfg
        self.actions = ['up','down','right','left']

        # Q-table and Eligibility Trace — same shape
        shape = (cfg.grid_rows, cfg.grid_cols, 4)
        self.Q = np.random.uniform(0, 0.01, shape)
        self.Q[gold] = 0
        for h in holes: self.Q[h] = 0
        self.E = np.zeros(shape)   # ★ Eligibility Trace

        # Hyperparameters
        self.epsilon = cfg.epsilon_init
        self.alpha   = cfg.alpha_init
        self.total_steps = 0
        self.episode     = 0

        # Per-step state
        self._reset_state()

    def _reset_state(self):
        self.prev_s = self.cur_s = (0, 0)
        self.prev_a = self.cur_a = None
        self.cur_r  = None

    def _decay_epsilon(self):
        self.epsilon = max(
            self.cfg.epsilon_min,
            self.cfg.epsilon_init / (self.episode + 1)
        )

    def _decay_alpha(self):
        if self.cfg.alpha_decay == "step":
            self.alpha = self.cfg.alpha_init / (self.total_steps + 1)
        # cosine schedule etc. add as needed

    def act(self) -> str:
        """ε-greedy action selection"""
        self.prev_a = self.cur_a
        self.total_steps += 1
        self._decay_alpha()
        r, c = self.cur_s
        if np.random.random() < self.epsilon:
            action = np.random.choice(self.actions)
        else:
            action = self.actions[np.argmax(self.Q[r, c])]
        self.cur_a = action
        return action

    def observe(self, new_pos: Tuple, reward: float, done: bool):
        """
        SARSA(λ) update — Backward View
        δ = R + γQ(s',a') - Q(s,a)
        E(s,a) += 1
        Q ← Q + α·δ·E  (all states)
        E ← γλE
        """
        cur_ai = self.actions.index(self.cur_a)

        if self.prev_a is not None:
            prev_ai = self.actions.index(self.prev_a)
            pr, pc  = self.prev_s
            cr, cc  = self.cur_s

            # TD Error
            q_sa    = self.Q[pr, pc, prev_ai]
            q_spap  = self.Q[cr, cc, cur_ai]
            delta   = self.cur_r + self.cfg.gamma * q_spap - q_sa

            # ★ Eligibility Trace update
            self.E[pr, pc, prev_ai] += 1

            # ★ Vectorized Q update — numpy makes this O(|S||A|) fast
            self.Q += self.alpha * delta * self.E

            # ★ Decay all traces
            self.E *= (self.cfg.gamma * self.cfg.lambda_)

        # Advance state
        self.prev_s = self.cur_s
        self.cur_s  = new_pos
        self.cur_r  = reward

        if done:
            # Terminal transition (Q(s',..)=0)
            pr, pc = self.prev_s
            delta  = self.cur_r - self.Q[pr, pc, cur_ai]
            self.E[pr, pc, cur_ai] += 1
            self.Q += self.alpha * delta * self.E
            self.E *= (self.cfg.gamma * self.cfg.lambda_)

    def reset_episode(self):
        """Episode শেষে call করো"""
        self.episode += 1
        self._decay_epsilon()
        self._reset_state()
        self.E[:] = 0  # ★ CRITICAL — trace clear না করলে episodes bleed

    def greedy_action(self, state: Tuple) -> str:
        r, c = state
        return self.actions[np.argmax(self.Q[r, c])]

Q-Learning Algorithm — ধাপে ধাপে

📋 Q-Learning Pseudocode — বাংলায়

১. Q table শুরু করো যেকোনো মান দিয়ে। Terminal state-এর Q = 0।

২. প্রতিটি episode-এ state s থেকে শুরু করো।

৩. s যদি terminal না হয়:

→ ε-greedy policy মেনে action a বেছে নাও

→ a করো, reward R এবং পরবর্তী state s' observe করো

→ Greedy policy মেনে a* বেছে নাও → a* = argmax Q(s', ·)

→ Q আপডেট: Q(s,a) ← Q(s,a) + α[R + γQ(s',a*) − Q(s,a)]

→ s ← s'

৪. পরের episode-এ যাও।

Q-Learning Update:   Q(s,a) ← Q(s,a) + α [ R + γ · maxa' Q(s',a') − Q(s,a) ]

SARSA Update:         Q(s,a) ← Q(s,a) + α [ R + γ · Q(s', a') − Q(s,a) ]
পার্থক্য: Q-Learning-এ max Q(s',·) — সেরা সম্ভাব্য future value। SARSA-তে Q(s',a') — agent যা নেবে তার value।

import numpy as np
from collections import defaultdict

class QAgent:
    """
    Q-Learning Agent — Off-Policy TD Control.
    SARSA-র মতোই কিন্তু observe()-এ A* = argmax Q(s',.) ব্যবহার করে।
    """
    def __init__(self, grid_size=(7,10), start=(3,0),
                 gold=(3,7), epsilon=0.5, gamma=.8, holes=[]):
        self.actions  = ['up', 'down', 'right', 'left']
        self.start    = start
        self.EPSILON  = epsilon
        self.GAMMA    = gamma
        self.ALPHA    = 1

        # Q-table: random init, terminal states → 0
        self.Q = np.random.uniform(size=(grid_size[0], grid_size[1], 4))
        self.Q[gold[0], gold[1]] = 0
        for h in holes: self.Q[h[0], h[1]] = 0

        self.curr_a = self.prev_a = None
        self.curr_pos = start
        self.prev_pos = None
        self.curr_r = None
        self.step = 0

    def act(self):
        """ε-greedy policy দিয়ে action বেছে নাও।"""
        self.prev_a = self.curr_a
        if np.random.uniform() < self.EPSILON:
            a = np.random.choice(self.actions)   # explore
        else:
            a = self.actions[np.argmax(self.Q[self.curr_pos])]  # exploit
        self.curr_a = a
        self.step += 1
        self.ALPHA = 1 / self.step
        return a

    def observe(self, new_pos, reward, end_episode):
        """
        ★ Q-Learning-এর হৃদয় ★
        SARSA:       A' = ε-greedy(Q(s',.))   ← agent যা করবে
        Q-Learning:  A* = argmax Q(s',.)       ← সেরা সম্ভাব্য action
        """
        curr_a_idx = self.actions.index(self.curr_a)

        if self.prev_a is not None:
            prev_a_idx  = self.actions.index(self.prev_a)
            # ★ Q-Learning: argmax (greedy) — not ε-greedy!
            best_a_idx  = np.argmax(self.Q[self.curr_pos])
            q_sa        = self.Q[self.prev_pos[0], self.prev_pos[1], prev_a_idx]
            q_sp_astar  = self.Q[self.curr_pos[0], self.curr_pos[1], best_a_idx]
            update = (1-self.ALPHA)*q_sa + self.ALPHA*(self.curr_r + self.GAMMA*q_sp_astar)
            self.Q[self.prev_pos[0], self.prev_pos[1], prev_a_idx] = update

        self.prev_pos  = self.curr_pos
        self.curr_pos  = new_pos
        self.curr_r    = reward

        if end_episode:
            self.Q[self.prev_pos[0], self.prev_pos[1], curr_a_idx] = \
                (1-self.ALPHA)*self.Q[self.prev_pos[0], self.prev_pos[1], curr_a_idx] + \
                self.ALPHA * reward

    def reset(self):
        self.prev_a = self.curr_a = None
        self.curr_pos = self.start
        self.prev_pos = None
        self.curr_r  = None
        self.step = 1

SARSA:    Q(s,a) ← Q(s,a) + α[R + γQ(s', a') − Q(s,a)]  a' ~ ε-greedy

হ্যাঁ, Q-Learning convergence guarantee আছে যদি তিনটি শর্ত পূরণ হয়:

১. GLIE (Greedy in the Limit with Infinite Exploration): সব state-action pair অসীমবার visit করতে হবে।

২. Robbins-Monro: Learning rate α শর্ত — Σ αₙ = ∞ এবং Σ αₙ² < ∞।

৩. Finite, stationary MDP।

⚠️ Function approximation (neural network) ব্যবহার করলে guarantee থাকে না — তবু DQN সাধারণত কাজ করে।

import numpy as np
import matplotlib.pyplot as plt
from collections import defaultdict

class GridWorld10x10:
    def __init__(self):
        self.size = 10
        self.goal = (9, 9)
        self.moves = [(-1,0),(1,0),(0,1),(0,-1)]

    def reset(self): return (0,0)

    def step(self, s, a):
        r = max(0, min(9, s[0]+a[0]))
        c = max(0, min(9, s[1]+a[1]))
        ns = (r, c)
        done = ns == self.goal
        return ns, (10 if done else -1), done

def train_qlearning(env, n_ep=5000, eps=0.1, gamma=0.99):
    Q = defaultdict(lambda: np.zeros(4))
    rewards = []
    for ep in range(n_ep):
        s, total, done = env.reset(), 0, False
        alpha = 1 / (ep+1)
        while not done:
            a = np.random.randint(4) if np.random.random()<eps else np.argmax(Q[s])
            ns, r, done = env.step(s, env.moves[a])
            Q[s][a] += alpha*(r + gamma*np.max(Q[ns]) - Q[s][a])  # max!
            s, total = ns, total+r
        rewards.append(total)
    return Q, rewards

env = GridWorld10x10()
Q_ql, rew_ql = train_qlearning(env)
rolling = np.convolve(rew_ql, np.ones(100)/100, mode='valid')
plt.plot(rolling, color='#10b981', label='Q-Learning')
plt.title('Q-Learning Training Curve (10x10 Grid)')
plt.xlabel('Episode'); plt.ylabel('Avg Reward')
plt.legend(); plt.show()

Glossary — সব পরিভাষা একনজরে

Agent
যে সিদ্ধান্ত নেয় ও পরিবেশে কাজ করে — আমাদের AI program
Environment
যে জগতে agent বাস করে ও interact করে
State (s)
পরিবেশের বর্তমান অবস্থা — agent কোথায় আছে
Action (a)
agent যা করতে পারে — up, down, left, right
Reward (R)
একটি ধাপে পাওয়া তাৎক্ষণিক পুরস্কার বা শাস্তি
Return (G)
একটি ধাপ থেকে শেষ পর্যন্ত discount করা মোট reward
Policy (π)
কোন state-এ কোন action নেওয়া হবে তার কৌশল
Value V(s)
state s থেকে শুরু করে policy π মেনে প্রত্যাশিত return
Q(s, a)
state s-এ action a নিয়ে তারপর π মেনে প্রত্যাশিত return
Gamma (γ)
Discount factor — ভবিষ্যৎ reward কতটা গুরুত্বপূর্ণ (0 থেকে 1)
Epsilon (ε)
ε-greedy-তে exploration-এর সম্ভাবনা
Alpha (α)
Learning rate — প্রতি ধাপে কতটুকু পরিবর্তন হবে
Episode
শুরু থেকে শেষ পর্যন্ত একটি সম্পূর্ণ run
MDP
Markov Decision Process — RL-এর মূল গাণিতিক framework
TD Error
R + γQ(s',a') - Q(s,a) — প্রত্যাশা ও বাস্তবতার পার্থক্য
Bootstrap
পুরনো Q estimate দিয়ে নতুন Q update করা (MC করে না)
On-policy
যে policy থেকে data সংগ্রহ করা হয় সেটাই improve করা (SARSA)
Off-policy
ভিন্ন policy থেকে data নিয়ে target policy শেখা (Q-Learning)
Replay Buffer
অভিজ্ঞতা (s,a,r,s') জমা রাখার স্থান — DQN-এ ব্যবহার
Off-Policy
ভিন্ন policy থেকে data নিয়ে target policy শেখা (Q-Learning)
Eligibility Trace E(s,a)
TD(λ)-এ প্রতিটি state-action pair-এর "credit" — কতটা সম্প্রতি visit হয়েছে তার decay করা স্মৃতি
TD(λ)
TD learning (n=1) ও Monte Carlo (n=∞)-এর মধ্যবর্তী — eligibility trace দিয়ে সব n-step একত্রে combine করে
n-step Return
n ধাপ সামনে দেখে update করার পদ্ধতি — n=1 হলে TD, n=∞ হলে MC
GLIE
Greedy in the Limit — অসীম exploration, শেষে greedy
