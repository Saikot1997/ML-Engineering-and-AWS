⏱ টাইম সিরিজ (Time Series)

টাইম সিরিজ কী? — একদম সহজ ভাষায়

ধরো তুমি প্রতিদিন সকালে তোমার বাসার তাপমাত্রা মাপছো। জানুয়ারিতে ৮°C, ফেব্রুয়ারিতে ১০°C, জুলাইতে ৩৫°C... এই ডেটাটা সময়ের সাথে সাথে সংগ্রহ করা হচ্ছে — এটাই হলো টাইম সিরিজ!

Univariate vs Multivariate

Univariate (এককীয়)

একটিমাত্র পরিমাপ সময়ের সাথে ট্র্যাক করা হয়।

উদাহরণ: প্রতিদিনের তাপমাত্রা শুধু।

Multivariate (বহুকীয়)

একই সাথে একাধিক পরিমাপ ট্র্যাক করা হয়।

উদাহরণ: তাপমাত্রা + আর্দ্রতা + বায়ুচাপ একসাথে।

টাইম সিরিজ বিশ্লেষণের ৩টি প্রধান লক্ষ্য

১
বোঝা (Understanding): ডেটার পেছনের ঘটনাটা কী? কেন এই প্যাটার্ন দেখা যাচ্ছে?
২
মডেলিং (Modeling): ডেটাকে একটি গাণিতিক মডেলে প্রকাশ করা।
৩
পূর্বাভাস (Forecasting): ভবিষ্যতে কী হবে সেটা আগে থেকে অনুমান করা।

টাইম সিরিজের ৩টি উপাদান

যেকোনো টাইম সিরিজকে ৩টি অংশে ভেঙে দেখা যায়। এটাকে ডিকম্পোজিশন বলে।

চিত্র ১: টাইম সিরিজের তিনটি মূল উপাদান — Trend, Seasonality এবং Noise
💻 Python কোড: ৩টি উপাদান তৈরি করা
import numpy as np

# ১. Trend: একটি সরল রেখা (নিম্নমুখী)
# range(1095) মানে ১০৯৫টি দিন (প্রায় ৩ বছর)
trend = -2.2 * np.array(range(1095)) + 5

# ২. Seasonality: sin এবং cos দিয়ে পর্যায়বৃত্ত প্যাটার্ন
# 365 দিয়ে ভাগ করলে বার্ষিক চক্র হয়
period = np.array([
    160 * np.sin(2 * np.pi / 365 * x) + 80 * np.cos(2 * np.pi / 100 * x)
    for x in range(0, 1095)
])

# ৩. Noise: গড় ৩, স্ট্যান্ডার্ড ডেভিয়েশন ২ সহ র‍্যান্ডম সংখ্যা
white_noise = np.random.normal(3, 2, size=1095)
🧠 কোড বোঝার টিপস
  • np.array(range(1095)) — ০ থেকে ১০৯৪ পর্যন্ত ১০৯৫টি সংখ্যা
  • np.sin(...) / np.cos(...) — ত্রিকোণমিতির ফাংশন, ওয়েভ তৈরি করে
  • np.random.normal(mean, std, size) — গাউসিয়ান/নরমাল র‍্যান্ডম ডেটা

Additive vs Multiplicative মডেল

টাইম সিরিজ তৈরি করার দুটো উপায় আছে — উপাদানগুলোকে যোগ করবে, নাকি গুণ করবে?

চিত্র ২: Additive মডেলে ওঠানামার পরিমাণ স্থির থাকে, Multiplicative মডেলে ট্রেন্ডের সাথে সাথে ওঠানামাও বাড়ে/কমে
🔑 কোনটা ব্যবহার করবো?
  • Additive: যখন Seasonality-র পরিমাণ ট্রেন্ডের উপর নির্ভর করে না। যেমন: প্রতি গ্রীষ্মে বিক্রি ঠিক ১০০টা বাড়ে।
  • Multiplicative: যখন Seasonality ট্রেন্ডের অনুপাতে পরিবর্তিত হয়। যেমন: ব্যবসা বড় হলে বিক্রির ওঠানামাও বড় হয়।
💻 Python: দুটো মডেল একসাথে দেখানো
import matplotlib.pyplot as plt

fig, ax = plt.subplots(1, 2, figsize=(15, 4))

# Additive: শুধু যোগ করো
plt.subplot(1, 2, 1)
plt.plot(trend + period + white_noise, color="#808B96")
plt.title("Time Series: Additive Model")

# Multiplicative: গুণ করো
plt.subplot(1, 2, 2)
plt.plot(trend * (1 + period) * (1 + white_noise), color="#808B96")
plt.title("Time Series: Multiplicative Model")

plt.show()

Stationarity — স্থিতিশীলতা কী এবং কেন জরুরি?

এটা টাইম সিরিজের সবচেয়ে গুরুত্বপূর্ণ ধারণাগুলোর একটি। অনেকেই এটা নিয়ে ভয় পায়, কিন্তু আসলে সহজ।

📖 Stationarity মানে কী?
একটি সিরিজ Stationary তখনই, যখন তার গড় (Mean), ভেরিয়েন্স (Variance) এবং অটোকোভেরিয়েন্স সময়ের সাথে পরিবর্তিত হয় না — মানে এগুলো স্থির থাকে।
চিত্র ৩: Stationary সিরিজে গড় স্থির থাকে; Non-Stationary সিরিজে ট্রেন্ড থাকে

৩টি শর্ত পূরণ হলেই Stationary:

E(Xₜ) = μ     [গড় স্থির]
Var(Xₜ) = σ²    [ভেরিয়েন্স স্থির]
Cov(Xₜ, Xₜ₊ₕ) = γ(h)    [সময় নির্ভর নয়]

Augmented Dickey-Fuller (ADF) Test

গ্রাফ দেখে সবসময় বোঝা যায় না — তাই আমরা একটি statistical test ব্যবহার করি।

📊 ADF Test-এর ফলাফল বোঝার নিয়ম
  • p-value < 0.05 → সিরিজটি Stationary ✅ (null hypothesis বাতিল)
  • p-value ≥ 0.05 → সিরিজটি Non-Stationary ❌ (differencing দরকার)
💻 Python: ADF Test চালানো
from statsmodels.tsa.stattools import adfuller

# sunspots ডেটায় ADF test
_, p_value, _, _, _, _ = adfuller(sunspots)
print(p_value)  # p > 0.05 → Non-Stationary!

# সমাধান: Differencing করো
# .diff() মানে: প্রতিটি মান = বর্তমান মান - আগের মান
# .dropna() মানে: প্রথম সারিটা NaN হয়ে যায়, সেটা বাদ দাও
sunspots_diff = sunspots.diff().dropna()

# এবার আবার test করো
_, p_value, _, _, _, _ = adfuller(sunspots_diff)
print(p_value)  # p < 0.05 → এখন Stationary! ✅
🤔 Differencing কী?

যদি আমার সিরিজ হয়: [10, 12, 15, 19, 24]

Differencing-এর পর হবে: [2, 3, 4, 5] (প্রতিটি মান থেকে আগেরটা বাদ)

এতে ট্রেন্ড বাদ পড়ে যায়, সিরিজ Stationary হয়ে যায়।

AR, MA, ARMA, ARIMA মডেল — সহজ ভাষায়

চিত্র ৪: AR, MA, ARMA — সবই Stationary সিরিজের জন্য। ARIMA Non-Stationary সিরিজের জন্য।

১. AR মডেল (Autoregressive)

📖 AR মানে কী?

"Auto" মানে নিজে। "Regressive" মানে রিগ্রেশন। তাহলে AR মানে — নিজের অতীতের মানের উপর রিগ্রেশন।

সহজ কথায়: আজকের বিক্রি গত কয়েকদিনের বিক্রির উপর নির্ভর করে।

AR(p) সূত্র:

Xₜ = φ₀ + φ₁Xₜ₋₁ + φ₂Xₜ₋₂ + ... + φₚXₜ₋ₚ + εₜ

এখানে p হলো কতদিন আগের ডেটা দেখা হচ্ছে। AR(1) মানে শুধু গতকালের ডেটা ব্যবহার হয়।

২. MA মডেল (Moving Average)

📖 MA মানে কী?

এখানে Moving Average মানে সাধারণ গড় নয়! MA মানে অতীতের error (ভুল)-এর উপর নির্ভর করা।

সহজ কথায়: গতকাল যতটা "ভুল পূর্বাভাস" দিয়েছিলাম, সেটা দিয়ে আজকের পূর্বাভাস ঠিক করছি।

MA(q) সূত্র:

Xₜ = εₜ + θ₁εₜ₋₁ + θ₂εₜ₋₂ + ... + θ_qεₜ₋_q

৩. ARMA মডেল

AR + MA একসাথে। শুধু Stationary সিরিজের জন্য।

ARMA(p,q):

Xₜ = φ₀ + φ₁Xₜ₋₁ + ... + φₚXₜ₋ₚ + εₜ + θ₁εₜ₋₁ + ... + θ_qεₜ₋_q

৪. ARIMA মডেল (সবচেয়ে গুরুত্বপূর্ণ!)

ARIMA = AR + I + MA। এখানে I মানে "Integration" — অর্থাৎ Differencing।

📝 ARIMA(p, d, q) — তিনটি প্যারামিটার
প্যারামিটারমানে কীউদাহরণ
p (AR order)কতদিন আগের মান ব্যবহার করবp=2 → গত ২ দিনের মান
d (I order)কতবার differencing করতে হয়েছেd=1 → একবার differencing
q (MA order)কতদিন আগের error ব্যবহার করবq=2 → গত ২ দিনের error
💡 AIC, BIC, HQIC — সেরা p, q কীভাবে বেছে নেবো?

অনেক সম্ভাব্য (p,q) কম্বিনেশন try করে Information Criteria দিয়ে সেরাটা বেছে নেওয়া হয়। মান যত কম, মডেল তত ভালো।

Criterionকখন ব্যবহারবৈশিষ্ট্য
AICPredictive models-এর জন্যজটিল মডেল পছন্দ করে
BICExplanatory models-এর জন্যসরল মডেল পছন্দ করে
HQICদুটোর মাঝামাঝিব্যালেন্সড

ACF ও PACF গ্রাফ — p এবং q এর মান বোঝার উপায়

চিত্র ৫: ACF থেকে q এবং PACF থেকে p নির্ধারণ করার নিয়ম
💻 Python: ACF ও PACF প্লট
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

plt.figure(figsize=(12, 6))

# ACF Plot (q নির্ধারণের জন্য)
plt.subplot(1, 2, 1)
plot_acf(sunspots_diff, lags=40, ax=plt.gca())
plt.title('ACF — q বোঝার জন্য')

# PACF Plot (p নির্ধারণের জন্য)
plt.subplot(1, 2, 2)
plot_pacf(sunspots_diff, lags=40, ax=plt.gca())
plt.title('PACF — p বোঝার জন্য')

plt.tight_layout()
plt.show()

হাতে-কলমে: Sunspots ডেটাসেট দিয়ে ARIMA

💻 সম্পূর্ণ ARIMA workflow — ধাপে ধাপে
import itertools
from statsmodels.tsa.arima.model import ARIMA

# ধাপ ১: ডেটা লোড
sunspots = pd.read_csv('sunspots.csv')
sunspots = sunspots.set_index('Date')
sunspots.index = pd.to_datetime(sunspots.index)

# ধাপ ২: সব (p,d,q) কম্বিনেশন try করো
p = range(0, 6)  # 0 থেকে 5
q = range(0, 6)
d = [1]  # একবার differencing করেছিলাম

pdq = list(itertools.product(p, d, q))

# ধাপ ৩: BIC দিয়ে সেরা মডেল বেছে নাও
best_bic = float("inf")
best_model = None

for order in pdq:
    try:
        model = ARIMA(sunspots['SUNACTIVITY'], order=order).fit()
        if model.bic < best_bic:
            best_bic = model.bic
            best_model = model
    except:
        continue

# ধাপ ৪: পূর্বাভাস করো
pred = best_model.get_prediction(start='1990', end='2012', typ='levels')
pred_mean = pred.predicted_mean
⚠️ ARIMA-র সীমাবদ্ধতা
  • দূর ভবিষ্যতের পূর্বাভাস দুর্বল — সময়ের সাথে গড়ের দিকে চলে যায়
  • Seasonal pattern থাকলে SARIMA ভালো
  • Stock price-এর মতো unpredictable ডেটায় কাজ করে না

ডাইমেনশনালিটি রিডাকশন কেন দরকার?

ধরো তোমার কাছে একটা ডেটাসেট আছে যেখানে প্রতিটি ছবির ৭৮৪টি pixel আছে (28×28)। প্রতিটি pixel একটি ফিচার। তাহলে তোমার ডেটা আছে ৭৮৪ মাত্রায় (dimension)!

😱 "Curse of Dimensionality" — উচ্চ মাত্রার সমস্যা
  • মাত্রা বেশি হলে মডেল ট্রেইন করতে অনেক সময় লাগে
  • ৩+ মাত্রা ভিজুয়ালাইজ করা অসম্ভব
  • অনেক ফিচার আসলে একই তথ্য বহন করে (redundant)
  • Overfitting-এর ঝুঁকি বাড়ে
✅ সমাধান: Dimensionality Reduction

৭৮৪টি ফিচার থেকে সবচেয়ে গুরুত্বপূর্ণ তথ্য বজায় রেখে মাত্র ২-৩টি নতুন ফিচারে নামিয়ে আনা।

চিত্র ৬: ৭৮৪ মাত্রার ডেটা ২ মাত্রায় নামিয়ে আনলে cluster দৃশ্যমান হয়

PCA — Principal Component Analysis

মূল ধারণাটা বোঝার জন্য একটা উদাহরণ

ধরো তুমি একটা ৩D বস্তুর ছায়া দেওয়ালে ফেলছো। দেওয়ালটা ২D। এমনভাবে আলো ধরো যাতে ছায়ায় বস্তুর সবচেয়ে বেশি তথ্য বোঝা যায়। PCA ঠিক এই কাজটাই করে — সবচেয়ে "informative" অভিক্ষেপ (projection) খোঁজে।

চিত্র ৭: PCA সেই অক্ষ খোঁজে যেখানে Variance (ছড়ানো) সবচেয়ে বেশি — এতে সবচেয়ে বেশি তথ্য থাকে

PCA হাতে-কলমে: Chocolate ডেটাসেট

🍫 প্রেক্ষাপট

একটি চকলেট কোম্পানির ২৯ জন বিশেষজ্ঞ ৬টি চকলেট টেস্ট করেছে। প্রতিটি চকলেটকে ১৪টি গুণমান (CocoaA, MilkF, Sweetness, Bitterness...) দিয়ে ১-১০ স্কেলে রেট দেওয়া হয়েছে। আমরা PCA দিয়ে দেখব কোন চকলেট একই রকম, কোনটা আলাদা।

💻 ধাপে ধাপে Python কোড
# ধাপ ১: ডেটা লোড এবং দেখা
df = pd.read_csv('chocolat.csv')
df['Panelist'] = df['Panelist'].astype(str)
display(df.head())

# ধাপ ২: ANOVA test — প্রতিটি attribute-এ significant difference আছে কিনা
import statsmodels.api as sm
from statsmodels.formula.api import ols

attributes = df.iloc[:,4:].columns
results = {}

for attr in attributes:
    lm = ols(f'{attr} ~ Panelist + Product', data=df).fit()
    table = sm.stats.anova_lm(lm)
    results[attr] = table['PR(>F)'].iloc[:2].to_list()
    # p < 0.05 মানে Product ও Panelist উভয়ই attribute-কে প্রভাবিত করছে

# ধাপ ৩: চকলেট ভিত্তিক গড় নিই
choco = df.drop(['Panelist','Session','Rank'], axis=1)
choco = choco.groupby(['Product']).mean()

# ধাপ ৪: PCA চালানো (prince library)
import prince

pca = prince.PCA(n_components=2)  # 14D → 2D
pca = pca.fit(choco)

# ধাপ ৫: প্রতিটি চকলেটের 2D কোঅর্ডিনেট পাই
row_coords = pca.row_coordinates(choco)

# ধাপ ৬: বিন্দুচিত্র (scatter plot) আঁকি
fig, ax = plt.subplots()
ax.scatter(row_coords[0], row_coords[1])

for i, label in enumerate(choco.index):
    ax.annotate(label, (row_coords.iloc[i, 0], row_coords.iloc[i, 1]))

ax.set_xlabel('Dimension 1 (PC1)')
ax.set_ylabel('Dimension 2 (PC2)')
plt.show()
চিত্র ৮: PCA-র Individuals Graph — choc1 ও choc3 PC1 অক্ষে একে অপরের বিপরীতে, choc2 ও choc5 একই রকম

🔍 Correlation Circle বোঝার নিয়ম
  • ডানদিকে arrow → PC1-এর সাথে positive correlation
  • বামদিকে arrow → PC1-এর সাথে negative correlation
  • উপরে arrow → PC2-এর সাথে positive correlation
  • দীর্ঘ arrow → ঐ PC-টি সেই variable ভালোভাবে ব্যাখ্যা করছে
  • একই দিকের arrows → ঐ variables পরস্পর correlated

UMAP — যখন PCA যথেষ্ট নয়

❌ PCA কখন ব্যর্থ হয়?
  • যখন ডেটার মধ্যে non-linear সম্পর্ক আছে
  • যখন ডেটায় outlier (অতিরিক্ত দূরবর্তী মান) থাকে
  • ছবির মতো জটিল ডেটায় PCA cluster ভালো করে ধরতে পারে না
✅ UMAP কী?

UMAP = Uniform Manifold Approximation and Projection

UMAP উচ্চ মাত্রার ডেটার স্থানীয় কাঠামো (local neighborhood) সংরক্ষণ করে কম মাত্রায় নামিয়ে আনে। কাছের বিন্দু কাছেই থাকে, দূরের বিন্দু দূরেই থাকে।

চিত্র ৯: UMAP ৩টি ধাপে কাজ করে — প্রতিবেশী চিহ্নিত, অপটিমাইজ, ২D আউটপুট

UMAP হাতে-কলমে: Fashion MNIST

👗 Fashion MNIST কী?

Zalando-র ৬০,০০০টি পোশাকের ছবি। প্রতিটি ছবি 28×28 = 784 pixel। প্রতিটি pixel একটি feature। ১০টি category: T-shirt, Pants, Sweater, Dress, Coat, Sandal, Shirt, Sneakers, Bag, Boots।

💻 UMAP কোড — সম্পূর্ণ
import pandas as pd
import umap
import umap.plot
import matplotlib.pyplot as plt

# ধাপ ১: ডেটা লোড
df = pd.read_csv('fashion-mnist_train.csv')
target = df['label']         # 0-9 class label
data = df.drop('label', axis=1)  # 784 pixel values

# ধাপ ২: প্রথম ছবিটা দেখো
img = data.iloc[0]
img = np.array(img).reshape((28, 28))  # 784 → 28x28
plt.imshow(img, cmap='gray')

# ধাপ ৩: UMAP চালাও
umap_model = umap.UMAP(
    n_neighbors=15,   # কতজন প্রতিবেশী দেখব (বড় = global structure)
    min_dist=0.1,     # বিন্দুগুলো কতটা কাছে আসতে পারবে
    n_components=2    # 784D → 2D
)
embedding = umap_model.fit_transform(data)
# embedding.shape = (60000, 2) — প্রতিটি ছবির 2D coordinate

# ধাপ ৪: ফলাফল দেখাও (রঙ = label)
plt.figure(figsize=(10, 8))
plt.scatter(embedding[:, 0], embedding[:, 1], c=target, s=0.5)
plt.title("UMAP: Fashion MNIST")
plt.colorbar()
plt.show()

# ধাপ ৫: উন্নত visualization (umap.plot ব্যবহার করে)
mapper = umap.UMAP(n_neighbors=15, min_dist=0.1).fit(data)
umap.plot.points(mapper, labels=target)

SHAP — আধুনিক সমাধান

⭐ SHAP কী?

SHAP = SHapley Additive exPlanations

SHAP মূলত Game Theory থেকে Shapley Value-এর ধারণা ব্যবহার করে প্রতিটি feature-এর অবদান মাপে।

চিত্র ১১: SHAP গেম থিওরি ব্যবহার করে প্রতিটি feature-কে একজন "খেলোয়াড়" হিসেবে বিবেচনা করে

SHAP হাতে-কলমে: Titanic ডেটাসেট

💻 সম্পূর্ণ কোড: ডেটা থেকে SHAP পর্যন্ত
import pandas as pd
import xgboost as xgb
import shap
from sklearn.model_selection import train_test_split

# ধাপ ১: ডেটা লোড ও প্রস্তুত
df = pd.read_csv('titanic.csv')

X = df[['Sex', 'Pclass', 'Fare', 'Age']].copy()
y = df['Survived']

# Sex কলাম: male=1, female=0
X.Sex = X.Sex.apply(lambda x: 1 if x == 'male' else 0)

# Missing value বাদ দাও
X = X.dropna()
y = y[X.index]

# ধাপ ২: Train-Test split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# ধাপ ৩: XGBoost মডেল ট্রেইন (powerful কিন্তু black box!)
model = xgb.XGBClassifier()
model.fit(X_train, y_train)

# ধাপ ৪: SHAP Explainer তৈরি করো
# TreeExplainer → Tree-based মডেলের জন্য দ্রুত
explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X)
# shap_values.shape = (n_samples, n_features)
# প্রতিটি sample-এর জন্য প্রতিটি feature-এর SHAP value

# ধাপ ৫: Global importance (Bar Plot)
shap.summary_plot(shap_values, X, plot_type='bar')

# ধাপ ৬: Detailed summary plot
shap.summary_plot(shap_values, X)

# ধাপ ৭: Dependence plot (একটি feature কীভাবে কাজ করছে)
shap.dependence_plot('Age', shap_values, X, interaction_index='Pclass')

# ধাপ ৮: Local explanation (একটি নির্দিষ্ট যাত্রী)
shap.initjs()  # JavaScript visualization চালু
shap.force_plot(explainer.expected_value, shap_values[1, :], X.iloc[1, :])

  • 💰 বেশি ভাড়া দেওয়া → সম্ভাবনা বাড়ায়
  • 👴 বয়স্ক হওয়া → সম্ভাবনা কমায়
  • ইতিহাস জানি: "Women and children first" — SHAP এটাই confirm করছে!

৩. Force Plot — একজন ব্যক্তির জন্য Local Explanation

💻 Force Plot কোড ও ব্যাখ্যা
# একটি নির্দিষ্ট যাত্রীর (index=1) prediction ব্যাখ্যা
shap.initjs()
shap.force_plot(
    explainer.expected_value,  # baseline (সব যাত্রীর গড় prediction)
    shap_values[1, :],          # এই যাত্রীর SHAP values
    X.iloc[1, :]               # এই যাত্রীর actual feature values
)
🔍 Force Plot বোঝা
  • লাল তীর (→): এই feature prediction বাড়াচ্ছে
  • নীল তীর (←): এই feature prediction কমাচ্ছে
  • Base value + সব SHAP = final prediction
  • উদাহরণ: Pclass=1 ✅, Sex=female ✅, Fare=71 ✅, Age=38 ❌

৪. Dependence Plot — একটি feature কীভাবে কাজ করছে?

💻 Dependence Plot
# Age feature কীভাবে survival-কে প্রভাবিত করছে?
# interaction_index='Pclass' → Pclass দিয়ে রঙ করা হবে
shap.dependence_plot('Age', shap_values, X, interaction_index='Pclass')

# এই গ্রাফ থেকে দেখা যাবে:
# - X-axis: Age value
# - Y-axis: Age-এর SHAP value (ধনাত্মক = বেঁচে থাকায় সাহায্য করেছে)
# - রঙ: Pclass (লাল = 1st, নীল = 3rd)
# 
# সিদ্ধান্ত: তরুণ যাত্রীরা positive SHAP পায়, বিশেষত 1st class-এ।
# বয়স বাড়লে SHAP কমে, বিশেষত 3rd class-এ আরও বেশি।
