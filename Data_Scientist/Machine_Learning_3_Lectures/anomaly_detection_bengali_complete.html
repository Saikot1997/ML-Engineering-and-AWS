Q1 Anomaly Detection কী এবং এটা supervised নাকি unsupervised?
উত্তর: Anomaly Detection হলো ডেটার মধ্যে অস্বাভাবিক pattern খোঁজার প্রক্রিয়া। এটা দুটোই হতে পারে। Supervised হলে — labeled data থাকে (fraud/not fraud)। Unsupervised হলে — কোনো label নেই, শুধু pattern দেখে anomaly ধরে। বাস্তবে বেশিরভাগ ক্ষেত্রে unsupervised ব্যবহার হয় কারণ labeled fraud data পাওয়া কঠিন।
Q2 Class imbalance কী? Anomaly detection-এ কেন গুরুত্বপূর্ণ?
উত্তর: Class imbalance মানে হলো ডেটাতে একটা class অনেক বেশি (যেমন ৯৯% normal, মাত্র ১% fraud)। এই কারণে model সব কিছুকেই "normal" বলতে শিখে নেয়, কারণ তাতেই accuracy ৯৯% হয়! তাই accuracy দিয়ে model মাপা ঠিক না — বরং Precision, Recall, F1, ROC-AUC, MCC ব্যবহার করতে হয়।
Q3 Outlier এবং Anomaly কি একই জিনিস?
উত্তর: প্রায় একই, কিন্তু সূক্ষ্ম পার্থক্য আছে। Outlier হলো statistical term — ডেটার distribution থেকে দূরে থাকা point। Anomaly হলো domain-specific — যা context অনুযায়ী সন্দেহজনক। উদাহরণ: কারো height ৭ ফুট হওয়া outlier কিন্তু anomaly নয়। কিন্তু রাত ৩টায় ৫০,০০০ টাকা তোলা — এটা fraud anomaly।

Supervised vs Unsupervised

🧒 Kindergarten Explanation

Supervised Learning = তোমার মা তোমাকে আম দেখিয়ে বলে "এটা আম", কমলা দেখিয়ে বলে "এটা কমলা"। তুমি এই উদাহরণ দেখে শিখো। → Teacher আছে, label আছে।

Unsupervised Learning = মা কিছু বলেনি, তুমি নিজেই ফলগুলো দেখে বুঝলে যে কিছু গোলাকার-হলুদ, কিছু লম্বা-সবুজ। গ্রুপ করে ফেললে। → Teacher নেই, নিজে pattern খোঁজে।

বৈশিষ্ট্য Supervised Unsupervised
Label দরকার? ✅ হ্যাঁ (fraud/not fraud) ❌ না
Performance সাধারণত ভালো (KNN এর মতো) তুলনামূলক কম নির্ভরযোগ্য
কখন ব্যবহার যখন labeled data আছে যখন label নেই বা পাওয়া কঠিন
উদাহরণ Algorithm KNN, Random Forest, XGBoost DBSCAN, LOF, Isolation Forest, VAE
বাস্তব সমস্যা Labeled data পাওয়া কঠিন Accuracy কম হতে পারে
⚠️ গুরুত্বপূর্ণ কথা

এই module-এ KNN সেরা performance দিয়েছে কারণ এটা supervised — training data-এর label জানে। অন্য সব model (DBSCAN, LOF, Robust Covariance) unsupervised। তাই KNN-এর সাথে তুলনা করা সব সময় সঠিক না।

DBSCAN — Density-Based Clustering

📌 Full Form

Density-Based Spatial Clustering of Applications with Noise

🧒 Kindergarten Explanation

ধরো একটা বড় মাঠে মানুষ দাঁড়িয়ে আছে। কিছু মানুষ একসাথে গুচ্ছ হয়ে দাঁড়িয়ে, কিছু একা একা। DBSCAN বলবে — "যেখানে অনেক মানুষ কাছাকাছি আছে, সেটা একটা group বা cluster"। আর যে একা দাঁড়িয়ে, সে হলো Noise — মানে সে কোনো group-এ পড়েনি।

Anomaly detection-এ এই Noise points-ই আমাদের সন্দেহজনক/outlier!

DBSCAN-এর দুটো Parameter

📏 Epsilon (ε)

প্রতিটা point-এর চারদিকে একটা বৃত্ত আঁকো। এই বৃত্তের radius হলো epsilon।

ε ছোট = অনেক cluster, অনেক noise
ε বড় = কম cluster, সব মিলে যায়

🔢 minPoints

বৃত্তের ভেতরে কমপক্ষে কতটা point থাকলে সেটা "core" বলে ধরা হবে।

Rule: minPoints ≥ dimension + 1
সাধারণত = 2 × dimension

// DBSCAN: Core Point, Border Point, Noise

তিন ধরনের Point

🔵 Core Point

ε-radius-এর ভেতরে কমপক্ষে minPoints আছে। এটা cluster-এর কেন্দ্র।

🟣 Border Point

ε-radius-এর ভেতরে minPoints-এর কম আছে, কিন্তু কোনো Core Point-এর কাছে আছে।

🔴 Noise Point

কোনো cluster-এ পড়েনি। DBSCAN এটাকে -1 label দেয়। এটাই আমাদের Anomaly!

🚨 গুরুত্বপূর্ণ — DBSCAN Output

DBSCAN outlier-কে -1 দেয়। তাই কোড-এ: y_pred[y_pred == -1] = 1 → -1 মানে fraud (1) হিসেবে ধরো।

# Step 1: Library import করো
import pandas as pd
import numpy as np
from sklearn.cluster import DBSCAN
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report, confusion_matrix
from sklearn.metrics import roc_auc_score, matthews_corrcoef

# Step 2: Data load করো
df = pd.read_csv("creditcard.csv")

# Step 3: Amount ও Time normalize করো [-1, 1] এর মধ্যে
df['Vamount'] = StandardScaler().fit_transform(df['Amount'].values.reshape(-1, 1))
df['Vtime'] = StandardScaler().fit_transform(df['Time'].values.reshape(-1, 1))

# পুরানো column সরিয়ে দাও
df = df.drop(['Time', 'Amount'], axis=1)

# Step 4: Missing value সরাও
df = df.dropna()

# Step 5: X (features) এবং y (target) আলাদা করো
X = df.drop('Class', axis=1)
y = df['Class']

# Step 6: DBSCAN model তৈরি করো
# eps=0.4 → বৃত্তের radius
# min_samples=15 → কমপক্ষে ১৫টা point দরকার core হতে
model = DBSCAN(eps=0.4, min_samples=15)

# Step 7: Model train করো (fit করো)
model.fit(X.values)

# Step 8: Prediction নাও
y_pred = model.labels_.copy()

# DBSCAN -1 দেয় outlier-এর জন্য → আমরা এটাকে 1 (fraud) বানাই
y_pred[y_pred == -1] = 1   # -1 → fraud
y_pred[y_pred != 1] = 0   # বাকি সব → normal

# Step 9: Performance দেখো
print(f"Accuracy: {accuracy_score(y, y_pred):.4f}")
print(classification_report(y, y_pred))

# Step 10: বিস্তারিত metrics
print("Confusion Matrix:\n", confusion_matrix(y, y_pred))
print("ROC-AUC:", roc_auc_score(y, y_pred))
print("MCC:", matthews_corrcoef(y, y_pred))

E2 একটা DBSCAN pipeline তৈরি করো যেখানে: preprocessing → DBSCAN → evaluation → confusion matrix plot সব একসাথে থাকবে।
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.cluster import DBSCAN
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import (confusion_matrix, classification_report,
                              roc_auc_score, matthews_corrcoef, accuracy_score)

def dbscan_anomaly_pipeline(df, target_col='Class', eps=0.4, min_samples=15):
    """
    Complete DBSCAN Anomaly Detection Pipeline
    ---
    df: input DataFrame
    target_col: label column name
    eps: DBSCAN epsilon
    min_samples: DBSCAN minimum points
    """
    # 1. Preprocessing
    scaler = StandardScaler()
    X = df.drop(target_col, axis=1).dropna()
    y = df[target_col].dropna()
    X_scaled = scaler.fit_transform(X)

    # 2. DBSCAN fit
    model = DBSCAN(eps=eps, min_samples=min_samples, n_jobs=-1)
    labels = model.fit_predict(X_scaled)

    # 3. Convert labels: -1 → 1 (anomaly), rest → 0 (normal)
    y_pred = np.where(labels == -1, 1, 0)

    # 4. Metrics
    print("=" * 50)
    print(f"Epsilon: {eps}, MinSamples: {min_samples}")
    print(f"Clusters found: {len(set(labels)) - (1 if -1 in labels else 0)}")
    print(f"Noise points (anomalies): {(labels == -1).sum()}")
    print("=" * 50)
    print(f"Accuracy:  {accuracy_score(y, y_pred):.4f}")
    print(f"ROC-AUC:   {roc_auc_score(y, y_pred):.4f}")
    print(f"MCC:       {matthews_corrcoef(y, y_pred):.4f}")
    print(classification_report(y, y_pred, target_names=['Normal','Fraud']))

    # 5. Plot confusion matrix
    cm = confusion_matrix(y, y_pred)
    plt.figure(figsize=(6, 5))
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
                xticklabels=['Normal','Fraud'],
                yticklabels=['Normal','Fraud'])
    plt.title(f'DBSCAN Confusion Matrix (ε={eps})')
    plt.ylabel('Actual'); plt.xlabel('Predicted')
    plt.tight_layout()
    plt.show()

    return y_pred, model

Variational Auto-Encoder (VAE)

🧒 Kindergarten Explanation — Auto-Encoder কী?

ধরো তোমার কাছে একটা ছবি আছে — একটা বিড়ালের। তুমি এই ছবি একটা কাগজে এঁকে সেটা ভাঁজ করে ছোট করলে (compress), তারপর আবার খুলে দেখলে বিড়ালটা আছে কিনা।

Encoder = ছবি compress করা (বড় → ছোট)
Latent Space = compress করা ছোট version
Decoder = আবার বড় করা (ছোট → বড়)

যদি বিড়ালটা ঠিকমতো ফেরত না আসে — মানে decoder ঠিকমতো reconstruct করতে পারেনি — সেটাই Anomaly!

VAE vs AE — পার্থক্য কী?

বিষয় Auto-Encoder (AE) Variational AE (VAE)
Latent Space Fixed point (deterministic) Distribution (μ এবং σ শেখে)
Sampling নেই z = μ + σ × ε, যেখানে ε ~ N(0,I)
নতুন Data Generate সীমিত করতে পারে (generative model)

import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# VAE Architecture সংজ্ঞায়িত করো
class VAE(nn.Module):
    def __init__(self, input_dim=30, latent_dim=10):
        super(VAE, self).__init__()
        
        # Encoder: input → latent distribution parameters
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU()
        )
        
        # Mean (μ) এবং log-variance (log σ²) আলাদা layer
        self.fc_mu = nn.Linear(32, latent_dim)
        self.fc_logvar = nn.Linear(32, latent_dim)
        
        # Decoder: latent z → reconstructed output
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 32),
            nn.ReLU(),
            nn.Linear(32, 64),
            nn.ReLU(),
            nn.Linear(64, input_dim),
            nn.Sigmoid()    # output [0,1] range
        )
    
    def reparameterize(self, mu, logvar):
        """
        Reparameterization trick:
        z = μ + σ * ε, যেখানে ε ~ N(0, I)
        এটা দরকার কারণ sampling differentiable না,
        কিন্তু এভাবে করলে backprop হয়।
        """
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)    # ε ~ N(0, I)
        return mu + eps * std
    
    def forward(self, x):
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        z = self.reparameterize(mu, logvar)
        x_recon = self.decoder(z)
        return x_recon, mu, logvar

# VAE Loss Function (Reconstruction Loss + KL Divergence)
def vae_loss(x_recon, x, mu, logvar):
    # Reconstruction loss: কতটা ভালো reconstruct হলো
    recon_loss = nn.functional.mse_loss(x_recon, x, reduction='sum')
    # KL Divergence: latent distribution কতটা N(0,I) এর কাছাকাছি
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + kl_loss

# Anomaly Score বের করো
def anomaly_score(model, x_tensor):
    model.eval()
    with torch.no_grad():
        x_recon, mu, logvar = model(x_tensor)
        # Per-sample reconstruction error
        scores = torch.mean((x_tensor - x_recon)**2, dim=1)
    return scores.numpy()

# Threshold দিয়ে anomaly ধরো
def predict_anomaly(scores, threshold=0.02):
    return (scores > threshold).astype(int)  # 1=anomaly, 0=normal

from sklearn.metrics import f1_score, precision_recall_curve
import numpy as np

def find_optimal_threshold(model, X_val, y_val):
    """
    Validation set দিয়ে F1 maximize করা threshold খোঁজো
    """
    scores = anomaly_score(model, torch.tensor(X_val, dtype=torch.float32))

    # Precision-Recall curve থেকে optimal threshold
    precisions, recalls, thresholds = precision_recall_curve(y_val, scores)
    f1_scores = 2 * (precisions * recalls) / (precisions + recalls + 1e-8)
    optimal_idx = np.argmax(f1_scores)
    optimal_threshold = thresholds[optimal_idx]

    print(f"Optimal Threshold: {optimal_threshold:.5f}")
    print(f"At this threshold — Precision: {precisions[optimal_idx]:.4f}, "
          f"Recall: {recalls[optimal_idx]:.4f}, "
          f"F1: {f1_scores[optimal_idx]:.4f}")

    return optimal_threshold

Local Outlier Factor (LOF)
Unsupervised Density-based
🧒 Kindergarten

LOF প্রতিটা point-কে জিজ্ঞেস করে: "তোমার প্রতিবেশীরা কতটা ঘন করে বাস করে, আর তুমি নিজে কতটা ঘন এলাকায় আছো?" যদি সবার প্রতিবেশীরা ঘন এলাকায় থাকে, কিন্তু তুমি একা পড়ে আছো — তুমিই outlier!

LOF Score: score > 1 মানে outlier। যত বড়, তত বেশি outlier।

সূত্র: LOF(p) = avg(lrd(neighbor)) / lrd(p)

lrd = local reachability density

✅ সুবিধা

Local density দেখে — global threshold দরকার নেই। Different density-র cluster-এও কাজ করে।

Q1 Fraud detection-এ Accuracy ব্যবহার না করে কোন metric ব্যবহার করবো? কেন?
কেন Accuracy ব্যর্থ: ধরো ১০০টা transaction-এর মধ্যে ১টা fraud। সব কিছুকে "normal" বললেই Accuracy = ৯৯%! কিন্তু model কিছুই detect করেনি।

ভালো Metrics:
🔹 Precision = "যাদের fraud বলেছি, তাদের মধ্যে আসলে কতজন fraud?" → False Alarm কমাও
🔹 Recall = "মোট fraud-এর মধ্যে কতটা ধরা পড়েছে?" → Miss কমাও
🔹 F1 Score = Precision ও Recall এর harmonic mean
🔹 ROC-AUC = Different threshold-এ model কেমন করে তার সার্বিক চিত্র
🔹 MCC = Matthews Correlation Coefficient — imbalanced class-এ সবচেয়ে reliable single metric
Q2 ROC-AUC = 0.5 মানে কী? DBSCAN-এ এটা কেন হলো?
ROC-AUC = 0.5 মানে model যদি মুদ্রা ছুঁড়ে সিদ্ধান্ত নিতো (Random guess), তাহলেও এতটুকুই পেতো! মানে model কোনো useful pattern শেখেনি।

ROC-AUC = 1.0 → Perfect
ROC-AUC = 0.5 → Random
ROC-AUC < 0.5 → উল্টো predict করছে (label flip করলে better হবে)

DBSCAN-এ কেন এটা হলো: Creditcard dataset high-dimensional (30 features)। High dimension-এ Euclidean distance এর মানে হারিয়ে যায় (curse of dimensionality)। তাই density-based DBSCAN কাজ করে না।
Q3 MCC (Matthews Correlation Coefficient) কী? কখন ব্যবহার করবো?
MCC = একটাই নম্বর দিয়ে বলে model কতটা ভালো — TP, TN, FP, FN সব কিছু consider করে।

Range: -1 থেকে +1
🔹 MCC = +1 → Perfect prediction
🔹 MCC = 0 → Random prediction
🔹 MCC = -1 → সম্পূর্ণ উল্টো prediction

কখন ব্যবহার করবো: যখন class imbalanced (যেমন ৯৯% normal, ১% fraud)। F1 শুধু positive class দেখে, কিন্তু MCC দুটো class-ই সমান গুরুত্ব দিয়ে দেখে।
Q4 Production-এ কোন anomaly detection model deploy করবো? Decision making framework বলো।
Decision Framework:

✅ Labeled data আছে? → KNN, XGBoost, Random Forest (Supervised)
✅ Labeled data নেই + Speed দরকার? → Isolation Forest
✅ Data Gaussian distributed? → Robust Covariance
✅ Local density pattern আছে? → LOF
✅ Complex temporal/image data? → VAE বা Autoencoder
✅ Spatial clustering করতে হবে? → DBSCAN

Real Production Strategy: কোনো universal best নেই! একাধিক model train করো, validation set-এ compare করো, F1/MCC/ROC-AUC দেখে সেরাটা বাছো।
Q5 Undercomplete vs Overcomplete autoencoder কী? কোনটা কখন ব্যবহার করবো?
Undercomplete: Latent dimension < Input dimension। Bottleneck থাকে → model compress করতে বাধ্য → শুধু গুরুত্বপূর্ণ feature শেখে।
→ Anomaly detection-এ এটা বেশি ব্যবহার হয়।

Overcomplete: Latent dimension > Input dimension। Compress করে না → সহজে copy করতে পারে → regularization ছাড়া কাজ করে না।
→ Sparse autoencoder বা denoising autoencoder-এর সাথে ব্যবহার হয়।

Anomaly detection-এর জন্য → Undercomplete বেছে নাও।

    results.append(evaluate_model("LOF", y_test, lof_pred, lof_score))
    
    # 4. Robust Covariance
    rc = EllipticEnvelope(contamination=0.01, random_state=42)
    rc.fit(X_train)
    rc_pred = (rc.predict(X_test) == -1).astype(int)
    rc_score = rc.mahalanobis(X_test)
    results.append(evaluate_model("Robust Covariance", y_test, rc_pred, rc_score))
    
    # 5. DBSCAN
    dbscan = DBSCAN(eps=0.4, min_samples=15, n_jobs=-1)
    dbscan.fit(X_test)  # DBSCAN transductive, test-এই fit করতে হয়
    db_pred = np.where(dbscan.labels_ == -1, 1, 0)
    results.append(evaluate_model("DBSCAN", y_test, db_pred))
    
    return pd.DataFrame(results).sort_values('MCC', ascending=False)

d = √Σ(xᵢ−yᵢ)²

d = (Σ|xᵢ−yᵢ|ᵖ)^(1/p)

d = Σ|xᵢ−yᵢ|

Q1 KNN-কে "lazy learner" বলা হয় কেন?
উত্তর: KNN training-এর সময় কোনো কাজ করে না! শুধু data মনে রাখে। Prediction-এর সময় সব কাজ হয় — প্রতিটা prediction-এ পুরো training set-এর সাথে distance হিসাব করতে হয়। তাই "lazy" — train করে না, inference-এ সব করে। এটা training fast কিন্তু prediction slow করে।
Q2 K-এর মান কীভাবে choose করবে? Odd K কেন better?
উত্তর: Cross-validation দিয়ে সেরা K খোঁজো। Odd K ভালো কারণ binary classification-এ tie হওয়ার সম্ভাবনা নেই — K=4 তে 2-2 tie সম্ভব কিন্তু K=3 বা K=5-এ না। Starting point হিসেবে K=√n (training data size-এর square root) ব্যবহার করো।
Q3 KNN-এ কেন feature normalization আবশ্যক?
উত্তর: KNN distance-based। ধরো Age: 0–100, Salary: 0–100,000। Distance হিসাব করলে Salary সব dominate করবে — Age-এর কোনো প্রভাব থাকবে না। StandardScaler বা MinMaxScaler দিয়ে normalize করলে সব feature সমান weight পায়।
Q4 Imbalanced data-তে accuracy কেন misleading? কী ব্যবহার করবে?
উত্তর: ৯৯.৮% Normal data-তে model সব কিছুকে Normal বললেও accuracy ৯৯.৮%! কিন্তু fraud detection একেবারে fail। তাই ব্যবহার করো: Recall (fraud কতটা ধরলো), Precision (false alarm কম কিনা), F1-Score, ROC-AUC, MCC Score।
Q5 KNN-এর computational complexity কত? Large data-তে কী করবে?
উত্তর: Prediction: O(n×d) — n=training size, d=features। ১০ মিলিয়ন rows-এ প্রতিটা prediction-এ ১০ মিলিয়নবার distance। সমাধান: algorithm='kd_tree' বা 'ball_tree' — এগুলো O(log n) এ nearest neighbor খোঁজে। অথবা Approximate Nearest Neighbor (FAISS) ব্যবহার করো।

LOF Model — Local Outlier Factor

🎯 এক লাইনে LOF

LOF বলে: "তুমি তোমার পাড়ার সাথে মিলছো কিনা?" — Global outlier না, local outlier ধরে। Unsupervised।

🧒 শিশুদের মতো করে বুঝি

একটা শহরে দুটো পাড়া। পাড়া-A: ধনী, সবাই গাড়ি চালায়। পাড়া-B: গরিব, সবাই রিকশায় চলে। এখন পাড়া-B-তে একজন হেলিকপ্টারে চলে — সে তার local পাড়ার তুলনায় অদ্ভুত, সে হলো local outlier!

LOF ঠিক এটাই করে। প্রতিটা data point-কে তার neighborhood-এর সাথে তুলনা করে। আশেপাশের থেকে অনেক আলাদা হলে → LOF score বেশি → Anomaly!

lof = LocalOutlierFactor(
    n_neighbors=10,         # ১০ জন প্রতিবেশী

    contamination=0.002      # ~০.২% fraud

y_pred[y_pred==1]  = 0

Q1 LOF এবং KNN-এর মূল পার্থক্য কী?
উত্তর: KNN = supervised (labeled data লাগে), classification করে (কোন class?)। LOF = unsupervised (no labels), outlier score দেয় (কতটা অদ্ভুত?)। KNN majority vote করে, LOF local density compare করে।

উত্তর: Global outlier = পুরো dataset-এর তুলনায় extreme (mean থেকে ৩σ)। Local outlier = শুধু তার নিজের পাড়ার (neighborhood) তুলনায় extreme। LOF-এর বিশেষত্ব: globally normal কিন্তু locally outlier — এটা ধরতে পারে। ঘন cluster-এর মাঝে ফাঁকা জায়গায় থাকা point local outlier।

উত্তর (PDF থেকে সরাসরি):
১. Normal point-এর কাছে neighbor না থাকলে সেটাকেও anomaly মনে করে
২. O(n²) — large dataset-এ অনেক slow
৩. High dimensions-এ সব distance similar → score interpret কঠিন
৪. Threshold নেই — কতটা বেশি হলে outlier, domain-specific
Real-time fraud detection-এ LOF rarely ব্যবহার হয়।
Q4 LOF-এ PCA কেন ব্যবহার করলাম? Tradeoff কী?
উত্তর: LOF-এর O(n²) complexity + ২৮ features + ২৮৪,৮০৭ rows = অসম্ভব slow। PCA দিয়ে ২৮→২ features করলে দ্রুত। Tradeoff: কিছু information হারায়, accuracy কমে। এটাই LOF vs KNN performance gap-এর কারণ।

Robust Covariance — Elliptic Envelope

🎯 এক লাইনে Robust Covariance

ডেটাকে একটা ellipse (ডিমের আকার)-এ আঁটানোর চেষ্টা করে। এর বাইরে যে পড়ে → Anomaly! Mahalanobis distance ব্যবহার করে।

🧒 শিশুদের মতো করে বুঝি

তুমি একটা মাঠে ৯৮টা ফুটবল এবং ২টা cricket ball ছুঁড়লে। ফুটবলগুলো একটা ellipse (ডিমের মতো এলাকা)-তে পড়বে। Cricket ball দুটো সেই ellipse-এর বাইরে পড়বে! Robust Covariance এই ellipse তৈরি করে। বাইরের জিনিস = Anomaly!

Mahalanobis Distance = "ডিমের কেন্দ্র থেকে কতটা দূরে" — কিন্তু ডেটার shape (covariance) অনুযায়ী adjust করা।

// Elliptic Envelope — Normal vs Outlier
📐 Mahalanobis Distance — কী এবং কেন Euclidean থেকে ভালো?

Euclidean: সহজ, কিন্তু features-এর correlation ignore করে।

Mahalanobis: Covariance matrix ব্যবহার করে। Correlated features handle করে। Dimensionless।

d = √[(x−μ)ᵀ Σ⁻¹ (x−μ)]

Σ = covariance matrix, μ = mean। Z-score-এর multivariate version।

💡 Real-world মানে

কোনো point distribution-এর center থেকে অনেক দূরে থাকলে (তার নিজের scale অনুযায়ী) → extreme observation → সম্ভবত anomaly। Predictive maintenance-এ sensor anomaly detect করতে ব্যবহার হয়।

python — EllipticEnvelope (Robust Covariance)
import pandas as pd
import numpy as np
import warnings; warnings.filterwarnings("ignore")
from sklearn.covariance import EllipticEnvelope, MinCovDet
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import (
    accuracy_score, classification_report,
    confusion_matrix, roc_auc_score,
    matthews_corrcoef
)

# ===== Data Load & Preprocess =====
df = pd.read_csv("creditcard.csv")
df['Vamount'] = StandardScaler().fit_transform(df[['Amount']])
df['Vtime']   = StandardScaler().fit_transform(df[['Time']])
df = df.drop(['Time','Amount'], axis=1).dropna()
X, y = df.drop('Class', axis=1), df['Class']

# ===== EllipticEnvelope Model =====
# contamination: ~০.২% fraud rate
# support_fraction: ৯০% data দিয়ে covariance estimate — outlier-দের effect কমায়
el = EllipticEnvelope(contamination=0.002, support_fraction=0.9)
el.fit(X.values)
y_pred = el.predict(X.values)

# Convert: -1=Outlier→1=Fraud, 1=Normal→0
y_pred[y_pred==1]  = 0
y_pred[y_pred==-1] = 1

print(f"Accuracy: {accuracy_score(y.values, y_pred):.4f}")
print(classification_report(y.values, y_pred))
print("Confusion Matrix:\n", confusion_matrix(y.values, y_pred))
print(f"ROC-AUC: {roc_auc_score(y.values, y_pred):.4f}")
print(f"MCC:     {matthews_corrcoef(y.values, y_pred):.4f}")

# ===== Bonus: Mahalanobis Distance নিজে দেখো =====
mcd = MinCovDet(support_fraction=0.9)
mcd.fit(X.values)
mahal_dist = mcd.mahalanobis(X.values)
print("Top 5 Mahalanobis distances (potential outliers):")
print(np.sort(mahal_dist)[-5:])

Q1 Mahalanobis distance কী এবং Euclidean থেকে কীভাবে আলাদা?
উত্তর: Euclidean সব dimension equally treat করে, correlation ignore করে। Mahalanobis covariance matrix ব্যবহার করে: correlated features handle করে, dimensionless, scale-invariant। X আর Y strongly correlated হলে Mahalanobis সেটা জানে — Euclidean জানে না।

python — Isolation Forest with GridSearchCV (Recall optimization)
import numpy as np
import pandas as pd
from sklearn.ensemble import IsolationForest
from sklearn.model_selection import train_test_split, GridSearchCV, StratifiedKFold
from sklearn.metrics import make_scorer, recall_score, classification_report
import seaborn as sns

# ===== Data Load =====
df = pd.read_csv("creditcard.csv")

# sklearn convention: -1=Outlier, 1=Inlier
# আমাদের: 1=Fraud, 0=Normal → convert: Fraud→-1, Normal→1
df['Class'].replace({1:-1, 0:1}, inplace=True)
target = df['Class']

# ২৮৪,৮০৭ rows বড় → ২০,০০০ Normal + সব Fraud রাখি
df_inliers  = df[df['Class']==1][:20000]
df_outliers = df[df['Class']==-1]
df = pd.concat([df_inliers, df_outliers])
target = df['Class']

frac = len(df_outliers)/len(df)
print(f"Fraud fraction: {frac:.4f}")

# Train-test split
X_train, X_test, y_train, y_test = train_test_split(
    df, target, test_size=0.2)
X_train = X_train.drop('Class', axis=1)
X_test  = X_test.drop('Class', axis=1)
X_train = X_train.drop('Time', axis=1)
X_test  = X_test.drop('Time', axis=1)

# ===== Basic Isolation Forest =====
isof = IsolationForest(contamination=0.03, n_estimators=100, n_jobs=-1)
isof.fit(X_train)
y_pred = isof.predict(X_test)
print(classification_report(y_test, y_pred))

# ===== GridSearchCV — Recall Optimize =====
# Fraud detection-এ Recall সবচেয়ে important!
# একটাও fraud miss = customer-এর টাকা চুরি
skf   = StratifiedKFold(n_splits=3)
folds = list(skf.split(X_train, y_train))
resc  = make_scorer(recall_score, pos_label=-1)  # Fraud class recall

params = {
    'contamination': np.linspace(0.01, 0.05, 10),
    'n_estimators':  [100, 200, 300]
}
search = GridSearchCV(IsolationForest(), params, scoring=resc, cv=folds, n_jobs=-1)
search.fit(X_train, y_train)

y_pred_opt = search.best_estimator_.predict(X_test)
print(f"Best params: {search.best_params_}")
print(classification_report(y_test, y_pred_opt))

🔷 One-Class SVM — Novelty Detection

🎯 One-Class SVM এক লাইনে

শুধু "normal" data দিয়ে train করে। নতুন কিছু "normal" এর বাইরে হলে → Anomaly। Novelty detection — training data-তে fraud নেই!

🧒 One-Class SVM সহজে

তুমি শুধু ভালো আপেল দেখেছো। কখনো পচা দেখোনি। এখন কেউ একটা ফল দিলো — "এটা আমার চেনা ভালো আপেলের মতো না!" → পচা (anomaly)!

Novelty Detection = training-এ কোনো outlier নেই (clean data only)। One-Class SVM শুধু normal (label=1) data দিয়ে train করে, origin থেকে data-কে hyperplane দিয়ে আলাদা করে।

python — One-Class SVM (Novelty Detection)
from sklearn import svm
from sklearn.preprocessing import MinMaxScaler

# ===== শুধু Normal data দিয়ে Train =====
# Novelty detection assumption: training data clean (fraud নেই)
y_inliers        = y_train[y_train.values==1]
X_train_inliers  = X_train.loc[list(y_inliers.index)]

# ===== Scale: -1 to 1 =====
# One-Class SVM origin থেকে data separate করে → -1 to 1 ভালো কাজ করে
scaling          = MinMaxScaler(feature_range=(-1,1)).fit(X_train_inliers)
X_train_scaled   = scaling.transform(X_train_inliers)
X_test_scaled    = scaling.transform(X_test)

# ===== One-Class SVM =====
# nu     = outlier proportion (~fraud fraction)
# kernel = 'rbf' — Gaussian kernel, non-linear boundary
# gamma  = hyperplane shape — 'scale' means auto-adjusted
clf = svm.OneClassSVM(kernel='rbf', nu=0.005, gamma='scale')
clf.fit(X_train_scaled)  # শুধু Normal দিয়ে train!

y_pred = clf.predict(X_test_scaled)
# Returns: 1=Normal, -1=Anomaly (novelty)

print(classification_report(y_test, y_pred))
print(pd.crosstab(y_test, y_pred, rownames=['Actual'], colnames=['Predicted']))

Isolation Forest & One-Class SVM — Interview Questions
Q1 Isolation Forest কীভাবে কাজ করে? Tree depth কেন anomaly score?
উত্তর: Random feature বেছে random split করে বারবার। Anomaly point isolated — কম split-এ আলাদা হয় (shallow depth)। Normal point-দের isolate করতে অনেক split লাগে (deep)। Anomaly score = average path length — যত কম, তত বেশি anomaly। n_estimators টা tree-এর ensemble।
Q2 contamination parameter ভুল হলে কী হয়?
উত্তর: contamination বড় → বেশি Normal-কে anomaly বলবে (false positive ↑)। contamination ছোট → real anomaly miss করবে (false negative ↑)। Domain knowledge বা cross-validation দিয়ে সঠিক value বেছে নাও। GridSearchCV দিয়ে optimize করো recall-এর উপর।
Q3 Novelty Detection এবং Outlier Detection-এর পার্থক্য কী?
Novelty Detection: Training data clean। শুধু normal দিয়ে train। নতুন anomaly খোঁজে। → One-Class SVM

Outlier Detection: Training-এও outlier থাকতে পারে। Model সেগুলো সহ্য করে। → Isolation Forest, LOF, Robust Covariance
Q4 Isolation Forest vs LOF — কোনটা কখন choose করবে?
Isolation Forest: Large data (লক্ষ rows), real-time, high dimensions → O(n log n) ✅
LOF: Local density patterns গুরুত্বপূর্ণ, small dataset → O(n²) ⚠
Production fraud detection-এ Isolation Forest বেশি ব্যবহার হয় — scalable এবং fast।

    def __init__(self, contamination=0.002):
        self.contamination = contamination
        self.best_model    = None
        self.results       = {}

    def preprocess(self, filepath):
        df = pd.read_csv(filepath)
        sc = StandardScaler()
        df['Amount_sc'] = sc.fit_transform(df[['Amount']])
        df['Time_sc']   = sc.fit_transform(df[['Time']])
        df = df.drop(['Amount','Time'], axis=1).dropna()
        self.X, self.y = df.drop('Class',axis=1), df['Class']
        print(f"✅ Loaded: {df.shape} | Fraud: {self.y.mean():.4%}")
        return self

    def balance(self):
        fraud  = self.X[self.y==1]
        normal = self.X[self.y==0].sample(len(fraud), random_state=42)
        Xb     = pd.concat([normal,fraud])
        yb     = self.y.loc[Xb.index]
        self.X_train,self.X_test,self.y_train,self.y_test = \
            train_test_split(Xb,yb,test_size=0.2,random_state=42)
        return self

    def _score(self, name, model, yp):
        f1  = f1_score(self.y_test,yp,pos_label=1)
        roc = roc_auc_score(self.y_test,yp)
        self.results[name] = {'f1':f1,'roc':roc,'model':model}
        print(f"  {name}: F1={f1:.4f} ROC={roc:.4f}")

    def train_all(self):
        print("\n🔄 Training models...")
        # KNN
        knn = KNeighborsClassifier(n_neighbors=5,n_jobs=-1)
        knn.fit(self.X_train,self.y_train)
        self._score("KNN",knn,knn.predict(self.X_test))
        # Isolation Forest
        isof = IsolationForest(contamination=self.contamination,n_jobs=-1)
        isof.fit(self.X_train)
        ip   = np.where(isof.predict(self.X_test)==-1,1,0)
        self._score("IsolationForest",isof,ip)
        # Select best
        best = max(self.results,key=lambda x:self.results[x]['f1'])
        self.best_model = self.results[best]['model']
        print(f"\n🏆 Best: {best}")
        return self

    def save(self, path="fraud_model.pkl"):
        joblib.dump(self.best_model, path)
        print(f"✅ Saved: {path}")

# Usage (Method chaining)

         .preprocess("creditcard.csv")
         .balance()
         .train_all())

def ip_to_int(ip):
    """'192.168.1.1' → 192+168+1+1 = 362"""

def flow_to_int(v):
    """Flow ID string → numeric"""
    try:
        p = v.split('-')
        if len(p)!=5: return None
        i1,i2,pt1,pt2,pr = p
        return ip_to_int(i1)+ip_to_int(i2)+int(pt1)+int(pt2)+int(pr)
    except: return None

EX-3 (Advanced Interview) Anomaly detection-এ accuracy কেন misleading? Mathematical proof দাও।
Mathematical Proof:

Dataset: N=100,000 transactions | Fraud=200 (0.2%) | Normal=99,800

Naive model — সব Normal বলে:
• Accuracy = 99,800/100,000 = 99.8% ← দেখতে দারুণ!
• Recall for Fraud = 0/200 = 0% ← কোনো fraud ধরেনি!

তাই সঠিক metrics:
• Precision = TP/(TP+FP) — fraud বললে কতটা সত্যি?
• Recall = TP/(TP+FN) — সত্যিকার fraud কতটা ধরলো?
• F1 = 2×P×R/(P+R) — balance
• MCC = (TP×TN−FP×FN)/√((TP+FP)(TP+FN)(TN+FP)(TN+FN))
• ROC-AUC = random fraud-কে random normal এর চেয়ে বেশি score দেওয়ার probability

from scipy import stats
import datetime

class DriftMonitor:
    """KS-test দিয়ে data drift detect করো।
    Drift মানে: production data-র distribution training data থেকে পরিবর্তন হয়েছে।
    """

    def __init__(self, reference_df):
        self.ref    = reference_df
        self.alerts = []

    def check_drift(self, new_df, alpha=0.05):
        """প্রতিটা feature-এ KS test চালাও।
        p_value < alpha হলে distribution পরিবর্তন হয়েছে → drift!
        """
        report = {}
        for col in self.ref.columns:
            _, p = stats.ks_2samp(self.ref[col], new_df[col])
            report[col] = {'p_value':p, 'drifted':p<alpha}
            if p < alpha:
                self.alerts.append(f"⚠️ DRIFT: {col} (p={p:.4f})")
        return report

    def report(self):
        print(f"\n📊 Drift Report — {datetime.datetime.now().strftime('%Y-%m-%d %H:%M')}")
        if self.alerts:
            [print(a) for a in self.alerts]
            print("→ Consider retraining the model!")
        else:
            print("✅ No drift detected — model still valid")
