টাইম সিরিজ বিশ্লেষণ: Trend, Seasonality, Residual 🔬

একটা টাইম সিরিজ দেখলে মনে হয় সব মিলিয়ে জগাখিচুড়ি। কিন্তু আসলে এটা তিনটা অংশ দিয়ে তৈরি। চলো বুঝি।

🍰

উপমা: ধরো একটা কেক বানানো হচ্ছে — তাতে আছে: ময়দা (Trend) + চিনি (Seasonality) + কিছু অপ্রত্যাশিত মশলা (Residual/Noise)। তুমি কেক খেলে এই তিনটা আলাদা করতে পারবে না, কিন্তু সব মিলিয়েই কেকের স্বাদ হয়।

টাইম সিরিজের তিনটি উপাদান এবং দুটি মডেলের পার্থক্য

Logarithm Transform কেন নিই?

Multiplicative model এ কাজ করা কঠিন। কিন্তু log নিলে:

log(X_t) = log(T_t) + log(1+S_t) + log(1+ε_t)

এখন এটা Additive হয়ে গেছে! Additive model নিয়ে কাজ করা অনেক সহজ কারণ এখানে সব component যোগ করা আছে।

📱

উপমা: ধরো তোমার ফোনের ব্যাটারি — গ্রীষ্মে সবসময় ১০% বেশি drain হলে সেটা Additive। কিন্তু যদি সবসময় ১০% বেশি (মানে ১০০ থেকে ৯০, কিন্তু ৫০ থেকে ৪৫) drain হয়, সেটা Multiplicative। পার্থক্যটা কি বুঝলে?

🔑 চেনার উপায়

Additive কিনা দেখো: গ্রাফে seasonal ওঠানামার উচ্চতা (amplitude) কি সব জায়গায় একই?
Multiplicative কিনা দেখো: সময়ের সাথে কি seasonal swing বড় হচ্ছে?

AirPassengers ডেটায় যতই বছর যাচ্ছে seasonal swing বড় হচ্ছে → Multiplicative!

Automatic Decomposition: seasonal_decompose 🔧

statsmodels লাইব্রেরির seasonal_decompose function দিয়ে Python নিজেই আমাদের জন্য Trend, Seasonality ও Residual আলাদা করে দেয়।

Python — Decomposition
from statsmodels.tsa.seasonal import seasonal_decompose

# Step 1: Decompose করো (default: additive)
res_add = seasonal_decompose(airpass)
res_add.plot()
plt.show()
# ← এটা ভালো ফল দেবে না! Residual এ বড় variation থাকবে

# Step 2: Multiplicative model ব্যবহার করো
res_mul = seasonal_decompose(airpass, model='multiplicative')
res_mul.plot()
plt.show()
# ← এটা ভালো ফল দেবে — Residual প্রায় random হবে

# Step 3: Log transform নাও (Multiplicative → Additive)
airpasslog = np.log(airpass)
plt.plot(airpasslog)
plt.show()
# এখন seasonal amplitude প্রায় constant

Seasonal Adjustment (CVS) কী?

Seasonality বাদ দিলে আসল trend পরিষ্কার দেখা যায়। এটাকে বলে Seasonally Adjusted Series।

Python — Seasonally Adjusted Series
# Log-transformed series তে decompose করো
mult = seasonal_decompose(airpasslog)

# Seasonal component বাদ দাও
cvs = airpasslog['#Passengers'] - mult.seasonal

# Original scale এ ফিরে যাও (exp নাও)
x_cvs = np.exp(cvs)

# একসাথে plot করো
plt.plot(airpass, label='Original')
plt.plot(x_cvs, label='Seasonally Adjusted')
plt.legend()
plt.show()
✅ Seasonal Adjustment কেন দরকার?

Seasonality বাদ দিলে লুকানো pattern দেখা যায়। উদাহরণ: AirPassengers এ seasonal adjustment করলে দেখা যায় ১৯৫৮ ও ১৯৬০ সালে যাত্রী সংখ্যা কমেছিল — যেটা original graph এ বোঝা যেত না।

প্র. (ML Engineer Level): তোমার কাছে একটা e-commerce সাইটের ২ বছরের weekly revenue ডেটা আছে। কীভাবে বুঝবে এটা Additive নাকি Multiplicative? কোড লিখে দেখাও।
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.tsa.seasonal import seasonal_decompose

# Method 1: চোখে দেখো — seasonal swing বাড়ছে কিনা?
plt.plot(revenue)

Moving Average পদ্ধতি 📊

seasonal_decompose আসলে ভেতরে ভেতরে Moving Average (MA) ব্যবহার করে trend বের করে। চলো নিজে হাতে বুঝি।

🎸

উপমা: ধরো তুমি একটা গান শুনছো যেখানে অনেক noise আছে। তুমি যদি কানে হাত দিয়ে একটু চাপ দাও, তাহলে কিছুটা smooth শোনায়। Moving Average ঠিক এটাই করে — ডেটার "noise" কমিয়ে আসল pattern দেখায়।

Moving Average কীভাবে noise কমিয়ে trend বের করে

Centered Moving Average — Even Period

যখন seasonality এর period এমন হয় (যেমন ১২ মাস), তখন centered MA ব্যবহার করতে হয়। এতে extreme গুলো ½ weight পায়।

M₁₂X_t = (1/12) × (½X_{t-6} + X_{t-5} + ... + X_t + ... + X_{t+5} + ½X_{t+6})

Python এ Moving Average

Python — Moving Average
# ১২-মাসের centered moving average
airpass_ma = airpasslog.rolling(
    window=12,    # ১২টা মান নিয়ে average
    center=True  # centered window
).mean()

# Plot করো
plt.plot(airpasslog, color='blue', label='Original')
plt.plot(airpass_ma, color='red', label='Moving Average')
plt.legend()
plt.show()

হাতে হাতে Seasonality বের করা (৫ ধাপে)

  • ১
    Moving Average M₁₂X_t বের করো (Trend approximation)
  • ২
    Series থেকে MA বিয়োগ করো: X_t - M₁₂X_t
  • ৩
    প্রতি মাসের average নাও (seasonality coefficient)
  • ৪
    সব coefficient এর মোট average বিয়োগ করে center করো
  • ৫
    Original series থেকে seasonal coefficient বিয়োগ করো
Python — Manual Seasonality Extraction
# Step 1: MA বের করা হয়েছে উপরে

# Step 2: Difference
airpasslog_without_ma = airpasslog - airpass_ma
airpasslog_without_ma = airpasslog_without_ma.dropna()  # NaN বাদ দাও

# Step 3 & 4: Month ধরে average নাও, center করো
df = airpasslog_without_ma.copy()
df['month'] = df.index.month

seasonality = df.groupby('month').mean()
seasonality = seasonality - seasonality.mean()  # center

# Step 5: Seasonal vector বানাও (১২ × ১২ = ১৪৪ মাস)
seasonal_vector = np.zeros(144)
j = 0
for i in range(12):
    seasonal_vector[j:j+12] = seasonality.iloc[:, 0]
    j += 12

# Seasonally adjusted series
airpasslog_cvs = airpasslog["#Passengers"] - seasonal_vector
airpass_cvs = np.exp(airpasslog_cvs)  # Original scale এ ফিরে যাও

Regression Model দিয়ে টাইম সিরিজ পূর্বাভাস 📈

আমরা জানি Linear Regression কীভাবে কাজ করে। কিন্তু টাইম সিরিজে Feature গুলো কোথা থেকে আসবে? উত্তর: আগের মানগুলো থেকেই!

X_t = β₀ + β₁·X_{t-1} + β₂·X_{t-2} + ... + βₚ·X_{t-p} + ε_t

মানে: আজকের যাত্রী সংখ্যা = গত মাসের সংখ্যার উপর ভিত্তি করে predict করছি।

Feature Engineering: Lag তৈরি

Python — Lag Features
df = pd.read_csv('AirPassengers.csv', index_col='Month', parse_dates=True)

# Lag Feature: গত মাসের মান
df['Passengers_lag1'] = df['#Passengers'].shift(1)
# shift(1) মানে: প্রতিটা মানকে ১ ঘর নিচে নামাও
# তাহলে row t তে পাবো X_{t-1} এর মান

# Rolling Window Feature: গত ৩ মাসের গড়
df['Passengers_MA_3months'] = df['#Passengers'].rolling(window=3).mean()

# NaN বাদ দাও
df = df.dropna()

print(df.head())

Train-Test Split — টাইম সিরিজের সঠিক উপায়

টাইম সিরিজে সবসময় শেষের অংশ test set হবে — random split না!
Python — Linear Regression Model
from sklearn.linear_model import LinearRegression
from sklearn.metrics import root_mean_squared_error

# Feature ও Target
X = df[['Passengers_lag1']]   # Feature: গত মাসের মান
y = df['#Passengers']         # Target: এই মাসের মান

# শেষ ২৪ মাস test set
X_train = X.iloc[:-24]
X_test  = X.iloc[-24:]
y_train = y.iloc[:-24]
y_test  = y.iloc[-24:]

# Model তৈরি ও train
model = LinearRegression()
model.fit(X_train, y_train)

# Predict ও evaluate
y_pred = model.predict(X_test)
rmse = root_mean_squared_error(y_test, y_pred)
print(f"RMSE: {rmse:.2f}")

# Visualization
plt.figure(figsize=(10, 6))
plt.plot(y.index, y, label='Actual')
plt.plot(y_test.index, y_pred, label='Predicted', linestyle='--')
plt.legend()

def create_lag_features(series, lags=[1, 7, 30], rolling_windows=[7, 30]):

ARMA Model: AR ও MA Process 🧠

AR (Auto-Regressive) Process কী?

🔮

উপমা: তুমি কি জানো তোমার আজকের মেজাজ অনেকটাই গতকালের মেজাজের উপর নির্ভর করে? AR process ঠিক এটাই বলে — আজকের মান আগের মানের উপর নির্ভরশীল।

X_t = α₁·X_{t-1} + α₂·X_{t-2} + ... + αₚ·X_{t-p} + ε_t

AR(p) মানে: আজকের মান = আগের p টা মানের weighted sum + error

MA (Moving Average) Process কী?

🌊

উপমা: ভূমিকম্পের পর কয়েকদিন ধরে aftershock থাকে। MA process বলে: আজকের মান আগের ভুল (error) গুলোর উপর নির্ভরশীল।

X_t = ε_t + β₁·ε_{t-1} + β₂·ε_{t-2} + ... + βq·ε_{t-q}

MA(q) মানে: আজকের মান = আগের q টা error এর weighted sum

ARMA(p,q) = AR + MA

X_t = Σαᵢ·X_{t-i} + ε_t + Σβᵢ·ε_{t-i}
AR ও MA এর পার্থক্য বোঝার চিত্র
⚠️ ARMA এর সীমাবদ্ধতা

ARMA শুধুমাত্র stationary সিরিজে কাজ করে। AirPassengers এর মতো trend বা seasonality থাকলে ARMA সরাসরি ব্যবহার করা যাবে না। এর জন্য দরকার ARIMA বা SARIMA।

Stationarity, Differencing, ACF ও PACF 📉

Stationarity (স্থিরতা) কী?

⚖️

উপমা: ধরো একটা দোলনা — যদি এটা একই জায়গায় দুলতে থাকে, এটা stationary। কিন্তু যদি দুলতে দুলতে এগিয়ে যায় (trend), সেটা non-stationary।

📐 Weak Stationarity — তিনটি শর্ত

(১) Constant Mean: E(X_t) = μ — গড় সময়ের সাথে পরিবর্তন হবে না
(২) Constant Variance: Var(X_t) = σ² — variance সব সময় একই
(৩) Autocovariance depends only on lag: X_t ও X_{t-k} এর সম্পর্ক শুধু k এর উপর নির্ভরশীল, t এর উপর না

Stationary ও Non-stationary সিরিজের পার্থক্য

Differencing কী এবং কেন করি?

Differencing মানে: প্রতিটা মানের বদলে সেটা ও আগের মানের পার্থক্য ব্যবহার করা।

∇X_t = X_t - X_{t-1}

যদি X_t = αt + ε_t (linear trend), তাহলে: ∇X_t = α + ε_t - ε_{t-1}

Trend চলে গেছে! এখন stationary।

SARIMA কী?

SARIMA(p, d, q)(P, D, Q)_k
ParameterমানেAirPassengers এ মান
pNon-seasonal AR order0 (PACF দেখে)
dNon-seasonal differencing1 (trend বাদ দিতে)

QSeasonal MA order1

from sklearn.linear_model import LinearRegression
from sklearn.metrics import root_mean_squared_error, mean_absolute_error
import pandas as pd
import numpy as np

def ts_linear_regression(series, n_lags=12, test_size=24):
    """
    টাইম সিরিজের জন্য Linear Regression pipeline
    series: pandas Series with datetime index
    n_lags: কতটা পুরনো মান ব্যবহার করবে
    test_size: শেষ কতটা মাস test করবে
    """
    # Feature matrix তৈরি
    df = pd.DataFrame({'y': series})
    for lag in range(1, n_lags+1):
        df[f'lag_{lag}'] = series.shift(lag)
    df = df.dropna()

    X = df.drop('y', axis=1)
    y = df['y']

    # Chronological split
    X_train, X_test = X.iloc[:-test_size], X.iloc[-test_size:]
    y_train, y_test = y.iloc[:-test_size], y.iloc[-test_size:]

    model = LinearRegression()
    model.fit(X_train, y_train)
    pred = model.predict(X_test)

    return {
        'model': model,
        'rmse': root_mean_squared_error(y_test, pred),
        'mae': mean_absolute_error(y_test, pred),
        'predictions': pd.Series(pred, index=y_test.index)
    }

from statsmodels.tsa.seasonal import seasonal_decompose

def decompose_series(series, period=12):
    """
    টাইম সিরিজ decompose করো এবং best model return করো
    """
    # Log transform (Multiplicative কে Additive বানাতে)
    log_series = np.log(series)

    # Decompose
    result = seasonal_decompose(log_series, period=period)

    # Components বের করো
    trend = np.exp(result.trend)
    seasonal = np.exp(result.seasonal)
    residual = np.exp(result.resid)

    # Seasonally adjusted
    adjusted = series / seasonal

    return {
        'trend': trend,
        'seasonal': seasonal,
        'residual': residual,
        'adjusted': adjusted
    }

import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller
import warnings
warnings.filterwarnings('ignore')

def fit_arima(series, order=(1,1,1), test_size=12):
    """
    ARIMA model fit করো এবং evaluate করো
    order: (p, d, q) tuple
    """
    # Stationarity check
    adf_stat, p_val = adfuller(series.[:-test_size])[:2]
    print(f"ADF p-value: {p_val:.4f} ({'stationary' if p_val < 0.05 else 'non-stationary'})")

    # Train-test split
    train = series.iloc[:-test_size]
    test = series.iloc[-test_size:]

    # ARIMA fit
    model = sm.tsa.ARIMA(train, order=order)
    fitted = model.fit()

    # Forecast
    forecast = fitted.forecast(steps=test_size)

    rmse = np.sqrt(np.mean((test.values - forecast.values)**2))
    print(f"RMSE: {rmse:.2f} | AIC: {fitted.aic:.2f}")

    return fitted, forecast

import statsmodels.api as sm
import numpy as np
import pandas as pd
from itertools import product

def auto_sarima(series, p_range=[0,1], q_range=[0,1,2],
                d=1, D=1, P=0, Q=1, k=12):
    """
    AIC দিয়ে সেরা SARIMA orders খোঁজো
    """
    best_aic = np.inf
    best_order = None
    best_model = None

    for p, q in product(p_range, q_range):
        try:
            model = sm.tsa.SARIMAX(
                series,
                order=(p, d, q),
                seasonal_order=(P, D, Q, k),
                enforce_stationarity=False,
                enforce_invertibility=False
            )
            result = model.fit(disp=False)
            if result.aic < best_aic:
                best_aic = result.aic
                best_order = (p, d, q)
                best_model = result
        except:
            continue

    print(f"সেরা order: {best_order}, AIC: {best_aic:.2f}")
    return best_model

# ব্যবহার:

from prophet import Prophet
from prophet.diagnostics import cross_validation, performance_metrics
import itertools, numpy as np, pandas as pd

def prophet_pipeline(df, date_col, value_col,
                       test_months=12, tune=True):
    """
    Prophet complete pipeline
    df: DataFrame
    date_col: তারিখের কলামের নাম
    value_col: value কলামের নাম
    """
    # Prophet format
    prophet_df = df.rename(columns={date_col: 'ds', value_col: 'y'})
    train = prophet_df.iloc[:-test_months]
    test = prophet_df.iloc[-test_months:]

    if tune:
        param_grid = {
            'changepoint_prior_scale': [0.01, 0.1, 0.5],
            'seasonality_prior_scale': [0.1, 1, 10]
        }
        all_params = [dict(zip(param_grid.keys(), v))
                      for v in itertools.product(*param_grid.values())]
        rmses = []
        for params in all_params:
            m = Prophet(**params).fit(train)
            cv = cross_validation(m, horizon='90 days')
            rmses.append(performance_metrics(cv)['rmse'].values[0])
        best_params = all_params[np.argmin(rmses)]
    else:
        best_params = {}

    # Final model
    model = Prophet(**best_params)
    model.fit(train)
    future = model.make_future_dataframe(periods=test_months, freq='ME')
    forecast = model.predict(future)

    from sklearn.metrics import root_mean_squared_error
    rmse = root_mean_squared_error(
        test['y'], forecast['yhat'].tail(test_months)
    )
    print(f"Final RMSE: {rmse:.2f}")
    return model, forecast

🎙️ Category ১: Conceptual Questions
Q1. Stationarity কী এবং কেন এটা ARIMA এর জন্য জরুরি?

Stationarity মানে একটা টাইম সিরিজের statistical properties (mean, variance, autocorrelation) সময়ের সাথে পরিবর্তন হয় না। ARIMA এর জন্য জরুরি কারণ: ARIMA এর mathematical assumptions গুলো stationary process এর উপর based। Non-stationary series এ fit করলে spurious correlation দেখা দেয় — model একটা pattern দেখে যেটা আসলে নেই। Differencing করে non-stationary series কে stationary করা যায়।

Q2. ACF ও PACF এর পার্থক্য কী? কোনটা দিয়ে AR এবং কোনটা দিয়ে MA এর order বোঝা যায়?

ACF (Autocorrelation Function): X_t ও X_{t-h} এর মধ্যে correlation — intermediate lags এর effect বাদ দেয় না।
PACF (Partial ACF): X_t ও X_{t-h} এর মধ্যে correlation যেখানে intermediate lags এর effect বাদ দেওয়া হয়।

নিয়ম: ACF cuts off after lag q → MA(q) | PACF cuts off after lag p → AR(p) | উভয়ই tails off → ARMA(p,q)

Q3. AIC vs BIC — কোনটা কখন ব্যবহার করবে?

AIC কম parameters কে কম penalize করে — prediction accuracy maximize করতে চাইলে ব্যবহার করো।
BIC বেশি parameters কে বেশি penalize করে — simple model prefer করলে (interpretability) BIC ব্যবহার করো।
যদি sample size ছোট হয় তাহলে AICc (corrected AIC) ব্যবহার করা উচিত।

Q4. ARIMA(1,1,1) মানে কী?

• p=1: AR(1) — আগের ১টা মান ব্যবহার করে
• d=1: ১ বার differencing করা হয়েছে (trend বাদ দেওয়া)
• q=1: MA(1) — আগের ১টা error ব্যবহার করে

Equation: ∇X_t = α₁·∇X_{t-1} + ε_t + β₁·ε_{t-1}

Q6. Time Series Cross-Validation কীভাবে করবে?
from sklearn.model_selection import TimeSeriesSplit
import numpy as np

def time_series_cv(X, y, model, n_splits=5):
    """
    Expanding window cross-validation
    প্রতিটা fold এ training set বড় হয়, test সবসময় শেষে
    """
    tscv = TimeSeriesSplit(n_splits=n_splits)
    scores = []

    for fold, (train_idx, test_idx) in enumerate(tscv.split(X)):
        X_tr, X_te = X.iloc[train_idx], X.iloc[test_idx]
        y_tr, y_te = y.iloc[train_idx], y.iloc[test_idx]

        model.fit(X_tr, y_tr)
        pred = model.predict(X_te)
        rmse = np.sqrt(np.mean((y_te.values - pred)**2))
        scores.append(rmse)
        print(f"Fold {fold+1}: RMSE = {rmse:.2f}")

    print(f"\nMean RMSE: {np.mean(scores):.2f} ± {np.std(scores):.2f}")
    return scores

import numpy as np

def evaluate_forecast(y_true, y_pred):
    # MAE: সহজ, interpretable
    mae = np.mean(np.abs(y_true - y_pred))

    # RMSE: বড় error কে বেশি penalize করে
    rmse = np.sqrt(np.mean((y_true - y_pred)**2))

    # MAPE: percentage error — scale independent
    mape = np.mean(np.abs((y_true - y_pred) / y_true)) * 100

    # sMAPE: symmetric MAPE — 0 এর কাছে মান থাকলে ভালো
    smape = np.mean(2 * np.abs(y_true-y_pred) / (np.abs(y_true)+np.abs(y_pred))) * 100

    # MASE: compared to naive forecast
    naive_mae = np.mean(np.abs(np.diff(y_true)))
    mase = mae / naive_mae  # <1 means better than naive

    print(f"MAE:   {mae:.2f}")
    print(f"RMSE:  {rmse:.2f}")
    print(f"MAPE:  {mape:.2f}%")
    print(f"sMAPE: {smape:.2f}%")
    print(f"MASE:  {mase:.2f}")

# RMSE: outlier sensitive, engineering problem

ADF Test — Stationarity পরীক্ষার হাতিয়ার 🧪

Augmented Dickey-Fuller (ADF) test হলো সবচেয়ে জনপ্রিয় stationarity test। এটা দিয়ে নিশ্চিত হওয়া যায় যে series টা সত্যিই stationary কিনা।

📐 ADF Test এর Hypothesis

H₀ (Null Hypothesis): সিরিজে একটা unit root আছে → Non-stationary
H₁ (Alternative): সিরিজে unit root নেই → Stationary

নিয়ম: p-value < 0.05 হলে H₀ reject করো → সিরিজ stationary ✓

⚖️

সহজ ভাষায়: ধরো তুমি জজ। কেউ বলছে "এই সিরিজটা non-stationary"। তোমাকে প্রমাণ দেখাতে হবে যে সে ভুল। যদি p-value < 0.05 হয়, তুমি বলতে পারো "না, এটা stationary!" ADF test সেটাই করে।

Python — ADF Test সম্পূর্ণ Implementation
import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller
import numpy as np
import pandas as pd

def adf_test_full(series, series_name="Series"):
    """
    ADF test করো এবং সুন্দর করে result দেখাও
    """
    result = adfuller(series.dropna(), autolag='AIC')

    print(f"\n{'='*50}")
    print(f"ADF Test: {series_name}")
    print(f"{'='*50}")
    print(f"ADF Statistic : {result[0]:.4f}")
    print(f"p-value       : {result[1]:.4f}")
    print(f"Lags Used     : {result[2]}")
    print(f"Observations  : {result[3]}")
    print("\nCritical Values:")
    for key, val in result[4].items():
        print(f"  {key}: {val:.4f}")

    if result[1] < 0.05:
        print("\n✅ সিদ্ধান্ত: STATIONARY (p < 0.05)")
    else:
        print("\n❌ সিদ্ধান্ত: NON-STATIONARY (p >= 0.05) → Differencing দরকার")

    return result[1] < 0.05

# Step-by-step stationarity check pipeline:
airpasslog = np.log(airpass)

print("Step 1: Original log series")
is_stat = adf_test_full(airpasslog['#Passengers'], "airpasslog")

if not is_stat:
    print("\nStep 2: 1st order differencing")
    diff1 = airpasslog.diff().dropna()
    is_stat = adf_test_full(diff1['#Passengers'], "1st diff")

if not is_stat:
    print("\nStep 3: Seasonal differencing (period=12)")
    diff2 = diff1.diff(periods=12).dropna()
    adf_test_full(diff2['#Passengers'], "Seasonal diff")

def check_stationarity(series):
    p = adfuller(series.dropna())[1]
    print(f"ADF p-value: {p:.4f} → {'✅ Stationary' if p < 0.05 else '❌ Non-stationary'}")
    return p < 0.05

d = 0

while not check_stationarity(series_work) and d < 3:
    series_work = series_work.diff().dropna()
    d += 1

# Seasonal differencing
D = 0
series_work_s = series_work.copy()
while not check_stationarity(series_work_s) and D < 2:
    series_work_s = series_work_s.diff(periods=12).dropna()
    D += 1

print(f"d={d}, D={D}")

########################################
# STEP 4: ACF/PACF → p, q, P, Q
########################################
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))
plot_acf(series_work_s, lags=36, ax=ax1)
plot_pacf(series_work_s, lags=36, ax=ax2)
plt.show()
# Plot দেখে manually p, q, P, Q ঠিক করো

########################################
# STEP 5: MODEL SELECTION (Grid Search)
########################################
from itertools import product

best_aic = np.inf
best_params = None

for p, q, P, Q in product([0,1], [0,1], [0,1], [0,1]):
    try:
        m = sm.tsa.SARIMAX(
            log_sales,
            order=(p, d, q),
            seasonal_order=(P, D, Q, 12),
            enforce_stationarity=False
        ).fit(disp=False)
        if m.aic < best_aic:
            best_aic = m.aic
            best_params = (p, d, q, P, D, Q)
    except: continue

p, d, q, P, D, Q = best_params
print(f"Best: SARIMA({p},{d},{q})({P},{D},{Q})_12 | AIC: {best_aic:.2f}")

########################################
# STEP 6: FINAL MODEL + EVALUATION
########################################
train = log_sales.iloc[:-12]
test  = log_sales.iloc[-12:]

final_model = sm.tsa.SARIMAX(
    train,
    order=(p, d, q),
    seasonal_order=(P, D, Q, 12)
).fit(disp=False)

pred_log = final_model.forecast(steps=12)
pred = np.exp(pred_log)
actual = np.exp(test)

rmse = root_mean_squared_error(actual, pred)
mape = np.mean(np.abs((actual-pred)/actual))*100
print(f"Test RMSE: {rmse:.2f} | MAPE: {mape:.2f}%")

⚡ Rapid Fire Interview Questions (সংক্ষিপ্ত উত্তর)
Q: White noise কী?

Mean = 0, constant variance, কোনো autocorrelation নেই — সম্পূর্ণ random। ভালো model এর residual হওয়া উচিত white noise।

Q: Overfitting টাইম সিরিজে কীভাবে ধরবে?

Train error খুব কম কিন্তু Test error অনেক বেশি। Solution: সহজ model (কম orders), cross-validation, information criteria (AIC/BIC) দিয়ে select করো।

Q: Prophet কি SARIMA এর চেয়ে সবসময় ভালো?

না। SARIMA: ছোট dataset, interpretability দরকার হলে। Prophet: holiday effects আছে, missing data আছে, non-linear trend আছে। নির্ভর করে use-case এর উপর।

Q: Seasonal differencing কী বোঝায়?

X_t থেকে X_{t-k} বিয়োগ করা, যেখানে k হলো season period। মাসিক ডেটায়: এই মাসের মান - গত বছরের এই মাসের মান। Seasonality বাদ দেওয়ার জন্য।

Q: MAPE এর সমস্যা কী?

y_true = 0 হলে infinity হয়ে যায়। ছোট values এ asymmetric — under-forecast কে বেশি penalize করে। Alternative: sMAPE বা MASE ব্যবহার করো।

Q: Time series এ feature scaling দরকার কি?

ARIMA/SARIMA/Prophet এ না। কিন্তু Regression-based বা Neural Network based model এ হ্যাঁ। তবে scaling করলে inverse transform করতে হবে predictions এ।
