গ্রেডিয়েন্ট ও Autograd — PyTorch-এর সবচেয়ে বড় জাদু ▼

গ্রেডিয়েন্ট মানে কী?

ধরো তুমি পাহাড়ের মাঝে দাঁড়িয়ে আছ, চোখ বন্ধ করে। তুমি নিচে নামতে চাও (সর্বনিম্ন বিন্দু খুঁজতে চাও)। তোমার পা দিয়ে অনুভব করো — কোন দিকে ঢাল আছে? সেই ঢালের তথ্যই গ্রেডিয়েন্ট।

গ্রেডিয়েন্ট বলে দেয় — "এই দিকে এগোলে ফাংশনের মান বাড়বে"। তুমি উল্টো দিকে এগোও → মান কমে → Gradient Descent!

PyTorch নিজেই সব ফাংশনের গ্রেডিয়েন্ট হিসাব করতে পারে → এটাই Autograd।

চিত্র: Gradient Descent — প্রতিটি ধাপে ঢাল বরাবর নিচে নামো

Python — requires_grad, backward(), .grad 
import torch

# ফাংশন সংজ্ঞায়ন
# f(x) = x² − x + 2
def f(x):
    return x**2 - x + 2

# requires_grad=True মানে:
# "PyTorch, এই টেনসরের জন্য সব অপারেশন মনে রাখো
#  পরে gradient হিসাব করতে হবে"
x = torch.tensor(2.0, requires_grad=True)

# forward pass: ফাংশনের মান হিসাব করো
y = f(x)
print(y)  # tensor(4., grad_fn=AddBackward0)
# grad_fn মানে PyTorch জানে কীভাবে backward যেতে হবে

# backward pass: gradient হিসাব করো
# df/dx = 2x - 1 → x=2 এ df/dx = 2(2)-1 = 3
y.backward()

# gradient দেখো
print(x.grad)  # tensor(3.) → সঠিক! ✓

# ⚠️ সতর্কতা: backward() একাধিকবার চালালে gradient জমা হয়!
# প্রতিটি iteration-এ gradient reset করতে হবে:
x.grad = None  # অথবা optimizer.zero_grad()
⚠️

সবচেয়ে কমন ভুল: Gradient Accumulation

PyTorch-এ gradient জমা হয় (accumulate) — মানে প্রতিটি backward() পুরানো gradient-এর সাথে যোগ হয়। তাই প্রতিটি iteration-এ x.grad = None বা optimizer.zero_grad() দিতে হবে। না দিলে training একদম উল্টো দিকে যাবে!

PyTorch Dynamic Graph বোঝো

PyTorch প্রতিটি অপারেশন একটি গ্রাফে লিখে রাখে। y = f(x) চালালে ভেতরে একটি গ্রাফ তৈরি হয়: x → (x**2) → (x**2 - x) → (x**2 - x + 2) → y। y.backward() এই গ্রাফে উল্টো দিকে হেঁটে (chain rule দিয়ে) প্রতিটি নোডের gradient বের করে। এই কারণেই এটাকে Backpropagation বলে।

অপটিমাইজার — মডেলকে স্মার্টভাবে ট্রেইন করা ▼

অপটিমাইজার হলো একজন চালাক নেভিগেটর। তুমি বলছ "আমি পাহাড়ের নিচে যেতে চাই (loss কমাতে চাই)"। অপটিমাইজার বলে "ঠিক আছে, আমি জানি কতটুকু এগোতে হবে (learning rate) এবং কোন দিকে (gradient)। তুমি শুধু বলো কতটা দ্রুত যেতে চাও।"

Adam optimizer সবচেয়ে জনপ্রিয় — এটি নিজেই learning rate adjust করে প্রতিটি parameter-এর জন্য।

Python — Adam Optimizer দিয়ে f(x) minimize করো 
import torch

def f(x):
    return x**2 - x + 2

# শুরুর মান x=2.0
x = torch.tensor(2.0, requires_grad=True)

# Adam optimizer তৈরি
# params=[x] মানে: এই টেনসরকে optimize করো
# lr=1e-1 = learning rate = 0.1 (প্রতি ধাপে কতটুকু নড়বে)
optimizer = torch.optim.Adam(params=[x], lr=1e-1)

print(f"শুরু: x={x.item():.4f}, f(x)={f(x).item():.4f}")

# ২০০ বার iteration করে minimum খোঁজো
for i in range(200):
    # ধাপ ১: আগের gradient মুছে ফেলো
    x.grad = None

    # ধাপ ২: ফাংশনের মান হিসাব করো (forward pass)
    y = f(x)

    # ধাপ ৩: gradient হিসাব করো (backward pass)
    y.backward()

    # ধাপ ৪: optimizer দিয়ে x আপডেট করো
    optimizer.step()

print(f"শেষ: x*={x.item():.4f}")   # ≈ 0.5 (সত্যিকারের minimum)
print(f"f(x*)={f(x).item():.4f}")   # ≈ 1.75
print(f"gradient={x.grad.item():.6f}")  # ≈ 0 (minimum-এ gradient শূন্য!)

# গাণিতিক সত্যতা যাচাই:
# f'(x) = 2x - 1 = 0 → x = 0.5 ✓
# f(0.5) = 0.25 - 0.5 + 2 = 1.75 ✓

ML Engineering Level

প্রশ্ন ১ — ইন্টারভিউ: requires_grad এর কাজ কী? কখন False করবে?

requires_grad=True: PyTorch এই tensor-এর উপর সব অপারেশনের gradient tracking করে। Model-এর trainable parameter-এ True দিতে হয়।

requires_grad=False: Inference/validation-এ দরকার নেই। এতে memory ও computation বাঁচে। torch.no_grad() block-এ সব tensor automatically False হয়ে যায়।

কখন False: ১) Pre-trained layer freeze করতে (Transfer Learning), ২) Evaluation/inference, ৩) Input data tensor (শুধু parameter-ই learn করে, data না)

প্রশ্ন ২ — ইন্টারভিউ: backward() একাধিকবার call করলে কী হয়?

PyTorch gradient accumulate করে — মানে x.grad += new_gradient করে, replace করে না। তাই দুইবার backward() ডাকলে gradient দ্বিগুণ হয়। এছাড়া computation graph default-এ free হয়ে যায়, তাই দ্বিতীয়বার backward() করতে গেলে error আসে (retain_graph=True না দিলে)। Solution: প্রতিটি iteration-এ optimizer.zero_grad() বা x.grad = None।

কোডিং চ্যালেঞ্জ — ML Project: Custom Loss দিয়ে Optimization

Rosenbrock function (ML benchmark): f(x, y) = (1−x)² + 100(y−x²)² minimize করো Adam optimizer দিয়ে। প্রতি ১০ iteration-এ loss print করো এবং minimum x*, y* বের করো।

Python — Rosenbrock Optimization
import torch

def rosenbrock(x, y):
    return (1 - x)**2 + 100 * (y - x**2)**2

# শুরুর মান (সাধারণত (-1, 1) থেকে শুরু করা হয়)
x = torch.tensor(-1.0, requires_grad=True)
y = torch.tensor( 1.0, requires_grad=True)

optimizer = torch.optim.Adam(params=[x, y], lr=1e-2)

for i in range(1000):
    optimizer.zero_grad()
    loss = rosenbrock(x, y)
    loss.backward()
    optimizer.step()
    if i % 100 == 0:
        print(f"Iter {i:4d}: loss={loss.item():.6f}, x={x.item():.4f}, y={y.item():.4f}")

print(f"\nসর্বনিম্ন বিন্দু: x*={x.item():.4f}, y*={y.item():.4f}")
# সঠিক উত্তর: x*=1, y*=1, f(1,1)=0

Rosenbrock function হলো optimization algorithm-এর benchmark। এর minimum হলো (1, 1) কিন্তু খুঁজে পেতে কঠিন কারণ "banana valley" আকৃতির।

import torch
import torch.nn as nn

# nn.Module inherit করে নিজের Layer তৈরি করো
class CustomLinearLayer(nn.Module):
    def __init__(self, input_dim, output_dim):
        # সব nn.Module-এর শুরুতে এটা লিখতে হবে
        super(CustomLinearLayer, self).__init__()

        # nn.Parameter মানে: এই tensor trainable
        # requires_grad=True automatically set হয়
        # torch.randn: random initialization (normal distribution)
        self.W = nn.Parameter(torch.randn(input_dim, output_dim))
        self.b = nn.Parameter(torch.randn(output_dim))

    def forward(self, x):
        # @ = matrix multiplication (PyTorch-এ matmul-এর shortcut)
        # x: [batch, input_dim]
        # W: [input_dim, output_dim]
        # b: [output_dim]
        # result: [batch, output_dim]
        return x @ self.W + self.b

# Layer তৈরি: ১৩ feature → ১ output (wine quality)
# X.shape[1] = 13 (মোট features)
customLinearRegression = CustomLinearLayer(input_dim=13, output_dim=1)

# nn.Module এর দরকারি methods:
# .parameters() → সব trainable weight দেখো
list(customLinearRegression.parameters())

# .zero_grad() → সব gradient শূন্য করো
customLinearRegression.zero_grad()

# .training → True=train mode, False=eval mode
print(customLinearRegression.training)  # True

MSE Loss — Mean Squared Error

MSE = (১/N) × Σ(ŷᵢ − yᵢ)² → ভবিষ্যদ্বাণী ও সত্যিকার মানের পার্থক্যের বর্গের গড়। বড় ভুলকে বেশি শাস্তি দেয় (বর্গ করার কারণে)। Regression সমস্যায় সবচেয়ে জনপ্রিয়।

Python — সম্পূর্ণ Training Loop 
import torch
import pandas as pd
from sklearn.model_selection import train_test_split

# ডেটা লোড করো
df = pd.read_csv('wine_quality.csv')
X = df.drop(['quality'], axis=1).values
y = df['quality'].values

X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.8, random_state=1234)

# টেনসরে রূপান্তর — dtype মেলাতে হবে!
X_train_tensor = torch.tensor(X_train, dtype=torch.float32)
y_train_tensor = torch.tensor(y_train, dtype=torch.float32)

# Custom MSE Loss function
def mse_loss(predictions, targets):
    return ((predictions - targets) ** 2).mean()

# মডেল ও Optimizer
model = CustomLinearLayer(X.shape[1], 1)
optimizer = torch.optim.Adam(params=model.parameters(), lr=1e-1)

# Training Loop — ১০০ epoch
nb_epoch = 100
for i in range(nb_epoch):
    # ১. Gradient শূন্য করো (প্রতিটি epoch-এ অবশ্যই!)
    model.zero_grad()

    # ২. Forward pass: model output হিসাব করো
    y_hat = model(X_train_tensor)  # shape: [N, 1]

    # ৩. Loss হিসাব করো
    # y_hat: [N, 1], y_train_tensor: [N] → shape mismatch!
    # [:, 0] দিয়ে [N, 1] → [N] করো
    loss_value = mse_loss(y_hat[:, 0], y_train_tensor)

    # ৪. Backward pass: gradient হিসাব করো
    loss_value.backward()

    # ৫. Optimizer step: weights আপডেট করো
    optimizer.step()

    if i % 10 == 0:
        print(f"Epoch {i}: Loss = {loss_value.item():.4f}")

from sklearn.metrics import mean_absolute_error

def evaluate(X, y):

    model.eval()

    # no_grad: gradient graph তৈরি হবে না → মেমরি বাঁচে, দ্রুত

        y_pred = model(X)

    predictions = y_pred.detach().cpu().numpy()
    true_vals = y.cpu().numpy()

    mse = ((predictions[:, 0] - true_vals) ** 2).mean()
    mae = mean_absolute_error(true_vals, predictions[:, 0])
    return mse, mae

NB02 — ইন্টারভিউ ও প্রজেক্ট অনুশীলন

ML Engineering Level

প্রশ্ন ১ — ইন্টারভিউ: nn.Parameter vs torch.tensor-এর পার্থক্য কী?

nn.Parameter: এটি একটি special tensor যেটি nn.Module-এর attribute হলে automatically model.parameters()-এ যোগ হয়। requires_grad=True default। Optimizer এটি খুঁজে পায় এবং update করে।

torch.tensor: সাধারণ tensor। nn.Module-এ রাখলেও parameters()-এ আসে না, optimizer update করে না। শুধু data store-এর জন্য।

Rule: কোনো মান train করতে চাইলে → nn.Parameter। শুধু রাখতে চাইলে → register_buffer বা plain tensor।

প্রশ্ন ২ — ইন্টারভিউ: detach(), cpu(), numpy() — কেন এই ক্রমে লিখতে হয়?

detach(): gradient graph থেকে tensor আলাদা করে। NumPy-তে convert করার আগে করতে হয়, না হলে error।

cpu(): GPU tensor-কে CPU-তে আনো। NumPy শুধু CPU tensor নিতে পারে।

numpy(): PyTorch tensor → NumPy ndarray।

ক্রম: tensor.detach().cpu().numpy() — এটাই সঠিক। GPU না থাকলে cpu() optional, কিন্তু রাখা ভালো।

কোডিং চ্যালেঞ্জ — ML Engineering: Wine Quality Regressor with Early Stopping

Training loop-এ early stopping যোগ করো: যদি পরপর ১০ epoch validation loss না কমে, training বন্ধ করো। Best model weights সেভ করো।

Python — Early Stopping + Best Model Save
import torch, copy

model = CustomLinearLayer(X_train.shape[1], 1)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-2)

best_val_loss = float('inf')
best_weights  = None
patience      = 10   # ১০ epoch ধৈর্য ধরো
no_improve    = 0

X_tr = torch.tensor(X_train, dtype=torch.float32)
y_tr = torch.tensor(y_train, dtype=torch.float32)
X_vl = torch.tensor(X_test,  dtype=torch.float32)
y_vl = torch.tensor(y_test,  dtype=torch.float32)

for epoch in range(500):
    model.train()
    model.zero_grad()
    y_hat = model(X_tr)[:, 0]
    loss = ((y_hat - y_tr) ** 2).mean()
    loss.backward()
    optimizer.step()

    # Validation
    model.eval()
    with torch.no_grad():
        val_loss = ((model(X_vl)[:, 0] - y_vl) ** 2).mean().item()

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        best_weights = copy.deepcopy(model.state_dict())
        no_improve = 0
    else:
        no_improve += 1

    if no_improve >= patience:
        print(f"Early stopping at epoch {epoch}")
        break

# Best weights পুনরুদ্ধার করো
model.load_state_dict(best_weights)
print(f"Best Val Loss: {best_val_loss:.4f}")

import torch
import torch.nn as nn
from torch import optim

device = "cpu"  # GPU থাকলে "cuda" লিখতো

# nn.Sequential দিয়ে MLP মডেল তৈরি
# input: 13 features → 100 → 100 → 100 → 50 → 1 output
model = nn.Sequential(
    nn.Linear(X.shape[1], 100),  # 13 → 100
    nn.ReLU(),                     # Activation
    nn.Linear(100, 100),
    nn.ReLU(),
    nn.Linear(100, 100),
    nn.ReLU(),
    nn.Linear(100, 50),
    nn.ReLU(),
    nn.Linear(50, 1)  # শেষ: 1 output (regression)
).to(device)

# Loss ও Optimizer
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters(), 1e-3)

# Batch Training Loop
epochs = 100
for epoch in range(epochs):
    model.train()   # Train mode (Dropout সক্রিয়)
    loss_total = 0

    for batch in train_loader:
        X_batch, y_batch = batch

        # Device-এ পাঠাও
        X_batch = X_batch.to(device)
        y_batch = y_batch.to(device)

        # Gradient শূন্য
        model.zero_grad()

        # Forward: prediction
        # float32 dtype মেলানো দরকার!
        y_pred = model(X_batch.to(torch.float32))[:, 0]

        # Loss হিসাব

        # Backward + update
        loss.backward()

        # Gradient clipping — exploding gradient রোধ করে
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

        optimizer.step()
        loss_total += loss.item()

    avg_loss = loss_total / len(train_loader)
    if epoch % 10 == 0:
        print(f"Epoch {epoch+1}/{epochs} — Loss: {avg_loss:.4f}")

প্রশ্ন ১ — ইন্টারভিউ: model.train() এবং model.eval() কখন কল করতে হয় এবং কেন?

model.train(): Training loop-এর শুরুতে। এতে Dropout layer সক্রিয় হয় (random neurons বন্ধ করে), BatchNorm running statistics update করে।

model.eval(): Validation/Test evaluation-এর আগে। Dropout বন্ধ (সব neurons ব্যবহার), BatchNorm fixed statistics ব্যবহার করে। এটা না দিলে validation result ভুল হবে।

ক্রম: for epoch → model.train() → train batches → model.eval() → torch.no_grad() → val batches

প্রশ্ন ২ — ইন্টারভিউ: 1 Epoch মানে কী? Batch size বড় করলে কী হয়?

1 Epoch: পুরো training dataset একবার দেখা শেষ করা। Dataset 1000 samples, batch_size=100 → 1 epoch = 10 batch = 10 optimizer.step()।

Batch size বড়: ↑ Memory usage, ↑ Training speed (কম steps), কিন্তু কখনো generalization খারাপ হতে পারে (sharp minima-তে আটকায়)।

Batch size ছোট: ↓ Memory, বেশি noise (কিন্তু regularization effect দেয়), ধীর কিন্তু often better generalization।

কোডিং চ্যালেঞ্জ — Production: Training + Validation Loss Tracker

import numpy as np

train_losses, val_losses = [], []

for epoch in range(100):
    # --- Training ---
    model.train()

            v_loss += criterion(pred, y_b.float()).item()

best_ep = np.argmin(val_losses) + 1
print(f"Best Epoch: {best_ep}, Val Loss: {val_losses[best_ep-1]:.4f}")

device = "cpu"

# ধাপ ৪: CNN মডেল তৈরি
# Input: [batch, 3, 64, 64]
# Conv2d(in_channels=3, out_channels=16, kernel_size=3)
#   → output: 62×62 (64-3+1=62)
# MaxPool2d(2) → 31×31
# Conv2d(16→32) → 29×29
# MaxPool2d(2) → 14×14  (29//2=14)
# Conv2d(32→64) → 12×12
# MaxPool2d(2) → 6×6
# Flatten → 64*6*6 = 2304
model = nn.Sequential(
    nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),

    nn.Conv2d(in_channels=16, out_channels=32, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),

    nn.Conv2d(in_channels=32, out_channels=64, kernel_size=3),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2),

    nn.Flatten(),                     # 64×6×6 → 2304
    nn.Linear(64 * 6 * 6, 64),
    nn.ReLU(),
    nn.Linear(64, 4)   # 4 classes — Softmax CrossEntropyLoss-এ আছে
).to(device)

# ধাপ ৫: Loss (Classification → CrossEntropyLoss)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=1e-2)

# ধাপ ৬: Training Loop (batch-এ)
for epoch in range(10):
    model.train()
    loss_total = 0
    for i, (X_batch, y_batch) in enumerate(dataloader_train):
        X_batch = X_batch.to(device)
        y_batch = y_batch.to(device)
        model.zero_grad()
        y_pred = model(X_batch.float())
        loss = criterion(y_pred, y_batch)
        loss.backward()
        optimizer.step()
        loss_total += loss.item()
    print(f"Epoch {epoch+1}: Avg Loss={loss_total/len(dataloader_train):.4f}")

CrossEntropyLoss বুঝি — Classification-এর Loss

📊

CrossEntropyLoss = Softmax + NLLLoss একসাথে

Model output (logits): [2.1, 0.3, -1.2, 0.8] → Softmax → probability → সত্যিকারের class-এর probability-র negative log।

যদি সত্যিকারের class-এর probability বেশি → loss কম। ভুল prediction → loss বেশি।

গুরুত্বপূর্ণ: CrossEntropyLoss-এ raw logits দাও (Softmax আলাদা করে apply করো না)।

NB04 — ইন্টারভিউ ও প্রজেক্ট অনুশীলন

ML Engineering Level

প্রশ্ন ১ — ইন্টারভিউ: Conv2d layer output size কীভাবে হিসাব করো?

সূত্র: output_size = (input_size − kernel_size + 2×padding) / stride + 1

উদাহরণ: Input 64×64, Conv2d(kernel=3, padding=0, stride=1) → (64−3+0)/1+1 = 62

MaxPool2d(2): output = input / 2 (half করে দেয়)

ট্রিক: padding=1 দিলে kernel_size=3 এর জন্য output size input-এর সমান থাকে।

প্রশ্ন ২ — ইন্টারভিউ: CNN-এ কেন Flatten দরকার?

Conv2d এবং MaxPool2d কাজ করে 2D image-এ (H×W)। কিন্তু Linear layer চায় 1D vector। তাই CNN-এর শেষে Flatten দিয়ে [batch, channels, H, W] → [batch, channels×H×W] করতে হয়।

উদাহরণ: [32, 64, 6, 6] → Flatten → [32, 2304]। তারপর Linear(2304, 64) দেওয়া যায়।

কোডিং চ্যালেঞ্জ — Production: CNN Evaluation with Per-Class Accuracy

Test set-এ CNN evaluate করো। প্রতিটি class-এর আলাদা accuracy report করো। sklearn-এর classification_report ব্যবহার করো।

Python — Per-Class CNN Evaluation
from sklearn.metrics import classification_report, accuracy_score
import numpy as np

CLASS_NAMES = ['glioma_tumor', 'meningioma_tumor', 'no_tumor', 'pituitary_tumor']

def evaluate_cnn(model, dataloader, device):
    model.eval()
    all_preds, all_labels = [], []

    with torch.no_grad():
        for X_b, y_b in dataloader:
            X_b = X_b.to(device)
            logits = model(X_b.float())
            # logits → class index (argmax)
            preds = logits.argmax(dim=1).cpu().numpy()
            all_preds.extend(preds)
            all_labels.extend(y_b.numpy())

    all_preds  = np.array(all_preds)
    all_labels = np.array(all_labels)

    acc = accuracy_score(all_labels, all_preds)
    print(f"Overall Accuracy: {acc:.4f} ({acc*100:.2f}%)")
    print("\nPer-Class Report:")
    print(classification_report(all_labels, all_preds,
                                 target_names=CLASS_NAMES,
                                 digits=4))
    return acc

"ফ্রিজ করা" মানে — এই লেয়ারগুলো পরিবর্তন করা যাবে না। যেমন একটি বইয়ের বেশিরভাগ অধ্যায় লক করা আছে, শুধু শেষ অধ্যায় সম্পাদনা করা যাবে।

কেন ফ্রিজ করি? কারণ প্রথম দিকের লেয়ারগুলো সাধারণ ফিচার (প্রান্ত, রেখা, রঙ) শিখেছে — এগুলো সব ছবির জন্যই কাজে লাগে। শুধু শেষের ক্লাসিফায়ার লেয়ার আমাদের নতুন কাজের জন্য।

import torch.nn as nn

device = "cpu"  # GPU থাকলে "cuda" লিখো

# in_features → আগের লেয়ার যতটি ফিচার দেয় (MobileNetV2-এ 1280)
# num_classes → নতুন আউটপুট সাইজ (আমাদের ৪টি ক্লাস)
model.classifier[-1] = nn.Linear(model.classifier[-1].in_features, num_classes)

Learning Rate Scheduler — স্বয়ংক্রিয় Learning Rate নিয়ন্ত্রণ ▼

Learning Rate কী? কেন এটি গুরুত্বপূর্ণ?

ধরো তুমি পাহাড় থেকে নামছ এবং তোমাকে সবচেয়ে গভীর উপত্যকায় (সর্বনিম্ন loss) পৌঁছাতে হবে।

Learning Rate বড় হলে: বড় বড় পদক্ষেপ নাও → দ্রুত নামছ, কিন্তু উপত্যকা পেরিয়ে যেতে পারো!
Learning Rate ছোট হলে: ছোট ছোট পদক্ষেপ → নিরাপদ, কিন্তু অনেক সময় লাগে।

সমাধান: শুরুতে বড় পদক্ষেপ, কাছে এলে ছোট পদক্ষেপ। এটাই Scheduler করে!

চিত্র: বিভিন্ন Scheduler-এ Learning Rate পরিবর্তন

Scheduler-এর তালিকা ও ব্যাখ্যা

Scheduler কী করে কখন ব্যবহার করবে
StepLR প্রতি N epoch পর LR কমায় (ধাপে ধাপে) সাধারণ কাজে, যখন কত epoch লাগবে জানো
ReduceLROnPlateau loss উন্নতি না হলে LR কমায় ★ সবচেয়ে নিরাপদ পছন্দ — স্বয়ংক্রিয় সিদ্ধান্ত নেয়
CosineAnnealingLR cosine curve মেনে LR ওঠানামা করায় আধুনিক ডিপ লার্নিং, fine-tuning
ExponentialLR প্রতি epoch-এ exponentially কমায় দ্রুত convergence দরকার হলে
OneCycleLR প্রথমে বাড়ায়, তারপর কমায় fast.ai স্টাইল ট্রেনিং

ReduceLROnPlateau সম্পূর্ণ কোড

Python — Optimizer + Scheduler 
from torch import optim

# Adam optimizer: প্রতিটি প্যারামিটারের নিজস্ব learning rate রাখে
# model.parameters(): শুধু ট্রেইনযোগ্য প্যারামিটার
# 1e-3 = 0.001 (শুরুর learning rate)
optimizer = optim.Adam(model.parameters(), 1e-3)

# ReduceLROnPlateau scheduler:
# mode='min'  → validation loss কমলে ভালো (minimize করছি)
# factor=0.1  → LR = LR × 0.1 (১০ ভাগের ১ ভাগ করো)
# patience=5  → ৫টি epoch উন্নতি না হলে তবেই LR কমাও
# verbose=True → কখন LR কমলো সেটা print করো
scheduler = optim.lr_scheduler.ReduceLROnPlateau(
    optimizer,
    mode='min',
    factor=0.1,
    patience=5,
    verbose=True
)

Training Loop কী?

প্রতিটি epoch-এ মডেল একবার পুরো ডেটাসেট দেখে। প্রতিটি batch-এ: ফরোয়ার্ড পাস → loss → ব্যাকপ্রপ → ওজন আপডেট। এটাই বারবার চলে।

Python — সম্পূর্ণ Training + Validation Loop 
from torch import optim
from tqdm.notebook import tqdm  # progress bar

epochs = 5
optimizer = optim.Adam(model.parameters(), 1e-3)

for epoch in range(epochs):
    
    # ===== TRAINING PHASE =====
    # model.train() → কিছু লেয়ার (Dropout, BatchNorm) ট্রেনিং মোডে যায়
    model.train()
    loss_total = 0
    
    # tqdm: progress bar দেখায়
    progress_bar = tqdm(dataloader_train, desc=f"Epoch {epoch}")
    
    for i, batch in enumerate(progress_bar):
        X_batch, y_batch = batch
        
        # Device-এ পাঠাও + preprocess প্রয়োগ করো
        X_batch = preprocess(X_batch.to(device))
        y_batch = y_batch.to(device)
        
        # গ্র্যাডিয়েন্ট শূন্য করো (পুরানো গ্র্যাডিয়েন্ট সরাও)
        # না করলে গ্র্যাডিয়েন্ট জমতে থাকবে!
        model.zero_grad()
        
        # Forward pass: মডেল দিয়ে prediction করো
        y_pred = model(X_batch.to(torch.float32))
        
        # Loss হিসাব করো
        loss = criterion(y_pred, y_batch)
        
        # Backward pass: প্রতিটি প্যারামিটারের গ্র্যাডিয়েন্ট হিসাব করো
        loss.backward()
        
        # Gradient descent: optimizer ওজন আপডেট করে
        optimizer.step()
        
        loss_total += loss.item()
        progress_bar.set_postfix({"loss": f"{loss_total/(i+1):.3f}"})
    
    # ===== VALIDATION PHASE =====
    # model.eval() → Dropout বন্ধ, BatchNorm inference মোডে
    model.eval()
    val_loss = 0.0
    
    # torch.no_grad(): গ্র্যাডিয়েন্ট হিসাব বন্ধ → মেমরি ও সময় বাঁচে
    with torch.no_grad():
        for X_val, y_val in dataloader_test:
            X_val = preprocess(X_val.to(device))
            y_val = y_val.to(device)
            outputs = model(X_val.to(torch.float32))
            loss = criterion(outputs, y_val)
            val_loss += loss.item()
    
    val_loss /= len(dataloader_test)
    
    # Scheduler-কে validation loss জানাও
    # যদি loss না কমে, scheduler LR কমিয়ে দেবে
    scheduler.step(val_loss)
    
    print(f"Epoch {epoch+1}/{epochs} | "
          f"Train Loss: {loss_total/len(dataloader_train):.3f} | "
          f"Val Loss: {val_loss:.3f}")

from sklearn.metrics import accuracy_score
import numpy as np

def evaluate(dataloader_val):
    model.eval()
    predictions, true_vals = [], []
    loss_val_total = 0
    
    for X_batch, y_batch in dataloader_val:
        X_batch = preprocess(X_batch.to(device))
        y_batch = y_batch.to(device)
        
        with torch.no_grad():
            y_pred = model(X_batch.to(torch.float32))
            loss = criterion(y_pred, y_batch)
            loss_val_total += loss.item()
        
        # logits → numpy → সংরক্ষণ করো
        predictions.extend(y_pred.detach().cpu().numpy())
        true_vals.extend(y_batch.cpu().numpy())
    
    predictions = np.argmax(np.array(predictions), axis=-1)
    # argmax: সর্বোচ্চ স্কোরের ক্লাস index = predicted class
    
    return {
        "loss": loss_val_total / len(dataloader_val),
        "accuracy": accuracy_score(true_vals, predictions)
    }

metrics = evaluate(dataloader_test)

Gradient কী? — একদম সহজ ভাষায়

গ্র্যাডিয়েন্ট হলো "ঢাল"। তুমি যদি একটি পাহাড়ে দাঁড়িয়ে থাকো, তোমার পা একটু নড়ালে মাটি কতটা উঁচু বা নিচু হয় — সেটাই গ্র্যাডিয়েন্ট।

গণিতে: ∂y/∂x মানে — x একটু পরিবর্তন হলে y কতটা পরিবর্তন হয়?

যদি ∂y/∂x = 200 → x একটু বাড়ালে y অনেক বেড়ে যায় → x অনেক গুরুত্বপূর্ণ!
যদি ∂y/∂x = -2 → x বাড়লে y সামান্য কমে → x কম গুরুত্বপূর্ণ।

হাতে-কলমে উদাহরণ: y = 10x₁² + x₂² − 2x₃

y(x₁, x₂, x₃) = 10·x₁² + x₂² − 2·x₃
বিন্দু (10, 5, 5) তে:
∂y/∂x₁ = 20·x₁ = 20×10 = 200 ← x₁ সবচেয়ে গুরুত্বপূর্ণ!
∂y/∂x₂ = 2·x₂ = 2×5 = 10
∂y/∂x₃ = −2 = −2 ← x₃ বাড়লে y কমে
Python — PyTorch Autograd দিয়ে Gradient 
import torch

def f(x1, x2, x3):
    return 10*x1**2 + x2**2 - 2*x3

# requires_grad=True: এই tensor-এর গ্র্যাডিয়েন্ট ট্র্যাক করো
x1 = torch.tensor(10.0, requires_grad=True)
x2 = torch.tensor(5.0,  requires_grad=True)
x3 = torch.tensor(5.0,  requires_grad=True)

# Forward pass: গণনা করো
y = f(x1, x2, x3)

# Backward pass: সব গ্র্যাডিয়েন্ট স্বয়ংক্রিয়ভাবে হিসাব হয়
y.backward()

print(f"∂y/∂x₁ = {x1.grad.item()}")  # 200.0
print(f"∂y/∂x₂ = {x2.grad.item()}")  # 10.0
print(f"∂y/∂x₃ = {x3.grad.item()}")  # -2.0

# Saliency map-এর জন্য: input × gradient (আরো স্থিতিশীল)
# x ও gradient এর গুণফল = সেই input-এর প্রকৃত প্রভাব
print(f"x₁ × ∂y/∂x₁ = {(x1.grad*x1).item()}")  # 2000.0
print(f"x₂ × ∂y/∂x₂ = {(x2.grad*x2).item()}")  # 50.0
print(f"x₃ × ∂y/∂x₃ = {(x3.grad*x3).item()}")  # -10.0

input × gradient কেন?

শুধু gradient অস্থির হতে পারে (খুব গভীর নেটওয়ার্কে)। input × gradient দিলে "এই input-এর মান যদি 0 হতো তাহলে আউটপুটে কতটা পরিবর্তন হতো" — সেই হিসাব পাওয়া যায়। এটি Integrated Gradients এবং Grad-CAM-এর মূল ধারণা।

GradCAM — ছবির কোন অংশ দেখে মডেল সিদ্ধান্ত নেয় ▼

GradCAM কী? — শিশুর মতো বুঝি

তুমি ছবি দেখে "বিড়াল" বলেছ। আমি জিজ্ঞেস করলাম: "কোথায় দেখলে?" তুমি ছবির বিড়ালের মুখের দিকে আঙুল দেখালে।

GradCAM ঠিক এটাই করে! এটি একটি heat map (তাপ মানচিত্র) তৈরি করে যেখানে "গরম" (লাল) অংশগুলো মডেলের সিদ্ধান্তে সবচেয়ে বেশি প্রভাব ফেলেছে।

GradCAM = Gradient-weighted Class Activation Mapping
গ্র্যাডিয়েন্ট × অ্যাক্টিভেশন = গুরুত্বের মানচিত্র

চিত্র: GradCAM-এর সম্পূর্ণ প্রক্রিয়া (Source: LearnOpenCV অনুসরণে)

GradCAM-এর ধাপসমূহ

  1. Target layer নির্বাচন: CNN-এর শেষ convolutional layer (ResNet50-এ 'layer4'). কেন শেষ layer? কারণ এটি সবচেয়ে জটিল ও নির্দিষ্ট ফিচার ধরে।
  2. Forward hook: Target layer-এর activation output সংরক্ষণ করো।
  3. Forward pass: ছবি মডেলে দিয়ে prediction পাও।
  4. Backward pass: target class-এর score (yᶜ)-এর সাপেক্ষে target layer-এর gradient হিসাব করো।
  5. Global Average Pooling: gradients-এর spatial মাত্রায় গড় নাও → αᵏ (importance weight)।
  6. Weighted sum + ReLU: activations × αᵏ গুণ করো, সব channel যোগ করো, ReLU দিয়ে negative সরাও।
Python — GradCAM সম্পূর্ণ Implementation 
import torch
import torch.nn.functional as F
import numpy as np
import matplotlib.pyplot as plt
from torchvision import models, transforms
from torchvision.models import ResNet50_Weights
from PIL import Image

# মডেল লোড
weights = ResNet50_Weights.IMAGENET1K_V1
model = models.resnet50(weights=weights)

# Preprocessing: ResNet50 চায় 224×224, normalized
preprocess = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])

def make_gradcam_heatmap(img_tensor, model, target_layer_name, pred_index=None):
    """
    img_tensor: প্রস্তুত ছবি tensor [1, C, H, W]
    model: প্রি-ট্রেইনড মডেল
    target_layer_name: কোন layer-এর activation দেখব ('layer4')
    pred_index: কোন ক্লাসের জন্য heatmap (None হলে সর্বোচ্চ probability)
    """
    
    # Hook: target layer-এর output সংরক্ষণ করো
    # Hook মানে: layer-এর কাজ শেষ হলে আমাদের function call করো
    def forward_hook(module, input, output):
        model.features = output  # activation সংরক্ষণ
    
    hook = model._modules.get(target_layer_name).register_forward_hook(forward_hook)
    
    # Forward pass
    output = model(img_tensor)
    
    hook.remove()  # hook সরাও (মেমরি পরিষ্কার)
    
    # কোন ক্লাসের জন্য? না বললে সর্বোচ্চটি নাও
    if pred_index is None:
        pred_index = output.argmax(dim=1).item()
    
    # সেই ক্লাসের score
    y = output[0, pred_index]
    
    # Backward: y-এর সাপেক্ষে target layer-এর gradient
    model.zero_grad()
    model.features.retain_grad()  # intermediate layer-এর gradient রেখো
    y.backward(retain_graph=True)
    
    # Gradient ও Activation সংগ্রহ
    gradients  = model.features.grad[0]  # [C, H, W]
    activations = model.features[0]      # [C, H, W]
    
    # Global Average Pooling: প্রতিটি channel-এর importance weight
    # dim=[1,2] মানে: H ও W মাত্রায় গড় নাও
    pooled_grads = torch.mean(gradients, dim=[1, 2])  # [C]
    
    # Activation × weight
    for i in range(len(pooled_grads)):
        activations[i, :, :] *= pooled_grads[i]
    
    # Channel মাত্রায় গড় → heatmap [H, W]
    heatmap = torch.mean(activations, dim=0).detach().numpy()
    
    # ReLU: negative মান সরাও (negative = ক্লাসের বিরুদ্ধে প্রমাণ)
    # Normalize: 0-1 এর মধ্যে আনো
    heatmap = np.maximum(heatmap, 0)
    heatmap /= np.max(heatmap)
    
    return heatmap

# ব্যবহার
img = Image.open("cat_dog.png")
img_tensor = preprocess(img).unsqueeze(0)  # batch dimension যোগ

dog_index = 159  # ImageNet-এ Rhodesian Ridgeback

heatmap_dog = make_gradcam_heatmap(img_tensor, model, 'layer4', dog_index)
heatmap_cat = make_gradcam_heatmap(img_tensor, model, 'layer4', cat_index)

# দেখাও
fig, axes = plt.subplots(2, 2, figsize=(10, 7))
axes[0,0].imshow(img);          axes[0,0].set_title("মূল ছবি")
axes[0,1].imshow(heatmap_dog, cmap='jet'); axes[0,1].set_title("কুকুরের গুরুত্বপূর্ণ অঞ্চল")
axes[1,0].imshow(img);          axes[1,0].set_title("মূল ছবি")
axes[1,1].imshow(heatmap_cat, cmap='jet'); axes[1,1].set_title("বিড়ালের গুরুত্বপূর্ণ অঞ্চল")
plt.tight_layout(); plt.show()

Integrated Gradients — পথের গ্র্যাডিয়েন্টের সমষ্টি ▼

Integrated Gradients কী?

ধরো তুমি শূন্য থেকে একটি পূর্ণ ছবির দিকে হাঁটছ — ধীরে ধীরে ছবিটি উজ্জ্বল হচ্ছে। প্রতিটি পদক্ষেপে মডেলের মতামত কতটা বদলাচ্ছে সেটা মাপো। সব পদক্ষেপের মতামত যোগ করলে পাবে: ছবির কোন অংশ সিদ্ধান্তে কতটা অবদান রেখেছে।

GradCAM vs IG: GradCAM শুধু একটি মধ্যবর্তী layer দেখে। IG সরাসরি input pixel স্তরে কাজ করে — তাই ছবিতে pixel-level resolution পাওয়া যায়।

IG-এর গণিত — সহজ ভাষায়

বেসলাইন (x'): সম্পূর্ণ কালো ছবি [সব pixel = 0]
Input (x): আসল ছবি

পথের বিন্দু k: x'ₖ = x' + (k/m) × (x - x')
k=0 → কালো ছবি, k=m → আসল ছবি, মাঝে m টি মধ্যবর্তী ছবি

IG(x) = (x - x') × (1/m) × Σ [∂F(x'ₖ)/∂x'ₖ]
k=1 to m

ব্যাখ্যা: "পথের সব gradient যোগ করো, ইনপুটের পার্থক্য দিয়ে গুণ করো"

চিত্র: Integrated Gradients — baseline থেকে input পর্যন্ত পথের gradient সমষ্টি

Captum কী?

Facebook AI-এর তৈরি PyTorch-নির্দিষ্ট interpretability লাইব্রেরি। "Captum" মানে লাতিনে "বোঝা"। এতে আছে: Integrated Gradients, DeepLIFT, SHAP, GradCAM, Occlusion ইত্যাদি। তিনটি গ্রুপ: Primary Attribution, Layer Attribution, Neuron Attribution।

Python — Captum দিয়ে Integrated Gradients 
from captum.attr import LayerIntegratedGradients

# LayerIntegratedGradients: একটি নির্দিষ্ট layer-এর সাপেক্ষে IG হিসাব করে
# model: আমাদের ResNet50
# model.conv1: ResNet50-এর প্রথম convolutional layer (input-এর কাছাকাছি)
lig = LayerIntegratedGradients(model, model.conv1)

device = "cpu"

def show_importance(model, input_tensor, target=0, device=device):
    """
    model: ResNet50 মডেল
    input_tensor: প্রস্তুত ছবি tensor [1, C, H, W]
    target: কোন ক্লাসের গুরুত্ব দেখব (ImageNet class index)
    return: importance map [H, W] (প্রতিটি pixel-এর গুরুত্ব)
    """
    input_tensor = input_tensor.to(device)
    model.to(device)
    
    # IG হিসাব:
    # inputs: আসল ছবি
    # target: যে ক্লাসের attribution চাই
    # n_steps: পথে কতটি মধ্যবর্তী বিন্দু (বেশি = নির্ভুল, কিন্তু ধীর)
    # return_convergence_delta: True হলে approximation error ফেরত দেয়
    attributions, delta = lig.attribute(
        inputs=input_tensor,
        target=target,
        return_convergence_delta=True,
        n_steps=100
    )
    
    # attributions shape: [1, C, H, W]
    # .sum(dim=1): channel মাত্রায় যোগ করো → [H, W]
    # .squeeze(0): batch dimension সরাও
    importance = attributions.sum(dim=1).squeeze(0)
    
    # Normalize
    importance = importance / torch.norm(importance)
    importance = importance.cpu().detach().numpy()
    
    return importance

# ব্যবহার
heatmap_dog = show_importance(model, img_tensor, dog_index)
heatmap_cat = show_importance(model, img_tensor, cat_index)

Occlusion পদ্ধতি — সবচেয়ে সহজ ধারণা

তোমার কাছে একটি ছবি আছে যেখানে বিড়াল আছে। তুমি ছবির বিভিন্ন অংশ কালো কাপড় দিয়ে ঢেকে দাও এবং মডেলকে প্রতিবার জিজ্ঞেস করো: "এটা বিড়াল?"

যখন তুমি বিড়ালের মুখ ঢাকলে, মডেল বলল "আমি নিশ্চিত না"। অন্য অংশ ঢাকলে কোনো পরিবর্তন নেই।

উপসংহার: মুখের অংশটি সবচেয়ে গুরুত্বপূর্ণ!

এই পদ্ধতিতে Gradient লাগে না। যেকোনো মডেলে কাজ করে। কিন্তু অনেক সময় লাগে (প্রতিটি অবস্থানের জন্য একটি forward pass)।

Occlusion-এর ধাপ

1

Sliding Window

একটি আয়তক্ষেত্রাকার মাস্ক তৈরি করো (যেমন 15×15 pixel)।

2

Slide করো

মাস্কটি ছবির উপর দিয়ে সরাও (stride = 8 pixel)।

3

Impact মাপো

প্রতিটি অবস্থানে prediction কতটা বদলায় সেটা রেকর্ড করো।

4

Map তৈরি

সব impact একসাথে রাখলেই importance map তৈরি হয়।

Python — Captum Occlusion 
from captum.attr import Occlusion
import numpy as np

# Occlusion object তৈরি
lig = Occlusion(model)

# Sliding window এর আকার: (channel, H, W)
# (3, 15, 15) → RGB তিনটি channel-এ 15×15 pixel মাস্ক
sliding_window_shapes = (3, 15, 15)

img_tensor = preprocess(img).unsqueeze(0)
device = "cpu"

def show_importance_occlusion(model, input_tensor, target=0, device="cpu"):
    input_tensor = input_tensor.to(device)
    model.to(device)
    
    # Occlusion attribution হিসাব:
    # strides=(3, 8, 8) → channel 3 skip, H দিয়ে 8 pixel, W দিয়ে 8 pixel slide
    # target → কোন ক্লাসের attribution
    # sliding_window_shapes → মাস্কের আকার
    attributions = lig.attribute(
        inputs=input_tensor,
        strides=(3, 8, 8),
        target=target,
        sliding_window_shapes=sliding_window_shapes
    )
    
    # Channel মাত্রায় যোগ → [H, W]
    importance = attributions.sum(dim=1).squeeze(0)
    importance = importance.cpu().detach().numpy()
    
    # GradCAM-এর মতো normalize
    importance = np.maximum(importance, 0)
    importance /= np.max(importance)
    
    return importance

heatmap_dog = show_importance_occlusion(model, img_tensor, dog_index)
heatmap_cat = show_importance_occlusion(model, img_tensor, cat_index)

প্রজেক্ট অনুশীলন: সম্পূর্ণ Interpretability Pipeline

তোমার ব্রেইন টিউমার মডেলের জন্য একটি interpretability রিপোর্ট তৈরি করো যা: (১) তিনটি পদ্ধতি তুলনা করবে, (২) ভুল prediction-এর কারণ বিশ্লেষণ করবে, (৩) PDF রিপোর্ট সংরক্ষণ করবে।

import matplotlib.pyplot as plt
import matplotlib.gridspec as gridspec
from matplotlib.backends.backend_pdf import PdfPages
import torch, numpy as np

class InterpretabilityPipeline:
    def __init__(self, model, preprocess, class_names, device="cpu"):
        self.model = model
        self.preprocess = preprocess
        self.class_names = class_names
        self.device = device
        # তিনটি method initialize করো
        from captum.attr import LayerGradCam, LayerIntegratedGradients, Occlusion
        self.gradcam = LayerGradCam(model, model._modules.get('layer4'))
        self.ig = LayerIntegratedGradients(model, model.conv1)
        self.occ = Occlusion(model)

    def analyze(self, img_tensor, true_label):
        """একটি ছবির সম্পূর্ণ interpretability বিশ্লেষণ"""
        inp = img_tensor.to(self.device)
        
        # Prediction
        with torch.no_grad():
            logits = self.model(inp)
            pred = logits.argmax(dim=1).item()
            confidence = torch.softmax(logits, dim=1)[0, pred].item()
        
        results = {
            'true_label': self.class_names[true_label],
            'pred_label': self.class_names[pred],
            'confidence': confidence,
            'correct': pred == true_label,
            'heatmaps': {}
        }
        
        # GradCAM
        attr = self.gradcam.attribute(inp, target=pred)
        hm = attr.sum(1).squeeze(0).cpu().detach().numpy()
        hm = np.maximum(hm, 0); hm /= (np.max(hm) + 1e-8)
        results['heatmaps']['GradCAM'] = hm
        
        # Integrated Gradients
        attr, _ = self.ig.attribute(inp, target=pred,
                                     return_convergence_delta=True, n_steps=50)
        hm = attr.sum(1).squeeze(0).cpu().detach().numpy()
        hm = hm / (np.linalg.norm(hm) + 1e-8)
        results['heatmaps']['Integrated Gradients'] = hm
        
        # Occlusion
        attr = self.occ.attribute(inp, strides=(3,8,8), target=pred,
                                   sliding_window_shapes=(3,15,15))
        hm = attr.sum(1).squeeze(0).cpu().detach().numpy()
        hm = np.maximum(hm, 0); hm /= (np.max(hm) + 1e-8)
        results['heatmaps']['Occlusion'] = hm
        
        return results

    def generate_pdf_report(self, test_samples, pdf_path="interpretability_report.pdf"):
        with PdfPages(pdf_path) as pdf:
            for i, (img_tensor, label) in enumerate(test_samples[:5]):
                results = self.analyze(img_tensor, label)
                
                fig = plt.figure(figsize=(16, 5))
                fig.suptitle(
                    f"নমুনা {i+1} | সত্য: {results['true_label']} | "
                    f"পূর্বাভাস: {results['pred_label']} | "
                    f"আস্থা: {results['confidence']:.1%} | "
                    f"{'✅ সঠিক' if results['correct'] else '❌ ভুল'}",
                    fontsize=13
                )
                # Heatmaps দেখাও
                methods = list(results['heatmaps'].items())
                for j, (name, hm) in enumerate(methods):
                    ax = fig.add_subplot(1, len(methods), j+1)
                    ax.imshow(hm, cmap='jet')
                    ax.set_title(name); ax.axis('off')
                
                pdf.savefig(fig, bbox_inches='tight')
                plt.close()
        
        print(f"✅ রিপোর্ট সংরক্ষিত: {pdf_path}")

# ব্যবহার

🧒 Occlusion কী?

একটি পোস্টার দেখছ, বুঝতে চাইছ কোন অংশ সবচেয়ে গুরুত্বপূর্ণ। একটি কাগজ দিয়ে বিভিন্ন অংশ ঢেকে দেখলে — যখন ঢাকলে মডেল ভুল উত্তর দেয়, সেই অংশটাই গুরুত্বপূর্ণ! Occlusion ঠিক এই কাজটি করে — একটি sliding window দিয়ে ছবির অংশ ঢেকে দেখে মডেলের prediction কতটা বদলায়।

from captum.attr import Occlusion

def model_output_occ(inputs):
    return model(inputs)[0]

occ = Occlusion(model_output_occ)

def show_occlusion(model, input_tensor, target=0, device="cpu"):
    input_tensor = input_tensor.to(device)
    model.to(device)

    # strides=(3,8,8): 3 channel, প্রতি ৮ pixel-এ window সরে
    # sliding_window_shapes=(3,15,15): ৩ channel, ১৫×১৫ pixel বক্স ঢাকে

        inputs=input_tensor,
        strides=(3, 8, 8),
        target=target,
        sliding_window_shapes=(3, 15, 15)

    importance = attributions.sum(dim=1).squeeze(0)
    importance = importance / torch.norm(importance)
    return importance.cpu().detach().numpy()

📌 LIG vs Occlusion — কোনটি কখন?

LIG (Layer Integrated Gradients): Gradient-based, দ্রুত, তবে ViT-এ patch-level granularity।

Python — Production Sentiment Analyzer 
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch
import torch.nn.functional as F
from dataclasses import dataclass
from typing import List

@dataclass
class SentimentResult:
    text: str
    label: str
    confidence: float
    is_certain: bool

class ProductionSentimentAnalyzer:
    def __init__(self,
                 model_name="nlptown/bert-base-multilingual-uncased-sentiment",
                 confidence_threshold=0.6):
        self.device = "cuda" if torch.cuda.is_available() else "cpu"
        self.threshold = confidence_threshold
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModelForSequenceClassification.from_pretrained(model_name)
        self.model.to(self.device).eval()

    def predict_batch(self, texts: List[str], batch_size=16) -> List[SentimentResult]:
        results = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i:i+batch_size]
            inputs = self.tokenizer(
                batch, return_tensors="pt",
                truncation=True, padding=True, max_length=512
            ).to(self.device)
            with torch.no_grad():
                outputs = self.model(**inputs)
            probs = F.softmax(outputs.logits, dim=-1)
            confidences, predicted = probs.max(dim=-1)
            for j, text in enumerate(batch):
                conf = confidences[j].item()
                results.append(SentimentResult(
                    text=text,
                    label=self.model.config.id2label[predicted[j].item()],
                    confidence=conf,
                    is_certain=conf >= self.threshold
                ))
        return results

# ব্যবহার
analyzer = ProductionSentimentAnalyzer(confidence_threshold=0.65)
texts = ["Great product!", "Okay I guess", "Absolutely terrible."]
for r in analyzer.predict_batch(texts):
    status = "✅" if r.is_certain else "⚠️ Uncertain"
    print(f"{status} | {r.label} ({r.confidence:.1%}) | '{r.text[:30]}'")

কীভাবে কাজ করে

  1. একটি বড় dataset-এ প্রশিক্ষিত মডেল নাও (যেমন ImageNet-এ ResNet50)

Python — সম্পূর্ণ Transfer Learning Template 
import torch
import torch.nn as nn
from torchvision import models
from torchvision.models import ResNet50_Weights

def build_transfer_model(num_classes, freeze_all=True, unfreeze_last_n=0):
    """
    num_classes: তোমার কাজের ক্লাস সংখ্যা
    freeze_all: সব layer ফ্রিজ করবে?
    unfreeze_last_n: শেষ কতটি ResNet block খোলা রাখবে (fine-tuning)
    """
    weights = ResNet50_Weights.DEFAULT
    model = models.resnet50(weights=weights)

    # সব ফ্রিজ করো
    if freeze_all:
        for param in model.parameters():
            param.requires_grad = False

    # Fine-tuning: শেষ n block খোলো
    blocks = [model.layer1, model.layer2, model.layer3, model.layer4]
    for block in blocks[-unfreeze_last_n:]:
        for param in block.parameters():
            param.requires_grad = True

    # নতুন classifier
    model.fc = nn.Sequential(
        nn.Dropout(0.3),
        nn.Linear(model.fc.in_features, num_classes)
    )

    total = sum(p.numel() for p in model.parameters())
    trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
    print(f"মোট: {total:,} | ট্রেইনযোগ্য: {trainable:,} ({trainable/total:.1%})")
    return model, weights

# ব্যবহার
model, weights = build_transfer_model(num_classes=4, freeze_all=True, unfreeze_last_n=1)

GradCAM (Gradient-weighted Class Activation Mapping)

Interpretability CNN Visualization XAI

🧒 শিশুর মতো ব্যাখ্যা

তোমাকে লুকানো জিনিস খুঁজতে বলা হয়েছে। তুমি খুঁজে পেয়েছ। এখন আমি বললাম: "কোথায় ছিল?" তুমি যেখানে দেখলে সেখানে আঙুল দেখাও। GradCAM মডেলকে জিজ্ঞেস করে: "কোথায় দেখে এই সিদ্ধান্ত নিলে?" এবং সেই জায়গা রঙ দিয়ে চিহ্নিত করে।

সূত্র

αᵏ = (1/Z) × Σᵢ Σⱼ (∂yᶜ / ∂Aᵏᵢⱼ) [Global Average Pooling of gradients]
GradCAM = ReLU(Σₖ αᵏ × Aᵏ) [Weighted sum of activation maps + ReLU]
Python — Production-ready GradCAM Class 
import torch, numpy as np
import cv2  # pip install opencv-python

class GradCAM:
    """Production-ready GradCAM — যেকোনো CNN মডেলে কাজ করে"""

    def __init__(self, model, target_layer):
        self.model = model
        self.target_layer = target_layer
        self.gradients = None
        self.activations = None
        self._register_hooks()

    def _register_hooks(self):
        def forward_hook(module, inp, out):
            self.activations = out.detach()

        def backward_hook(module, grad_in, grad_out):
            self.gradients = grad_out[0].detach()

        self.target_layer.register_forward_hook(forward_hook)
        self.target_layer.register_full_backward_hook(backward_hook)

    def generate(self, input_tensor, class_idx=None):
        self.model.eval()
        output = self.model(input_tensor)

        if class_idx is None:
            class_idx = output.argmax(dim=1).item()

        self.model.zero_grad()
        output[0, class_idx].backward(retain_graph=True)

        # αᵏ: channel-wise global average of gradients
        weights = self.gradients.mean(dim=[2, 3], keepdim=True)  # [1, C, 1, 1]
        cam = (weights * self.activations).sum(dim=1).squeeze()   # [H, W]
        cam = torch.relu(cam).numpy()

        # Normalize + resize to original image size
        cam = (cam - cam.min()) / (cam.max() - cam.min() + 1e-8)
        cam = cv2.resize(cam, (224, 224))
        return cam, class_idx

    def overlay(self, original_img_np, cam, alpha=0.4):
        """মূল ছবির উপর heatmap overlay করো"""
        heatmap = cv2.applyColorMap(np.uint8(255 * cam), cv2.COLORMAP_JET)
        heatmap = cv2.cvtColor(heatmap, cv2.COLOR_BGR2RGB)
        overlay = (1 - alpha) * original_img_np + alpha * heatmap / 255
        return np.clip(overlay, 0, 1)

Integrated Gradients

Interpretability Axiomatic High-Resolution Any Model

🧒 শিশুর মতো ব্যাখ্যা

কালো ঘরে (বেসলাইন) থেকে ধীরে ধীরে আলো জ্বালাও (input)। প্রতিটি মুহূর্তে দেখো আলো বাড়লে মডেলের মত কতটা বদলায়। যে জায়গায় আলো জ্বালালে সবচেয়ে বেশি পরিবর্তন হয় — সেটাই সবচেয়ে গুরুত্বপূর্ণ।

সূত্র

IG(x) = (x − x') × (1/m) × Σ [∂F(x' + k/m × (x−x')) / ∂x] for k=1..m
x' = baseline (কালো ছবি), m = step count (50-300), F = মডেলের output
Python — Integrated Gradients নিজে implement করো (Captum ছাড়া) 
import torch

def integrated_gradients(model, input_tensor, target_class, baseline=None, n_steps=100):
    """
    model: যেকোনো differentiable PyTorch model
    input_tensor: [1, C, H, W] shape-এর ছবি
    target_class: কোন ক্লাসের attribution চাই
    baseline: নিরপেক্ষ ইনপুট (None হলে কালো ছবি)
    n_steps: interpolation step সংখ্যা
    """
    if baseline is None:
        baseline = torch.zeros_like(input_tensor)

    # interpolated inputs: baseline → input, m টি পদক্ষেপে
    alphas = torch.linspace(0, 1, n_steps).to(input_tensor.device)
    interpolated = [baseline + alpha * (input_tensor - baseline) for alpha in alphas]
    interpolated = torch.cat(interpolated, dim=0).requires_grad_(True)

    # সব interpolated input-এ forward pass
    model.eval()
    outputs = model(interpolated)
    target_scores = outputs[:, target_class].sum()

    # Gradient হিসাব (একসাথে সব interpolation point-এ)
    grads = torch.autograd.grad(target_scores, interpolated)[0]  # [m, C, H, W]

    # Riemann sum (trapezoid): সব gradient-এর গড়
    avg_grads = grads.mean(dim=0, keepdim=True)  # [1, C, H, W]

    # IG = (input - baseline) × average_gradient
    ig = (input_tensor - baseline) * avg_grads
    return ig  # [1, C, H, W] — প্রতিটি pixel-এর attribution

Occlusion Sensitivity

Interpretability Gradient-free Any Model Black-box

🧒 শিশুর মতো ব্যাখ্যা

তোমার বন্ধু ছবি দেখে বলছে "এটা বিড়াল"। তুমি ছবির আলাদা আলাদা অংশ হাত দিয়ে ঢেকে দিলে। যখন বিড়ালের চোখ ঢাকলে সে বলল "নিশ্চিত না" — তার মানে চোখটা গুরুত্বপূর্ণ ছিল। এটাই Occlusion।

Python — Occlusion Sensitivity (Captum ছাড়া) 
import torch, numpy as np

def occlusion_sensitivity(model, input_tensor, target_class,
                           window_size=15, stride=8, fill_value=0):
    """
    window_size: মাস্কের আকার (pixel)
    stride: কতটুকু সরাবে প্রতিবার
    fill_value: মাস্ক করা অংশ কী দিয়ে ভরবে (0=কালো, 0.5=ধূসর)
    """
    model.eval()
    _, C, H, W = input_tensor.shape
    
    # মূল prediction score
    with torch.no_grad():
        base_score = torch.softmax(model(input_tensor), dim=1)[0, target_class].item()
    
    # Importance map (H × W, সব শূন্য দিয়ে শুরু)
    importance_map = np.zeros((H, W))
    count_map = np.zeros((H, W))  # কতবার প্রতিটি pixel ঢাকা হয়েছে
    
    # Sliding window
    for y in range(0, H - window_size + 1, stride):
        for x in range(0, W - window_size + 1, stride):
            occluded = input_tensor.clone()
            occluded[0, :, y:y+window_size, x:x+window_size] = fill_value
            
            with torch.no_grad():
                score = torch.softmax(model(occluded), dim=1)[0, target_class].item()
            
            # Base score - new score = গুরুত্ব (যত বেশি কমেছে, তত গুরুত্বপূর্ণ ছিল)
            importance_map[y:y+window_size, x:x+window_size] += (base_score - score)
            count_map[y:y+window_size, x:x+window_size] += 1
    
    # গড় নাও (কিছু pixel একাধিকবার ঢাকা হয়েছে)
    importance_map = np.where(count_map > 0, importance_map / count_map, 0)
    return importance_map

from sklearn.metrics import (
    accuracy_score, classification_report,
    confusion_matrix, roc_auc_score
)
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

def full_evaluation(model, dataloader, class_names, device="cpu"):
    """সম্পূর্ণ model evaluation — production-ready"""
    model.eval()
    all_preds, all_true, all_probs = [], [], []

    with torch.no_grad():
        for X, y in dataloader:
            X, y = X.to(device), y.to(device)
            logits = model(X)
            probs = torch.softmax(logits, dim=1)
            preds = logits.argmax(dim=1)

            all_preds.extend(preds.cpu().numpy())
            all_true.extend(y.cpu().numpy())
            all_probs.extend(probs.cpu().numpy())

    all_preds = np.array(all_preds)
    all_true  = np.array(all_true)
    all_probs = np.array(all_probs)

    # ১. Accuracy
    acc = accuracy_score(all_true, all_preds)
    print(f"Accuracy: {acc:.4f} ({acc*100:.2f}%)")

    # ২. Precision, Recall, F1 (per class)
    print("\nClassification Report:")
    print(classification_report(all_true, all_preds, target_names=class_names))

    # ৩. Confusion Matrix
    cm = confusion_matrix(all_true, all_preds)
    fig, ax = plt.subplots(figsize=(8, 6))
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
                xticklabels=class_names, yticklabels=class_names, ax=ax)
    ax.set_xlabel('পূর্বাভাস'); ax.set_ylabel('সত্য')
    ax.set_title('Confusion Matrix')
    plt.tight_layout(); plt.savefig('confusion_matrix.png', dpi=150)
    plt.show()

    # ৪. ROC-AUC (multiclass)
    # one-vs-rest পদ্ধতিতে
    try:
        auc = roc_auc_score(all_true, all_probs, multi_class='ovr')
        print(f"ROC-AUC (OvR): {auc:.4f}")
    except:
        print("ROC-AUC হিসাব করা যায়নি")

    return {'accuracy': acc, 'confusion_matrix': cm, 'probabilities': all_probs}

# ব্যবহার
class_names = ['glioma', 'meningioma', 'no_tumor', 'pituitary']
results = full_evaluation(model, dataloader_test, class_names)

weights = MobileNet_V2_Weights.DEFAULT

# ২. Loss + Optimizer + Scheduler
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), 1e-3)
scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, 'min', patience=5)
preprocess = weights.transforms()

# ৩. Training Loop
for epoch in range(epochs):
    model.train()
    for X, y in dataloader_train:
        model.zero_grad()
        loss = criterion(model(preprocess(X)), y)
        loss.backward(); optimizer.step()
    model.eval()
    val_loss = sum(criterion(model(preprocess(X)), y).item()
                   for X, y in dataloader_test) / len(dataloader_test)
    scheduler.step(val_loss)

                         return_convergence_delta=True, n_steps=100)

Gradient-based পদ্ধতির মূল সীমাবদ্ধতা

  • Gradient saturation: খুব গভীর নেটওয়ার্কে gradient প্রায় শূন্য হয়ে যায় (vanishing gradient)। IG এটি baseline integration দিয়ে কমায়।
  • Input sensitivity: সামান্য noise দিলে attribution map অনেক বদলাতে পারে।
  • Linear assumption: GradCAM ও IG ধরে নেয় মডেল locally linear — বাস্তবে সত্য নাও হতে পারে।

কীভাবে কাজ করে — ৬টি ধাপ

  1. Hugging Face Hub থেকে pre-trained মডেল ডাউনলোড

import torch, evaluate, numpy as np
from PIL import Image
from transformers import (AutoImageProcessor, AutoModelForImageClassification,
                           TrainingArguments, Trainer)

MODEL_ID = "WinKawaks/vit-small-patch16-224"
processor = AutoImageProcessor.from_pretrained(MODEL_ID)
model = AutoModelForImageClassification.from_pretrained(
    MODEL_ID, num_labels=4, ignore_mismatched_sizes=True
)

class ImageDataset(torch.utils.data.Dataset):
    def __init__(self, X, y): self.X, self.y = X, y
    def __getitem__(self, idx):
        enc = processor(Image.open(self.X[idx]), return_tensors="pt")
        return {"pixel_values": enc["pixel_values"][0], "labels": torch.tensor(self.y[idx])}
    def __len__(self): return len(self.X)

acc = evaluate.load("accuracy")
def compute_metrics(ep):
    return acc.compute(predictions=np.argmax(ep.predictions,-1), references=ep.label_ids)

trainer = Trainer(
    model=model,
    args=TrainingArguments("./output", num_train_epochs=5, per_device_train_batch_size=8,
                            learning_rate=2e-5, evaluation_strategy="epoch",
                            load_best_model_at_end=True),
    train_dataset=ImageDataset(X_train, y_train),
    eval_dataset=ImageDataset(X_test, y_test),
    compute_metrics=compute_metrics
)
trainer.train()
model.save_pretrained("./my_finetuned_model")

🧒 শিশুর মতো ব্যাখ্যা

Integrated Gradients: মডেল বলল "এটা টিউমার"। আমরা জিজ্ঞেস করি — ছবির কোন অংশ দেখে বলল? Gradient হিসাব করে বলা যায় কোন pixel পরিবর্তন হলে সিদ্ধান্ত সবচেয়ে বদলায়।
Occlusion: একটি কালো বক্স দিয়ে ছবির বিভিন্ন অংশ ঢেকে দেখো — যে অংশ ঢাকলে মডেল সবচেয়ে বেশি ভুল করে, সেটাই সবচেয়ে গুরুত্বপূর্ণ।

Python — LIG + Occlusion Combined Template
from captum.attr import LayerIntegratedGradients, Occlusion
import torch, numpy as np

def model_fn(x): return model(x)[0]

# LIG
lig = LayerIntegratedGradients(model_fn, model.vit.embeddings.patch_embeddings.projection)
def lig_map(img_t, target):
    attr, _ = lig.attribute(img_t, target=target, return_convergence_delta=True, n_steps=50)
    imp = attr.sum(dim=1).squeeze(0)
    return (imp / torch.norm(imp)).cpu().detach().numpy()

# Occlusion
occ = Occlusion(model_fn)
def occ_map(img_t, target):
    attr = occ.attribute(img_t, strides=(3,8,8), target=target, sliding_window_shapes=(3,15,15))
    imp = attr.sum(dim=1).squeeze(0)
    return (imp / torch.norm(imp)).cpu().detach().numpy()

সাধারণ ইন্টারভিউ প্রশ্ন ও উত্তর

Q: Transfer Learning কখন কাজ করে না?

যখন নতুন ডেটা মূল training ডেটার থেকে অনেক আলাদা (domain shift অনেক বেশি)। যেমন: ImageNet মডেল দিয়ে satellite image — কিছুটা কাজ করবে। কিন্তু X-ray → audio waveform — কাজ করবে না কারণ data structure সম্পূর্ণ ভিন্ন।

Q: GradCAM এবং LIME-এর পার্থক্য কী?

GradCAM: CNN-নির্দিষ্ট, gradient-based, দ্রুত। শুধু ছবিতে কাজ করে।
LIME (Local Interpretable Model-agnostic Explanations): যেকোনো মডেলে কাজ করে (model-agnostic)। ছোট perturbation করে local linear মডেল fit করে। ধীর কিন্তু universal।

Q: model.train() এবং model.eval()-এর পার্থক্য কী?

model.train(): Dropout সক্রিয় (random neurons বন্ধ করে overfitting কমায়), BatchNorm running statistics update করে।
model.eval(): Dropout বন্ধ (সব neurons ব্যবহার), BatchNorm frozen statistics ব্যবহার করে। Validation ও inference-এ অবশ্যই eval() দিতে হবে।

Q: torch.no_grad() কেন ব্যবহার করি?

Inference বা validation-এ gradient computation দরকার নেই। torch.no_grad() দিলে:
১. Gradient graph তৈরি হয় না → মেমরি ৩০-৪০% কম লাগে
২. Computation দ্রুত হয়
৩. GPU memory overflow এড়ানো যায় বড় batch-এ

Q: CrossEntropyLoss কীভাবে কাজ করে?

CrossEntropyLoss = Softmax + Negative Log-Likelihood একসাথে।
সূত্র: L = −log(softmax(yᶜ)) যেখানে c = সত্যিকারের ক্লাস।
যদি সঠিক ক্লাসের probability বেশি হয় → loss কম। ভুল prediction → loss বেশি।
input: raw logits (Softmax ব্যবহার করো না আলাদা করে!)

Q: n_steps=100 in Integrated Gradients — এটা বাড়ালে কী হয়?

n_steps বাড়ালে → numerical integration আরো নির্ভুল হয় → convergence_delta কমে।
কিন্তু → computation বেশি লাগে (n_steps টি forward pass হয়)।
Practice: n_steps=20 দ্রুত prototype-এ, n_steps=300 production-এ। convergence_delta ≈ 0 হলে যথেষ্ট।
