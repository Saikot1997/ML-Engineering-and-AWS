📊 ডেটাসেটে কী কী আছে?

কলামের নামকী ধরনের ডেটাউদাহরণব্যাখ্যা

🖼️ পিক্সেল ডেটা কীভাবে কাজ করে?

এই অংশটা অনেকেই প্রথমে বুঝতে পারে না, তাই একদম সহজ করে বলছি:

পিক্সেল ডেটা কীভাবে CSV-তে স্ট্রিং হিসেবে সংরক্ষিত থাকে

📥 ডেটা লোড করা

নিচের কোডটি প্রতিটি নোটবুকের শুরুতে চালানো হয়:

Pythonডেটা লোড ও পিক্সেল রূপান্তর
import pandas as pd
import numpy as np

df = pd.read_csv('age_gender.csv', sep=',')

# 'pixels' কলামে এখন স্ট্রিং আছে যেমন "120 133 145 ..."
# আমরা সেটিকে numpy array-এ রূপান্তর করছি
df['pixels'] = df['pixels'].apply(lambda x : 
    np.array(x.split()).astype(np.int16))
🔍 lambda লাইনটি কী করছে?

x.split() → স্ট্রিং "120 133 145"-কে ["120", "133", "145"] লিস্টে ভাগ করে
np.array(...) → লিস্টটিকে numpy array করে
.astype(np.int16) → স্ট্রিং থেকে int16 সংখ্যায় রূপান্তর করে

ফলাফল: প্রতিটি সারিতে pixels কলামে এখন array([120, 133, 145, ...]) আছে — 2304টি সংখ্যার একটি array।

🔢 int16 কী?

পিক্সেল মান 0 থেকে 255 — এটি একটি ছোট সংখ্যা। int16 মানে 16-bit integer, যা -32768 থেকে 32767 পর্যন্ত ধরতে পারে। এটি int64 থেকে কম মেমোরি নেয়। 2304 × ১ লক্ষ সারি = অনেক ডেটা, তাই মেমোরি বাঁচানো জরুরি।

📐 X-এর shape কেন (-1, 48, 48, 1)?

PythonX তৈরি করা
X = np.array(df['pixels'].tolist())
# এখন X.shape = (n_samples, 2304)  → 2D array

X = X.reshape(-1, 48, 48, 1)
# এখন X.shape = (n_samples, 48, 48, 1)  → 4D array

reshape করার কারণ ও 4D array-এর মানে

অধ্যায় ২

CNN কী এবং কেন?

CNN মানে Convolutional Neural Network। এটি সাধারণ নিউরাল নেটওয়ার্ক থেকে আলাদা কারণ এটি ছবির স্থানিক (spatial) তথ্য ধরে রাখতে পারে।

🤔 সাধারণ NN দিয়ে ছবি বিশ্লেষণ করলে কী সমস্যা?

⚠️ সমস্যা: Flatten করলে প্রতিবেশিত্ব হারিয়ে যায়

ধরো একটি মুখের ছবিতে নাক মাঝখানে আছে। যদি 48×48 ছবিকে সরাসরি 2304 সংখ্যার সারি বানিয়ে দেই, তাহলে মডেল জানবে না যে দুটো পিক্সেল পাশাপাশি ছিল কি না। এটি সেলাই ছেড়ে দিয়ে সুতো গুনলে কাপড় চিনতে না পারার মতো।

✅ CNN কীভাবে সমাধান করে?

CNN ছবির উপর দিয়ে একটি ছোট ফিল্টার (kernel) স্লাইড করে। এই ফিল্টার একবারে একটি ছোট অংশ (যেমন 3×3 বা 5×5 পিক্সেল) দেখে এবং প্যাটার্ন খোঁজে।

CNN আর্কিটেকচার — ছবি থেকে সিদ্ধান্ত পর্যন্ত

🔧 প্রতিটি Layer কী করে?

C
Conv2D — Convolutional Layer

একটি ছোট ফিল্টার (যেমন 5×5) পুরো ছবির উপর দিয়ে স্লাইড করে। প্রতিটি অবস্থানে ফিল্টার ও ছবির পিক্সেলের গুণফলের যোগফল হিসাব করে। ফলে প্যাটার্ন (কোণা, রেখা, বক্র) খুঁজে পাওয়া যায়। filters=16 মানে ১৬টি ভিন্ন প্যাটার্ন খোঁজার চেষ্টা হবে।

M
MaxPooling2D — সংকোচন Layer

2×2 উইন্ডোর মধ্যে সর্বোচ্চ মানটি রাখে, বাকিগুলো ছেড়ে দেয়। ফলে ছবির সাইজ অর্ধেক হয়ে যায়। কম ডেটা, বেশি গুরুত্বপূর্ণ তথ্য। এছাড়া মডেলকে ছবিতে জিনিসটি ঠিক কোথায় আছে তার প্রতি কম সংবেদনশীল করে (translation invariance)।

D
Dropout — অতিরিক্ত শেখা রোধ

প্রতি training step-এ এলোমেলোভাবে কিছু নিউরন বন্ধ করে দেয়। rate=0.2 মানে ২০% নিউরন সাময়িকভাবে বন্ধ থাকবে। এতে মডেল নির্দিষ্ট নিউরনের উপর নির্ভর করতে পারে না — ফলে overfitting কমে।

F
Flatten — সমতল করা

3D feature map (যেমন 9×9×64) কে একটি 1D vector-এ পরিণত করে (5184 সংখ্যা)। এরপর Dense layer ব্যবহার করা যায়।

Δ
Dense — সংযুক্ত Layer

প্রতিটি ইনপুট প্রতিটি নিউরনের সাথে সংযুক্ত। এটি ফিচারগুলিকে সমন্বিত করে চূড়ান্ত সিদ্ধান্তে পৌঁছায়।

II. মডেল তৈরি করা

Pythonলিঙ্গ শনাক্তকরণ CNN আর্কিটেকচার
input_shape = (48, 48, 1)

model = Sequential()

# ব্লক ১: বড় ফিল্টার দিয়ে মোটা প্যাটার্ন ধরা
model.add(Conv2D(filters=16, kernel_size=(5, 5), padding='valid', 
              input_shape=input_shape, activation='relu'))
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Dropout(rate=0.2))

# ব্লক ২: ছোট ফিল্টার দিয়ে সূক্ষ্ম প্যাটার্ন
model.add(Conv2D(filters=32, kernel_size=(3, 3), padding='valid', 
              activation='relu'))
model.add(MaxPooling2D(pool_size=(2, 2)))

# ব্লক ৩: আরও গভীর প্যাটার্ন
model.add(Conv2D(filters=64, kernel_size=(3, 3), padding='valid', 
              activation='relu'))
model.add(MaxPooling2D(pool_size=(2, 2)))
model.add(Dropout(rate=0.2))

# সমতল করে Dense layer-এ পাঠানো
model.add(Flatten())
model.add(Dense(units=64, activation='relu'))
model.add(Dropout(rate=0.2))

# Output layer — ১টি নিউরন, sigmoid → 0 থেকে 1
model.add(Dense(units=1, activation='sigmoid'))
🔍 'valid' padding মানে কী?

padding='valid' মানে ছবির কিনারায় কোনো অতিরিক্ত পিক্সেল যোগ করা হবে না। ফলে output ছোট হয়ে যায়।
padding='same' মানে কিনারায় শূন্য (0) যোগ করা হবে যাতে output আর input একই সাইজ থাকে।

48×48 → Conv2D(5×5, valid) → 44×44 → MaxPool(2×2) → 22×22 → Conv2D(3×3, valid) → 20×20 → MaxPool → 10×10 → Conv2D(3×3, valid) → 8×8 → MaxPool → 4×4

🔍 epoch ও batch_size কী?

ধরো ১০,০০০ ছবি আছে।
batch_size=32 → প্রতিবার ৩২টি ছবি দেখে weight update করে। ১০,০০০÷৩২ = ~৩১৩ বার update হবে।
epoch=20 → এই ৩১৩ বার update-এর প্রক্রিয়া ২০ বার পুনরাবৃত্তি হবে।
history → প্রতি epoch-এর loss ও accuracy সংরক্ষণ করে, যা পরে গ্রাফ করা হয়।

লিঙ্গ শনাক্তকরণে Dense(units=1, activation='sigmoid') ছিল — কারণ 0 থেকে 1 এর মধ্যে উত্তর দরকার (সম্ভাবনা)।

বয়স অনুমানে Dense(units=1) — কোনো activation নেই! কারণ বয়স যেকোনো ধনাত্মক সংখ্যা হতে পারে (0, 25, 79...)। Sigmoid দিলে সর্বোচ্চ 1 দিত, যেটা বয়স হিসেবে অর্থহীন।

MSE ও MAE কী?

MSE = (1/n) × Σ(y_true - y_pred)²
MAE = (1/n) × Σ|y_true - y_pred|
📐 সহজ উদাহরণ

ধরো সত্যিকার বয়স = 30, মডেলের অনুমান = 25।
ত্রুটি = 30 - 25 = 5
MAE contribution: |5| = 5 বছর
MSE contribution: 5² = 25

MAE বোঝা সহজ ("গড়ে ৫ বছর ভুল")। MSE বড় ত্রুটিকে বেশি শাস্তি দেয়।

x = MaxPooling2D((2, 2))(x)
x = Dropout(0.2)(x)
x = Conv2D(32, (3, 3), activation='relu')(x)
x = MaxPooling2D((2, 2))(x)
x = Conv2D(64, (3, 3), activation='relu')(x)
x = MaxPooling2D((2, 2))(x)
x = Dropout(0.2)(x)
x = Flatten()(x)
x = Dense(128, activation='relu')(x)
x = Dropout(0.2)(x)
x = Dense(64, activation='relu')(x)

age = Dense(1, activation='sigmoid')(x)      # normalized বয়স

Custom Loss Function — সবচেয়ে জটিল অংশ

এটি এই পুরো প্রজেক্টের সবচেয়ে সৃজনশীল অংশ। একটি মডেল তিনটি ভিন্ন ধরনের কাজ করছে — তাহলে কীভাবে তাদের performance মাপা যাবে?

সমস্যাটি কী?

⚠️ তিনটি আলাদা সমস্যা, তিনটি আলাদা loss

বয়স (Regression): MSE ব্যবহার করা উচিত → কিন্তু মান 0-1 (normalize করা)
লিঙ্গ (Binary Classification): Binary Crossentropy ব্যবহার করা উচিত
জাতিসত্তা (5-class Classification): Sparse Categorical Crossentropy ব্যবহার করা উচিত

এই তিনটিকে একটি সংখ্যায় মিলিয়ে মডেলকে একটিই সংকেত দিতে হবে।

সমাধান: Weighted Sum

L_total = λ_age × L_age + λ_gender × L_gender + λ_ethnicity × L_ethnicity
PythonCustom Loss Function সম্পূর্ণ কোড
# Weight coefficients — হাতে ঠিক করা (tuning করা যায়)
lambda_age = 10         # বয়স loss-কে 10 গুণ বেশি গুরুত্ব
lambda_gender = 1      # লিঙ্গ loss — স্বাভাবিক
lambda_ethnicity = 2   # জাতিসত্তা loss — দ্বিগুণ

# বয়সের loss: MSE নিজে লেখা
def loss_age(y_true, y_pred):
    return tf.reduce_mean(tf.square(y_true - y_pred), axis=-1)

# লিঙ্গের loss: Binary Crossentropy
def loss_gender(y_true, y_pred):
    return tf.keras.losses.BinaryCrossentropy()(y_true, y_pred)

# জাতিসত্তার loss: Sparse Categorical (label integer, softmax output)
def loss_ethnicity(y_true, y_pred):
    return tf.keras.losses.SparseCategoricalCrossentropy()(y_true, y_pred)

# মূল loss function — সব একসাথে
def loss_function(y_true, y_pred):
    return (
        lambda_age * loss_age(
            tf.cast(y_true[:,0], tf.float32),  # column 0 = বয়স
            y_pred[:,0]
        ) +
        lambda_gender * loss_gender(
            y_true[:,1],   # column 1 = লিঙ্গ
            y_pred[:,1]
        ) +
        lambda_ethnicity * loss_ethnicity(
            y_true[:,2],   # column 2 = জাতিসত্তা
            y_pred[:,2:]  # column 2 থেকে শেষ পর্যন্ত (5টি)= softmax output
        )
    )
🔍 tf.cast কেন দরকার?

y_true array-এ age column হয়তো float64 বা int64 হিসেবে সংরক্ষিত। কিন্তু y_pred সবসময় float32। TensorFlow এই দুটোর মধ্যে গণনা করতে পারে না যদি type ভিন্ন হয়। তাই tf.cast(..., tf.float32) দিয়ে float32-এ রূপান্তর করতে হয়।

λ (lambda) এর মান কেন এভাবে?

Lambda coefficient দিয়ে loss scaling ভারসাম্য করা

Custom Metrics

PythonCustom metrics — প্রতিটি কাজের আলাদা মূল্যায়ন
def metric_age(y_true, y_pred):
    # MAE × max_age → বছরে ত্রুটি ফিরিয়ে দেয়
    return tf.keras.metrics.MAE(y_true[:,0], y_pred[:,0]) * max_age

def metric_gender(y_true, y_pred):
    # Binary accuracy
    return tf.keras.metrics.binary_accuracy(y_true[:,1], y_pred[:,1])

def metric_ethnicity(y_true, y_pred):
    # Sparse categorical accuracy
    return tf.keras.metrics.sparse_categorical_accuracy(
        y_true[:,2], y_pred[:,2:]
    )
📓 নোট: metric_age-এ * max_age কেন? কারণ মডেল normalized বয়স (0-1) অনুমান করে। MAE-ও তাহলে 0-1 স্কেলে। পড়তে সুবিধার জন্য max_age গুণ করলে MAE বছরে পাওয়া যায়। যেমন MAE = 0.08, max_age = 79 → 0.08 × 79 ≈ 6.3 বছর ত্রুটি।

def show_prediction_webcam(model, faceArea=300):
    # imageWebCam = JavaScript থেকে আসা base64 string (PNG ছবি)

🔍 tf.expand_dims কী করে?

মডেল একটি ছবি নয়, batch নেয়। একটি ছবির shape হলো (48, 48, 1)। কিন্তু মডেলের দরকার (1, 48, 48, 1) — অর্থাৎ 1টি ছবির batch।
tf.expand_dims(img, axis=0) → (48,48,1) থেকে (1,48,48,1) হয়।

১. বয়স অনুমানে output layer-এ activation function কোনটি এবং কেন?
কোনো activation নেই (linear)। কারণ বয়স যেকোনো ধনাত্মক সংখ্যা হতে পারে। sigmoid দিলে 0-1 সীমিত হয়ে যেত।
২. reset_index(drop=True) কেন করা হয়?
ফিল্টারিং করার পর index এলোমেলো হয়। reset করলে 0, 1, 2, 3... ক্রমানুসারে হয়, যা পরে random indexing-এর সময় প্রয়োজন।
৩. Sequential API ও Functional API-এর মূল পার্থক্য কী?
Sequential একটি সরলরেখার মতো layer। Functional API-তে শাখা (branches), shared layers এবং multiple inputs/outputs সম্ভব।
৪. lambda_age = 10 কেন? lambda_gender = 1 কেন?
বয়সের MSE loss অনেক ছোট (normalized হওয়ায়) — তাই 10 গুণ বাড়ানো হয়েছে যাতে সব loss একই স্কেলে থাকে।
৫. y_pred[:,2:] দিয়ে ethnicity কেন পাওয়া যায়?
concat করার পর output = [age, gender, eth0, eth1, eth2, eth3, eth4]। index 0=age, 1=gender, 2: থেকে শেষ = ethnicity 5 probabilities।
