ডেটাসেট: age_gender.csv

📊 ডেটাসেট কী?

ডেটাসেট মানে হলো একটা বিশাল টেবিল। যেমন Excel-এর মতো। প্রতিটি সারিতে (row) একটি মানুষের তথ্য আছে।

কলামের নাম মানে কী উদাহরণ ধরন
age মানুষটির বয়স 25, 43, 7... সংখ্যা (0 থেকে ~100)
gender লিঙ্গ 0 = পুরুষ, 1 = মহিলা 0 বা 1
ethnicity জাতিসত্তা 0=White, 1=Black, 2=Asian, 3=Indian, 4=Hispanic 0 থেকে 4
pixels মুখের ছবির পিক্সেল "128 130 145 122..." Text (সংখ্যার string)
⚠️ গুরুত্বপূর্ণ

pixels কলামটা একটু অদ্ভুত। ছবিটা সরাসরি রাখা নেই — বরং ছবির সব পিক্সেলের মান একটা লম্বা text হিসেবে রাখা আছে, যেমন: "128 130 145 122 100..."। আমাদের এটাকে সংখ্যার অ্যারেতে রূপান্তর করতে হবে।

পিক্সেল কী? ছবি কীভাবে সংরক্ষিত হয়?

কল্পনা করো একটা ছবি আসলে হাজারো ছোট ছোট বর্গক্ষেত্রের সমষ্টি। প্রতিটি বর্গক্ষেত্রকে বলে পিক্সেল। প্রতিটি পিক্সেলে একটা সংখ্যা থাকে — কালো-সাদা ছবিতে সেই সংখ্যাটা 0 থেকে 255 পর্যন্ত। 0 মানে একদম কালো, 255 মানে একদম সাদা।

চিত্র: একটি ছোট 6×6 কালো-সাদা ছবি এবং তার পিক্সেল মান
pixels কলামকে অ্যারেতে রূপান্তর — ব্যাখ্যা সহ Python 
# ডেটা লোড করা
df = pd.read_csv('age_gender.csv', sep=',')

# 'pixels' কলামে এখন আছে: "128 130 145 122 ..."  (একটা text)
# আমরা সেটাকে সংখ্যার অ্যারেতে বদলাব
df['pixels'] = df['pixels'].apply(
    lambda x : np.array(x.split()).astype(np.int16)
)
# x.split() → ["128", "130", "145", ...] (list of strings)
# np.array(...) → numpy array তৈরি
# .astype(np.int16) → সংখ্যায় রূপান্তর (int16 = ছোট সংখ্যা, মেমরি কম লাগে)
🔍 lambda কী?

lambda x: ... মানে হলো একটি ছোট্ট একলাইন ফাংশন। apply() মানে হলো "প্রতিটি সারিতে এই কাজটা করো।" একসাথে মানে: "প্রতিটি সারির pixels কলামের জন্য x.split() করে numpy array বানাও।"

CNN কী এবং কীভাবে কাজ করে?

🧠 CNN = Convolutional Neural Network

CNN হলো এক বিশেষ ধরনের কৃত্রিম নিউরাল নেটওয়ার্ক যেটা ছবি বোঝার জন্য তৈরি। এটা ছবির মধ্যে প্যাটার্ন খোঁজে — প্রথমে ছোট প্যাটার্ন (যেমন রেখা, বাঁক), তারপর বড় প্যাটার্ন (যেমন চোখ, নাক, মুখ)।

মানুষ কীভাবে ছবি দেখে? তুমি প্রথমে দেখো রেখা আর রঙ, তারপর সেই রেখা মিলিয়ে চোখ-নাক চিনতে পারো, তারপর মুখের পুরো অবয়ব বোঝো। CNN-ও ঠিক তাই করে — স্তরে স্তরে।

চিত্র: CNN-এর সামগ্রিক কার্যপ্রণালী
§ ০৪

CNN-এর প্রতিটি স্তর বিস্তারিত

🔎 Conv2D — Convolutional Layer

কল্পনা করো একটা ম্যাগনিফাইং গ্লাস। তুমি সেটা দিয়ে ছবির উপর দিয়ে ধীরে ধীরে সরাও এবং প্রতিটি ছোট অংশ দেখো। Conv2D ঠিক এভাবে একটা "ফিল্টার" (কার্নেল) ছবির উপর দিয়ে স্লাইড করে এবং প্রতিটি জায়গায় একটা সংখ্যা বের করে।

চিত্র: Convolution অপারেশন — ফিল্টার ছবির উপর দিয়ে স্লাইড করছে

Conv2D(filters=16, kernel_size=(5, 5), activation='relu') এর মানে

  • filters=16 → ১৬টি আলাদা ফিল্টার ব্যবহার হবে। প্রতিটি ফিল্টার আলাদা ধরনের প্যাটার্ন খোঁজে (কেউ রেখা খোঁজে, কেউ বাঁক খোঁজে)।
  • kernel_size=(5,5) → প্রতিটি ফিল্টার ৫×৫ সাইজের ছোট বর্গাকার।
  • activation='relu' → ReLU অ্যাক্টিভেশন: নেগেটিভ মান শূন্য করে দেয়, পজিটিভ রাখে।
  • padding='valid' → ছবির কিনারায় কোনো padding নেই — ফলে আউটপুট সাইজ একটু ছোট হয়।

⬇️ MaxPooling2D — ছবি সংকোচন

কল্পনা করো তুমি একটা বড় ছবিকে ছোট thumbnail বানাচ্ছ। MaxPooling ঠিক তাই করে — প্রতি 2×2 ব্লক থেকে সবচেয়ে বড় সংখ্যাটা রাখে, বাকি তিনটা ফেলে দেয়। এতে ছবি ছোট হয়, কিন্তু গুরুত্বপূর্ণ তথ্য থাকে।

চিত্র: MaxPooling — প্রতিটি 2×2 এলাকা থেকে সর্বোচ্চ মান নেওয়া হচ্ছে

🎲 Dropout — অতিরিক্ত মুখস্থ থেকে বাঁচা

Dropout মানে হলো পরীক্ষার আগে কিছু পড়া বন্ধ করে দেওয়া — ইচ্ছে করে। Training-এর সময় এলোমেলোভাবে কিছু নিউরন "বন্ধ" করে দেওয়া হয়। এতে মডেল মুখস্থ করার বদলে সত্যিকারের প্যাটার্ন শিখতে বাধ্য হয়। rate=0.2 মানে ২০% নিউরন বন্ধ।

📐 Flatten — 3D থেকে 1D

Flatten মানে হলো একটা বহুতল ভবনকে একটা লম্বা সারিতে সাজানো। Conv2D-এর পর ডেটা থাকে 3D (উচ্চতা × প্রস্থ × ফিল্টার)। Dense layer-এর দরকার 1D। Flatten সেটাই করে।

চিত্র: Flatten — 3D টেনসর → 1D ভেক্টর

🔗 Dense Layer — সিদ্ধান্ত নেওয়া

Dense Layer হলো মস্তিষ্কের সিদ্ধান্ত নেওয়ার অংশ। প্রতিটি নিউরন আগের সব নিউরনের সাথে যুক্ত। এটি Flatten-এর আউটপুট থেকে চূড়ান্ত উত্তর বের করে।

⚡ Activation Functions — সিদ্ধান্তের ভাষা

Activationআউটপুট রেঞ্জকোথায় ব্যবহারকেন
relu 0 থেকে ∞ Hidden layers নেগেটিভ বাদ, পজিটিভ রাখে। দ্রুত শেখে।
sigmoid 0 থেকে 1 Binary output (লিঙ্গ) 0 = পুরুষ, 1 = মহিলা হিসেবে ব্যাখ্যা সহজ
softmax 0 থেকে 1 (যোগফল=1) Multi-class (জাতিসত্তা) ৫টা সম্ভাবনা, যোগ করলে ১০০%
কোনো activation নেই যেকোনো সংখ্যা Regression (বয়স) বয়স যেকোনো সংখ্যা হতে পারে

Functional API দিয়ে Multi-output মডেল Python 
from tensorflow.keras import Model
from tensorflow.keras.layers import ..., Input

input_model = Input(48, 48, 1)  # ইনপুট নোড

# ভাগ করা অংশ (shared backbone)
x = Conv2D(16, (5,5), activation='relu')(input_model)
x = MaxPooling2D(2,2)(x)
x = Dropout(0.2)(x)
# ... আরও স্তর ...
x = Dense(128, activation='relu')(x)
x = Dropout(0.2)(x)
x = Dense(64, activation='relu')(x)

# তিনটা আলাদা আউটপুট — একই x থেকে
age       = Dense(1, activation='sigmoid')(x)  # বয়স (normalize করা)
gender    = Dense(1, activation='sigmoid')(x)  # লিঙ্গ (0 বা 1)
ethnicity = Dense(5, activation='softmax')(x)  # জাতিসত্তা (5 ক্লাস)

# মডেল তৈরি: ইনপুট → আউটপুট (concat করা)
model = Model(
    inputs=input_model,
    outputs=tf.concat([age, gender, ethnicity], axis=-1)
)
# tf.concat → age(1) + gender(1) + ethnicity(5) = মোট 7টি মান

কাস্টম Loss Function

❓ সমস্যা কী?

তিনটি কাজে তিনটি আলাদা loss দরকার। Keras-এর একটা বিল্ট-ইন loss দিয়ে কাজ হবে না। তাই আমরা নিজেরাই তৈরি করব।

চিত্র: কাস্টম Loss — তিনটির যোগফল
কাস্টম Loss Function — সম্পূর্ণ কোড Python 
lambda_age       = 10  # বয়সের loss-কে ১০ গুণ গুরুত্ব
lambda_gender    = 1
lambda_ethnicity = 2

def loss_age(y_true, y_pred):
    # MSE: (আসল - ভবিষ্যদ্বাণী)² এর গড়
    return tf.reduce_mean(tf.square(y_true - y_pred), axis=-1)

def loss_gender(y_true, y_pred):
    return tf.keras.losses.BinaryCrossentropy()(y_true, y_pred)

def loss_ethnicity(y_true, y_pred):
    return tf.keras.losses.SparseCategoricalCrossentropy()(y_true, y_pred)
    # Sparse = ক্লাস লেবেল সংখ্যা হিসেবে দেওয়া (0,1,2,3,4)
    # Categorical = one-hot encoded হলে (তখন [1,0,0,0,0] ইত্যাদি)

def loss_function(y_true, y_pred):
    return (
        lambda_age       * loss_age(tf.cast(y_true[:,0], tf.float32), y_pred[:,0])
        + lambda_gender    * loss_gender(y_true[:,1], y_pred[:,1])
        + lambda_ethnicity * loss_ethnicity(y_true[:,2], y_pred[:,2:])
    )
    # y_true[:,0] → সব সারির ০ নম্বর কলাম (বয়স)
    # y_true[:,1] → সব সারির ১ নম্বর কলাম (লিঙ্গ)
    # y_true[:,2] → সব সারির ২ নম্বর কলাম (জাতিসত্তা)
    # y_pred[:,2:] → ৩ থেকে শেষ পর্যন্ত (জাতিসত্তার ৫টা মান)
💡 tf.cast কেন?

tf.cast(y_true[:,0], tf.float32) — বয়সের মান হয়তো integer হিসেবে সংরক্ষিত। MSE গণনায় float দরকার। cast টাইপ বদলায়।

def metric_age(y_true, y_pred):
    # MAE × max_age → আসল বছরে রূপান্তর
    return tf.keras.metrics.MAE(y_true[:,0], y_pred[:,0]) * max_age

def metric_gender(y_true, y_pred):
    # Binary accuracy: ০ বা ১ সঠিক হলে True
    return tf.keras.metrics.binary_accuracy(y_true[:,1], y_pred[:,1])

def metric_ethnicity(y_true, y_pred):
    # Sparse categorical accuracy: সঠিক ক্লাস কতবার?
    return tf.keras.metrics.sparse_categorical_accuracy(
        y_true[:,2], y_pred[:,2:]
    )

# সব একসাথে compile
model.compile(
    loss=loss_function,
    optimizer='adam',
    metrics=[metric_age, metric_gender, metric_ethnicity]
)
