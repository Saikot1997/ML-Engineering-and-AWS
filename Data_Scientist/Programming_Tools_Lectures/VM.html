অধ্যায় ১

Virtual Machine (VM) — মাথা থেকে পা পর্যন্ত বোঝো

একদম শূন্য থেকে শুরু। কিছুই জানা লাগবে না আগে থেকে।

VM কী জিনিস?

ধরো, তোমার কাছে একটা কম্পিউটার আছে। এখন তুমি চাচ্ছ আরেকটা কম্পিউটার ব্যবহার করতে — কিন্তু পকেটে টাকা নেই নতুন কম্পিউটার কিনতে! 😅

এই সমস্যার সমাধান হলো Virtual Machine — সংক্ষেপে VM।

VM হলো একটা "নকল কম্পিউটার" যেটা তোমার আসল কম্পিউটারের ভেতরে চলে। আসল কম্পিউটারের কিছু RAM, CPU, এবং Disk নিয়ে একটা আলাদা কম্পিউটার তৈরি করা হয় — সফটওয়্যার দিয়ে।

💡

সহজ ভাষায়: তোমার কম্পিউটার = একটা বাসা। VM = সেই বাসার ভেতরে আরেকটা ছোট বাসা। দুটো বাসা আলাদা, কিন্তু একই জমির উপরে।

VM কেন দরকার?

এখন প্রশ্ন হলো — কেন আমরা VM ব্যবহার করব? সরাসরি কম্পিউটারে কাজ করলেই তো হয়!

🛡️ নিরাপত্তা (Isolation)

VM-এ কোনো ভুল হলে বা virus ঢুকলে — তোমার আসল কম্পিউটার সম্পূর্ণ নিরাপদ থাকে। VM রিসেট করলেই সব ঠিক।

🧪 Testing Sandbox

নতুন software বা code test করার জন্য আলাদা পরিবেশ। ভাঙলেও ক্ষতি নেই — reset করো।

📦 Portability

VM-কে যেকোনো কম্পিউটারে নিয়ে যাওয়া যায়। Team-এর সবাই একই environment-এ কাজ করতে পারে।

🔄 Reproducibility

Data Science-এ একই environment মানে একই ফলাফল। "আমার মেশিনে চলছে কিন্তু তোমার মেশিনে চলছে না" — এই সমস্যা নেই।

🎯

Data Science-এ VM: Machine Learning project-এ সবাই একই VM ব্যবহার করে মানে — একজন যে result পেয়েছে, অন্যজনও একই result পাবে। Code reproducible হয়।

Hypervisor — VM-এর manager

Hypervisor হলো সেই software যেটা VM তৈরি করে এবং manage করে। এটা আসল কম্পিউটারের hardware এবং VM-গুলোর মাঝখানে থাকে।

Hypervisor দুই ধরনের:

Type কোথায় চলে উদাহরণ ব্যবহার
Type 1 (Bare Metal) সরাসরি Hardware-এর উপর VMware ESXi, Hyper-V বড় Server/Cloud
Type 2 (Hosted) OS-এর উপর চলে VirtualBox, VMware Workstation Personal কম্পিউটার
☁️

Cloud VM: AWS, Google Cloud, Azure — এরা লক্ষ লক্ষ VM manage করে। তুমি যখন কোনো cloud service ব্যবহার করো, আসলে তুমি তাদের physical server-এ একটা VM পাচ্ছ।

File System — ফাইল কীভাবে সাজানো থাকে?

Linux VM-এ সব কিছু একটা গাছের মতো সাজানো থাকে। মূল (root) থেকে শুরু হয়ে branch হয়ে যায়।

এই গাছের গোড়াকে বলা হয় root, এবং এটাকে / দিয়ে প্রকাশ করা হয়।

Path — ফাইলের ঠিকানা

ফাইলের ঠিকানা দেওয়ার দুইটা পদ্ধতি আছে:

📍 Absolute Path (সম্পূর্ণ ঠিকানা)

Root (/) থেকে শুরু করে পুরো ঠিকানা। যেখান থেকেই দেখো — একই ঠিকানা।

/home/ubuntu/projects/model.py

🏠 বাড়ির সম্পূর্ণ address দেওয়ার মতো — "ঢাকা, গুলশান, রোড ১, বাড়ি ৫"

📌 Relative Path (আপেক্ষিক ঠিকানা)

তুমি এখন যেখানে আছ — সেখান থেকে ঠিকানা।

projects/model.py

🧭 "এখান থেকে সোজা গিয়ে বাঁয়ে মোড়" — এর মতো।

Special Symbols

Symbolমানেউদাহরণ
/Root directory (একদম উপরে)/home
~তোমার home directory~/projects = /home/ubuntu/projects
.এখন যে folder-এ আছ./model.py
..এক ধাপ উপরে যাও../documents

🔑 উদাহরণ: .. ব্যবহার করে navigate করা

ধরো তুমি আছ /home/ubuntu/projects/ml folder-এ।

  • ../ → যাবে /home/ubuntu/projects/
  • ../../ → যাবে /home/ubuntu/
  • ../../documents → যাবে /home/ubuntu/documents/

IP Address — কম্পিউটারের ঠিকানা

Internet-এ প্রতিটা device-এর একটা নিজস্ব পরিচয় নম্বর থাকে — এটাই IP Address।

এটা দেখতে এরকম: 192.168.1.105 — চারটা সংখ্যা (0-255) dot দিয়ে আলাদা করা।

⚠️ Dynamic IP — গুরুত্বপূর্ণ!

Cloud VM (যেমন AWS)-এর IP address প্রতিবার VM চালু করলে বদলে যায়। তাই VM বন্ধ করে আবার চালু করলে নতুন IP দেখে নিতে হবে।

প্রশ্ন ১: Hypervisor কী এবং এটা কীভাবে কাজ করে?

✅ উত্তর দেখো

Hypervisor হলো এমন software যা physical computer-এর resource (CPU, RAM, Storage) ভাগ করে একাধিক Virtual Machine চালায়। এটা VM এবং hardware-এর মাঝে layer হিসেবে কাজ করে। Type 1 সরাসরি hardware-এ চলে (বেশি efficient), Type 2 চলে OS-এর উপরে।

প্রশ্ন ২: Absolute path এবং Relative path-এর মধ্যে পার্থক্য কী?

✅ উত্তর দেখো

Absolute path: সবসময় root (/) থেকে শুরু হয়। যেমন: /home/ubuntu/file.py

Relative path: তুমি এখন যেখানে আছ সেখান থেকে হিসাব। যেমন: যদি তুমি /home/ubuntu-তে থাকো, তাহলে শুধু file.py লিখলেই হবে।

প্রশ্ন ৩: VM ব্যবহার কেন Data Science-এ গুরুত্বপূর্ণ? ৩টা কারণ বলো।

✅ উত্তর দেখো
  1. Reproducibility: সবাই একই environment ব্যবহার করে, তাই code সবার কম্পিউটারে একইভাবে চলে।
  2. Isolation: Experiments isolated environment-এ চলে, main system affect হয় না।
  3. Scalability: Cloud-এ powerful VM নিয়ে বড় model train করা যায়।

প্রশ্ন ৪: Dynamic IP vs Static IP — ML deployment-এ কোনটা কেন দরকার?

✅ উত্তর দেখো

Production deployment-এ Static IP দরকার। কারণ যদি তুমি কোনো ML model API serve করো এবং IP বদলে যায়, তাহলে সব client connection ভেঙে পড়বে। Development/Testing-এ Dynamic IP ঠিক আছে।

অধ্যায় ২

SSH — দূরের কম্পিউটারে ঢোকার চাবিকাঠি

SSH মানে Secure Shell। নিরাপদে remote machine-এ connect করার পদ্ধতি।

SSH কী?

ধরো তোমার বন্ধুর বাড়ির কম্পিউটারে কিছু কাজ করতে হবে। তুমি সেই বাড়িতে না গিয়ে, তোমার নিজের কম্পিউটার থেকেই সেটা control করতে চাও — এটাই SSH (Secure Shell)।

Authentication Key (.pem file) — ডিজিটাল তালা-চাবি

SSH-এ password দেওয়ার বদলে একটা বিশেষ ফাইল ব্যবহার করা হয় — .pem file। এটা তোমার digital চাবির মতো।

SSH দিয়ে VM-এ Connect করা

Step 1: .pem ফাইলের permission ঠিক করো (Mac/Linux)

chmod 400 my_key.pem

এটা না করলে SSH বলবে "এই key-এর permission অনেক বেশি open, আমি ব্যবহার করব না"।

Step 2: Connect করো

ssh -i "my_key.pem" ubuntu@1.2.3.4
  • -i "my_key.pem" → identity file (তোমার চাবি)
  • ubuntu → VM-এর user name
  • 1.2.3.4 → VM-এর IP address (এটা বদলে দাও)
⚠️

Windows-এ: Folder separator হিসেবে \ ব্যবহার করো।
ssh -i "Downloads\my_key.pem" ubuntu@1.2.3.4

Mac/Linux-এ: / ব্যবহার করো।
ssh -i "Downloads/my_key.pem" ubuntu@1.2.3.4

Step 3: Logout করা

exit

SSH connection বন্ধ হবে। কিন্তু VM চলতে থাকবে।

Common SSH Errors — সমস্যা ও সমাধান

❌ Error 1: "Permission denied (publickey)"

কারণ: .pem ফাইলের permission ঠিক নেই।

সমাধান (Mac/Linux):

chmod 400 my_key.pem

সমাধান (Windows): File Properties → Security → তোমার username শুধু Read permission রাখো।

❌ Error 2: "No such file or directory" (.pem file)

কারণ: .pem ফাইলের path ভুল দিয়েছ।

সমাধান: আগে .pem ফাইল যে folder-এ আছে সেখানে যাও, তারপর connect করো:

# আগে সেই folder-এ যাও
cd ~/Downloads
# তারপর connect করো
ssh -i "my_key.pem" ubuntu@1.2.3.4

❌ Error 3: "Connection timed out"

কারণ: VM বন্ধ আছে অথবা IP address ভুল।

সমাধান: VM চালু করো এবং নতুন IP address চেক করো।

❌ Error 4: "Remote host identification has changed"

কারণ: VM reset হওয়ার পর IP বদলে গেছে কিন্তু পুরনো key আছে।

সমাধান:

ssh-keygen -R 1.2.3.4  # পুরনো key মুছো

SSH Tunnel — Port Forwarding

কখনো কখনো VM-এ চলা কোনো app (যেমন Jupyter Notebook বা ML API) তোমার browser-এ দেখতে চাইলে SSH Tunnel ব্যবহার করতে হয়।

# Format: ssh -i key.pem -L LOCAL_PORT:localhost:REMOTE_PORT user@IP
ssh -i "my_key.pem" -L 8888:localhost:8888 ubuntu@1.2.3.4

# তারপর তোমার browser-এ যাও:
# http://localhost:8888  ← এটা VM-এর Jupyter দেখাবে!

অধ্যায় ২: SSH Connection

প্রশ্ন ১: SSH key-based authentication পাসওয়ার্ড authentication-এর চেয়ে কেন ভালো?

✅ উত্তর দেখো

Key-based: Brute force attack সম্ভব না (key অনেক লম্বা), password মনে রাখতে হয় না, automation সহজ। Password: সহজে crack করা যায়, phishing-এ চুরি হতে পারে।

প্রশ্ন ২: তুমি যদি ML model-কে VM-এ FastAPI দিয়ে serve করো port 8000-এ, তাহলে তোমার laptop-এ test করতে কী command লাগবে?

✅ উত্তর দেখো 
ssh -i "key.pem" -L 8000:localhost:8000 ubuntu@VM_IP

তারপর browser-এ http://localhost:8000/docs খোলো।

প্রশ্ন ৩: chmod 400 key.pem কেন দরকার? এর মানে কী?

✅ উত্তর দেখো

400 মানে: শুধু owner read করতে পারবে, অন্য কেউ কিছুই করতে পারবে না। SSH নিরাপত্তার জন্য দাবি করে key শুধু তুমিই দেখতে পাবে — অন্য user বা group নয়।

Visual Studio Code — Programmer-এর সেরা হাতিয়ার

VS Code হলো একটা শক্তিশালী code editor যেটা দিয়ে VM-এও সরাসরি কাজ করা যায়।

VS Code কী?

VS Code হলো Microsoft-এর তৈরি একটা free code editor। এটা দিয়ে:

  • 🐍 Python, JavaScript, C++ সহ শত শত language-এ code লেখা যায়
  • 🔌 Hundreds of extension install করা যায়
  • 🖥️ Remote machine-এ সরাসরি connect করে কাজ করা যায়
  • 🐛 Debugging করা যায়
  • 📁 File tree দেখা যায় সুন্দর UI-তে

VS Code Install ও Setup

VS Code download করো: code.visualstudio.com — তোমার OS অনুযায়ী download করো।
Install করো: Download হওয়া file run করো এবং installer-এর instructions follow করো।
Extensions খোলো: VS Code খুলে Ctrl+Shift+X চাপো (Mac: Cmd+Shift+X)।
"Remote - SSH" extension install করো — Microsoft-এর official extension।
"Remote Explorer" extension ও install করো।

VS Code দিয়ে VM-এ Connect করা

First Time Connection

  1. VS Code-এর left sidebar-এ Remote Explorer icon-এ click করো।
  2. SSH section-এ + button-এ click করো।
  3. SSH command type করো:
ssh -i "Downloads/my_key.pem" ubuntu@1.2.3.4
  1. .ssh/config file select করো।
  2. Refresh করো → IP address দেখা যাবে।
  3. Connect arrow-এ click করো → OS হিসেবে Linux select করো।
🔄

পরের বার connect করতে: VM-এর IP বদলে যায়। Remote Explorer → SSH → Gear icon → .ssh/config file খুলো → IP address update করো।

Terminal খোলো VM-এ

Connected হওয়ার পর Terminal খুলতে: Ctrl + ` (backtick) অথবা Terminal → New Terminal menu।

এখন এই terminal সরাসরি VM-এ কাজ করে!

📥 VM থেকে File Download করা

VS Code-এ file tree দেখাও → যে file download করতে চাও তার উপর Right Click → Download → তোমার computer-এ কোথায় save করবে বলো।

def binary_search(sorted_arr, target):
    """
    ML Use Case: Hyperparameter search, threshold finding,
    sorted prediction score-এ class boundary খোঁজা
    """
    left, right = 0, len(sorted_arr) - 1

    while left <= right:
        mid = (left + right) // 2

        if sorted_arr[mid] == target:
            return mid
        elif sorted_arr[mid] < target:
            left = mid + 1   # ডান দিকে যাও
        else:
            right = mid - 1  # বাম দিকে যাও

    return -1

৩. Bubble Sort (বুদবুদের মতো)

⚠️ বড় data-তে ব্যবহার করা উচিত না। Concept বোঝার জন্য গুরুত্বপূর্ণ।

def bubble_sort(arr):
    n = len(arr)
    arr = arr.copy()  # original change করব না

    for i in range(n):
        swapped = False
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:  # কোনো swap না হলে sorted!
            break
    return arr

def merge_sort(arr):
    """
    ML Use Case: Large dataset sorting, ranking predictions,
    feature importance sorting
    """
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])   # বাম অর্ধেক
    right = merge_sort(arr[mid:])  # ডান অর্ধেক

    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])
    return result

৫. Quick Sort (দ্রুত ভাগ করে সাজানো)

শিশুদের ভাষায়: একটা সংখ্যা বেছে নাও (pivot)। তার চেয়ে ছোট সব বামে, বড় সব ডানে রাখো। তারপর বাম আর ডান দলে আবার একই কাজ করো।

Best: O(n log n) Average: O(n log n) Worst: O(n²)

✅ Average case-এ সবচেয়ে দ্রুত। In-place সাজানো যায়।

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left  = [x for x in arr if x < pivot]
    mid   = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + mid + quicksort(right)

from collections import deque

def bfs(root):
    """ML Use: Decision Tree structure বোঝা, max depth বের করা"""
    if not root:
        return []
    result, queue = [], deque([root])
    while queue:
        node = queue.popleft()
        result.append(node.val)
        if node.left: queue.append(node.left)
        if node.right: queue.append(node.right)
    return result

# ML Application: Decision Tree depth calculation
def max_depth(node):
    """
    ML: Decision Tree overfit হচ্ছে কিনা check করতে depth measure করি
    """
    if not node:
        return 0
    return 1 + max(max_depth(node.left), max_depth(node.right))

৬. BFS (Breadth-First Search)

শিশুদের ভাষায়: তুমি একটা বাড়ির center room থেকে শুরু করে সব room visit করতে চাও। আগে কাছের সব room দেখো, তারপর তাদের পাশের room...

from collections import deque

def bfs_graph(graph, start):
    """
    ML Use: Recommendation system-এ similar users খোঁজা,
    Knowledge graph traversal, Feature dependency chain
    """
    visited = set()
    queue = deque([start])
    order = []

    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            order.append(node)
            for neighbor in graph.get(node, []):
                if neighbor not in visited:
                    queue.append(neighbor)
    return order

    'user_D': ['user_B'],
    'user_E': ['user_C']

def dfs_graph(graph, start, visited=None):

def fibonacci_dp(n):
    """Memoization দিয়ে — একই calculation দুইবার করব না"""
    memo = {}
    def fib(k):
        if k <= 1: return k
        if k in memo: return memo[k]  # আগে calculate করা আছে?
        memo[k] = fib(k-1) + fib(k-2)
        return memo[k]
    return fib(n)

# Longest Common Subsequence — NLP-তে text similarity
def lcs_length(s1, s2):
    """
    ML Use: Text similarity, Edit distance variant,
    Sequence alignment in bioinformatics ML
    """
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]

৮. KNN (K-Nearest Neighbors)

শিশুদের ভাষায়: তুমি নতুন একটা ফল দেখলে — চেনো না। কাছের ৫টা ফল দেখো যেগুলো তোমার পরিচিত। সেই ৫টার মধ্যে ৩টা আম হলে — নতুন ফলটাও আম!

import numpy as np
from collections import Counter

class KNNClassifier:
    """
    K-Nearest Neighbors — Distance-based classification
    Simple কিন্তু powerful। No training phase।
    """

    def __init__(self, k=3):
        self.k = k

    def fit(self, X_train, y_train):
        """Training = just memorize data"""
        self.X_train = np.array(X_train)
        self.y_train = np.array(y_train)

    def _euclidean_distance(self, x1, x2):
        """দুই point-এর মাঝের দূরত্ব"""
        return np.sqrt(np.sum((x1 - x2) ** 2))

    def predict(self, X_test):
        return [self._predict_single(x) for x in X_test]

    def _predict_single(self, x):
        # সব training point-এর সাথে দূরত্ব মাপো
        distances = [
            self._euclidean_distance(x, x_train)
            for x_train in self.X_train
        ]
        # K সবচেয়ে কাছের neighbors
        k_indices = np.argsort(distances)[:self.k]
        k_labels = [self.y_train[i] for i in k_indices]
        # সবচেয়ে বেশি আসা label = prediction
        return Counter(k_labels).most_common(1)[0][0]

import numpy as np
import matplotlib.pyplot as plt

class LinearRegressionGD:
    """
    Gradient Descent দিয়ে Linear Regression।
    ML Engineering-এর মূল ভিত্তি।
    """

    def __init__(self, learning_rate=0.01, epochs=1000):
        self.lr = learning_rate
        self.epochs = epochs
        self.losses = []  # loss track করব

    def fit(self, X, y):
        n_samples = X.shape[0]
        # Weights initialize করো
        self.weights = np.zeros(X.shape[1])
        self.bias = 0

        for epoch in range(self.epochs):
            # Forward pass: prediction
            y_pred = np.dot(X, self.weights) + self.bias

            # Loss (MSE)
            loss = np.mean((y_pred - y) ** 2)
            self.losses.append(loss)

            # Gradients (পাহাড়ের ঢালু)
            dw = (2/n_samples) * np.dot(X.T, (y_pred - y))
            db = (2/n_samples) * np.sum(y_pred - y)

            # Update weights (ঢালু অনুযায়ী নামো)
            self.weights -= self.lr * dw
            self.bias    -= self.lr * db

            if epoch % 100 == 0:
                print(f"Epoch {epoch}: Loss = {loss:.4f}")

    def predict(self, X):
        return np.dot(X, self.weights) + self.bias

from collections import deque

def topological_sort(graph):
    """
    Kahn's algorithm — ML pipeline ordering
    কোন step আগে run করতে হবে?
    """
    in_degree = {node: 0 for node in graph}
    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] = in_degree.get(neighbor, 0) + 1

    queue = deque([n for n in in_degree if in_degree[n] == 0])
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph.get(node, []):
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    if len(order) != len(graph):
        raise ValueError("Cycle detected in pipeline!")
    return order

def best_model_config(models, budget):
    """
    Knapsack DP — সীমিত compute time-এ সবচেয়ে বেশি accuracy পাও
    models: [(name, compute_time, accuracy_gain), ...]
    budget: total compute hours available
    """
    n = len(models)
    dp = [[0.0] * (budget + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        name, cost, gain = models[i - 1]
        for b in range(budget + 1):
            # এই model না নিলে
            dp[i][b] = dp[i-1][b]
            # এই model নিলে (যদি budget থাকে)
            if b >= cost:
                dp[i][b] = max(dp[i][b], dp[i-1][b-cost] + gain)

    # কোন models নেওয়া হয়েছে backtrack করো
    selected = []
    b = budget
    for i in range(n, 0, -1):
        if dp[i][b] != dp[i-1][b]:
            selected.append(models[i-1][0])
            b -= models[i-1][1]

    return dp[n][budget], selected

১০. K-Means Clustering

শিশুদের ভাষায়: ক্লাসের সব ছাত্রকে তিনটা গ্রুপে ভাগ করতে হবে — কিন্তু আগে থেকে কে কোন গ্রুপে সেটা জানা নেই! তাই এভাবে করো: ৩টা জায়গায় দাঁড়াও (center)। সবাই কাছের center-এর কাছে চলে যাক। তারপর center নতুন গ্রুপের মাঝখানে সরে যাক। আবার সবাই কাছের center-এ। এভাবে repeat করো যতক্ষণ না stable হয়।

Training: O(n·k·i·d)

n=data points, k=clusters, i=iterations, d=features

import numpy as np

class KMeans:
    """
    K-Means Clustering — Unsupervised Learning
    ML Use: Customer segmentation, Document clustering,
    Anomaly detection, Feature learning
    """

    def __init__(self, k=3, max_iters=100, tol=1e-4):
        self.k = k
        self.max_iters = max_iters
        self.tol = tol  # convergence tolerance

    def fit(self, X):
        np.random.seed(42)
        # Random থেকে k টা point বেছে নাও initial center হিসেবে
        idx = np.random.choice(len(X), self.k, replace=False)
        self.centers = X[idx].copy()

        for iteration in range(self.max_iters):
            # প্রতিটা point কোন center-এর কাছে?
            labels = self._assign_clusters(X)

            # নতুন center = প্রতিটা cluster-এর mean
            new_centers = np.array([
                X[labels == j].mean(axis=0) if (labels == j).any() else self.centers[j]
                for j in range(self.k)
            ])

            # Converged? (centers আর নড়ছে না)
            shift = np.linalg.norm(new_centers - self.centers)
            if shift < self.tol:
                print(f"Converged at iteration {iteration}")
                break
            self.centers = new_centers

        self.labels_ = labels
        return self

    def _assign_clusters(self, X):
        # প্রতিটা point থেকে সব center-এর দূরত্ব
        distances = np.array([
            np.linalg.norm(X - center, axis=1)
            for center in self.centers
        ])
        return np.argmin(distances, axis=0)

    def predict(self, X):
        return self._assign_clusters(X)

    def inertia(self, X):
        """Within-cluster sum of squares — কম হলে ভালো cluster"""
        labels = self._assign_clusters(X)
        return sum(
            np.sum((X[labels == j] - self.centers[j]) ** 2)
            for j in range(self.k)
        )

"Naive" কারণ এটা assume করে প্রতিটা feature সম্পূর্ণ independent — বাস্তবে এটা সত্য না, তবু ভালো কাজ করে।

import numpy as np

class GaussianNaiveBayes:
    """
    Gaussian Naive Bayes — Continuous features-এর জন্য
    ML Use: Text classification, Spam detection,
    Medical diagnosis, Real-time classification
    """

    def fit(self, X, y):
        self.classes = np.unique(y)
        self.params = {}

        for c in self.classes:
            X_c = X[y == c]
            self.params[c] = {
                'prior': len(X_c) / len(X),  # P(class)
                'mean': X_c.mean(axis=0),        # প্রতিটা feature-এর mean
                'var':  X_c.var(axis=0) + 1e-9  # variance (0 হলে সমস্যা)
            }

    def _gaussian_log_prob(self, x, mean, var):
        """Gaussian probability log form-এ (numerical stability)"""
        return -0.5 * np.sum(
            np.log(2 * np.pi * var) + (x - mean) ** 2 / var
        )

    def predict(self, X):
        predictions = []
        for x in X:
            scores = {
                c: np.log(p['prior']) + self._gaussian_log_prob(x, p['mean'], p['var'])
                for c, p in self.params.items()
            }
            predictions.append(max(scores, key=scores.get))
        return np.array(predictions)

১২. Decision Tree (সিদ্ধান্ত গাছ)

শিশুদের ভাষায়: "আজ ক্রিকেট খেলব কি?" — প্রথম প্রশ্ন: "বৃষ্টি হচ্ছে?" হ্যাঁ → খেলব না। না → "রোদ আছে?" হ্যাঁ → খেলব। না → "মাঠ ভেজা?" — এভাবে গাছের মতো প্রশ্ন করতে করতে সিদ্ধান্তে পৌঁছাও।

প্রতিটা node-এ সবচেয়ে ভালো question বেছে নেওয়া হয় — যেটা data-কে সবচেয়ে বেশি আলাদা করে। এই measure-কে বলে Information Gain বা Gini Impurity।

import numpy as np

class DecisionTreeNode:
    def __init__(self):
        self.feature = None      # কোন feature-এ split?
        self.threshold = None    # কত value-তে split?
        self.left = None         # বাম শাখা
        self.right = None        # ডান শাখা
        self.value = None         # leaf node-এর prediction

class SimpleDecisionTree:
    """
    Decision Tree Classifier — Gini Impurity দিয়ে split
    ML Use: Feature importance, Interpretable ML,
    Base learner for Random Forest/Gradient Boosting
    """

    def __init__(self, max_depth=3, min_samples_split=2):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.root = None

    def _gini(self, y):
        """Gini impurity — 0 মানে pure, 0.5 মানে সম্পূর্ণ mixed"""
        classes, counts = np.unique(y, return_counts=True)
        probs = counts / len(y)
        return 1 - np.sum(probs ** 2)

    def _best_split(self, X, y):
        """সবচেয়ে ভালো feature ও threshold খোঁজো"""
        best_gain = -1
        best_feature, best_threshold = None, None
        parent_gini = self._gini(y)
        n = len(y)

        for feature in range(X.shape[1]):
            thresholds = np.unique(X[:, feature])
            for t in thresholds:
                left_mask = X[:, feature] <= t
                right_mask = ~left_mask

                if left_mask.sum() == 0 or right_mask.sum() == 0:
                    continue

                # Weighted gini of children
                left_gini  = self._gini(y[left_mask])
                right_gini = self._gini(y[right_mask])
                child_gini = (left_mask.sum()/n)*left_gini + (right_mask.sum()/n)*right_gini

                gain = parent_gini - child_gini
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature
                    best_threshold = t

        return best_feature, best_threshold, best_gain

    def _build(self, X, y, depth):
        node = DecisionTreeNode()

        # Stop conditions
        if (depth >= self.max_depth or
            len(y) < self.min_samples_split or
            len(np.unique(y)) == 1):
            # Leaf: majority class
            node.value = np.bincount(y).argmax()
            return node

        feature, threshold, gain = self._best_split(X, y)

        if gain <= 0 or feature is None:
            node.value = np.bincount(y).argmax()
            return node

        node.feature = feature
        node.threshold = threshold
        left_mask = X[:, feature] <= threshold
        node.left  = self._build(X[left_mask],  y[left_mask],  depth+1)
        node.right = self._build(X[~left_mask], y[~left_mask], depth+1)
        return node

    def fit(self, X, y):
        self.root = self._build(np.array(X), np.array(y), depth=0)

    def _predict_one(self, x, node):
        if node.value is not None:
            return node.value
        if x[node.feature] <= node.threshold:
            return self._predict_one(x, node.left)
        return self._predict_one(x, node.right)

    def predict(self, X):
        return [self._predict_one(x, self.root) for x in np.array(X)]

শিশুদের ভাষায়: তোমার কাছে n টা বই আছে। একটা বই খুঁজতে কত সময় লাগবে? যদি এক এক করে দেখো — n বার। যদি alphabetically সাজানো থাকে এবং binary search করো — log₂(n) বার। n বড় হলে পার্থক্য বিশাল।

Big-O নাম উদাহরণ (বাস্তব) n=1000-এ operations
O(1) Constant Dictionary lookup, Array index access 1
O(log n) Logarithmic Binary Search ~10
O(n) Linear Linear Search, Single loop 1,000
O(n log n) Linearithmic Merge Sort, Heap Sort, Tim Sort ~10,000
O(n²) Quadratic Bubble Sort, Nested loops 1,000,000
O(2ⁿ) Exponential Recursive Fibonacci (naive) 2^1000 ≈ ∞

💡 ML Engineering-এ Big-O কেন জানতে হবে?

  • Data preprocessing: O(n²) loop কি আসলে O(n)-এ করা যায় vectorization দিয়ে?
  • Feature engineering: nested loop-এ feature create করলে dataset বড় হলে system hang করবে।
  • Inference time: Production-এ KNN-এর O(n·d) predict — large n হলে too slow, index structure দরকার।
  • Interview: System design-এ "তোমার solution scale করবে কি 10x data-তে?" — এর উত্তর Big-O থেকে আসে।

    return arr

def get_execution_order(graph):
    """Topological sort — কোন step আগে চলবে"""
    in_degree = {n: 0 for n in graph}
    for node in graph:
        for dep in graph[node]:
            in_degree[dep] += 1
    q = deque([n for n, d in in_degree.items() if d == 0])
    order = []
    while q:
        node = q.popleft(); order.append(node)
        for dep in graph[node]:
            in_degree[dep] -= 1
            if in_degree[dep] == 0: q.append(dep)
    return order

def find_threshold_binary_search(probas, y_true, target_recall=0.80):
    """
    Binary Search: সবচেয়ে বেশি precision যেখানে recall >= target
    Fraud detection-এ recall গুরুত্বপূর্ণ (fraudকে miss করা যাবে না)
    """
    thresholds = np.linspace(0.01, 0.99, 200)
    left, right = 0, len(thresholds) - 1
    best_t, best_f1 = 0.5, 0

    while left <= right:
        mid = (left + right) // 2
        t = thresholds[mid]
        preds = (probas >= t).astype(int)
        rec = recall_score(y_true, preds, zero_division=0)
        f1  = f1_score(y_true, preds, zero_division=0)

        if rec >= target_recall:
            if f1 > best_f1:
                best_f1 = f1; best_t = t
            right = mid - 1  # আরও কম threshold চেষ্টা করো
        else:
            left = mid + 1

    return best_t, best_f1

📌 Algorithm Quick Cheatsheet — Interview-এর জন্য

🔍 কখন কোন Search?

  • Linear Search: unsorted, ছোট data, যেকোনো condition
  • Binary Search: sorted array, threshold খোঁজা
  • Hash lookup: exact match, O(1) দরকার
  • BFS: shortest path, level-by-level
  • DFS: cycle detection, path existence

📊 কখন কোন Sort?

  • Python sorted(): সবসময় (Timsort, O(n log n))
  • Merge Sort: stable sort, linked list
  • Quick Sort: average case fastest, in-place
  • Bubble Sort: শুধু শেখার জন্য, production-এ না
  • Counting Sort: integer, bounded range

🤖 ML Algorithm কখন?

  • KNN: simple baseline, anomaly detection
  • Naive Bayes: text, fast, high dimensional
  • Decision Tree: interpretable, feature importance
  • K-Means: clustering, segmentation
  • Gradient Descent: neural nets, deep learning

⚡ DP কখন ব্যবহার করব?

  • Overlapping subproblems আছে
  • Optimal substructure আছে
  • Sequence/path optimization
  • Knapsack-style resource allocation
  • String edit distance, LCS
