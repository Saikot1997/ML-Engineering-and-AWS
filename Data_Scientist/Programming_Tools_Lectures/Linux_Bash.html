Linux-এর ইতিহাস ও পরিচিতি

Linux হলো একটি মুক্ত (Free) ও ওপেন সোর্স অপারেটিং সিস্টেম। এর মানে হলো যে কেউ এটি বিনামূল্যে ব্যবহার করতে পারে এবং এর কোড দেখতে ও পরিবর্তন করতে পারে।

💡
অপারেটিং সিস্টেম কী?
তোমার কম্পিউটারে যে সফটওয়্যার প্রথমে চালু হয় এবং বাকি সব কাজ পরিচালনা করে — সেটাই Operating System। যেমন Windows, macOS, Linux।

সিস্টেম আর্কিটেকচার — ফাইল সিস্টেম

Linux-এ সব কিছু গাছের মতো (Tree Structure) সাজানো। সবচেয়ে উপরে আছে Root যাকে / দিয়ে বোঝানো হয়। এর নিচে সব ফাইল ও ফোল্ডার থাকে।

🌳
Windows vs Linux — পথের পার্থক্য
Windows-এ: C:\Users\Chaiti\Documents\file.txt
Linux-এ: /home/chaiti/documents/file.txt
Linux-এ backslash (\) নয়, forward slash (/) ব্যবহার হয়।

প্রতিটি ফোল্ডারের বিস্তারিত

ফোল্ডারপুরো নামকী থাকে
/binBinaryমূল সিস্টেম কমান্ড যেমন ls, cp, bash
/bootBootসিস্টেম চালু হওয়ার জন্য প্রয়োজনীয় ফাইল
/devDeviceHardware-এর virtual representation (হার্ডডিস্ক, USB ইত্যাদি)
/etcEt ceteraসিস্টেম configuration — password, network settings ইত্যাদি
/homeHomeপ্রতিটি user-এর নিজস্ব ডেটা। /home/ubuntu হলো ubuntu user-এর ঘর
/libLibraryপ্রোগ্রাম চালাতে দরকারি shared library ফাইল
/mediaMediaUSB, CD/DVD mount হওয়ার জায়গা
/mntMountঅস্থায়ীভাবে mount করা directory
/optOptionalতৃতীয় পক্ষের সফটওয়্যার
/procProcessচলমান প্রক্রিয়া সম্পর্কে তথ্য (virtual filesystem)
/rootRoot HomeRoot user (superuser)-এর home directory
/sbinSystem Binaryশুধু root user ব্যবহার করতে পারে এমন কমান্ড
/tmpTemporaryঅস্থায়ী ফাইল — restart দিলে সব মুছে যায়
/usrUserUser-level অ্যাপ্লিকেশন ও লাইব্রেরি
/varVariableLog ফাইল, database, email — যা নিয়মিত পরিবর্তন হয়

প্রথম কমান্ডসমূহ — Terminal ব্যবহার

Terminal বা Command Line হলো Linux-এর সাথে কথা বলার জায়গা। এখানে text দিয়ে কমান্ড টাইপ করো, Linux সেটা বাস্তবায়ন করে।

Terminal Prompt বোঝা

// Terminal Prompt-এর অংশগুলো

pwd — আমি এখন কোথায় আছি?

pwd মানে Print Working Directory। এটি চালালে তোমার বর্তমান অবস্থান দেখাবে।

bashউদাহরণ
pwd
/home/ubuntu

# মানে হলো: আমি এখন /home/ubuntu ফোল্ডারে আছি

ls — ফোল্ডারের ভেতরে কী আছে?

ls মানে List। এটি দিয়ে কোনো ফোল্ডারে কী কী আছে তা দেখা যায়।

bashls কমান্ড
ls               # বর্তমান ফোল্ডার দেখো
ls /             # root ফোল্ডার দেখো
ls /usr/bin      # /usr/bin ফোল্ডার দেখো

# অপশন সহ:
ls -a            # লুকানো ফাইলসহ দেখো (. দিয়ে শুরু ফাইল)
ls -l            # বিস্তারিত তথ্যসহ দেখো
ls -lh           # ফাইলের সাইজ মানুষের বোঝার মতো (KB, MB)
ls -R            # সব subfolderও দেখো (Recursive)
ls -la           # লুকানো ফাইলসহ বিস্তারিত

total 24
drwxr-xr-x 3 ubuntu ubuntu 4096 Oct 16 14:00 Documents
-rw-r--r-- 1 ubuntu ubuntu  512 Oct 16 13:50 file1.txt
💡
. এবং .. কী?
ls -a চালালে দেখবে . এবং .. আছে।
. মানে বর্তমান ফোল্ডার নিজেই।
.. মানে parent ফোল্ডার (এক ধাপ উপরে)।
যেমন তুমি /home/ubuntu-এ থাকলে, .. হলো /home।

cd — স্থান পরিবর্তন

cd মানে Change Directory। এদিক ওদিক যাওয়ার কমান্ড।

bashcd কমান্ড
cd /              # root-এ যাও
cd /home/ubuntu   # সম্পূর্ণ path দিয়ে যাও
cd ~              # নিজের home-এ ফিরে যাও
cd                # শুধু cd লিখলেও home-এ যাবে
cd ..             # এক ধাপ উপরে যাও
cd ../..          # দুই ধাপ উপরে যাও
cd Documents     # বর্তমান ফোল্ডারের Documents-এ যাও

Absolute Path vs Relative Path

// দুই ধরনের পথ

man — যেকোনো কমান্ডের সাহায্য

কোনো কমান্ড কীভাবে ব্যবহার করতে হয় জানতে man ব্যবহার করো।

bash
man ls           # ls কমান্ডের manual দেখো
ls --help        # সংক্ষিপ্ত সাহায্য দেখো
# man থেকে বের হতে q চাপো

Environment Variables — পরিবেশ চলক

Environment Variable হলো সিস্টেমের বিশেষ চলক (variable) যা সিস্টেমের আচরণ নিয়ন্ত্রণ করে। যেমন PATH variable বলে দেয় কোথায় কমান্ড খুঁজতে হবে।

🔑
গুরুত্বপূর্ণ Environment Variables
PATH — কমান্ড কোথায় খুঁজবে
HOME — home directory-র পথ
USER — বর্তমান user-এর নাম
PWD — বর্তমান directory (pwd কমান্ড এটাই দেখায়)
bashEnvironment Variable তৈরি ও ব্যবহার
# Variable তৈরি করো
export MY_USERNAME="chaiti.das"

# Variable-এর মান দেখো ($ ব্যবহার করো)
echo $MY_USERNAME
chaiti.das

# সব Environment Variable দেখো
printenv

# Variable মুছে ফেলো
unset MY_USERNAME

# এরপর echo করলে কিছু দেখাবে না
echo $MY_USERNAME
⚠️
Session বন্ধ হলে Variable মুছে যায়!
উপরের পদ্ধতিতে তৈরি variable শুধু বর্তমান session-এ কাজ করে। Terminal বন্ধ করলে চলে যাবে। Permanent করতে হলে .bashrc ফাইল সম্পাদনা করতে হবে।

.bashrc ফাইল — স্থায়ী সেটিংস

.bashrc হলো একটি hidden configuration ফাইল (নামের শুরুতে . আছে তাই hidden)। প্রতিবার terminal খুললে এটি স্বয়ংক্রিয়ভাবে চালু হয়।

bash.bashrc সম্পাদনা করা
# home-এ যাও
cd

# nano দিয়ে .bashrc খোলো
nano .bashrc

# ফাইলের শেষে এই লাইন যোগ করো:
export my_var="Hello"
alias graphic_card='lspci -vnn | egrep "VGA|3D|Display"'

# Ctrl+X, তারপর Y, তারপর Enter চাপো

# বর্তমান session-এ apply করো
source .bashrc
📝
alias কী?
Alias দিয়ে দীর্ঘ কমান্ডের জন্য সংক্ষিপ্ত নাম তৈরি করা যায়। উপরের উদাহরণে graphic_card টাইপ করলেই সেই দীর্ঘ কমান্ডটি চলবে।
অধ্যায় ০৫

ফাইল ও ফোল্ডার তৈরি, কপি, সরানো, মুছে ফেলা

touch — খালি ফাইল তৈরি

bash
touch my_file           # my_file নামে ফাইল তৈরি
touch file1 file2 file3  # একসাথে তিনটি ফাইল তৈরি
touch directory1/file4  # নির্দিষ্ট folder-এ ফাইল তৈরি

# touch দিয়ে ইতিমধ্যে থাকা ফাইলের "last modified" তারিখ আপডেট হয়

mkdir — ফোল্ডার তৈরি

bash
mkdir my_directory       # folder তৈরি
mkdir -p a/b/c           # nested folder তৈরি (একসাথে সব)
mkdir dir1 dir2 dir3    # একসাথে তিনটি folder

rm — মুছে ফেলা

bash
rm file3                 # একটি ফাইল মুছো
rm -r directory1         # folder ও তার সবকিছু মুছো (-r = recursive)
rm -f file.txt           # জোর করে মুছো (confirmation ছাড়া)
rm -rf folder           # folder জোর করে মুছো
🚨
rm -rf / — কখনো চালাবে না!
rm -rf / মানে root থেকে সব মুছে ফেলো। এটি পুরো সিস্টেম ধ্বংস করে দেবে! Linux-এ Recycle Bin নেই, মুছলে চলে যায়।

cp — কপি করা

bash
cp file1 directory2/          # file1 কে directory2-এ কপি করো
cp file1 directory2/new_file1 # নাম বদলে কপি করো
cp -r folder1 folder2         # folder সহ কপি করো (-r দিতে হবে)

mv — সরানো বা নাম বদলানো

bash
mv file2 directory2/new_file2 # সরাও এবং নাম পরিবর্তন করো
mv old_name.txt new_name.txt  # শুধু নাম বদলাও (একই জায়গায়)
mv folder1 /home/ubuntu/     # অন্য জায়গায় সরাও

ফাইল পড়া, লেখা ও সম্পাদনা

echo — Text প্রিন্ট করা

bash
echo hello world          # terminal-এ hello world দেখাবে
hello world

echo hello world > file1  # file1-এ লিখবে (আগের সব মুছে দেবে)
echo more text >> file2   # file2-এর শেষে যোগ করবে

# > vs >> পার্থক্য:
echo line1 > test.txt    # test.txt তে "line1" লিখবে
echo line2 > test.txt    # পূর্বের "line1" মুছে "line2" লিখবে ⚠️
echo line3 >> test.txt   # "line2"-এর পরে "line3" যোগ করবে ✅

cat — ফাইলের সম্পূর্ণ বিষয়বস্তু দেখা

bash
cat file1                  # file1-এর সব বিষয়বস্তু দেখো
hello world

cat file1 file2            # দুটো ফাইল একসাথে দেখো

head ও tail — শুরু ও শেষ দেখা

bash
head root_content          # প্রথম ১০ লাইন দেখো
head -n 2 root_content     # প্রথম ২ লাইন দেখো
tail root_content          # শেষ ১০ লাইন দেখো
tail -n 3 root_content     # শেষ ৩ লাইন দেখো
tail -f logfile.log        # realtime-এ log দেখো (Ctrl+C দিয়ে বের হও)

Redirection Flows — Input/Output পুনর্নির্দেশনা

Linux-এ প্রতিটি প্রোগ্রামের তিনটি ডিফল্ট "নল" (stream) আছে:

// তিনটি Standard Stream

Output Redirection

bashOutput Redirection
# > : stdout কে ফাইলে পাঠাও (আগের content মুছে)
ls / > root_content
echo "hello" > myfile.txt

# >> : stdout কে ফাইলে যোগ করো
echo "world" >> myfile.txt

# 2> : stderr (error) কে ফাইলে পাঠাও
cat no_file 2> errors.txt
# error terminal-এ দেখাবে না, errors.txt-এ যাবে

# 2>> : error ফাইলে যোগ করো
cat another_no_file 2>> errors.txt

# stdout ও stderr একই ফাইলে
ls -l > output.txt 2>&1

# Object তৈরি করো
cat people.json | jq '.[] | {name, height}'
