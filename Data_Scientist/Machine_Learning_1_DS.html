পাঠ্যক্রম অনুযায়ী বিষয়বস্তু ও Scikit-learn API

বিষয় Scikit-learn Class / Function কী করে লেকচার
Train-Test Split train_test_split() ডেটা ৮০/২০ ভাগে ভাগ করা, Data Leakage এড়ানো L1, L2
Missing Value পূরণ SimpleImputer Median (numerical) বা Mode (categorical) দিয়ে NaN পূরণ L1
Categorical Encoding OneHotEncoder Text category → binary columns (position কলাম) L1
Feature Scaling StandardScaler z = (x − μ) / σ → সব feature একই scale-এ L1, L2
Linear Regression LinearRegression সংখ্যাসূচক output predict (house price, salary) L2
Polynomial Regression PolynomialFeatures Non-linear relationship ধরতে feature powers তৈরি L2
Ridge / Lasso Ridge / Lasso Regularization — overfitting কমানো L2
Logistic Regression LogisticRegression Binary classification baseline, Sigmoid output L1 L3
Support Vector Machine SVC Maximum margin hyperplane, kernel trick L3
K-Nearest Neighbors KNeighborsClassifier কাছের k প্রতিবেশীদের vote নেওয়া L3
Naive Bayes GaussianNB Bayes theorem দিয়ে probabilistic classification L3
Decision Tree DecisionTreeClassifier হ্যাঁ/না প্রশ্নের গাছ, interpretable L1 L3
Random Forest RandomForestClassifier অনেক tree → majority vote, সবচেয়ে শক্তিশালী L1 L3
XGBoost XGBClassifier Gradient boosting ensemble, competition-winning L3
Hyperparameter Search GridSearchCV সব combination × k-fold CV → সেরা param L1 L3
Evaluation (Classification) classification_report Precision, Recall, F1-score per class L1 L3
Evaluation (Regression) r2_score, mean_squared_error R², RMSE, MAE — regression performance L2
K-Means Clustering KMeans n_clusters গ্রুপে ভাগ, centroid iteratively update L4
Hierarchical Clustering AgglomerativeClustering Bottom-up merging, dendrogram দেখা L4
Mean Shift MeanShift K নির্দিষ্ট করা লাগে না, density-based L4
Clustering Evaluation silhouette_score Cluster মান পরিমাপ (−1 থেকে +1, বেশি ভালো) L4
Model Persistence joblib.dump / load Trained model disk-এ সেভ ও পরে লোড L1

🔑 সবচেয়ে গুরুত্বপূর্ণ নিয়ম

আগে Split, পরে সব কিছু। Train-Test Split সবসময় Imputation, Scaling, Encoding-এর আগে করতে হবে। তা না হলে Data Leakage হয় — model পরীক্ষার প্রশ্নপত্র আগে দেখে ফেলে!

⚠️ fit() শুধু train-এ

SimpleImputer, StandardScaler, OneHotEncoder — সবকিছুর fit() শুধু X_train-এ করতে হবে। Test set-এ শুধু transform()। এটাই Data Leakage ঠেকানোর মূল পদ্ধতি।

📊 Accuracy মানেই সব নয়

Imbalanced dataset-এ (যেমন: ৯৫% না, ৫% হ্যাঁ) শুধু Accuracy দেখলে ভুল হবে। Recall দেখো যখন False Negative বড় সমস্যা (রোগ শনাক্ত, fraud detection)।

🌲 কোন মডেল কখন?

Logistic Regression: Baseline · Decision Tree: Interpretability দরকার হলে · Random Forest: Best accuracy · XGBoost: Competition/production · K-Means: Label নেই, grouping দরকার।

🔍 GridSearchCV ব্যবহার

সব hyperparameter combination পরীক্ষা করে। ছোট param grid-এ GridSearchCV, বড় grid-এ RandomizedSearchCV ব্যবহার করো। scoring='recall' দিয়ে target metric নির্দিষ্ট করো।

🧩 Clustering-এ K বেছে নেওয়া

Elbow Method: Distortion বনাম K graph-এ "কনুই" খোঁজো। Silhouette Score: সর্বোচ্চ score মানে সেরা K। Mean Shift-এ K নির্দিষ্ট করতে হয় না — bandwidth-ই সব নির্ধারণ করে।
