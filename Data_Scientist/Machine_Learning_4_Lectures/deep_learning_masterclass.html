নিউরাল মডেলিং — জৈবিক থেকে কৃত্রিম নিউরন

১. জৈবিক নিউরন — মস্তিষ্কের আসল ইউনিট

কল্পনা কর, তুমি গরম কিছু ছুঁয়েছ। তোমার হাত থেকে একটা সংকেত মস্তিষ্কে যায়, মস্তিষ্ক সিদ্ধান্ত নেয়, আবার সংকেত ফিরে আসে — "হাত সরাও!" এই পুরো প্রক্রিয়াটা নিউরনের মাধ্যমে হয়।

জৈবিক নিউরনের ৩টি মূল অংশ:

  • ডেনড্রাইট (Dendrites): তথ্য গ্রহণ করার অংশ — বাইরে থেকে সংকেত আসে এখানে
  • সোমা / কোষ দেহ (Soma): তথ্য প্রক্রিয়া করার কেন্দ্র — সব ইনপুট যোগ করে
  • অ্যাক্সন (Axon): তথ্য পাঠানোর পথ — ফলাফল পরবর্তী নিউরনে পাঠায়
  • সিন্যাপস (Synapse): নিউরনের সংযোগ বিন্দু — এখানেই "ওজন" নির্ধারিত হয়

🔑 থ্রেশহোল্ড নিয়ম: যদি সব ইনপুটের যোগফল একটা সীমা (threshold) পার করে — তবেই সংকেত পাঠায়, নাহলে চুপ থাকে। এটাই activation-এর ধারণা!

২. কৃত্রিম নিউরন — পার্সেপ্ট্রন (Perceptron)

পার্সেপ্ট্রন হলো জৈবিক নিউরনের গণিতগত নকল। এটা একটা সহজ সূত্র:

Output = f(b + w₁·x₁ + w₂·x₂ + ... + wₙ·xₙ)
জৈবিক নিউরন কৃত্রিম নিউরন (পার্সেপ্ট্রন) ভূমিকা
ডেনড্রাইট ইনপুট সিগন্যাল (x) বাইরে থেকে তথ্য নেওয়া
সিন্যাপস সংযোগ ওজন (w) কোন তথ্য কতটা গুরুত্বপূর্ণ
কোষ দেহ / সোমা যোগফল নোড (Σ) সব ইনপুট × ওজন যোগ করা
অ্যাক্সন আউটপুট সিগন্যাল (ŷ) পরবর্তী নিউরনে পাঠানো
থ্রেশহোল্ড অ্যাক্টিভেশন ফাংশন f() সিদ্ধান্ত নেওয়া — "ফায়ার" করব কি না
🎯 ইন্টারভিউ প্রশ্ন
  1. Q: পার্সেপ্ট্রনের সীমাবদ্ধতা কী?
    ✅ পার্সেপ্ট্রন শুধু linearly separable data classify করতে পারে — XOR সমস্যা সমাধান করতে পারে না।
  2. Q: Bias (b) কেন দরকার?
    ✅ Bias ছাড়া decision boundary সবসময় origin (0,0) দিয়ে যাবে। Bias দিয়ে আমরা boundary shift করতে পারি — model আরো flexible হয়।
  3. Q: Weight vector কীভাবে update হয়?
    ✅ Backpropagation + Gradient Descent দিয়ে। প্রতিটা training step-এ loss কমাতে weight একটু একটু adjust হয়।
অ্যা

অ্যাক্টিভেশন ফাংশন — নিউরনের সিদ্ধান্ত গ্রহণ পদ্ধতি

অ্যাক্টিভেশন ফাংশন কী এবং কেন দরকার?

ধর, তোমাকে জিজ্ঞেস করা হলো — "তুমি কি খুশি?" তুমি হয়তো বলবে হ্যাঁ বা না, বা একটা সংখ্যা ০ থেকে ১-এর মধ্যে। এই "সিদ্ধান্ত নেওয়া"-টাই অ্যাক্টিভেশন ফাংশনের কাজ।

অ্যাক্টিভেশন ফাংশন non-linearity যোগ করে — অর্থাৎ, নেটওয়ার্ক জটিল প্যাটার্ন শিখতে পারে।

কেন non-linear activation দরকার? যদি সব লেয়ারে শুধু linear (বা কোনো) activation না থাকে, তাহলে ১০০ লেয়ারও মাত্র একটা লেয়ারের সমান। Non-linearity ছাড়া deep network-এর কোনো সুবিধা নেই।

🎯 ইন্টারভিউ প্রশ্ন
  1. Q: ReLU-র "Dying ReLU" সমস্যা কী?
    ✅ যখন z < 0 হয়, ReLU সবসময় 0 দেয়। Gradient 0 হওয়ায় সেই নিউরন আর কখনো update হয় না — সে "মরে যায়"। Leaky ReLU বা ELU এই সমস্যা সমাধান করে।
  2. Q: Sigmoid বনাম Softmax কখন কোনটা ব্যবহার করবে?
    ✅ Binary classification (২টা class) → Sigmoid। Multi-class (৩+ class, mutually exclusive) → Softmax। Multi-label (একসাথে কয়েক class) → একাধিক Sigmoid।
  3. Q: Vanishing gradient সমস্যা কী?
    ✅ Deep network-এ backpropagation করার সময় gradient বারবার ছোট সংখ্যায় গুণ হয়ে প্রায় শূন্য হয়ে যায়। ফলে প্রথম দিকের লেয়ারগুলো ঠিকমতো শেখে না। ReLU, BatchNorm, residual connections এর সমাধান।

লস ফাংশন কী? — একদম সহজ উদাহরণ

কল্পনা কর তুমি একজন শিক্ষক। তোমার ছাত্র পরীক্ষায় ৬০ পেয়েছে, কিন্তু তুমি চেয়েছিলে ৯০। ভুলের পরিমাণ = ৯০ - ৬০ = ৩০। এই "ভুলের পরিমাণ"-টাই হলো loss।

মডেল যত কম ভুল করে, loss তত কম। লক্ষ্য: loss কমানো।

🎯 ইন্টারভিউ প্রশ্ন
  1. Q: MSE ও MAE-র পার্থক্য? Outlier থাকলে কোনটা ভালো?
    ✅ MSE বড় ভুলকে বেশি penalize করে (²)। Outlier থাকলে MSE distort হয়। MAE outlier-এ কম sensitive — তাই outlier থাকলে MAE ভালো।
  2. Q: Cross-entropy loss কেন classification-এ use করি, accuracy কেন না?
    ✅ Accuracy non-differentiable — gradient descent কাজ করে না। Cross-entropy differentiable এবং probability-based, তাই gradient-এর মাধ্যমে optimize করা যায়।

Gradient Descent কী? — পাহাড় থেকে নামার উপমা

কল্পনা কর, তুমি চোখ বন্ধ করে একটা পাহাড়ে আছ এবং নিচে নামতে চাও। তুমি পা দিয়ে অনুভব করো কোন দিকে ঢাল — এবং সেদিকেই এক ধাপ এগোও। এটাই Gradient Descent!

  • পাহাড় = loss function (এটা কমাতে চাই)
  • তোমার অবস্থান = weight-এর মান
  • ঢালের দিক = gradient (∂J/∂W)
  • প্রতিটা পদক্ষেপ = একটা weight update

গুরুত্বপূর্ণ hyperparameters:

  • Learning Rate (η): কত বড় পদক্ষেপে নামবে। বেশি → unstable; কম → খুব ধীর।
  • Epoch: পুরো ডেটাসেট কতবার দেখবে। বেশি → overfitting সম্ভব।
  • Batch Size: একবারে কতটা ডেটা দিয়ে weight update করবে।

সম্পূর্ণ ডেটা দিয়ে একবারে gradient হিসাব করা ব্যয়বহুল। তার বদলে আমরা ছোট ছোট batch ব্যবহার করি:

🎯 ইন্টারভিউ প্রশ্ন
  1. Q: SGD, Mini-batch GD, ও Full-batch GD-র পার্থক্য?
    ✅ SGD: একটা sample per step (noisy, fast). Full-batch: সব data per step (smooth, slow). Mini-batch: ছোট batch per step (সবচেয়ে ভালো balance, সবচেয়ে বেশি ব্যবহৃত)।
  2. Q: Adam optimizer কেন SGD-র চেয়ে ভালো?
    ✅ Adam adaptive learning rate ব্যবহার করে — প্রতিটা parameter-এর জন্য আলাদা lr। Momentum ও RMSprop-এর সুবিধা মেলানো। সাধারণত দ্রুত converge করে।
  3. Q: Learning rate ০.০১ vs ০.০০১ — কোনটা বেছে নেবে?
    ✅ Experimentation দরকার। সাধারণত ০.০০১ দিয়ে শুরু করি (Adam-এর default)। Learning rate scheduler দিয়ে epoch বাড়লে lr কমানো best practice।

def load_data(data):
    img_list = []   # খালি লিস্ট — এতে ছবি জমা হবে
    
    for i, f in enumerate(data.values):
        # f[0]=img_path, f[1]=bbox_x1, f[2]=bbox_y1, f[3]=bbox_x2, f[4]=bbox_y2
        
        img = cv2.imread("cars_train/" + f[0])  # ছবি পড়া
        
        # Bounding box দিয়ে গাড়িটা কেটে নেওয়া
        # img[y1:y2, x1:x2] — numpy array slicing
        img = img[f[2]:f[4], f[1]:f[3]]
        
        img = cv2.resize(img, (224, 224))  # সব ছবি একই সাইজে আনা
        img_list.append(img)              # লিস্টে যোগ
        
        if i % 100 == 0:
            print(i)  # প্রতি ১০০ ছবিতে প্রগ্রেস দেখানো
    
    return np.array(img_list)  # লিস্টকে NumPy অ্যারেতে রূপান্তর

Neural Network কী? — একেবারে মূল ধারণা

Dense Network-এ প্রতিটি নিউরন পরের স্তরের সব নিউরনের সাথে সংযুক্ত থাকে

🧮 একটি নিউরন কীভাবে কাজ করে?

প্রতিটি নিউরন আসলে একটি সহজ গণনা করে:

output = activation(w₁×x₁ + w₂×x₂ + w₃×x₃ + ... + b)

যেখানে:

  • x = ইনপুট মান (পিক্সেলের উজ্জ্বলতা)
  • w = ওজন (weight) — নেটওয়ার্ক এটা শেখে
  • b = bias — একটি constant মান
  • activation = একটি ফাংশন যেমন ReLU বা Softmax

Activation Functions — নিউরনের "সিদ্ধান্ত নেওয়ার পদ্ধতি"

🔶 ReLU (Hidden Layers-এ)

f(x) = max(0, x)

মানে: যদি মান নেগেটিভ হয়, শূন্য বানাও। না হলে একই রাখো। এটা খুব দ্রুত কাজ করে এবং ডিপ নেটওয়ার্কে ভালো।

🟢 Softmax (Output Layer-এ)

f(xᵢ) = eˣⁱ / Σeˣʲ

সব output-এর সম্ভাবনা যোগ করলে = ১। মানে: "৭০% গাড়ি_০, ২০% গাড়ি_১, ১০% গাড়ি_২" — এরকম।

CNN হলো ডিপ লার্নিংয়ের সবচেয়ে বড় উদ্ভাবনগুলোর একটি। এটা বিশেষভাবে ছবি বোঝার জন্য তৈরি। চলো বুঝি কেন এটা এত কার্যকর।

Dense Network বনাম CNN — মূল পার্থক্য

  • পিক্সেলের প্রতিবেশিত্ব বোঝে না
  • প্যারামিটার সংখ্যা বিশাল
  • ছবি ঘুরানো/সরানো হলে চিনতে পারে না

✅ CNN-এর সুবিধা

  • ছবির 3D কাঠামো বজায় রাখে
  • পিক্সেলের প্রতিবেশিত্ব বোঝে
  • প্যারামিটার শেয়ার হয় → অনেক কম
  • অনুবাদ-সহনশীল (translation invariant)

CNN-এর তিন ধরনের স্তর

🔍

Convolution Layer

ছোট ফিল্টার দিয়ে ছবি স্ক্যান করে features বের করে। প্রথমে সরল feature (রেখা, কোণা), পরে জটিল (চাকা, জানালা)।

📉

Pooling Layer

Feature map-এর সাইজ ছোট করে। সবচেয়ে গুরুত্বপূর্ণ তথ্যটুকু রাখে, বাকি ছাঁটাই করে।

⚡

Dense Layer (FC)

শেষে Dense Layer ব্যবহার হয় classification করতে। Flatten বা GlobalAveragePooling দিয়ে 3D → 1D করার পর।

CNN আর্কিটেকচার: বাম থেকে ডানে — ছবি ছোট হতে থাকে কিন্তু features আরও গভীর হয়

৫

Convolution — ছবি থেকে Feature বের করা

Convolution হলো CNN-এর হৃদয়। এটা একটি ছোট ফিল্টার (kernel) দিয়ে পুরো ছবি স্ক্যান করে এবং নির্দিষ্ট feature বের করে।

Convolution কীভাবে কাজ করে?

কল্পনা করো তোমার হাতে একটি ছোট আতশকাচ (magnifying glass) আছে। তুমি সেটা ছবির উপর বাম-থেকে-ডানে, উপর-থেকে-নিচে সরাচ্ছ এবং প্রতিটি অবস্থানে একটি হিসাব করছ। এটাই Convolution।

উপরের উদাহরণে: ৩×৩ ফিল্টারটি input-এর উপরের বাম কোণে রাখা হয়েছে। প্রতিটি position-এ element-wise গুণ করে সব যোগ করা হয়।

🧠 নেটওয়ার্ক কীভাবে ফিল্টারের মান শেখে?

আমরা ফিল্টারের মান নিজে দিই না। ট্রেনিংয়ের সময় Backpropagation এবং Gradient Descent ব্যবহার করে নেটওয়ার্ক নিজেই সেরা ফিল্টার খুঁজে বের করে। প্রথম কয়েকটি layer সাধারণ feature শেখে (রেখা, কোণা), পরের layer শেখে জটিল feature (চাকা, জানালা, দরজা)।

৬

Pooling — Feature Map ছোট করা

Convolution-এর পরে Feature Map অনেক বড় থাকে। Pooling এটাকে ছোট করে, কিন্তু সবচেয়ে গুরুত্বপূর্ণ তথ্য ধরে রাখে।

কেন Pooling দরকার?

কল্পনা করো একটি ছবিতে চাকা আছে — সেটা ছবির ঠিক কোথায় আছে সেটা গুরুত্বপূর্ণ নয়, গুরুত্বপূর্ণ হলো চাকার feature আছে কিনা। Pooling এই "অবস্থান-নিরপেক্ষতা" তৈরি করে।

Max Pooling: প্রতিটি ২×২ এলাকা থেকে সবচেয়ে বড় মান নেওয়া হয়

Max Pooling (বেশি ব্যবহৃত)

প্রতিটি টাইল থেকে সর্বোচ্চ মান নেওয়া হয়। সবচেয়ে শক্তিশালী feature বের করে। গাড়ির সবচেয়ে উজ্জ্বল বৈশিষ্ট্যগুলো ধরে রাখে।

Average Pooling

প্রতিটি টাইলের গড় মান নেওয়া হয়। সূক্ষ্ম বিস্তার ধরে, কিন্তু সবচেয়ে গুরুত্বপূর্ণ তথ্য কম emphasize করে।

নিজে CNN বানানো — Keras-এ Implementation

সম্পূর্ণ CNN আর্কিটেকচার

Python / Keras সম্পূর্ণ CNN মডেল — প্রতিটি লাইন ব্যাখ্যা সহ 
model = Sequential()

# ---- প্রিপ্রোসেসিং স্তর ----
# ছবি ২২৪×২২৪ → ৬০×৬০ রিসাইজ (কম্পিউটেশন কমাতে)
model.add(Resizing(60, 60, input_shape=[224,224,3]))

# পিক্সেল মান ০-২৫৫ → ০-১ নরমালাইজ (ট্রেনিং দ্রুত হয়)
model.add(Rescaling(1./255))

# ---- Feature Extraction ----
# ৩২টি ফিল্টার, প্রতিটি ৩×৩
model.add(Conv2D(32, (3, 3), activation='relu', padding='valid'))
model.add(MaxPooling2D((2, 2), strides=(2, 2)))  # সাইজ অর্ধেক
model.add(Dropout(0.3))  # ৩০% নিউরন রেন্ডমলি বন্ধ (overfitting কমাতে)

model.add(Conv2D(64, (3, 3), activation='relu', padding='valid'))
model.add(MaxPooling2D((2, 2), strides=(2, 2)))

model.add(Conv2D(128, (3, 3), activation='relu', padding='valid'))
model.add(MaxPooling2D((2, 2), strides=(2, 2)))
model.add(Dropout(0.3))

# ---- 3D → 1D রূপান্তর ----
model.add(Flatten())  # Conv output কে 1D vector-এ পরিণত করা

# ---- Classification স্তর ----
model.add(Dense(1024, activation='relu'))
model.add(Dropout(0.2))

model.add(Dense(512, activation='relu'))
model.add(Dropout(0.2))

model.add(Dense(256, activation='relu'))

# Output: ১০ ক্লাসের জন্য Softmax
model.add(Dense(nb_class, activation='softmax'))

# Compile
model.compile(
    optimizer=Adam(learning_rate=0.0005),  # ছোট learning rate = সাবধানে শেখা
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# Train
history = model.fit(
    X_train, data_train["class"],
    validation_data=(X_test, data_test['class']),
    batch_size=32,
    epochs=20,
    verbose=1
)

📐 padding='valid' বনাম padding='same' — কী পার্থক্য?

padding='valid'

ছবির বাইরে কিছু যোগ করা হয় না। Output সাইজ Input-এর চেয়ে ছোট হয়। যেমন: 5×5 input + 3×3 filter = 3×3 output।

padding='same'

ছবির চারপাশে শূন্য যোগ করা হয়। Output সাইজ Input-এর সমান থাকে। Stride=1 হলে 5×5 in → 5×5 out।

💡 Learning Rate কী?

Learning rate হলো প্রতি পদক্ষেপে model কতটুকু পরিবর্তন করবে সেই হার। 0.0005 মানে খুব ছোট পদক্ষেপে এগোনো — এটা সঠিক সমাধানে পৌঁছানোর সম্ভাবনা বাড়ায় কিন্তু বেশি সময় নেয়। অনেক বড় হলে সমাধান miss করে যেতে পারে।

Overfitting — ডিপ লার্নিংয়ের সবচেয়ে বড় শত্রু

Overfitting হলো যখন মডেল training data মুখস্থ করে ফেলে, কিন্তু নতুন data-তে ভালো কাজ করতে পারে না। এটা অনেকটা এমন — একজন ছাত্র পুরনো প্রশ্নপত্র মুখস্থ করে পরীক্ষায় যায়, কিন্তু নতুন প্রশ্ন দেখলে পারে না।

Overfitting: Training error কমতে থাকে, কিন্তু Validation error বাড়তে থাকে

Overfitting রোধের দুটি প্রধান উপায়

🎲 Dropout

Training-এর সময় কিছু নিউরন রেন্ডমলি বন্ধ করে দেওয়া হয়। প্রতিটি epoch-এ আলাদা নিউরন বন্ধ হয়। ফলে নেটওয়ার্ক শুধু নির্দিষ্ট নিউরনের উপর নির্ভর করতে পারে না।

Dropout(0.3) → ৩০% নিউরন বন্ধ

⚖️ Regularization

বড় weight-কে penalty দেওয়া হয়। এটা নেটওয়ার্ককে সরল সমাধান খুঁজতে বাধ্য করে। L1 বা L2 regularization সবচেয়ে বেশি ব্যবহৃত।

Loss = Loss + λ × Σ(w²)

Dropout: Training-এর সময় কিছু নিউরন (X চিহ্নিত) বন্ধ থাকে, Testing-এ সব চালু থাকে

৯

Data Augmentation — কৃত্রিম ডেটা তৈরি

Transfer Learning হলো ডিপ লার্নিংয়ের সবচেয়ে শক্তিশালী কৌশলগুলোর একটি। একটি বিশেষজ্ঞ ব্যক্তি যদি একটি নতুন কাজ শেখে, সে তার পুরনো জ্ঞান ব্যবহার করে — Transfer Learning-ও ঠিক তাই।

Transfer Learning কীভাবে কাজ করে?

Transfer Learning: VGG16-এর শেখা knowledge আমাদের গাড়ি শনাক্তকরণ সমস্যায় ব্যবহার করা হচ্ছে

তিনটি Fine-tuning Strategy

🔓

Strategy 1: সব layer Train করা

Pre-trained layer সহ সব কিছু re-train। বেশি ডেটা থাকলে ভালো, কিন্তু ধীর এবং overfitting-এর ঝুঁকি বেশি।

🔀

Strategy 2: কিছু layer Train

শেষের কিছু layer train করা, বাকি freeze। মাঝামাঝি পদ্ধতি — আমাদের ডেটার সাথে সামঞ্জস্য করা যায়।

❄️

Strategy 3: সব Freeze (আমাদের)

শুধু নতুন classification head train করা। কম ডেটায় দ্রুত ভালো ফলাফল। এই প্রজেক্টে এটাই ব্যবহার।

❓ GlobalAveragePooling2D কী?

VGG16-এর output হলো একটি 3D feature map (যেমন 7×7×512)। Classification-এর জন্য এটাকে 1D-তে আনতে হবে। Flatten() করলে 7×7×512 = 25,088 নিউরন হয়। কিন্তু GlobalAveragePooling2D() প্রতিটি 7×7 চ্যানেলের গড় নেয় → শুধু 512 নিউরন! অনেক কম প্যারামিটার, overfitting কম।

৪০ Epoch ট্রেনিংয়ের পর Transfer Learning মডেলের Validation Accuracy অনেক বেশি! কারণ VGG16 ইতিমধ্যে লক্ষ লক্ষ ছবি দেখে সাধারণ features শিখে আছে। আমাদের শুধু সেই knowledge নতুন কাজে adapt করতে হয়েছে।

নতুন উপাদান: BatchNormalization ও LeakyReLU

BatchNormalization

প্রতিটি batch-এর output normalize করে (গড় ≈০, variance ≈১)। এটা ট্রেনিং দ্রুত করে, gradient vanishing সমস্যা কমায়, এবং overfitting কমাতে সাহায্য করে। প্রতিটি Conv layer-এর পরে ব্যবহার করা হয়।

x_norm = (x - μ) / √(σ² + ε)

LeakyReLU

সাধারণ ReLU-তে নেগেটিভ মান শূন্য হয়ে যায় → neuron "মরে যায়"। LeakyReLU নেগেটিভ মানকে ছোট্ট একটু অনুমতি দেয় → "Dying ReLU" সমস্যা কমায়।

f(x) = x যদি x>0, নাহলে 0.01×x

from tensorflow.keras.layers import BatchNormalization, LeakyReLU

K.clear_session()
model = Sequential()

# ==== ব্লক ১: ৮টি ফিল্টার, ৫×৫ কার্নেল ====
# padding='same' → output সাইজ input সাইজের সমান
model.add(Conv2D(8, (5, 5), padding='same', input_shape=[224,224,3]))
model.add(BatchNormalization())   # output normalize
model.add(LeakyReLU())              # activation
model.add(Conv2D(8, (5, 5), padding='same'))
model.add(BatchNormalization())
model.add(LeakyReLU())
model.add(MaxPooling2D((2, 2), strides=(2, 2)))  # 224→112

# ==== ব্লক ২: ১৬টি ফিল্টার ====
model.add(Conv2D(16, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(Conv2D(16, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(MaxPooling2D((2, 2), strides=(2, 2)))  # 112→56

# ==== ব্লক ৩: ৩২টি ফিল্টার ====
model.add(Conv2D(32, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(Conv2D(32, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(MaxPooling2D((2, 2), strides=(2, 2)))  # 56→28

# ==== ব্লক ৪: ৬৪টি ফিল্টার ====
model.add(Conv2D(64, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(Conv2D(64, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(MaxPooling2D((2, 2), strides=(2, 2)))  # 28→14

# ==== ব্লক ৫: ১২৮টি ফিল্টার ====
model.add(Conv2D(128, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(Conv2D(128, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(MaxPooling2D((2, 2), strides=(2, 2)))  # 14→7

# ==== ব্লক ৬: ২৫৬টি ফিল্টার (সবচেয়ে গভীর) ====
model.add(Conv2D(256, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(Conv2D(256, (5, 5), padding='same'))
model.add(BatchNormalization()); model.add(LeakyReLU())
model.add(Conv2D(256, (5, 5), padding='same'))
model.add(BatchNormalization())   # এখানে LeakyReLU নেই

# GlobalAveragePooling: 7×7×256 → 256
model.add(GlobalAveragePooling2D())

# Output: ৪টি মান (Bounding Box regression এর জন্য!)
model.add(Dense(4))

# ==== Custom Loss Function ====
def loss_function(y_true, y_pred):
    # Bounding box এর (x, y, width, height) predict করার Loss
    return (K.square(y_true[:,0]-y_pred[:,0]) +   # x error²
            K.square(y_true[:,1]-y_pred[:,1]) +   # y error²
            K.square(K.sqrt(K.abs(y_true[:,2]))-K.sqrt(K.abs(y_pred[:,2]))) +  # √w
            K.square(K.sqrt(K.abs(y_true[:,3]))-K.sqrt(K.abs(y_pred[:,3]))))   # √h

model.compile(optimizer="adam", loss=loss_function)

এটা Classification করে না — এটা Object Detection করে! Output layer-এ ৪টি নিউরন আছে যেগুলো Bounding Box-এর কোঅর্ডিনেট (x, y, width, height) প্রেডিক্ট করে। Custom Loss Function √(width) এবং √(height) ব্যবহার করে — কারণ বড় box-এর ছোট ভুলের চেয়ে ছোট box-এর ছোট ভুল বেশি গুরুত্বপূর্ণ।

for k in K_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X_train)
    inertias.append(km.inertia_)
    silhouettes.append(silhouette_score(X_train, labels))

# Best k = highest silhouette score
best_k = list(K_range)[silhouettes.index(max(silhouettes))]
print(f"Best k: {best_k}, Silhouette: {max(silhouettes):.3f}")

km_final = KMeans(n_clusters=best_k, random_state=42).fit(X_train)
print("Cluster sizes:", {k: (km_final.labels_==k).sum() for k in range(best_k)})

def create_sequences(data, seq_len=30):
    X, y = [], []
    for i in range(len(data) - seq_len):
        X.append(data[i:i+seq_len])
        y.append(data[i+seq_len])
    return np.array(X), np.array(y)

🎯 ML Engineering ইন্টারভিউ — সিনিয়র লেভেল
  1. Q: কোন problem-এ কোন algorithm ব্যবহার করবে?
    → Image: CNN | Sequence/Time Series: LSTM/Transformer | Tabular: XGBoost/RF | Clustering: K-Means/DBSCAN | Text: Transformer
  2. Q: Overfitting ধরা ও সমাধান করার পদ্ধতি?
    → Train vs Validation loss gap দেখো। সমাধান: Dropout, L1/L2 regularization, Data Augmentation, Early Stopping, কম parameter।
  3. Q: Production-এ model deploy করার সময় কী কী দেখো?
    → Latency, throughput, memory usage, model drift monitoring (Evidently AI), versioning (MLflow/DVC), A/B testing।
  4. Q: Imbalanced dataset হলে কী করবে?
    → Oversampling (SMOTE), Undersampling, class_weight='balanced', Precision-Recall curve ব্যবহার (accuracy নয়), Focal Loss।
