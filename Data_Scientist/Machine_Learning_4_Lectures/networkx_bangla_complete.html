গ্রাফ কী? (What is a Graph?)

গ্রাফ হলো একটি ডেটা স্ট্রাকচার যেখানে দুটো জিনিস থাকে — নোড (Node/Vertex) এবং এজ (Edge)।

🔵

Node (নোড / বিন্দু)

গ্রাফের প্রতিটি সত্তা। মানুষ, শহর, ওয়েবপেজ, কম্পিউটার — যেকোনো কিছু নোড হতে পারে।

🔗

Edge (এজ / সংযোগ)

দুটি নোডের মধ্যে সম্পর্ক। বন্ধুত্ব, রাস্তা, লিংক, তার — এগুলো edge।

🌍 বাস্তব জীবনের উদাহরণ
  • Facebook/Instagram: প্রতিটি মানুষ = নোড | বন্ধুত্ব / ফলো = edge
  • Google Maps: প্রতিটি স্থান = নোড | রাস্তা = edge | দূরত্ব = weight
  • ইন্টারনেট: প্রতিটি ওয়েবপেজ = নোড | হাইপারলিংক = edge
  • ML Pipeline: প্রতিটি ধাপ = নোড | নির্ভরতা (dependency) = edge
  • Fraud Detection: লেনদেন ও অ্যাকাউন্ট = নোড | টাকার প্রবাহ = edge
চিত্র ১ — সামাজিক নেটওয়ার্ক গ্রাফ: প্রতিটি বৃত্ত = একজন মানুষ (নোড), প্রতিটি রেখা = বন্ধুত্ব (edge)
📐 গণিতের ভাষায়

গ্রাফ G = (V, E) যেখানে V = নোডের সেট এবং E = edge-এর সেট।
উদাহরণ: V = {A, B, C, D} এবং E = {(A,B), (B,C), (C,D), (D,A)}

↔️

Undirected Graph

Edge-এ কোনো দিক নেই। A-B মানে B-Aও। যেমন: Facebook বন্ধুত্ব — দুজনেই বন্ধু।

→

Directed Graph (DiGraph)

Edge-এ দিক আছে (তীর)। A→B মানে A থেকে B, কিন্তু B থেকে A নাও হতে পারে। যেমন: Twitter follow।

⚖️

Weighted Graph

প্রতিটি edge-এর একটি সংখ্যা (weight) আছে। যেমন: দূরত্ব, সময়, খরচ।

🔄

Loop

একটি নোড থেকে সেই নোডেই ফিরে আসা edge। বিশেষ ক্ষেত্রে ব্যবহার।

চিত্র ২ — Undirected (বাম): দুই দিকে যাওয়া যায় | Directed (ডান): তীরের দিকেই যাওয়া যায়

সোশ্যাল নেটওয়ার্ক গ্রাফ তৈরি

ML Engineering · Graph Construction · Beginner

সমস্যা: ৮ জন ML researcher আছে। তারা যদি একই paper co-author করে তাহলে edge আছে (weight = যতটি paper একসাথে লিখেছে):

  • R0–R1: 5 | R0–R2: 3 | R1–R3: 7 | R2–R3: 2 | R3–R4: 6
  • R4–R5: 4 | R5–R6: 8 | R6–R7: 1 | R7–R0: 9

কাজ: (a) Weighted undirected graph তৈরি করো (b) সবচেয়ে productive researcher খোঁজো (degree দিয়ে) (c) গ্রাফ আঁকো weight সহ।

ইন্টারভিউ প্রশ্ন: co-authorship network-এ graph কেন ব্যবহার করা হয়? Adjacency matrix vs list — sparse graph-এ কোনটা বেশি memory efficient?

add_weighted_edges_from() ব্যবহার করো। সবচেয়ে connected: max(G.degree(), key=lambda x: x[1])।
Pythonসমাধান
G = nx.Graph()
edges = [('R0','R1',5),('R0','R2',3),('R1','R3',7),
         ('R2','R3',2),('R3','R4',6),('R4','R5',4),
         ('R5','R6',8),('R6','R7',1),('R7','R0',9)]
G.add_weighted_edges_from(edges)
print("নোড:", G.number_of_nodes(), "| Edge:", G.number_of_edges())
top = max(G.degree(), key=lambda x: x[1])
print(f"সবচেয়ে productive: {top[0]} (degree={top[1]})")
pos = nx.circular_layout(G)
nx.draw(G, pos, with_labels=True, node_color='#75DFC1', node_size=700)
nx.draw_networkx_edge_labels(G, pos, edge_labels=nx.get_edge_attributes(G,'weight'))

উত্তর — ইন্টারভিউ: Graph ব্যবহার করা হয় কারণ researcher collaboration non-linear structure। Sparse graph-এ adjacency list বেশি efficient (O(V+E) memory vs matrix এর O(V²))।

ML Pipeline Dependency Graph

ML Engineering · Directed Graph · Intermediate

সমস্যা: একটি ML pipeline-এ dependency: DataIngestion → [DataCleaning, FeatureExtraction] → ModelTraining → [ModelEvaluation, ModelServing] → Monitoring

কাজ: (a) DiGraph তৈরি করো (b) কোন ধাপ সবচেয়ে critical (সবচেয়ে বেশি in_degree)? (c) topological sort করো (কোন ক্রমে কাজ করতে হবে)।

Topological sort: list(nx.topological_sort(G)) — এটা শুধু DAG-এ কাজ করে।
Python
G_pipe = nx.DiGraph()
G_pipe.add_edges_from([
    ('DataIngestion','DataCleaning'), ('DataIngestion','FeatureExtraction'),
    ('DataCleaning','ModelTraining'), ('FeatureExtraction','ModelTraining'),
    ('ModelTraining','ModelEvaluation'), ('ModelTraining','ModelServing'),
    ('ModelEvaluation','ModelServing'), ('ModelServing','Monitoring')
])
critical = max(G_pipe.in_degree(), key=lambda x: x[1])
print(f"Critical: {critical[0]} (in_degree={critical[1]})")
topo = list(nx.topological_sort(G_pipe))
print("Execution order:", topo)

Adjacency Matrix — সংলগ্নতা ম্যাট্রিক্স

গ্রাফকে কম্পিউটারে রাখার একটি উপায়: n×n বর্গ ম্যাট্রিক্স যেখানে A[i][j]=1 মানে নোড i ও j এর মধ্যে edge আছে, 0 মানে নেই।

চিত্র ৫ — Adjacency Matrix: row i ও column j তে 1 থাকলে i-j edge আছে
PythonMatrix ও List বের করা

Kruskal Algorithm — Minimum Spanning Tree (MST)

MST হলো সেই subgraph যা সব নোড কানেক্ট রাখে কিন্তু মোট edge weight সবচেয়ে কম।

🏙️ বাস্তব উদাহরণ

১০টি শহরে ইন্টারনেট ক্যাবল বসাতে চাও। সব শহর কানেক্ট করো কিন্তু মোট খরচ সবচেয়ে কম রাখো। এটাই MST সমস্যা — Kruskal এটা সমাধান করে।

Kruskal কীভাবে কাজ করে?

  1. সব edge weight অনুযায়ী ছোট থেকে বড় সাজাও
  2. সবচেয়ে ছোট edge নাও
  3. যদি এই edge যোগ করলে cycle হয় — বাদ দাও
  4. সব নোড কানেক্ট না হওয়া পর্যন্ত ২-৩ ধাপ চালু রাখো

Dijkstra Algorithm — সর্বসংক্ষিপ্ত পথ

Dijkstra দিয়ে দুটি নোডের মধ্যে সবচেয়ে কম weight-এর পথ খোঁজা যায়।

🗺️ Google Maps-এর মতো

Dijkstra কীভাবে কাজ করে?

  1. শুরু নোডের দূরত্ব = 0, বাকি সব = ∞
  2. শুরুর প্রতিবেশীদের দূরত্ব আপডেট করো
  3. সবচেয়ে কম দূরত্বের নোড বেছে নাও
  4. সেই নোডের প্রতিবেশীদের দূরত্ব আপডেট করো (ছোট হলে)
  5. সব নোড visited না হওয়া পর্যন্ত চালু রাখো

Louvain মেলানোর মাধ্যমে community খোঁজে, Girvan-Newman ভাঙার মাধ্যমে। যে edge দুটি community-র মধ্যে "সেতু" — সেটা সরালেই community আলাদা হয়।

📐 Edge Betweenness

সব নোড-জোড়ার মধ্যে shortest path গণনা করলে যে edge সবচেয়ে বেশিবার ব্যবহৃত হয় — সেটার edge betweenness সবচেয়ে বেশি। এই "bridge" edge-ই community আলাদা করে।

PythonGirvan-Newman Algorithm
from networkx.algorithms.community import girvan_newman
from networkx.algorithms.community.quality import performance

# Community generator
communities_gen = nx.algorithms.community.girvan_newman(z)

# প্রথম partition
community = next(communities_gen)
print("Performance:", performance(z, community))

communities_gen = nx.algorithms.community.girvan_newman(z)
best_score, best_part, scores = 0, None, []
for partition in communities_gen:
    score = performance(z, partition)
    if score >= best_score:
        best_part, best_score = partition, score
    scores.append(score)

plt.plot(range(len(scores)), scores)
plt.xlabel('Iteration'); plt.ylabel('Performance')

Simple PageRank Algorithm

📐 সূত্র

Initial: PR(Ai; 0) = 1/N (সব পেজ সমান)

Update: PR(Ai; t+1) = Σ [PR(Aj; t) / L(Aj)] — যেখানে Aj, Ai কে point করে এবং L(Aj) = Aj এর outgoing link সংখ্যা

PythonSimple PageRank
# Political blog graph লোড
Gr = nx.read_gml('polblogs.gml')
print(f"নোড: {nx.number_of_nodes(Gr)}, Edge: {nx.number_of_edges(Gr)}")

L = list(Gr.adj['alternateworlds.blogspot.com'])
G = Gr.subgraph(L)
N = nx.number_of_nodes(G)
dic = dict((L[i], i) for i in range(N))

def PageRankSimple(G, dic, pr_old):
    N = nx.number_of_nodes(G)
    pr_new = np.ones(N)
    for site in G.nodes():
        s = 0
        for nb in G.predecessors(site):
            s += pr_old[dic[nb]] / G.out_degree(nb)
        for n in G.nodes():
            if G.out_degree(n) == 0:
                s += pr_old[dic[n]] / N
        pr_new[dic[site]] = s
    return pr_new

# ৩ iteration
pr = np.ones(N) / N
for i in range(3):
    pr = PageRankSimple(G, dic, pr)
    print(f"iter {i+1}: sum={np.sum(pr):.4f}")

# শীর্ষ ৪ পেজ
for i in np.argsort(pr)[-4:]:
    print(f"  {list(dic.items())[i][0]}: PR={pr[i]:.4f}")

Damping Factor সহ PageRank

📐 Damping Factor সূত্র

PR(Ai; t+1) = (1-d)/N + d × Σ [PR(Aj;t) / L(Aj)]

d=0.85 মানে: ৮৫% সময় link follow করে, ১৫% সময় random পেজে যায়। বাস্তবসম্মত।

PythonPageRank with Damping Factor
def PageRankDF(G, dic, pr_old, d=0.85):
    N = nx.number_of_nodes(G)
    pr_new = np.ones(N)
    for site in G.nodes():
        s = 0
        for nb in G.predecessors(site):
            s += pr_old[dic[nb]] / G.out_degree(nb)
        for n in G.nodes():
            if G.out_degree(n) == 0:
                s += pr_old[dic[n]] / N
        pr_new[dic[site]] = (1-d)/N + d*s
    return pr_new

pr = np.ones(N) / N
for i in range(3):
    pr = PageRankDF(G, dic, pr)

Matrix Form — পুরো গ্রাফে PageRank

📐 Matrix সূত্র

R(t+1) = d·M·R(t) + (1-d)/N · 1

যেখানে M[i][j] = 1/L(Aj) যদি j→i edge থাকে, নয়তো 0। Column-of-zeros হলে সব coefficient = 1/N।

PythonMatrix PageRank — পুরো গ্রাফে
# Matrix M তৈরি
nodes = list(Gr.nodes())
N = len(nodes)
dic = dict((nodes[i], i) for i in range(N))
M = np.zeros((N, N))
for j in range(N):
    succs = list(Gr.successors(nodes[j]))
    nl = len(succs)
    for succ in succs:
        M[dic[succ], j] = 1/nl
for j in range(N):
    if np.sum(M[:,j]) == 0:
        M[:,j] = np.ones(N)/N

# Iteration
d = 0.85
iters = int(round(np.log(N)))
pr = np.ones(N)/N
for _ in range(iters):
    pr = d * np.matmul(M, pr) + (1-d)/N
print(f"Sum: {np.sum(pr):.4f}")

# শীর্ষ ১০ পেজ
for i in np.argsort(pr)[-10:]:
    print(f"  {nodes[i]}: {pr[i]:.6f}")

# NetworkX built-in PageRank (সরাসরি ব্যবহারযোগ্য)

# ── Scratch থেকে BFS (বুঝতে) ──
def bfs_scratch(graph_adj, start):
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        node = queue.popleft()      # সামনে থেকে নাও
        order.append(node)
        for neighbor in graph_adj.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)  # পেছনে দাও
    return order

Kruskal's Algorithm — Minimum Spanning Tree

সবচেয়ে কম খরচে সব নোড কানেক্ট করো

👶 শিশুদের ভাষায়

১০টি বাড়িতে বিদ্যুৎ দিতে হবে। প্রতিটি বাড়ির মধ্যে তার টানার খরচ আলাদা। সবচেয়ে সস্তা তার দিয়ে শুরু করো। চক্র (loop) হলে সেটা বাদ দাও। সব বাড়ি কানেক্ট না হওয়া পর্যন্ত চালাও।

# ── Scratch থেকে Kruskal ──
def kruskal(nodes, edges):
    # Union-Find (Disjoint Set)
    parent = {n: n for n in nodes}
    def find(x):
        while parent[x] != x: x = parent[x]
        return x
    def union(a, b):
        parent[find(a)] = find(b)
    mst_edges = []
    for w, u, v in sorted((w,u,v) for u,v,w in edges):
        if find(u) != find(v):  # cycle হবে না
            union(u, v)
            mst_edges.append((u, v, w))
    return mst_edges

result = kruskal(['A','B','C','D'],
                  [('A','B',1),('A','C',4),('B','C',2),('B','D',6),('C','D',3)])
print("MST:", result)

# ── Scratch থেকে Dijkstra ──
import heapq

def dijkstra(adj_weighted, start):
    dist = {node: float('inf') for node in adj_weighted}
    dist[start] = 0
    heap = [(0, start)]  # (দূরত্ব, নোড)
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]: continue
        for v, w in adj_weighted.get(u, []):
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(heap, (dist[v], v))
    return dist

graph = {
    'A': [('B',1),('C',4)],
    'B': [('C',2),('D',6)],
    'C': [('D',3)],
    'D': []
}
print(dijkstra(graph, 'A'))  # {'A':0,'B':1,'C':3,'D':6}

# ── Matrix form (সম্পূর্ণ গ্রাফে) ──
def pagerank_matrix(G, d=0.85, iters=50):
    nodes = list(G.nodes())
    N = len(nodes)
    idx = {n:i for i,n in enumerate(nodes)}
    M = np.zeros((N,N))
    for j,node in enumerate(nodes):
        succs = list(G.successors(node))
        nl = len(succs)
        if nl > 0:
            for s in succs: M[idx[s],j] = 1/nl
        else:
            M[:,j] = 1/N
    pr = np.ones(N)/N
    for _ in range(iters):
        pr = d*np.matmul(M,pr) + (1-d)/N
    return {nodes[i]: pr[i] for i in range(N)}

result = pagerank_matrix(G_dir)
print("Matrix PageRank:", result)

import pandas as pd
import numpy as np
from community.community_louvain import best_partition

# Transaction data (synthetic)
transactions = [
    ('ACC001','ACC002',5000), ('ACC001','ACC003',3000),
    ('ACC002','ACC004',4500), ('ACC003','ACC004',2000),
    ('ACC004','ACC001',7000),  # suspicious cycle!
    ('ACC005','ACC006',500),  ('ACC006','ACC007',600),

    ('ACC010','ACC008',900),   # another cycle!
]

        'out_degree': G.out_degree(node),

        'pagerank': pr.get(node, 0),
