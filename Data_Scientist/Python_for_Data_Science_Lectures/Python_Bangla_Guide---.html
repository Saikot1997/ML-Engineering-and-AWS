প্রশ্ন ০১ — Word Frequency (NLP)

"the model is good and the accuracy is high" — প্রতিটা word কতবার আছে count করো।

সমাধান দেখো
def word_count(s):
    freq = {}
    for w in s.lower().split():
        freq[w] = freq.get(w,0)+1
    return freq
print(word_count("the model is good and the accuracy is high"))
প্রশ্ন ০২ — Group by Parity

সমাধান দেখো
def parity(nums):
    return {"even":[n for n in nums if n%2==0], "odd":[n for n in nums if n%2!=0]}
print(parity([1,2,3,4,5,6,7,8]))

1. Bubble Sort (বুদবুদ সাজানো)

পাশাপাশি দুটো তুলনা করো, বড়টা পেলে swap করো — বারবার করো।

🫧 শিশুর ভাষায়

পানিতে বড় বুদবুদ উপরে ওঠে। প্রতিটা pass-এ সবচেয়ে বড় সংখ্যাটা শেষে চলে যায়।

Best:O(n)
Average/Worst:O(n²)
Space:O(1)
Python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        if not swapped: break  # already sorted!
    return arr

print(bubble_sort([0.72,0.91,0.55,0.88]))  # [0.55,0.72,0.88,0.91]

2. Merge Sort (ভাগ করে সাজাও)

List অর্ধেক ভাগ করো, দুটো আলাদা sort করো, তারপর merge করো। Divide & Conquer।

🃏 শিশুর ভাষায়

৮টা তাস → ৪+৪ → ২+২+২+২ → প্রতিটা sort → জোড়া দিতে থাকো।

All cases:O(n log n)
Space:O(n)
Python
def merge_sort(arr):
    if len(arr)<=1: return arr
    mid   = len(arr)//2
    left  = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return _merge(left, right)

def _merge(L, R):
    res, i, j = [], 0, 0
    while i<len(L) and j<len(R):
        if L[i]<R[j]: res.append(L[i]); i+=1
        else:          res.append(R[j]); j+=1
    return res + L[i:] + R[j:]

print(merge_sort([38,27,43,3,9,82]))  # [3,9,27,38,43,82]

3. Quick Sort (দ্রুত সাজানো)

Pivot বেছে নাও। Pivot-এর চেয়ে ছোটগুলো বামে, বড়গুলো ডানে। Recursively করো।

🎯 শিশুর ভাষায়

৫ কে pivot ধরলাম। ৫-এর চেয়ে ছোট সব বাম, বড় সব ডান। তারপর দুই দিক আলাদা sort করো।

Average:O(n log n)
Worst:O(n²)
Space:O(log n)
Python
def quick_sort(arr):
    if len(arr)<=1: return arr
    pivot  = arr[len(arr)//2]
    left   = [x for x in arr if x<pivot]
    middle = [x for x in arr if x==pivot]
    right  = [x for x in arr if x>pivot]
    return quick_sort(left) + middle + quick_sort(right)

print(quick_sort([3,6,8,10,1,2]))  # [1,2,3,6,8,10]

4. Binary Search (অর্ধেক করে খোঁজা)

Sorted array-তে মাঝখান দেখো। Target ছোট হলে বাম, বড় হলে ডান — প্রতিবার অর্ধেক কমে।

📖 শিশুর ভাষায়

Dictionary-তে "mango" খুঁজছো। মাঝখান খুললে "kangaroo" — তাই পেছনের অর্ধেক দেখো। এভাবে অর্ধেক করে খুব দ্রুত পাওয়া যায়।

Time:O(log n)
Space:O(1)
Python
def binary_search(arr, target):
    lo, hi = 0, len(arr)-1
    while lo<=hi:
        mid = (lo+hi)//2
        if   arr[mid]==target: return mid
        elif arr[mid]<target:  lo = mid+1
        else:                    hi = mid-1
    return -1

thr = [0.1,0.2,0.3,0.5,0.7,0.9]
print(binary_search(thr, 0.5))  # 3
print(binary_search(thr, 0.6))  # -1 (নেই)

# From scratch — কীভাবে কাজ করে বোঝার জন্য
def linear_regression(X, y):
    n    = len(X)
    xm   = sum(X)/n; ym = sum(y)/n
    num  = sum((X[i]-xm)*(y[i]-ym) for i in range(n))
    den  = sum((X[i]-xm)**2      for i in range(n))
    m    = num/den; b = ym-m*xm
    return m, b

6. K-Nearest Neighbors (KNN)

import math
from collections import Counter

def euclidean(a, b):
    return math.sqrt(sum((x-y)**2 for x,y in zip(a,b)))

def knn_predict(X_train, y_train, point, k=3):
    dists  = [(euclidean(point,x),y) for x,y in zip(X_train,y_train)]
    k_near = sorted(dists)[:k]
    labels = [lbl for _,lbl in k_near]
    return Counter(labels).most_common(1)[0][0]

X_train = [[1,2],[2,3],[8,8],[9,9]]
y_train = ["Normal","Normal","Arrhythmia","Arrhythmia"]
print(knn_predict(X_train, y_train, [1.5,2.5]))  # Normal
print(knn_predict(X_train, y_train, [8.5,8.5]))  # Arrhythmia

⛰️ শিশুর ভাষায়

তুমি পাহাড়ের চূড়ায় আছো, চোখ বন্ধ, সবচেয়ে নিচে নামতে চাও। পায়ের নিচে ঢাল কোন দিকে সেটা feel করো, সেই দিকে ছোট করে পা দাও। বারবার করো — কিছুক্ষণ পরে নিচে পৌঁছে যাবে।

Update:θ = θ - α·∇L

Python — gradient_descent.py
# Simple linear regression with gradient descent
def gradient_descent(X, y, lr=0.01, epochs=1000):
    m, b, n = 0.0, 0.0, len(X)
    for epoch in range(epochs):
        y_pred = [m*xi+b for xi in X]
        loss   = sum((y_pred[i]-y[i])**2 for i in range(n))/n
        dm     = -2/n*sum(X[i]*(y[i]-y_pred[i]) for i in range(n))
        db     = -2/n*sum(y[i]-y_pred[i]  for i in range(n))
        m     -= lr*dm
        b     -= lr*db
        if epoch%200==0:
            print(f"Epoch {epoch}: loss={loss:.4f}, m={m:.4f}, b={b:.4f}")
    return m, b

X = [1,2,3,4,5]; y = [3,5,7,9,11]  # y = 2x + 1
m, b = gradient_descent(X, y)
print(f"Final: y = {m:.3f}x + {b:.3f}")  # y ≈ 2.000x + 1.000

10. K-Means Clustering (গ্রুপে ভাগ করা)

K টা cluster center বসাও। প্রতিটা point কাছের center-এ assign করো। Center update করো। Repeat করো।

🎭 শিশুর ভাষায়

ক্লাসে ৩০ জন ছাত্র, ৩ টা গ্রুপ বানাতে হবে। শুরুতে যেকোনো ৩ জনকে leader বানাও। বাকিরা কাছের leader-এর গ্রুপে যাও। তারপর প্রতিটা গ্রুপের মাঝখান বের করো — ওটাই নতুন leader। বারবার করো।

Per iteration:O(n·K·d)
Python — kmeans.py
import random

def kmeans(data, K, iters=100):
    # শুরুতে random K টা center
    centers = random.sample(data, K)
    for _ in range(iters):
        # প্রতিটা point কাছের center-এ assign
        clusters = {i:[] for i in range(K)}
        for pt in data:
            dists = [(pt-c)**2 for c in centers]  # 1D
            clusters[dists.index(min(dists))].append(pt)
        # Center update করো
        new_c = [sum(clusters[i])/len(clusters[i]) if clusters[i] else centers[i]
                 for i in range(K)]
        if new_c == centers: break
        centers = new_c
    return centers, clusters

data = [1,1.5,2,8,9,9.5,50,51,52]
centers, clusters = kmeans(data, K=3)
print(f"Cluster centers: {[round(c,1) for c in centers]}")

# Sklearn version
