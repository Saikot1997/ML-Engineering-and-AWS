Multithreading & Multiprocessing

একসাথে অনেক কাজ করা — Concurrent ও Parallel programming Python-এ কীভাবে কাজ করে।

🏭 ৩.১ — Core Concepts

🖥️ CPU (Central Processing Unit)

Computer-এর মস্তিষ্ক। Instructions execute করে। Modern CPU-তে একাধিক core থাকে — প্রতিটা core আলাদা task করতে পারে।

🧠 Process vs Thread

Process: চলমান program, নিজস্ব memory।
Thread: Process-এর অংশ, memory share করে।

💼 Interview Preparation — Top 15 Q&A

ML Engineering ও Python interview-এ সবচেয়ে বেশি জিজ্ঞেস করা প্রশ্ন এবং সম্পূর্ণ উত্তর।

Q1: Python-এ type annotation কি বাধ্যতামূলক? MyPy ছাড়া কি কাজ করে?
Annotation বাধ্যতামূলক নয় — শুধু hint। Python interpreter enforce করে না। MyPy ছাড়াও code চলে, কিন্তু MyPy দিয়ে static check করা যায়। Production-এ CI/CD-এ MyPy চালানো হয়। Pydantic (FastAPI-তে) annotation enforce করে runtime-এ।
Q2: Decorator কী? @ syntax ছাড়া কীভাবে লেখা যায়?
Decorator একটা function যেটা অন্য function-কে argument নেয়, নতুন behavior wrap করে, এবং modified version return করে। @dec হলো func = dec(func)-এর shorthand। Framework: FastAPI (@app.get), pytest (@pytest.mark), Flask (@app.route)।
Q3: @functools.wraps কেন দরকার?
Decorator apply করলে function-এর __name__, __doc__, __annotations__ হারায়। @wraps(func) এই metadata wrapper-এ copy করে। Production logging, debugging, documentation tool, API schema generation-এ এটা critical।
Q4: Python GIL কী? ML-এ কীভাবে bypass করবে?
GIL = Global Interpreter Lock। CPython-এর mutex যেটা একসাথে একটাই thread Python bytecode চালাতে দেয়। CPU-bound ML training-এ multithreading কাজ করে না। Bypass: (১) multiprocessing — আলাদা process, আলাদা GIL। (২) NumPy/PyTorch C extension — GIL release করে। (৩) asyncio — I/O bound কাজে GIL সমস্যা নেই।
Q5: Thread, Process, Coroutine পার্থক্য কী?
Thread: OS-managed, shared memory, GIL সীমাবদ্ধ, I/O bound-এ ভালো। Process: নিজস্ব memory, GIL bypass, CPU bound-এ ভালো, overhead বেশি। Coroutine: User-managed, একটা thread-এ, explicit yield (await), I/O bound-এ সবচেয়ে efficient, হাজারো coroutine সম্ভব।
Q6: asyncio.gather() বনাম asyncio.create_task() পার্থক্য?
gather(): সব coroutine একসাথে schedule করে, সব শেষ হলে সব result list-এ দেয়। create_task(): immediately event loop-এ schedule হয়, individually await করা যায়, cancel করা যায়। ML ensemble inference-এ gather() সহজ। Individual task control দরকার হলে create_task()।
Q7: @lru_cache কখন ব্যবহার করবে? কী কী সীমাবদ্ধতা আছে?
ব্যবহার: Pure function (same input → same output), expensive computation, repeated input। ML-এ: tokenization cache, embedding cache, feature computation। সীমাবদ্ধতা: Arguments hashable হতে হবে (list চলবে না, tuple চলবে), memory বাড়ে, thread-safe নয়।
Q8: Binary Search-এর O(log n) মানে কী? ML-এ কোথায় দেখা যায়?
O(log n) মানে input দ্বিগুণ হলে মাত্র ১টা step বাড়ে। ১M element-এ max ২০ step! Linear O(n)-এ max ১M step। ML-এ: threshold optimization, hyperparameter grid search (sorted), nearest neighbor search (approximate), sorted model leaderboard query।
Q9: Dynamic Programming কী? Memoization বনাম Tabulation?
DP = Overlapping subproblem-এর result store করে reuse করা। Memoization (top-down): Recursive + cache, natural লেখা, stack overflow risk। Tabulation (bottom-up): Iterative, table fill করো, বেশি efficient। ML-এ: Viterbi (sequence labeling), CRF, RL value function, Levenshtein distance (NLP)।
Q10: BFS বনাম DFS — কোনটা কখন?
BFS (Queue): Shortest path, level-order traversal, closest node খুঁজতে। ML-এ: Knowledge graph shortest relation, neural layer dependency। DFS (Stack/Recursion): Cycle detection, topological sort, deeper exploration। ML-এ: Decision tree traversal, computation graph, hyperparameter tree search।
Q11: I/O bound বনাম CPU bound — কীভাবে চিনবে? কী ব্যবহার করবে?
I/O bound: Program বেশিরভাগ সময় wait করে (network, disk, API)। → Threading বা Async। CPU bound: Program বেশিরভাগ সময় calculation করে (matrix ops, image processing)। → Multiprocessing। ML-এ: Data download = I/O, Training = CPU, API call = I/O, Feature engineering = CPU।
Q12: Python-এ id() কী? Variable কীভাবে memory-তে থাকে?
id() object-এর memory address return করে। Python-এ variable = pointer — সরাসরি মান ধরে না, object-এর address ধরে। a = 5; b = 5 → id(a) == id(b) True (Python -5~256 integer cache করে, "interning")। a = 1000; b = 1000 → আলাদা id (বড় integer cache হয় না)।
Q13: Decorator chain-এ কোনটা আগে apply হয়?
নিচের decorator আগে apply হয়। @A @B def f = f = A(B(f))। Execution-এ A-এর wrapper আগে চলে (বাইরে), তারপর B, তারপর f। Analogy: পেঁয়াজ কাটো — বাইরের খোসা প্রথমে ধরো কিন্তু ভেতরের আগে লাগানো।
Q14: time.sleep() বনাম asyncio.sleep() — কখন কোনটা?
time.sleep() blocking — পুরো OS thread থামে, অন্য কিছু হয় না। asyncio.sleep() non-blocking — event loop অন্য coroutine চালায়। Async function-এ সবসময় asyncio.sleep() ব্যবহার করো, নাহলে পুরো async benefit নষ্ট। Regular sync code-এ time.sleep()।
Q15: Hash table কেন O(1)? সবসময় কি O(1)?
Hash function key-কে direct index-এ convert করে। Average case O(1)। Worst case O(n) — hash collision হলে (বিরল)। Python dict high-quality hash function ব্যবহার করে, collision খুব কম। ML-এ vocabulary (millions of words) থেকে O(1)-এ token id পাওয়া → tokenizer দ্রুত হয়।
