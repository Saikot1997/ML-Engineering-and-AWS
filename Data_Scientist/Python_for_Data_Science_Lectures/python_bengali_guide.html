Error ও Exception — কী এবং কেন?

Python-এ কোড লিখতে গেলে Error আসবেই। ভয় পাবেন না — এটা স্বাভাবিক। এমনকি ১০ বছরের অভিজ্ঞ Developer-রাও প্রতিদিন Error দেখেন। গুরুত্বপূর্ণ হলো Error পড়তে পারা এবং সমাধান করতে পারা।

🔴 Error কী?

ধরুন আপনি একটি রান্নার রেসিপি অনুসরণ করছেন। কিন্তু হঠাৎ রেসিপিতে লেখা আছে "আম কাটুন" — অথচ আপনার কাছে আম নেই। তখন আপনি থেমে যাবেন এবং বলবেন "আম নেই!"


Python-ও ঠিক একইভাবে কাজ করে। যখন সে কোনো নির্দেশ পালন করতে পারে না — সে থেমে যায় এবং একটি Error Message দেখায়। এই Error Message-ই হলো Python-এর "আম নেই!" বলা।

💡

মনে রাখুন: Error একটি সমস্যা নয় — এটি একটি সহায়তা! Python আপনাকে বলে দিচ্ছে কোথায় এবং কী সমস্যা হয়েছে।

চিত্র ১: একটি Python Error Message-এর গঠন

📖 Error Message কীভাবে পড়বেন?

  • প্রথমে শেষ লাইনটি দেখুন — সেখানেই মূল সমস্যার কথা লেখা থাকে
  • Traceback অংশটি পড়ুন — এটি বলে কোন file-এর কোন line-এ সমস্যা হয়েছে
  • → চিহ্নিত লাইনটি দেখুন — এটিই সমস্যার উৎস
  • Error-এর নাম মনে রাখুন (TypeError, ValueError, ইত্যাদি) — পরে Google-এ খুঁজতে কাজে লাগবে

Python-এর সব ধরনের Error

Python-এ অনেক ধরনের Error আছে। প্রতিটি Error একটি নির্দিষ্ট সমস্যার সংকেত দেয়। নিচে প্রতিটি Error বাংলায় উদাহরণ সহ বোঝানো হয়েছে।

Error-এর নাম কখন হয়? বাংলায় উদাহরণ Python উদাহরণ
TypeError ভুল ডেটা টাইপ ব্যবহার করলে সংখ্যার সাথে লেখা যোগ করার চেষ্টা করলে যেমন: ৫ + "আম" 5 + "hello"
ValueError সঠিক ধরন কিন্তু ভুল মান দিলে বয়স জিজ্ঞেস করলে "আম" বললে int("আম")
NameError যে variable আগে তৈরি করা হয়নি ক্লাসে হাজিরা দেওয়া হয়নি এমন ছাত্রকে ডাকা print(x) — x কখনো define করা হয়নি
IndexError List-এর বাইরে index দিলে ৩ জনের দলে ৫ নম্বর মানুষকে খোঁজা [1,2,3][10]
KeyError Dictionary-তে নেই এমন key খুঁজলে ফোনবুকে নেই এমন নাম খোঁজা d = {"নাম": "রিয়া"}; d["বয়স"]
AttributeError Object-এর নেই এমন attribute ব্যবহার পাথরকে উড়তে বলা [1,2,3].shape — list-এ shape নেই
SyntaxError Python-এর লেখার নিয়ম ভাঙলে বাক্যে ক্রিয়া ছাড়া কথা বলা for i in range len(x): — বন্ধনী নেই
IndentationError Tab/Space ঠিকমতো না দিলে প্যারা শুরু করতে ভুলে গেলে for loop-এর ভেতরের code সঠিকভাবে সরানো না হলে
ImportError Library import করতে না পারলে বইমেলায় নেই এমন বই কিনতে চাওয়া import numpi as np — ভুল বানান
ZeroDivisionError শূন্য দিয়ে ভাগ করলে শূন্য মানুষের মধ্যে কিছু ভাগ করা 10 / 0
FileNotFoundError File পাওয়া না গেলে যে ঠিকানা নেই সেখানে চিঠি পাঠানো open("নেই.csv")

প্রতিটি Error-এর কোড উদাহরণ (ভুল ও সঠিক)

AttributeError উদাহরণ

Python — ভুল
# list-এর কোনো shape attribute নেই
liste = [1, 2, 3]
liste.shape  # ❌ AttributeError!
Python — সঠিক
# list-এর দৈর্ঘ্য জানতে len() ব্যবহার করুন
len(liste)  # ✅ Output: 3

# shape শুধু numpy array-তে থাকে
import numpy as np
arr = np.array([1, 2, 3])
arr.shape  # ✅ Output: (3,)

IndentationError উদাহরণ

Python — ভুল
k = 0
for i in range(len(liste)):
k += 1  # ❌ ভেতরে যায়নি, IndentationError!
Python — সঠিক
k = 0
for i in range(len(liste)):
    k += 1  # ✅ 4টি space বা 1টি tab দিতে হবে
⚠️

গুরুত্বপূর্ণ: Python-এ indentation মানে হলো ভেতরের কোড আলাদা করা। for, if, while, def, class — এগুলোর পরের কোড অবশ্যই ভেতরে (indented) রাখতে হবে। সাধারণত 4টি space বা 1টি tab ব্যবহার করা হয়।

TypeError উদাহরণ — আমাদের মূল সমস্যা

Python — ভুল
dict_types = {

# একটি সুন্দর summary table বানানো
def summary(df):
    tab = pd.DataFrame(
        index=df.columns,  # ✅ সব column
        columns=['nb_unique_values', 'nb_missing_values', 'type']
    )
    tab.loc[:, 'nb_unique_values'] = df.nunique().values
    tab.loc[:, 'nb_missing_values'] = df.isna().sum().values
    tab.loc[:, 'type'] = df.dtypes.values
    return tab

EDA স্কিল পরীক্ষা
প্রশ্ন ১ (Interview-এ প্রায়ই জিজ্ঞেস করা হয়): একটি নতুন dataset পেলে আপনি প্রথম ১০ মিনিটে কী কী করবেন? একটি reusable EDA function লিখুন যা dataset-এর সম্পূর্ণ overview দেয়।
EDA Starter Function
def quick_eda(df, name="Dataset"):
    """Production-ready EDA function for any DataFrame."""
    print(f"{'='*60}")
    print(f" {name} Overview")
    print(f"{'='*60}")
    print(f"Shape: {df.shape[0]} rows, {df.shape[1]} columns")
    print(f"\n--- Columns & Types ---")
    print(df.dtypes)

    print(f"\n--- Missing Values ---")
    miss = df.isna().sum()
    print(miss[miss > 0])  # শুধু missing আছে এমন columns

    print(f"\n--- Duplicates ---")
    print(f"Duplicate rows: {df.duplicated().sum()}")

    print(f"\n--- Numeric Summary ---")
    print(df.describe())

    return df

# ব্যবহার:
quick_eda(data, "Video Game Sales")

Missing Values — হারানো ডেটা ঠিক করা

বাস্তব ডেটায় সবসময়ই কিছু missing (অনুপস্থিত) মান থাকে। এগুলো মোকাবেলা করাই হলো Data Scientist-এর অন্যতম প্রধান কাজ।

Missing Values কী?

ধরুন একটি হাসপাতালের রোগীদের তথ্য আছে। কিন্তু কিছু রোগী বয়স বলেননি — সেই জায়গাটা ফাঁকা। Python-এ এই ফাঁকাকে বলা হয় NaN (Not a Number)।

চিত্র ৪: Missing Value Imputation কৌশল

Python — Missing Values Handle করা
# কতটি missing value আছে?
df.isna().sum()

# Target variable-এর missing rows বাদ দেওয়া
df = df.dropna(subset=['target'])

# Categorical variable — Mode দিয়ে পূরণ

df['ca'].fillna(df['ca'].mode()[0], inplace=True)
# [0] কেন? কারণ mode() একটি Series return করে।

df['exang'].fillna(df['exang'].mode()[0], inplace=True)

# সব numeric column — Median দিয়ে পূরণ

🔢 Mean vs Median vs Mode — পার্থক্য কী?

ধরুন ৫ জনের বেতন: ১০, ১২, ১১, ১০০, ১৩ (হাজার টাকা)

  • Mean (গড়): (১০+১২+১১+১০০+১৩)/৫ = ২৯.২ — একটি অস্বাভাবিক বেতন (১০০) পুরো গড় নষ্ট করে দিয়েছে
  • Median (মধ্যমান): সাজালে → ১০, ১১, ১২, ১৩, ১০০ — মাঝের মান = ১২ — এটি বাস্তবসম্মত
  • Mode (বহুলমান): ১০ — সবচেয়ে বেশিবার এসেছে

নিয়ম: Outlier (অস্বাভাবিক মান) থাকলে Median ব্যবহার করুন। Category data হলে Mode।

import pandas as pd
import numpy as np
from sklearn.pipeline import Pipeline

from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.metrics import classification_report
import joblib  # model save করতে

# ১. Data Loading
df = pd.read_csv('heart_disease.csv', sep=';', index_col=0)

# ২. Data Cleaning
df.sex = df.sex.replace(['Male', 'Female'], [0, 1])
df = df.dropna(subset=['target'])

# ৩. Feature Engineering
X = df.drop('target', axis=1)
y = df['target'].astype(int)

# ৪. Sklearn Pipeline তৈরি (production best practice)
pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', MinMaxScaler()),
    ('classifier', RandomForestClassifier(n_estimators=100, random_state=42))
])

# ৫. Stratified K-Fold Cross-Validation
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
cv_scores = cross_val_score(pipeline, X, y, cv=cv, scoring='f1')
print(f"F1 Score: {cv_scores.mean():.3f} ± {cv_scores.std():.3f}")

# ৬. Final Training ও Model Save
pipeline.fit(X, y)
joblib.dump(pipeline, 'heart_disease_model.pkl')
print("Model saved successfully!")

# ৭. Model Load ও Inference
loaded_model = joblib.load('heart_disease_model.pkl')
new_patient = [[45, 1, 0, 150, 240, 0, 0, 165, 0, 0.5, 1, 0, 2]]

Data Quality Assessment Pipeline
Data Quality Checks
def data_quality_report(df):
    """
    Production-grade data quality assessment.
    Real ML projects-এ সবসময় এই ধরনের checks চালানো উচিত।
    """
    report = {}

    # ১. Missing Values
    missing = df.isna().sum()
    missing_pct = (missing / len(df) * 100).round(2)
    report['missing_pct'] = missing_pct[missing_pct > 0]

    # ২. Duplicates
    report['duplicate_rows'] = df.duplicated().sum()

    # ৩. Outliers (IQR method)
    numeric_cols = df.select_dtypes(include=[np.number]).columns
    outlier_counts = {}
    for col in numeric_cols:
        Q1 = df[col].quantile(0.25)
        Q3 = df[col].quantile(0.75)
        IQR = Q3 - Q1
        outliers = df[(df[col] < Q1 - 1.5*IQR) | (df[col] > Q3 + 1.5*IQR)]
        if len(outliers) > 0:
            outlier_counts[col] = len(outliers)
    report['outliers'] = outlier_counts

    # ৪. Class Imbalance (target column থাকলে)
    if 'target' in df.columns:
        report['class_balance'] = df['target'].value_counts(normalize=True)

    return report

# ব্যবহার:
quality = data_quality_report(df)
for key, value in quality.items():
    print(f"\n{key}:")
    print(value)
