Section 01

Statistical Series — পরিসংখ্যান শ্রেণী কী?

ডেটা বিশ্লেষণ শুরু হয় একটা সহজ প্রশ্ন দিয়ে: আমার কাছে কী ধরনের ডেটা আছে?

🧒
শিশুর মতো বুঝি
ধরো একটা ক্লাসে ২০ জনের উচ্চতা মাপলে: [165, 172, 168, 180, ...]। এই তালিকাটাই একটা Statistical Series। এর ক্রম গুরুত্বপূর্ণ না (time series ছাড়া) — মানে প্রথমে 165 হোক বা শেষে — হিসাব একই হবে।
চিত্র: দুই ধরনের variable — সংখ্যা বা বিভাগ
💡
দ্রুত চেনার উপায়
যে column-এ unique value-র সংখ্যা অনেক বেশি, সেটা সাধারণত quantitative। যেমন blood_pressure-এ ৬৩টা unique value — quantitative। sex-এ মাত্র ২টা ('M', 'F') — qualitative।
PYTHON
import pandas as pd
df = pd.read_csv('heart.csv')

# unique values দেখো
print(df['blood_pressure'].unique())  # অনেক → quantitative
print(df['sex'].unique())            # ['M' 'F'] → qualitative

# প্রতি column-এ unique value-র সংখ্যা
print(df.nunique())

# ডেটার ধরন দেখো
df.info()
# int64/float64 = quantitative
# object        = qualitative

# কোন ধরনের কতটা column আছে
df.dtypes.value_counts()
# int64     5
# object    3
Section 02

অবস্থান নির্দেশক — Position Indicators

একটা ডেটার "কেন্দ্র" কোথায়? Mean, Median, Quantile বলে দেয়।

🧒
শিশুর মতো বুঝি
১০ জনের বেতন: [৫০০০, ৫০০০, ৬০০০, ৭০০০, ৮০০০, ৮০০০, ৯০০০, ১০০০০, ১০০০০, ১০,০০,০০০]।
গড় (mean) = প্রায় ১ লাখ! কিন্তু বেশিরভাগ মানুষ ৫–১০ হাজার পাচ্ছে।
মধ্যক (median) = ৮০০০। এটাই বাস্তবতা! একটা CEO-র বেতন সব গড় নষ্ট করে দিতে পারে।
চিত্র: Q1, Q2 (Median), Q3 distribution-কে ৪ সমান ভাগে ভাগ করে। Outlier থাকলে Mean সরে যায়।
Methodকী বলেকোডRobust?
mean()সব মানের গড়df['col'].mean()❌ outlier-এ কাঁপে
median()মাঝের মান (৫০%)df['col'].median()✅ outlier-এ স্থির
min()সবচেয়ে ছোটdf['col'].min()❌
max()সবচেয়ে বড়df['col'].max()❌
quantile(0.25)Q1df['col'].quantile(0.25)✅
quantile(0.75)Q3df['col'].quantile(0.75)✅
PYTHON — Cholesterol বিশ্লেষণ
# heart.csv-এর cholesterol column
col = df['cholesterol']

print(f"সর্বনিম্ন:  {col.min()}")           # 0  ← সন্দেহজনক!
print(f"সর্বোচ্চ:  {col.max()}")           # 603
print(f"মধ্যক:     {col.median()}")       # 223.0
print(f"Q1 (25%):  {col.quantile(0.25)}") # 173.25
print(f"Q3 (75%):  {col.quantile(0.75)}") # 267.0

# একাধিক quantile একসাথে
print(col.quantile(q=[0.1, 0.5, 0.9]))

# Mean vs Median তুলনা
mean_val   = col.mean()    # 198.80
median_val = col.median()  # 223.00
print(f"পার্থক্য: {mean_val - median_val:.2f}") # -24.20
# Median > Mean → left skew অথবা নিচে outlier!
Section 03

Quartile ও IQR — ডেটার "মধ্যভাগ"

IQR = Q3 − Q1 — মাঝের ৫০% ডেটা কতটা ছড়িয়ে আছে তার পরিমাপ।

IQR ও Extreme Value সূত্র
IQR = Q3 − Q1
নিচের সীমা: Q1 − 1.5 × IQR  |  উপরের সীমা: Q3 + 1.5 × IQR
এই সীমার বাইরের মান = Extreme Value
PYTHON — IQR ও Extreme Value
# Cholesterol-এর IQR
Q1 = df['cholesterol'].quantile(0.25)  # 173.25
Q3 = df['cholesterol'].quantile(0.75)  # 267.00
IQR = Q3 - Q1                              # 93.75

lower = Q1 - 1.5 * IQR  # 126.375
upper = Q3 + 1.5 * IQR  # 407.625

print(f"Normal range: {lower:.2f} → {upper:.2f}")

# Extreme values
extreme = df[(df['cholesterol'] < lower) |
             (df['cholesterol'] > upper)]
print(f"Extreme values: {len(extreme)} টি")

# Reusable function
def iqr_bounds(series):
    Q1, Q3 = series.quantile(0.25), series.quantile(0.75)
    IQR = Q3 - Q1
    return Q1 - 1.5*IQR, Q3 + 1.5*IQR

lb, ub = iqr_bounds(df['cholesterol'])
Section 04

Extreme Value বনাম Outlier

এই দুটো অনেকে গুলিয়ে ফেলে — কিন্তু ইন্টারভিউতে পার্থক্য জিজ্ঞেস করা হয়।

⚡ Extreme Value

  • IQR সীমার বাইরে
  • বাস্তবে সম্ভব
  • সত্যিকারের ডেটা
  • উদাহরণ: ২.৫ মিটার লম্বা মানুষ
  • সাধারণত রাখা উচিত

🚫 Outlier

  • বাস্তবে থাকা সম্ভব না
  • ডেটা সংগ্রহে ভুল
  • অসম্ভব বা ভুল মান
  • উদাহরণ: cholesterol = 0
  • বাদ দিতে হবে
⚠️
বাস্তব পরিস্থিতি
Cholesterol = 0: মানুষ বেঁচে থাকলে 0 হয় না → true outlier → বাদ দাও।
Cholesterol = 603: বিরল কিন্তু সম্ভব → extreme value → রাখো।
PYTHON — Outlier বাদ দেওয়া
# True outliers চিহ্নিত করা (বাস্তবে অসম্ভব মান)
outliers = df[(df['cholesterol'] <= 0) |
              (df['cholesterol'] > 600)]
print(f"True outliers: {len(outliers)} টি")  # 173!

# Clean dataset
df_clean = df[(df['cholesterol'] > 0) &
              (df['cholesterol'] <= 600)]

print(f"Original mean: {df['cholesterol'].mean():.2f}")    # 198.80
print(f"Clean mean:    {df_clean['cholesterol'].mean():.2f}") # ~267

Mean আর Median-এর মধ্যে কোনটা বেশি "robust" এবং কেন? Real-world উদাহরণ দাও।
✅ সমাধান দেখো
Median বেশি robust — outlier-এ প্রভাবিত হয় না।

উদাহরণ: ৫ জনের বেতন [৩০০০০, ৩৫০০০, ৪০০০০, ৪৫০০০, ৫০০০০০০]
Mean = ১,১৩,০০০ (CEO-র বেতন টেনে উপরে তুলেছে)
Median = ৪০,০০০ (বাস্তব চিত্র)

ML-এ numerical imputation-এ median বেশি safe।
Section 05

Mean ও Standard Deviation

শুধু গড় জানলে হয় না — ডেটা কতটা ছড়িয়ে আছে সেটাও জানতে হবে।

Mean সূত্র
X̄ = (1/n) × Σ xᵢ
Standard Deviation (σ) সূত্র
σ = √[ (1/(n−1)) × Σ(xᵢ − X̄)² ]
n−1 কেন? Bessel's correction — sample থেকে population estimate করার জন্য।
চিত্র: σ ছোট = কেন্দ্রের কাছে, বড় = দূরে ছড়ানো
PYTHON — STD হাতে ও Pandas দিয়ে
import numpy as np

n    = len(df['cholesterol'])
mean = df['cholesterol'].mean()

# হাতে হিসাব
std_manual = np.sqrt(np.sum((df['cholesterol'] - mean)**2) / (n-1))
print(f"হাতে:   {std_manual:.4f}")  # 109.3841

# Pandas (default ddof=1 → n−1)
std_pd = df['cholesterol'].std()
print(f"Pandas: {std_pd:.4f}")     # 109.3841 ← একই!

# সব statistical summary
df.describe()
# count, mean, std, min, 25%, 50%, 75%, max
💼
ইন্টারভিউ প্রশ্ন — Section 05
প্রশ্ন ০৩ (ML Engineering)
Feature Scaling-এ StandardScaler কীভাবে কাজ করে? Mean ও STD ব্যবহার করে নিজে implement করো এবং কেন scale করা দরকার ব্যাখ্যা করো।
✅ সমাধান দেখো
SOLUTION
# Z-score: z = (x - mean) / std
def standard_scale(s):
    return (s - s.mean()) / s.std()

df['chol_scaled'] = standard_scale(df['cholesterol'])
print(df['chol_scaled'].mean().round(10))  # ≈ 0
print(df['chol_scaled'].std())              # ≈ 1

# কেন? KNN, SVM, Logistic Regression scale-sensitive।
# age range [28–77], cholesterol [0–603] →
# scale না করলে cholesterol বেশি প্রভাব ফেলবে।

from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
scaled = sc.fit_transform(df[['cholesterol']])

Boxplot — পাঁচটা সংখ্যায় পুরো গল্প

একটা boxplot দেখলেই বোঝা যায়: কোথায় কেন্দ্রীভূত, কতটা ছড়ানো, outlier আছে কিনা।

চিত্র: Boxplot সম্পূর্ণ ব্যাখ্যা — Whisker-এর বাইরে = Extreme values
✅
Boxplot পড়ার নিয়ম
১. Box ছোট → ডেটা কেন্দ্রীভূত (uniform)
২. Box বড় → ডেটা বিক্ষিপ্ত (varied)
৩. Median বাম দিকে → right-skewed
৪. Median ডান দিকে → left-skewed
৫. অনেক বিন্দু বাইরে → extreme values বা outliers
PYTHON — Boxplot তৈরি করা
import seaborn as sns

Normal Distribution — ঘণ্টার মতো বক্ররেখা

প্রকৃতির অনেক কিছু Normal Distribution মেনে চলে — মানুষের উচ্চতা, IQ score, measurement error।

🧒
শিশুর মতো বুঝি
একটা স্কুলে ৫০০ বাচ্চার উচ্চতা মাপলে: বেশিরভাগ ১৫০–১৬০ সেমি-র কাছাকাছি। খুব কম ১২০ বা ১৮০+। Plot করলে মাঝে উঁচু, দুই দিকে নিচু — ঠিক ঘণ্টার মতো। এটাই Normal Distribution!
চিত্র: 68-95-99.7 নিয়ম। ±2σ-এর মধ্যে প্রায় সব ডেটা থাকে।
PYTHON — Normal Distribution Simulation
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

# seed দিলে প্রতিবার একই result — reproducibility
np.random.seed(42)

# Standard Normal (μ=0, σ=1)
s100  = np.random.normal(loc=0, scale=1, size=100)
s1000 = np.random.normal(loc=0, scale=1, size=1000)

# বেশি sample → theory-র কাছাকাছি
sns.histplot(s100,  label='n=100',  alpha=0.5)
sns.histplot(s1000, label='n=1000', alpha=0.5)
plt.legend(); plt.show()

# নিজের parameter দিয়ে simulate করো
ech = np.random.normal(loc=12, scale=3, size=100)
# μ=12, σ=3 মানে: গড় ১২, standard deviation ৩

Q-Q Plot — ডেটা Normal কিনা চেক করা

Quantile-Quantile plot দিয়ে বোঝা যায় ডেটা normal distribution মেনে চলে কিনা।

🧒
শিশুর মতো বুঝি
দুই দলের ছাত্রকে উচ্চতা অনুযায়ী সাজালে। একই rank-এর ছাত্রের উচ্চতা তুলনা করো। যদি দুই দল একই distribution মেনে চলে, বিন্দুগুলো 45° সরলরেখায় পড়বে। এটাই Q-Q Plot।
চিত্র: Q-Q plot-এ 45° রেখায় বিন্দু = Normal। বাঁকা বিন্দু = অন্য distribution।
PYTHON — Q-Q Plot
import statsmodels.api as sm
import matplotlib.pyplot as plt

# age: প্রায় normal
sm.qqplot(df['age'], fit=True, line='45')
plt.title('Age Q-Q'); plt.show()

# cholesterol: NOT normal (outlier থাকায়)
sm.qqplot(df['cholesterol'], fit=True, line='45')
plt.title('Cholesterol Q-Q'); plt.show()

# সব column একসাথে
var_num = df.select_dtypes(include=['int', 'float'])
for col in var_num.columns:
    sm.qqplot(df[col], fit=True, line="45")
    plt.title(f'{col}'); plt.show()

# ফলাফল:
# age, heart_rate_max ≈ Normal
# cholesterol, blood_glucose = NOT Normal
💼
ইন্টারভিউ প্রশ্ন — Section 07–08
প্রশ্ন ০৪
কোন ML algorithm-গুলো normality assumption করে? Non-normal ডেটায় কী করবে?
✅ সমাধান দেখো
Normality assume করে: Linear Regression (residuals), LDA, Naive Bayes (Gaussian), t-test, ANOVA.

Non-normal ডেটায়:
• Right-skewed → log() বা sqrt() transform
• Non-parametric methods: Mann-Whitney U, Kruskal-Wallis
• Tree-based models (Random Forest, XGBoost) normality লাগে না
প্রশ্ন ০৫ (Advanced)
cholesterol column-কে log transformation করে normality test করো।
✅ সমাধান দেখো
SOLUTION
from scipy.stats import shapiro

df_c = df[df['cholesterol'] > 0].copy()
df_c['log_chol'] = np.log(df_c['cholesterol'])

stat_raw, p_raw = shapiro(df_c['cholesterol'].sample(500, random_state=42))
stat_log, p_log = shapiro(df_c['log_chol'].sample(500, random_state=42))

print(f"Raw p:  {p_raw:.4f}")  # খুব ছোট → NOT Normal
print(f"Log p:  {p_log:.4f}")  # বড় → more Normal!

# Q-Q আগে ও পরে তুলনা
fig, axes = plt.subplots(1, 2, figsize=(12, 5))
sm.qqplot(df_c['cholesterol'], fit=True, line='45', ax=axes[0])
sm.qqplot(df_c['log_chol'],    fit=True, line='45', ax=axes[1])
axes[0].set_title('আগে'); axes[1].set_title('পরে (log)')
plt.show()
Section 09

Correlation — দুটো variable-এর সম্পর্ক

একটা বাড়লে অন্যটা কি বাড়ে? কমে? কোনো সম্পর্ক নেই?

🧒
শিশুর মতো বুঝি
গরম বাড়লে আইসক্রিম বিক্রি বাড়ে → positive correlation।
গরম বাড়লে গরম কফি বিক্রি কমে → negative correlation।
গরম বাড়লে বই বিক্রি একই থাকে → zero correlation।
Pearson Correlation সূত্র
r(X,Y) = cov(X,Y) / (σ_X × σ_Y)
r সবসময় −1 থেকে +1-এর মধ্যে। |r| > 0.5 = strong | |r| < 0.5 = weak
PYTHON — Correlation Analysis
import numpy as np

# দুটো column-এর correlation

# H0: μ = 45 | H1: μ > 45 (ডেলিভারি সময় বেড়েছে) import numpy as np from scipy.stats import t, ttest_1samp delays = [40,39,46,40,42,46,38,50,43,62, 51,41,52,40,49,55,50,48,40,49] alpha = 0.05 # Test statistic হাতে S_obs = (np.mean(delays)-45) / (np.std(delays,ddof=1)/np.sqrt(len(delays))) print(f"S_obs: {S_obs:.4f}") # 3.3227 # p-value p_val = 1 - t.cdf(x=S_obs, df=len(delays)-1) print(f"p: {p_val:.6f}") # 0.001789 # সিদ্ধান্ত if p_val < alpha: print("✅ H0 বাতিল — ডেলিভারি সময় সত্যিই বেড়েছে!") # Scipy দিয়ে একলাইনে _, p2 = ttest_1samp(delays, popmean=45, alternative='greater') print(f"Scipy p: {p2:.6f}")

ইন্টারভিউ প্রশ্ন — Statistical Tests
Senior ML Engineer Level
প্রশ্ন ০৯
p-value 0.03 মানে কী? p-value 0.06 হলে কী করবে? Type I ও Type II error কী?
✅ সমাধান দেখো
p=0.03: 0.03 < 0.05 → H0 বাতিল। H0 সত্য হলে এই data দেখার সম্ভাবনা মাত্র ৩%। তাই H0 অবিশ্বাস্য।

p=0.06: 0.06 > 0.05 → H0 রাখো। কিন্তু H0 সত্য নিশ্চিত না — শুধু প্রমাণ যথেষ্ট নয়।

Type I Error (α): H0 সত্য কিন্তু আমরা বাতিল করলাম (False Positive)। Probability = α।
Type II Error (β): H1 সত্য কিন্তু H0 রাখলাম (False Negative)। Power = 1 − β।

PYTHON — স্বয়ংক্রিয় Test নির্বাচন
from scipy.stats import pearsonr, chi2_contingency, f_oneway def auto_test(df, col1, col2, alpha=0.05): """দুটো column দিলে সঠিক test বেছে নেয়।""" num = ['int64', 'float64'] n1 = str(df[col1].dtype) in num n2 = str(df[col2].dtype) in num if n1 and n2: stat, p = pearsonr(df[col1].dropna(), df[col2].dropna()) test = "Pearson" elif not n1 and not n2: ct = pd.crosstab(df[col1], df[col2]) stat, p, _, _ = chi2_contingency(ct) test = "Chi-Square" else: cat = col1 if not n1 else col2 num_col = col2 if not n1 else col1 groups = [g[num_col].dropna() for _, g in df.groupby(cat)] stat, p = f_oneway(*groups) test = "ANOVA" res = "✅ সম্পর্ক আছে" if p < alpha else "❌ সম্পর্ক নেই" print(f"{test}: p={p:.4f} → {res}") return p # ব্যবহার: df = pd.read_csv('heart.csv') auto_test(df, 'age', 'heart_rate_max') # Pearson auto_test(df, 'sex', 'heart_rate_max') # ANOVA auto_test(df, 'sex', 'chest_pain') # Chi-Square

PYTHON — Complete EDA Class
from scipy.stats import skew class EDA: def __init__(self, df): self.df = df.copy() self.num = df.select_dtypes(include=['int','float']).columns.tolist() self.cat = df.select_dtypes(include=['object']).columns.tolist() def overview(self): print(f"Shape: {self.df.shape}") missing = self.df.isnull().sum() if missing.any(): print(f"Missing:\n{missing[missing>0]}") else: print("✅ Missing নেই") def numerical_summary(self): s = self.df[self.num].describe().T s['skewness'] = [skew(self.df[c].dropna()) for c in self.num] print(s.round(2)) def outlier_report(self): for col in self.num: Q1, Q3 = self.df[col].quantile([0.25, 0.75]) IQR = Q3 - Q1 n_out = len(self.df[(self.df[col]1.5*IQR) | (self.df[col]>Q3+1.5*IQR)]) print(f" {col}: {n_out} outliers ({n_out/len(self.df)*100:.1f}%)") def run(self): print("="*45+"\n🔬 EDA REPORT\n"+"="*45) self.overview() print("\n📈 Numerical:"); self.numerical_summary() print("\n🔍 Outliers:"); self.outlier_report() for c in self.cat: print(f"\n🏷 {c}:\n{self.df[c].value_counts().head()}") # ব্যবহার: eda = EDA(pd.read_csv('heart.csv')) eda.run()
