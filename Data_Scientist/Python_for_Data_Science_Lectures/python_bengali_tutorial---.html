📦 Variable কী?

Variable হলো একটা নামের বাক্স — যেখানে তুমি যেকোনো তথ্য রাখতে পারো। পরে সেই নাম ব্যবহার করে তথ্যটা আবার বের করতে পারো।

মনে করো তোমার ঘরে অনেক ড্রয়ার আছে। প্রতিটা ড্রয়ারে একটা লেবেল লাগানো আছে — "মোজা", "শার্ট", "বই"। Variable ঠিক এরকমই — নাম দিয়ে তথ্য রাখো।

Variable হলো নামের বাক্স — ভিতরে বিভিন্ন ধরনের তথ্য থাকতে পারে

✍️ Variable কীভাবে বানায়?

Python-এ variable বানানো অনেক সহজ। শুধু নাম লেখো, তারপর = চিহ্ন, তারপর মান।

Python variable তৈরি করা 
# variable তৈরি করা এবং মান দেওয়া
a_variable = 9          # পূর্ণ সংখ্যা (integer)
my_name = "Saikot"    # লেখা (string)
temperature = 36.6   # দশমিক সংখ্যা (float)

# একটা variable-এর মান দিয়ে আরেকটা বানানো
some_other_variable = a_variable + 4   # ফলাফল: 13

# print() দিয়ে দেখানো
print(a_variable)
>>> 9
print(some_other_variable)
>>> 13
⚠️
= মানে "সমান" না, মানে "রাখো"!

Python-এ = মানে তুলনা করা না — মানে হলো "এই মানটা এই নামের বাক্সে রাখো"। যেমন: x = 5 মানে "x-এর বাক্সে 5 রাখো"।

📋 List কী?

List হলো একটা তালিকা — যেখানে একসাথে অনেকগুলো জিনিস রাখা যায়। মনে করো একটা বাজারের তালিকা: [আলু, পেঁয়াজ, টমেটো]।

Python-এ list বানাতে [ ] ব্যবহার করো এবং জিনিসগুলো কমা দিয়ে আলাদা করো।

Python list তৈরি করা 
# একটা সাধারণ list — বিভিন্ন ধরনের জিনিস রাখা যায়
a_list = [2, 3.0, "Hello"]

# ML-এ sensor readings এর list
temperature_readings = [36.1, 36.8, 37.2, 36.5, 38.0]

# Feature names এর list
feature_names = ["age", "heart_rate", "spo2", "temperature"]

🔢 Indexing — তালিকা থেকে একটা জিনিস বের করা

List-এর প্রতিটা জিনিসের একটা নম্বর আছে — সেটাকে বলে index। সবচেয়ে গুরুত্বপূর্ণ কথা: গণনা শুরু হয় 0 থেকে! (1 থেকে না!)

List-এর Index — সবুজ রঙে ধনাত্মক (সামনে থেকে), লাল রঙে ঋণাত্মক (পিছন থেকে)

Python indexing উদাহরণ 
a_list = [4, 3, 1, 2, 5, 10]

# ধনাত্মক index — সামনে থেকে গণনা
print(a_list[0])    # প্রথম উপাদান
>>> 4

print(a_list[2])    # তৃতীয় উপাদান (index 2)
>>> 1

# ঋণাত্মক index — পিছন থেকে গণনা
print(a_list[-1])   # শেষ উপাদান
>>> 10

print(a_list[-2])   # শেষ থেকে দ্বিতীয়
>>> 5

# উপাদান পরিবর্তন করা
a_list[0] = 99      # প্রথম উপাদান বদলে 99
print(a_list)
>>> [99, 3, 1, 2, 5, 10]

✂️ Slicing — তালিকার অংশ বের করা

Slicing দিয়ে list-এর একটা অংশ বের করা যায়। Syntax: list[start:end] — কিন্তু সাবধান: end index-এর উপাদানটা অন্তর্ভুক্ত হয় না!

Slicing: list[1:5] মানে index 1 থেকে 4 পর্যন্ত (5 বাদ)

Python slicing উদাহরণ 
my_list = [1, 5, "Hello", -1.4, "how", 103, "are", "you"]

# প্রথম 4টা উপাদান
first_elements = my_list[0:4]
print(first_elements)
>>> [1, 5, 'Hello', -1.4]

# শুরু থেকে index 4 পর্যন্ত (একই জিনিস)
first_elements = my_list[:4]

# শেষের 3টা উপাদান
last_elements = my_list[-3:]
print(last_elements)
>>> [103, 'are', 'you']

🛠️ List-এর Methods — তালিকা পরিবর্তন করার টুলস

Python-এর list-এ অনেক built-in পদ্ধতি (method) আছে। Method মানে হলো list-এর উপর করা যায় এমন কাজ। সিনট্যাক্স: list.method(argument)

Method কাজ (বাংলায়) উদাহরণ
pop(index) নির্দিষ্ট index-এর উপাদান মুছে দেয় এবং ফেরত দেয় my_list.pop(2)
remove(value) নির্দিষ্ট মানের প্রথম উপাদান মুছে দেয় my_list.remove("Hello")
insert(i, val) নির্দিষ্ট জায়গায় নতুন উপাদান যোগ করে my_list.insert(2, "Hi")
append(value) তালিকার শেষে নতুন উপাদান যোগ করে my_list.append(99)
extend(list2) দুটো তালিকা জোড়া লাগায় list1.extend(list2)
sort() তালিকা সাজায় (ascending বা descending) my_list.sort(reverse=True)
Python list methods উদাহরণ 
scores = [85, 92, 78, 95, 88]

# append — শেষে যোগ করা
scores.append(91)
print(scores)
>>> [85, 92, 78, 95, 88, 91]

# sort — ছোট থেকে বড়
scores.sort()
print(scores)
>>> [78, 85, 88, 91, 92, 95]

# sort — বড় থেকে ছোট
scores.sort(reverse=True)
print(scores)
>>> [95, 92, 91, 88, 85, 78]

# pop — একটা মুছে দেওয়া
removed = scores.pop(0)   # প্রথমটা মুছলাম
print("মুছে গেলো:", removed)
>>> মুছে গেলো: 95

অনুশীলন ৩ — ইন্টারভিউ প্রশ্ন 🎯

ইন্টারভিউতে জিজ্ঞেস করতে পারে: pop() এবং remove()-এর পার্থক্য কী? কখন কোনটা ব্যবহার করবে?

💡 উত্তর দেখো
Python — ব্যাখ্যা 
# pop() — INDEX দিয়ে মুছে, মুছে ফেলা মান RETURN করে
data = [10, 20, 30, 40]
removed_val = data.pop(1)   # index 1 = 20
print(removed_val)  # 20 পাওয়া গেলো
print(data)        # [10, 30, 40]

# remove() — VALUE দিয়ে মুছে, কিছু RETURN করে না
data2 = [10, 20, 30, 20]
data2.remove(20)  # শুধু প্রথম 20 মুছবে
print(data2)      # [10, 30, 20]

# কখন কোনটা?
# pop()    → যখন জানো কোন position-এ আছে
# remove() → যখন জানো কী মান আছে, position না

Tuples — অপরিবর্তনীয় তালিকা
Tuples and Tuple Assignment

🔒 Tuple কী?

Tuple দেখতে list-এর মতোই, কিন্তু একটা বড় পার্থক্য: Tuple-এর উপাদান পরিবর্তন করা যায় না! একবার বানানো হলে সেটা আর বদলানো সম্ভব না।

মনে করো তুমি পাথরে কিছু খোদাই করলে — সেটা আর মুছে বদলানো যাবে না। Tuple ঠিক এরকম।

List বনাম Tuple — পরিবর্তনযোগ্যতার পার্থক্য

Python tuple উদাহরণ 
# Tuple বানানোর উপায়
a_tuple = ("Hello", -1, 133)
b_tuple = "Hello", -1, 133  # এটাও একই কাজ করে

# Indexing (list-এর মতোই)
print(a_tuple[0])   # প্রথম উপাদান
>>> Hello

print(a_tuple[-1])  # শেষ উপাদান
>>> 133

# Tuple Assignment — একসাথে অনেক variable-এ মান দেওয়া!
x, y, z = a_tuple
print(x, y, z)
>>> Hello -1 133

# দুটো variable-এর মান বদলানো (elegant trick!)
a, b = 10, 5
print("আগে:", a, b)
a, b = b, a   # swap!
print("পরে:", a, b)
>>> আগে: 10 5
>>> পরে: 5 10

🔍 Comparison Operators — তুলনা করার চিহ্ন

দুটো জিনিস তুলনা করলে Python True অথবা False দেয়। এগুলোকে বলে Boolean মান।

🚨
= এবং == গুলিয়ে ফেলো না!

= মানে "মান রাখো (assignment)"। == মানে "তুলনা করো (comparison)"। x = 5 মানে x-এ 5 রাখো। x == 5 মানে x কি 5-এর সমান?

চিহ্ন অর্থ উদাহরণ (x=3, y=5) ফলাফল
< ছোট x < y True
<= ছোট বা সমান x <= y True
> বড় x > y False
>= বড় বা সমান x >= y False
== সমান x == y False
!= অসমান x != y True

Linear Search — সরলরেখায় খোঁজা

একটা তালিকায় একটার পর একটা করে দেখা — লক্ষ্যটা পাওয়া গেলে থামা

শিশুকে বোঝানোর মতো: মনে করো তোমার বইয়ের তাকে অনেক বই আছে। তুমি "হ্যারি পটার" খুঁজছো। প্রথম বইটা দেখলে — না এটা না। দ্বিতীয়টা দেখলে — না এটাও না। এভাবে একটার পর একটা দেখতে থাকলে যতক্ষণ না পাওয়া যায়।

Linear Search — একটার পর একটা দেখা

Python Linear Search 
def linear_search(data_list, target):
    """
    একটা list-এ target খোঁজে বের করে।
    পাওয়া গেলে index ফেরত দেয়, না পেলে -1।
    """
    for i in range(len(data_list)):
        if data_list[i] == target:
            return i   # পাওয়া গেছে!
    return -1         # পাওয়া যায়নি

# ML-তে feature খোঁজা
features = ["age", "weight", "spo2", "heart_rate"]
idx = linear_search(features, "spo2")
print(f"'spo2' পাওয়া গেছে index {idx}-এ")
>>> 'spo2' পাওয়া গেছে index 2-এ

Bubble Sort — বুদবুদের মতো সাজানো

পাশাপাশি দুটো তুলনা করো, বড়টাকে ডানে সরাও — বারবার করো

শিশুকে বোঝানোর মতো: মনে করো বাচ্চারা উচ্চতা অনুযায়ী লাইনে দাঁড়াবে। পাশাপাশি দুজনকে তুলনা করো — যে লম্বা সে একটু ডানে সরে যাক। এভাবে বারবার করলে সবচেয়ে লম্বা জন ধীরে ধীরে একদম ডানে চলে যায় — বুদবুদের মতো ভেসে উঠে!

Bubble Sort — বড় সংখ্যা বুদবুদের মতো ডানে ভাসে

Python Bubble Sort 
def bubble_sort(arr):
    """Bubble sort — O(n²) সময় জটিলতা"""
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                # swap — পাশাপাশি দুটো বদলানো
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

# ML — model scores সাজানো
model_scores = [0.85, 0.92, 0.78, 0.95, 0.88]
sorted_scores = bubble_sort(model_scores.copy())
print("সাজানো scores:", sorted_scores)
>>> সাজানো scores: [0.78, 0.85, 0.88, 0.92, 0.95]

Binary Search — অর্ধেক করে খোঁজা

সাজানো তালিকার মাঝখান থেকে শুরু করো — প্রতিবার অর্ধেক বাদ দাও

শিশুকে বোঝানোর মতো: মনে করো একটা অভিধানে "Python" শব্দ খুঁজছো। তুমি কি প্রথম পাতা থেকে শুরু করবে? না! মাঝখান খুলবে — যদি "Python" মাঝখানের চেয়ে পরে আসে, তাহলে সামনের অর্ধেক ফেলে দাও। এভাবে প্রতিবার অর্ধেক বাদ দাও।

Python Binary Search 
def binary_search(sorted_arr, target):
    """
    সাজানো তালিকায় দ্রুত খোঁজা।
    O(log n) — অনেক দ্রুত linear search-এর চেয়ে!
    """
    left, right = 0, len(sorted_arr) - 1

    while left <= right:
        mid = (left + right) // 2   # মাঝখান

        if sorted_arr[mid] == target:
            return mid           # পাওয়া গেছে!
        elif sorted_arr[mid] < target:
            left = mid + 1       # ডান অর্ধে যাও
        else:
            right = mid - 1      # বাম অর্ধে যাও
    return -1                   # পাওয়া যায়নি

# সাজানো threshold values-এ search
thresholds = [0.1, 0.2, 0.3, 0.5, 0.7, 0.9]
result = binary_search(thresholds, 0.5)
print(f"0.5 পাওয়া গেছে index {result}-এ")
>>> 0.5 পাওয়া গেছে index 3-এ

Two Pointer — দুই দিক থেকে এগিয়ে আসা

তালিকার দুই প্রান্ত থেকে মাঝে আসা — ML data processing-এ খুব কাজে লাগে

শিশুকে বোঝানোর মতো: মনে করো দুই বন্ধু একটা লম্বা বইয়ের দুই দিক থেকে পড়া শুরু করলো এবং মাঝখানে মিলিত হলো।

Python Two Pointer — সাজানো list-এ target sum খোঁজা 
def find_pair_with_sum(sorted_arr, target_sum):
    """
    সাজানো তালিকায় দুটো সংখ্যা খোঁজো যাদের যোগফল target।
    ML-এ: outlier pair detection-এ কাজে লাগে।
    """
    left = 0                       # বাম দিক
    right = len(sorted_arr) - 1   # ডান দিক

    while left < right:
        current_sum = sorted_arr[left] + sorted_arr[right]

        if current_sum == target_sum:
            return (sorted_arr[left], sorted_arr[right])
        elif current_sum < target_sum:
            left += 1   # ছোট — বাম pointer ডানে
        else:
            right -= 1  # বড় — ডান pointer বামে
    return None

# Sensor readings-এ pair খোঁজা
readings = [10, 20, 35, 40, 50, 70, 90]
pair = find_pair_with_sum(readings, 90)
print("যোগফল 90 এমন জুটি:", pair)
>>> যোগফল 90 এমন জুটি: (20, 70)

Sliding Window — জানালা সরানো

Time series data-এ moving average বের করা — ML-এ সবচেয়ে বেশি ব্যবহৃত

শিশুকে বোঝানোর মতো: মনে করো একটা জানালা দিয়ে 3টা বাড়ি দেখা যায়। জানালা একটু সরালে নতুন 3টা বাড়ি দেখা যায়। এভাবে জানালা সরিয়ে সরিয়ে পুরো রাস্তা দেখা যায়।

Python Sliding Window — Moving Average (Time Series ML) 
def moving_average(data, window_size):
    """
    Time series data-এর moving average বের করা।
    Health sensor data smoothing-এ খুব কাজে লাগে।
    """
    averages = []

    for i in range(len(data) - window_size + 1):
        # জানালার মধ্যে থাকা সংখ্যাগুলো
        window = data[i:i+window_size]
        avg = sum(window) / window_size
        averages.append(round(avg, 2))

    return averages

# Heart rate sensor data smoothing
heart_rate_raw = [72, 75, 71, 80, 78, 82, 76, 74, 79, 77]
smoothed = moving_average(heart_rate_raw, window_size=3)
print("Raw data:    ", heart_rate_raw)
print("Smoothed:    ", smoothed)

Smoothed:     [72.67, 75.33, 76.33, 80.0, 78.67, 77.33, 76.33, 76.67]

Min/Max Finding — সর্বোচ্চ ও সর্বনিম্ন খোঁজা

Data normalization-এ অপরিহার্য — ML preprocessing-এর মূল ধাপ

শিশুকে বোঝানোর মতো: মনে করো তোমার ক্লাসের সব বাচ্চার উচ্চতা মাপা হলো। এখন সবচেয়ে ছোট এবং সবচেয়ে লম্বা কে — এটাই খুঁজে বের করো।

Python Min-Max Normalization (ML Preprocessing) 
def find_min_max(data):
    """তালিকা থেকে সর্বনিম্ন ও সর্বোচ্চ বের করা"""
    minimum = data[0]
    maximum = data[0]

    for value in data:
        if value < minimum:
            minimum = value
        if value > maximum:
            maximum = value

    return minimum, maximum


def min_max_normalize(data):
    """
    Min-Max Normalization: সব মান 0 থেকে 1-এর মধ্যে আনা।
    Formula: (x - min) / (max - min)
    ML model training-এর আগে এটা করতে হয়!
    """
    min_val, max_val = find_min_max(data)
    range_val = max_val - min_val

    normalized = []
    for x in data:
        norm_val = (x - min_val) / range_val
        normalized.append(round(norm_val, 3))

    return normalized

# Sensor temperature data normalize করা
temperatures = [36.1, 37.5, 38.0, 36.8, 39.0, 36.5]
normalized_temps = min_max_normalize(temperatures)

print("আসল তাপমাত্রা:", temperatures)
print("Normalized    :", normalized_temps)
print("(সব মান 0-1 এর মধ্যে)")

⏱️ Algorithm Complexity — কোনটা কত দ্রুত?

Big O notation দিয়ে বোঝা যায় algorithm কত দ্রুত কাজ করে। n = ডেটার পরিমাণ।

Algorithm সময় জটিলতা সহজ ভাষায় ML ব্যবহার
Linear Search O(n) ডেটা দ্বিগুণ → সময় দ্বিগুণ Feature lookup
Binary Search O(log n) ডেটা দ্বিগুণ → সময় সামান্য বাড়ে Sorted data search
Bubble Sort O(n²) ডেটা দ্বিগুণ → সময় চারগুণ শুধু শেখার জন্য
Sliding Window O(n) ডেটা দ্বিগুণ → সময় দ্বিগুণ Time series preprocessing
Min/Max Find O(n) একবার পুরো তালিকা দেখতে হয় Normalization
