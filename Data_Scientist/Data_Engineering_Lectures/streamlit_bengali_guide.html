Interview Q&A অধ্যায় ১ — Streamlit Basics
সহজ
Q1. Streamlit কী এবং Data Science-এ কেন ব্যবহার করা হয়?

✅ উত্তর: Streamlit হলো একটি Python library যা Machine Learning ও Data Science প্রোজেক্টকে interactive web application এ রূপান্তরিত করে। এটি HTML/CSS/JavaScript না জেনেও শুধু Python দিয়ে professional web app বানানোর সুবিধা দেয়। Data Scientist রা তাদের model-এর result এবং visualization সহজে stakeholder দের দেখাতে এটি ব্যবহার করে।

💡 Interview tip: "rapid prototyping" এবং "model deployment" শব্দদুটি উল্লেখ করো।
মাঝারি
Q2. Streamlit এবং Flask/Django এর মধ্যে পার্থক্য কী?

✅ উত্তর: Flask/Django হলো General-purpose web frameworks যেগুলোতে HTML template, routing, database management সব manually করতে হয়। Streamlit শুধুমাত্র Data Science এর জন্য designed — এখানে শুধু Python লিখলেই UI automatically তৈরি হয়। Streamlit দিয়ে development অনেক দ্রুত, কিন্তু customization কম।

কঠিন (ML Engineer)
Q3. Production environment-এ Streamlit এর limitations কী কী?

✅ উত্তর: (১) Statelessness — প্রতিটি user interaction-এ পুরো script re-run হয়, যা heavy computation এর ক্ষেত্রে slow। (২) Multi-user scalability সীমিত। (৩) Complex UI customization কঠিন। (৪) Session state management manually করতে হয়। Production-এ st.cache_data() ও st.session_state ব্যবহার করে এই সমস্যাগুলো আংশিকভাবে সমাধান করা যায়।

Interview Q&A অধ্যায় ২ — Installation & Setup
সহজ
Q1. streamlit run app.py এবং python app.py এর মধ্যে পার্থক্য কী?

✅ উত্তর: python app.py দিলে script terminal-এ run হয়, কিন্তু কোনো web interface তৈরি হয় না। streamlit run app.py দিলে Streamlit তার নিজস্ব web server চালু করে এবং browser-এ automatically একটি interactive web page open করে। Streamlit script-কে একটি web app-এ রূপান্তরিত করে।

ML Engineering
Q2. Production deployment-এর জন্য requirements.txt কেন দরকার? কীভাবে বানাবে?

✅ উত্তর: requirements.txt-এ সব dependencies (libraries ও তাদের version) লেখা থাকে। অন্য কেউ বা server-এ deploy করার সময় pip install -r requirements.txt দিলে same environment তৈরি হয়। বানাতে: pip freeze > requirements.txt

📁 প্রথমে App Structure সেটআপ

Python · streamlit_app.py — Structure Setup
import streamlit as st
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# ── Data Load করো ──
df = pd.read_csv("train.csv")

# ── Sidebar Navigation ──
st.sidebar.title("📋 Table of Contents")
pages = ["Exploration", "DataVisualization", "Modelling"]
page = st.sidebar.radio("Go to", pages)

# ── Page 1: Exploration ──
if page == pages[0]:
    st.write("### 📊 Presentation of Data")
    
    # প্রথম ১০ টা row দেখাও
    st.dataframe(df.head(10))
    
    # Shape দেখাও (rows × columns)
    st.write(f"Dataset এর আকার: {df.shape[0]} rows × {df.shape[1]} columns")
    
    # Statistical summary
    st.dataframe(df.describe())
    
    # Missing values দেখানোর option
    if st.checkbox("Missing Values দেখাও"):
        st.dataframe(df.isna().sum().to_frame("Missing Count"))

if page == pages[2]:

    # ── Step 1: Irrelevant columns drop করো ──
    df = df.drop(["PassengerId", "Name", "Ticket", "Cabin"], axis=1)

    # ── Step 2: Target ও Features আলাদা করো ──
    y = df["Survived"]           # এটা predict করতে চাই
    X_cat = df[["Pclass", "Sex", "Embarked"]]   # Categorical

    # ── Step 3: Missing values fill করো ──
    for col in X_cat.columns:
        X_cat[col] = X_cat[col].fillna(X_cat[col].mode()[0])  # mode দিয়ে
    for col in X_num.columns:
        X_num[col] = X_num[col].fillna(X_num[col].median())  # median দিয়ে

    # ── Step 4: Categorical encode করো (One-Hot Encoding) ──
    X_cat_scaled = pd.get_dummies(X_cat, columns=X_cat.columns)
    X = pd.concat([X_cat_scaled, X_num], axis=1)

    # ── Step 5: Train/Test Split ──
    from sklearn.model_selection import train_test_split
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=0.2, random_state=123
    )

    # ── Step 6: Scaling ──
    from sklearn.preprocessing import StandardScaler
    scaler = StandardScaler()
    X_train[X_num.columns] = scaler.fit_transform(X_train[X_num.columns])
    X_test[X_num.columns] = scaler.transform(X_test[X_num.columns])

    # ── Step 7: Model Prediction Function ──
    from sklearn.ensemble import RandomForestClassifier
    from sklearn.svm import SVC
    from sklearn.linear_model import LogisticRegression
    from sklearn.metrics import confusion_matrix

    def prediction(classifier):
        if classifier == "Random Forest":
            clf = RandomForestClassifier()
        elif classifier == "SVC":
            clf = SVC()
        elif classifier == "Logistic Regression":
            clf = LogisticRegression()
        clf.fit(X_train, y_train)
        return clf

    def scores(clf, choice):
        if choice == "Accuracy":
            return clf.score(X_test, y_test)
        elif choice == "Confusion matrix":
            return confusion_matrix(y_test, clf.predict(X_test))

    # ── Step 8: Interactive Model Selection ──
    choice = ["Random Forest", "SVC", "Logistic Regression"]

    elif display == "Confusion matrix":
        st.dataframe(scores(clf, display))

Q1. fit_transform() এবং transform() এর মধ্যে পার্থক্য কী?

✅ উত্তর: fit_transform() প্রথমে training data থেকে statistics (mean, std) শেখে এবং তারপর transform করে। transform() শুধু আগে শেখা statistics ব্যবহার করে transform করে। Test data-এ কখনো fit_transform() দেবে না — এতে data leakage হয়। Test data সবসময় training data-এর mean/std দিয়ে scale করতে হবে।

Senior ML Engineer
Q2. Confusion Matrix এর চারটা cell কী কী মানে? F1 Score কখন Accuracy-র চেয়ে ভালো metric?

✅ উত্তর: Imbalanced dataset (যেমন: fraud detection যেখানে 99% normal, 1% fraud) এ Accuracy misleading হয়। একটা model সবসময় "normal" predict করলেও 99% accuracy পাবে! সেক্ষেত্রে F1 Score = 2×(Precision×Recall)/(Precision+Recall) ব্যবহার করো।

Good Practices — Cache Memory

🤔 সমস্যাটা বোঝো

Streamlit-এ যখনই user কোনো widget-এ click করে, পুরো Python script আবার থেকে শুরু হয়! যদি তোমার data loading বা model training ৫ মিনিট লাগে, তাহলে প্রতিটা click এ ৫ মিনিট অপেক্ষা? এই সমস্যার সমাধান হলো Cache।

Python · @st.cache_data ব্যবহার
import streamlit as st
import pandas as pd

# @st.cache_data decorator মানে: এই function-এর result memory-তে রাখো
# একই argument দিলে আবার run না করে memory থেকে দাও
@st.cache_data
def load_data(path):
    df = pd.read_csv(path)
    return df

@st.cache_data
def preprocess(df):
    # এই কাজ অনেক সময় লাগতে পারে
    df = df.dropna()
    return df

# এখন যতবার user কিছু করুক — data আবার load হবে না!
df = load_data("train.csv")
df_clean = preprocess(df)

# ── Cache এর আরো ব্যবহার — Model ──
@st.cache_resource  # ML model এর জন্য cache_resource ব্যবহার করো
def train_model(X_train, y_train):
    from sklearn.ensemble import RandomForestClassifier
    clf = RandomForestClassifier(n_estimators=100)
    clf.fit(X_train, y_train)
    return clf

# ── cache_data vs cache_resource ──
# cache_data: data (DataFrame, arrays) এর জন্য — serialize করা হয়
# cache_resource: ML models, DB connections এর জন্য — shared object
Interview + Coding অধ্যায় ৮ — Cache & Performance
Senior ML Engineer
Q1. @st.cache_data এবং @st.cache_resource এর মধ্যে কখন কোনটা ব্যবহার করবে?

✅ উত্তর: cache_data: data objects এর জন্য (DataFrame, lists, dicts)। Streamlit এটা pickle করে serialize করে, তাই প্রতিটা session নিজের copy পায়। cache_resource: shared resources এর জন্য (ML models, database connections, API clients)। সব sessions একই object share করে। Large model এর ক্ষেত্রে cache_resource memory efficient।

ML Engineering
Q2. Cache কখন invalidate হয়? কীভাবে manually clear করবে?

✅ উত্তর: Cache invalidate হয়: (১) Function এর code পরিবর্তন হলে (২) Function arguments পরিবর্তন হলে (৩) st.cache_data.clear() call করলে। ttl parameter দিয়ে time-based expiry set করা যায়: @st.cache_data(ttl=3600) মানে ১ ঘণ্টা পর cache expire।

Deep Learning Interview অধ্যায় ১১ — Word2Vec & NLP
Senior ML Engineer
Q1. Word2Vec CBOW এবং Skip-gram এর মধ্যে পার্থক্য কী? কখন কোনটা ব্যবহার করবে?

✅ উত্তর: CBOW (Continuous Bag of Words): context words → target word predict করে। দ্রুত, frequent words-এ ভালো। Skip-gram: একটা word → আশেপাশের context words predict করে। ধীর কিন্তু rare words-এ ভালো, large dataset-এ বেশি effective। Small dataset → CBOW। Large dataset → Skip-gram।

Advanced
Q2. Cosine Similarity কী? Word embeddings-এ কেন এটা ব্যবহার করা হয়?

✅ উত্তর: Cosine Similarity = dot(v1,v2) / (||v1|| × ||v2||)। এটা দুটো vector-এর মধ্যকার angle measure করে, magnitude নয়। Word embeddings-এ Euclidean distance-এর চেয়ে Cosine similarity ভালো কারণ words-এর semantic relationship direction-based (angle) হয়, size-based নয়। মান -1 থেকে 1 এর মধ্যে হয়, 1 মানে identical, 0 মানে unrelated।

Python — Complete ML Pipeline
import pandas as pd
import numpy as np
import joblib
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
import xgboost as xgb
from sklearn.metrics import f1_score
from sklearn.model_selection import cross_val_score

# 1. Load & Preprocess
df = pd.read_csv("data.csv")
X, y = df.drop("target", axis=1), df["target"]

# 2. Multiple Model Comparison
models = {
    "Logistic Regression": Pipeline([
        ("scaler", StandardScaler()),
        ("clf", LogisticRegression())
    ]),
    "Random Forest": RandomForestClassifier(random_state=42),
    "XGBoost": xgb.XGBClassifier(random_state=42)
}

results = {}
for name, model in models.items():
    scores = cross_val_score(model, X, y, cv=5, scoring="f1")
    results[name] = {"mean": scores.mean(), "std": scores.std()}
    print(f"{name}: {scores.mean():.3f} ± {scores.std():.3f}")

# 3. Best Model Save
best_name = max(results, key=lambda x: results[x]["mean"])
best_model = models[best_name]
best_model.fit(X, y)
joblib.dump(best_model, "best_model.joblib")
print(f"Best model: {best_name} saved!")
