১.১ OLTP — Online Transaction Processing

OLTP কী? ধরো তুমি bKash থেকে টাকা পাঠালে। তোমার ফোনে কয়েক সেকেন্ডের মধ্যেই কনফার্মেশন আসে। এই পুরো প্রক্রিয়াটাই OLTP। খুব দ্রুত, ছোট ছোট transaction handle করা।

Transaction মানে কী? শুধু টাকার লেনদেন নয়! যেকোনো সিস্টেমের মধ্যে যোগাযোগকে transaction বলে। তুমি ফেসবুকে like দিলে — সেটাও transaction। Netflix-এ video চালালে — সেটাও transaction।

# OLTP data — raw transactions
data = {
    'transaction_id': [1,2,3,4,5,6],
    'store_id':       [1,1,2,2,1,3],
    'product_id':     [1,1,1,2,1,2],
    'amount':         [132,12,65,34,66,90],
    'status':         ['Approved']*4 + ['Pending']*2
}
transactions = pd.DataFrame(data)

# তোমার কাজ: OLAP তৈরি করো
# ১. শুধু 'Approved' transactions নাও
# ২. store_id দিয়ে group করো
# ৩. total amount, transaction count, max amount বের করো

# সমাধান:
olap_result = (transactions
    .query("status == 'Approved'")
    .groupby('store_id')
    .agg(
        total_sales=('amount', 'sum'),
        transaction_count=('transaction_id', 'count'),
        max_sale=('amount', 'max')
    )
    .reset_index()
    .sort_values('total_sales', ascending=False)
)
print(olap_result)

import pandas as pd

def client_kpi_view(transactions_df, products_df, clients_df):
    """
    SQL VIEW-এর Python equivalent।
    প্রতিবার call করলে fresh ডেটা পাবে।
    ML feature store-এ এভাবেই features compute হয়।
    """
    # Step 1: Join করো (relational model অনুযায়ী)
    full = (transactions_df
        .merge(clients_df, on='ClientID')
        .merge(products_df, on='ProductID')
    )

    # Step 2: Transaction amount calculate করো
    full['amount'] = (
        full['ProductQuantity'] * full['ProductUnitPrice']
        * (100 - full['ProductDiscount']) / 100
    )

    # Step 3: Client-level aggregation (OLAP mesh = ClientID)
    kpis = full.groupby('ClientID').agg(
        transaction_count=('TransactionID', 'count'),
        max_transaction=('amount', 'max'),
        total_spend=('amount', 'sum')
    ).reset_index()

    # Step 4: Derived feature (useful for ML)
    kpis['avg_transaction'] = kpis['total_spend'] / kpis['transaction_count']

    return kpis

# ব্যবহার: যতবার call করো, fresh aggregated data পাও

Data Integrity — ডেটার অখণ্ডতা

কেন এত গুরুত্বপূর্ণ? যদি ডেটার integrity নষ্ট হয়, company ভুল data দেখে ভুল business decision নেবে। এটা কোটি টাকার ক্ষতি করতে পারে। ML model-এ garbage in, garbage out!

Python দিয়ে Data Integrity চেক

import pandas as pd
import requests

# ── ১. TYPE CHECK (Field Integrity) ──────────────────────────
def is_proper_type(record):
    """Field Integrity: correct type check"""
    if not isinstance(record['ClientID'], int):
        return False
    if not isinstance(record['ClientState'], str):
        return False
    return True

# ── ২. FULL VALIDATION (সব integrity একসাথে) ─────────────────
VALID_STATES = ['AZ', 'CO', 'KY', 'CA', 'GA', 'FL', 'MD']

def is_valid_record(record):
    """
    Entity + Field + Referential integrity চেক।
    ML pipeline-এ data ingestion-এর সময় এটা চালাও।
    """
    # Type check (Field Integrity)
    if not is_proper_type(record):
        return False

    # Missing value check (Field Integrity)
    for value in record.values():
        if value is None:
            return False

    # Referential check — valid state code
    if record['ClientState'] not in VALID_STATES:
        return False

    # Range check (Field Integrity)
    if not (1000 <= record['ClientZipCode'] <= 100000):
        return False

    # Date range check
    reg_date = pd.to_datetime(record['ClientRegister'])
    if not (pd.to_datetime("2022-01-01") <= reg_date <= pd.to_datetime("2022-12-31")):
        return False

    return True

# ── ৩. EXTRACT VALID/INVALID (ETL-র Extract step) ────────────
def extract_data(data: list) -> tuple:
    """
    Returns: (valid_df, invalid_df)
    ML use: valid_df → model training, invalid_df → data quality report
    """
    valid, invalid = [], []
    for record in data:
        (valid if is_valid_record(record) else invalid).append(record)

    return pd.DataFrame(valid), pd.DataFrame(invalid)

Normal Forms — ডেটাবেজ সাজানোর নিয়ম

Database Normalization মানে database-কে ধাপে ধাপে "পরিষ্কার ও সুশৃঙ্খল" করা। প্রতিটি ধাপকে Normal Form বলে।

কেন normalize করবো? Data redundancy (একই তথ্য বারবার) কমাতে, integrity নিশ্চিত করতে, এবং future-proof করতে।
📌 First Normal Form (1NF) — প্রথম স্তর

নিয়ম: প্রতিটি field-এ atomic value থাকতে হবে। মানে কোনো list, dictionary বা array field-এ থাকবে না।

❌ 0NF (ভুল) — Non-atomic

Date | Client | Product
05/12 | {"fn":"Pierre","city":"Paris"} | {"name":"Pencil"}
06/12 | {"fn":"Antoine","city":"Nantes"} | {"name":"Flower"}

Client ও Product field-এ dictionary — atomic নয়!

✅ 1NF (সঠিক) — Atomic values

Date | ClientFirst | ClientLast | City | Product
05/12 | Pierre | Adeikalam | Paris | Pencil
06/12 | Antoine | Tardivon | Nantes | Flower

সব field-এ single atomic value। No duplicate rows।

Composite/Super Key: এখন {Date, ClientFirst, ClientLast} মিলে একটি record identify করে। এটাকে composite primary key বলে — ভালো নয়, তবে technically 1NF।
📌 Second Normal Form (2NF) — দ্বিতীয় স্তর

নিয়ম: 1NF + কোনো non-key field কোনো subset of key-এর উপর নির্ভর করতে পারবে না।

সহজ সমাধান: একটি unique SaleID primary key যোগ করো।

# 2NF তৈরি করো — unique ID add করো
import pandas as pd

df = pd.DataFrame({
    'Date': ['05/12', '06/12'],
    'ClientFirst': ['Pierre', 'Antoine'],
    'ClientLast': ['Adeikalam', 'Tardivon'],
    'ClientCity': ['Paris', 'Nantes'],
    'ProductName': ['Pencil', 'Flower']

df.insert(0, 'SaleID', df.index + 1)
# এখন SaleID একাই সব কিছু identify করে → 2NF
📌 Third Normal Form (3NF) — তৃতীয় স্তর (সবচেয়ে সাধারণ)

নিয়ম: 2NF + কোনো non-key field অন্য non-key field-এর উপর নির্ভর করতে পারবে না।

সমস্যা: ClientCity আসলে ClientFirst+ClientLast-এর উপর নির্ভরশীল (একজন client-এর একটাই city)। তাই client তথ্য আলাদা table-এ নিয়ে যাও।

# Raw data (0NF)
raw = pd.DataFrame({

# ── 1NF: Atomic values extract করো ──────────────────────────
import json

def parse_athlete(s):
    d = json.loads(s)
    return pd.Series([d['fn'], d['ln'], d['nat']])

def parse_event(s):
    d = json.loads(s)
    return pd.Series([d['season'], d['year'], d['city']])

df = raw.copy()
df[['FirstName', 'LastName', 'Nationality']] = df['Athlete'].apply(parse_athlete)
df[['Season', 'Year', 'City']] = df['Event'].apply(parse_event)
df = df.drop(['Athlete', 'Event'], axis=1)
# এখন 1NF — সব atomic

# ── 2NF: Unique ID যোগ করো ─────────────────────────────────
df.insert(0, 'ID', range(1, len(df)+1))
# এখন 2NF — ID দিয়ে সব identify হয়

# ── 3NF: আলাদা table তৈরি করো ─────────────────────────────
athletes_table = df[['FirstName', 'LastName', 'Nationality']].copy()
athletes_table.insert(0, 'AthleteID', range(1, len(athletes_table)+1))

events_table.insert(0, 'EventID', range(1, len(events_table)+1))

Star Schema ও Snowflake Schema

❄️ Snowflake Schema

3NF database-এর নাম। অনেক ছোট table, তাদের মধ্যে complex interdependency। আকারে snowflake-এর মতো দেখায়।

  • Data redundancy প্রায় শূন্য
  • Integrity সর্বোচ্চ
  • Query জটিল — অনেক join লাগে
  • Slow query performance

⭐ Star Schema

Snowflake-এর simplified version। একটি central FACT table, তার চারপাশে DIMENSION tables সরাসরি সংযুক্ত।

  • সহজ বোঝা ও query করা
  • Fewer joins — faster query
  • Business team ব্যবহার করতে পারে
  • কিছু data redundancy থাকতে পারে

OLAP Cube — সর্বোচ্চ পারফরম্যান্স

OLAP Cube কী? ডেটাকে multi-dimensional cube হিসেবে দেখো। Brand × Region × Time = তিন axis। প্রতিটি cell-এ pre-aggregated sales value। Query-র সময় calculate করতে হয় না — আগেই done! এটাই তাকে lightning fast করে।
OLAP Cube-এর সমস্যা: জটিল ETL pipeline দরকার। বড় ডেটায় cube তৈরি করতে অনেক সময় লাগে। এজন্য Data Engineering team বড় হতে হয়।

ETL Pipeline — Extract, Transform, Load

ETL কী? ETL = Extract (বের করা) + Transform (রূপান্তর) + Load (লোড করা)। Raw data-কে Data Warehouse-এ পরিষ্কার, structured format-এ নেওয়ার পুরো প্রক্রিয়া।

import pandas as pd
import logging
from typing import Tuple, Optional

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger('ETL')

# E — EXTRACT: Data Lake থেকে ডেটা বের করা
# ══════════════════════════════════════════════════════
def extract_from_api(url: str) -> list:
    """
    JSON API থেকে data extract করো।
    ML pipeline-এ feature store থেকে data নেওয়ার মতো।
    """
    logger.info(ff"Extracting from: {url}")
    response = requests.get(url)
    response.raise_for_status()
    data = response.json()
    logger.info(ff"Extracted {len(data)} records")
    return data

def extract_csv(url: str) -> pd.DataFrame:
    """CSV থেকে extract"""
    df = pd.read_csv(url)
    logger.info(ff"CSV loaded: {df.shape}")
    return df

def extract_filtered(data: list, filter_col: str, filter_val: str) -> pd.DataFrame:
    """নির্দিষ্ট শর্তে filter করে extract"""
    filtered = [r for r in data if r.get(filter_col) == filter_val]
    return pd.DataFrame(filtered)

# ══════════════════════════════════════════════════════
# T — TRANSFORM: Data রূপান্তর করা
# ══════════════════════════════════════════════════════
def transform_join(clients_df, transactions_df, products_df) -> pd.DataFrame:
    """Multiple sources join করো"""
    joined = (clients_df
        .merge(transactions_df, on='ClientID')
        .merge(products_df, on='ProductID')
    )
    # Business logic: total amount calculate
    joined['TotalAmount'] = (
        joined['ProductQuantity'] *
        joined['ProductUnitPrice'] *
        (100 - joined.get('ProductDiscount', pd.Series(0))) / 100
    )
    return joined

def transform_clean(df: pd.DataFrame) -> Tuple[pd.DataFrame, dict]:
    """
    Duplicate ও missing values handle করো।
    Returns: (clean_df, quality_report)
    """
    report = {}

    # Duplicate check
    dup_count = df.duplicated().sum()
    report['duplicates_removed'] = dup_count
    df = df.drop_duplicates()

    # Missing value report
    null_counts = df.isna().sum()
    report['null_counts'] = null_counts[null_counts > 0].to_dict()

    # Drop rows with critical nulls
    critical_cols = ['ClientID', 'ProductID']
    critical_cols = [c for c in critical_cols if c in df.columns]
    df = df.dropna(subset=critical_cols)

    logger.info(ff"Clean: removed {dup_count} dups. Shape: {df.shape}")
    return df, report

# ══════════════════════════════════════════════════════
# L — LOAD: Data Warehouse-এ load করা
# ══════════════════════════════════════════════════════
def load_to_warehouse(df: pd.DataFrame, table_name: str, output_path: str = ""):
    """
    Data Warehouse-এ load করো।
    Real scenario-তে এখানে SQLAlchemy/BigQuery/Snowflake হবে।
    """
    # Star schema: fact ও dimension আলাদা করো
    if 'ProductID' in df.columns:
        dim_products = df[[c for c in df.columns
                           if c.startswith('Product')]].drop_duplicates()
        logger.info(ff"DIM Product: {dim_products.shape}")

    # Save as parquet (production-grade format)
    if output_path:
        df.to_parquet(ff"{output_path}/{table_name}.parquet", index=False)

    logger.info(ff"Loaded {table_name}: {df.shape}")
    return df

# ══════════════════════════════════════════════════════
# MAIN PIPELINE: সব একসাথে
# ══════════════════════════════════════════════════════
def run_etl_pipeline(config: dict):
    """
    Production ETL Pipeline।
    ML pipeline-এ feature generation-এর exact equivalent।

    logger.info("=== ETL PIPELINE শুরু ===")

    # E: Extract
    transactions = extract_csv(config['transactions_url'])
    products = extract_csv(config['products_url'])

    # T: Transform
    merged = transform_join(

    result = load_to_warehouse(clean_data, 'fact_orders')

Hash Join Algorithm

Database JOIN অপারেশনের সবচেয়ে দ্রুত উপায়
শিশুর ভাষায়: কল্পনা করো তোমার কাছে দুটো বাক্স আছে — একটায় বন্ধুদের নাম-নম্বর কার্ড, অন্যটায় পুরস্কারের নাম-নম্বর কার্ড। প্রথমে নাম-নম্বর কার্ডগুলো একটা dictionary-তে রেখে দাও (hash করো)। তারপর পুরস্কারের প্রতিটি card নিয়ে dictionary-তে দেখো — পাওয়া গেলে match!
Time Complexity: O(n + m)  |  Naive Nested Loop: O(n × m)
def hash_join(left: list, right: list, key: str) -> list:
    """
    Hash Join Implementation।
    SQL-এর INNER JOIN-এর efficient version।
    pandas merge() এটাই internally করে।
    """
    # Phase 1: Build — left table-কে hash map-এ রাখো
    hash_table = {}
    for row in left:
        k = row[key]
        if k not in hash_table:
            hash_table[k] = []
        hash_table[k].append(row)  # O(1) insertion

    # Phase 2: Probe — right table-এর প্রতিটি row match করো
    result = []
    for row in right:
        k = row[key]
        if k in hash_table:  # O(1) lookup!
            for left_row in hash_table[k]:
                merged = {**left_row, **row}
                result.append(merged)

    return result

# ML Example: Feature join
users = [{'user_id': 1, 'age': 25}, {'user_id': 2, 'age': 30}]
events = [{'user_id': 1, 'action': 'buy'}, {'user_id': 2, 'action': 'view'}]
result = hash_join(users, events, 'user_id')
print(result)  # [{user_id:1, age:25, action:'buy'}, ...]

Hash Aggregation (GROUP BY)

OLAP-এর মূল অ্যালগরিদম
শিশুর ভাষায়: তোমার class-এ অনেক বন্ধু আছে। তাদের শহর অনুযায়ী ভাগ করতে হবে এবং প্রতি শহরে কতজন তা গুনতে হবে। প্রথমে একটা খাতায় প্রতিটি শহরের নাম লিখে পাশে count রাখো। প্রতিটি বন্ধুর নাম পড়ে তার শহরের পাশে ১ যোগ করো। শেষে খাতায় দেখো!
GROUP BY key → aggregate function (SUM, COUNT, MAX, AVG)
from collections import defaultdict

def hash_group_by(data: list, group_key: str, agg_col: str, agg_func: str) -> list:
    """
    SQL GROUP BY-এর Python implementation।
    pandas groupby() এটাই করে।
    """
    # Hash map: key → accumulated values
    groups = defaultdict(list)
    for row in data:
        groups[row[group_key]].append(row[agg_col])

    # Aggregate
    funcs = {
        'sum': sum,
        'count': len,
        'max': max,
        'avg': lambda x: sum(x) / len(x) if x else 0
    }

    result = []
    for key, values in groups.items():
        result.append({
            group_key: key,
            ff"{agg_func}_{agg_col}": funcs[agg_func](values)
        })
    return result

Sort-Merge Join

Large sorted datasets-এর জন্য efficient join
শিশুর ভাষায়: দুটো সাজানো (sorted) বইয়ের তালিকা মেলাতে হবে। দুই তালিকার শুরু থেকে একটা একটা করে দেখো। যেটা ছোট সেটা এগিয়ে নাও। যখন দুটো মিলে, সেটা result-এ রাখো। দুটো তালিকা sorted থাকায় একবারেই কাজ হয়ে যায়!
Time: O(n log n) for sorting + O(n + m) for merging
def sort_merge_join(left: list, right: list, key: str) -> list:
    """
    Sort-Merge Join।
    Data warehouse-এ large tables join-এ ব্যবহার হয়।
    """
    # Phase 1: Sort (O(n log n))
    left_sorted = sorted(left, key=lambda x: x[key])
    right_sorted = sorted(right, key=lambda x: x[key])

    # Phase 2: Merge (O(n + m))
    result = []
    i, j = 0, 0
    while i < len(left_sorted) and j < len(right_sorted):
        lk = left_sorted[i][key]
        rk = right_sorted[j][key]

        if lk == rk:
            result.append({**left_sorted[i], **right_sorted[j]})
            j += 1  # one-to-many handle
        elif lk < rk:
            i += 1
        else:
            j += 1

    return result

Deduplication Algorithm

Duplicate records সরানো — Entity Integrity-র জন্য
শিশুর ভাষায়: তোমার কাছে একটা গান-তালিকা আছে, কিছু গান দুইবার আছে। একটা ব্যাগ নাও। প্রতিটি গান দেখো — ব্যাগে আগে থেকে আছে কিনা। থাকলে বাদ দাও, না থাকলে ব্যাগে রাখো। 
def deduplicate(data: list, key_cols: list, keep: str = 'first') -> list:
    """
    Deduplication — Entity Integrity maintain করে।
    ML context: training data-তে same sample থাকলে model overfit করে।
    """
    seen = set()
    result = []

    iterable = data if keep == 'first' else reversed(data)

    for row in iterable:
        # Composite key তৈরি করো
        composite_key = tuple(row.get(k) for k in key_cols)

        if composite_key not in seen:
            seen.add(composite_key)
            result.append(row)

    if keep == 'last':
        result.reverse()

    print(ff"Removed {len(data) - len(result)} duplicates")
    return result

Window / Rolling Aggregation

Time-series feature engineering-এ অপরিহার্য
শিশুর ভাষায়: প্রতিদিনের বৃষ্টির পরিমাণ মাপতে থাকো। "গত ৭ দিনের মোট বৃষ্টি কত?" জানতে একটা স্লাইডিং উইন্ডো দিয়ে দেখো — উইন্ডোটা প্রতিদিন এক ধাপ এগিয়ে যায়। 
import pandas as pd
import numpy as np

def create_window_features(df: pd.DataFrame,
                             value_col: str,
                             group_col: str,
                             windows: list = [7, 30]) -> pd.DataFrame:
    """
    Rolling window features তৈরি করো।
    ML: Time-series forecasting, fraud detection-এ critical।
    """
    df = df.sort_values([group_col, 'date'])

    for w in windows:
        grp = df.groupby(group_col)[value_col]
        # Rolling mean (trend)
        df[ff'rolling_mean_{w}d'] = grp.transform(
            lambda x: x.rolling(w, min_periods=1).mean()
        )
        # Rolling sum (total)
        df[ff'rolling_sum_{w}d'] = grp.transform(
            lambda x: x.rolling(w, min_periods=1).sum()
        )
        # Rolling std (volatility — useful for fraud detection)
        df[ff'rolling_std_{w}d'] = grp.transform(
            lambda x: x.rolling(w, min_periods=1).std().fillna(0)
        )

    return df

Bloom Filter — দ্রুত Referential Integrity Check

Large FK validation-এ memory-efficient approach
শিশুর ভাষায়: তোমার school-এ ৫০,০০০ ছাত্রের ID আছে। কোনো নতুন ID valid কিনা দেখতে পুরো list check করা ধীর। Bloom Filter হল একটা ছোট "ম্যাজিক পর্দা" — প্রায় নিশ্চিতভাবে বলতে পারে "এটা নেই" কিন্তু "আছে" বলতে গেলে ছোট chance-এ ভুল হতে পারে। 
import hashlib

class SimpleBloomFilter:
    """
    Probabilistic data structure।
    False positive possible, false negative impossible।
    ETL: লাখো FK check করতে হলে এটা use করো।
    Memory: O(m) যেখানে m << n
    """
    def __init__(self, size: int = 1000):
        self.size = size
        self.bit_array = [False] * size
        self.hash_count = 3

    def _hashes(self, item) -> list:
        item_str = str(item).encode()
        hashes = []
        for i in range(self.hash_count):
            h = hashlib.md5(item_str + str(i).encode()).hexdigest()
            hashes.append(int(h, 16) % self.size)
        return hashes

    def add(self, item):
        for h in self._hashes(item):
            self.bit_array[h] = True

    def might_contain(self, item) -> bool:
        """False → নিশ্চিতভাবে নেই। True → সম্ভবত আছে।"""
        return all(self.bit_array[h] for h in self._hashes(item))

    bf.add(cid)

test_ids = [1, 999, 200, 456]

    exists = bf.might_contain(tid)
    print(ff"ID {tid}: {'possibly valid' if exists else 'definitely invalid'}")

import pandas as pd
import numpy as np

def build_customer_features(users_path, transactions_path, products_path):
    """
    Complete ML feature engineering pipeline।
    Joins 3 tables (Star Schema query) → customer-level features।
    """
    # E: Extract
    users = pd.read_csv(users_path)
    txns = pd.read_csv(transactions_path)
    prods = pd.read_csv(products_path)

    # T: Transform — join (relational model)
    full = txns.merge(prods, on='product_id')

    # Calculate transaction amount
    full['amount'] = full['quantity'] * full['unit_price']

    # Aggregate to customer level (OLAP mesh = customer)
    features = full.groupby('user_id').agg(
        total_spend     =('amount', 'sum'),
        avg_basket      =('amount', 'mean'),
        purchase_count  =('transaction_id', 'count'),
        unique_products =('product_id', 'nunique'),
        fav_category    =('category', lambda x: x.mode()[0])
    ).reset_index()

    # Derived features
    features['product_diversity'] = (
        features['unique_products'] / features['purchase_count']
    )

    # L: Load — join back with user demographics
    final = users.merge(features, on='user_id', how='left')

    # Handle users with no purchases
    final['purchase_count'] = final['purchase_count'].fillna(0)
    final['total_spend'] = final['total_spend'].fillna(0)

    return final

def model_health_check(current_features, reference_features):
    issues = []
    for col in current_features.select_dtypes('number'):
        curr_mean = current_features[col].mean()
        ref_mean = reference_features[col].mean()
        drift = abs(curr_mean - ref_mean) / (abs(ref_mean) + 1e-9)

# Pattern 2: Duplicate ও null handle
def transform_clean_data(df: pd.DataFrame,
                          pk_col: str,
                          critical_cols: list) -> pd.DataFrame:
    """
    Data cleaning।
    ML: training data-তে dirty data থাকলে model ভুল শেখে।
    """
    original_size = len(df)

    # Entity Integrity: duplicate rows সরাও
    df = df.drop_duplicates(subset=[pk_col])
    dup_removed = original_size - len(df)

    # Field Integrity: critical columns-এ null সরাও
    df = df.dropna(subset=critical_cols)
    null_removed = original_size - dup_removed - len(df)

    # Non-critical nulls: fill করো
    df = df.fillna({
        col: df[col].median() if df[col].dtype in ['float64', 'int64']
             else 'Unknown'
        for col in df.columns
        if col not in critical_cols
    })

    print(ff"Cleaned: -{dup_removed} dups, -{null_removed} nulls. Remaining: {len(df):,}")
    return df

# Pattern 3: Type casting ও encoding (ML-ready)
def transform_ml_ready(df: pd.DataFrame,
                         cat_cols: list,
                         num_cols: list) -> pd.DataFrame:
    """
    Categorical encoding + Numerical scaling।
    ML model সংখ্যা বোঝে, string বোঝে না।
    """
    df = df.copy()

    # Categorical → numeric (Label Encoding)
    le = LabelEncoder()
    for col in cat_cols:
        if col in df.columns:
            df[ff"{col}_encoded"] = le.fit_transform(df[col].astype(str))

    # Numerical → scaled (StandardScaler)
    scaler = StandardScaler()
    existing_num = [c for c in num_cols if c in df.columns]
    if existing_num:
        df[[ff"{c}_scaled" for c in existing_num]] = scaler.fit_transform(df[existing_num])

    return df

import pandas as pd

# ══ LOAD PATTERNS ══════════════════════════════════════════════

# Pattern 1: Star Schema অনুযায়ী আলাদা করো
def load_star_schema(full_df: pd.DataFrame,
                      transactions_cols: list,
                      products_cols: list,
                      clients_cols: list) -> dict:
    """
    Full joined DataFrame থেকে Star Schema tables আলাদা করো।
    প্রতিটি table Data Warehouse-এ আলাদা আলাদা যাবে।
    """
    # Fact table (transactions)
    fact_table = (full_df[transactions_cols]
                  .drop_duplicates(subset=['TransactionID'])
                  .sort_values('TransactionID'))

    # Dimension tables
    dim_products = (full_df[products_cols]
                    .drop_duplicates(subset=['ProductID'])
                    .sort_values('ProductID'))

    dim_clients = (full_df[clients_cols]
                   .drop_duplicates(subset=['ClientID'])
                   .sort_values('ClientID'))

    print(ff"Fact(transactions): {fact_table.shape}")
    print(ff"Dim(products): {dim_products.shape}")
    print(ff"Dim(clients): {dim_clients.shape}")

    return {
        'fact_transactions': fact_table,
        'dim_products': dim_products,
        'dim_clients': dim_clients
    }

# Pattern 2: File formats (production-grade)
def load_to_files(tables: dict, output_dir: str = './warehouse'):

    ML context: daily model retraining-এ নতুন ডেটা append।
    """
    existing_pks = set(existing_df[pk_col])
    truly_new = new_df[~new_df[pk_col].isin(existing_pks)]
    combined = pd.concat([existing_df, truly_new], ignore_index=True)

    print(ff"Incremental load: +{len(truly_new)} new records. Total: {len(combined):,}")
    return combined

def transform_churn_features(raw: dict, config: ETLConfig) -> pd.DataFrame:
    logger = logging.getLogger('ETL.Transform')
    users, events = raw['users'], raw['events']
    ref_date = events['event_date'].max()

    # Step 1: Data integrity checks
    assert events['event_id'].nunique() == len(events), "Duplicate event_id!"
    orphan_mask = ~events['user_id'].isin(users['user_id'])
    if orphan_mask.sum() > 0:
        logger.warning(ff"Dropping {orphan_mask.sum()} orphan events")
        events = events[~orphan_mask]

    # Step 2: Feature engineering (OLAP aggregation)
    lookback = events[events['event_date'] >= ref_date - pd.Timedelta(days=config.lookback_days)]

    user_features = lookback.groupby('user_id').agg(
        total_events        =('event_id',   'count'),
        purchase_count      =('event_type', lambda x: (x=='purchase').sum()),
        total_spend         =('amount',     'sum'),
        avg_spend           =('amount',     'mean'),
        last_event_date     =('event_date', 'max'),
        first_event_date    =('event_date', 'min'),
    ).reset_index()

    # Step 3: Derived features
    user_features['days_since_last_event'] = (
        ref_date - user_features['last_event_date']
    ).dt.days
    user_features['activity_span_days'] = (
        user_features['last_event_date'] - user_features['first_event_date']
    ).dt.days + 1
    user_features['purchase_rate'] = (
        user_features['purchase_count'] / user_features['total_events'].clip(lower=1)
    )

    # Step 4: Label তৈরি করো (churn = ১৪ দিন কোনো event নেই)
    user_features['is_churned'] = (
        user_features['days_since_last_event'] > config.churn_threshold_days
    ).astype(int)

    # Step 5: Dimension join (Star Schema — users dimension)
    ml_dataset = users.merge(user_features, on='user_id', how='left')

    # Step 6: Clean users with no events
    ml_dataset = ml_dataset[
        ml_dataset['total_events'] >= config.min_events_required
    ].copy()

    logger.info(ff"Features ready: {ml_dataset.shape}. Churn rate: {ml_dataset['is_churned'].mean():.1%}")
    return ml_dataset

B-Tree Index — Database Query দ্রুত করার রহস্য

SQL database-এ সব index এই structure ব্যবহার করে
শিশুর ভাষায়: তোমার কাছে একটা বিশাল dictionary আছে (লাখো শব্দ)। "Python" শব্দ খুঁজতে কি প্রথম পাতা থেকে শুরু করবে? না! তুমি সরাসরি "P" section-এ যাও। B-Tree ঠিক এভাবে কাজ করে — একটা sorted tree structure যেখানে প্রতিটি node থেকে binary search করা যায়।
Time: O(log n) per lookup  |  Without index: O(n) full table scan
# Python-এ B-Tree-র মতো behavior: sorted dict / SortedList
from bisect import bisect_left

class SimpleIndex:
    """
    B-Tree index-এর simplified Python simulation।
    SQL: CREATE INDEX idx_customer ON orders(customer_id)
    """
    def __init__(self):
        self.keys = []     # sorted keys
        self.values = {}   # key → row reference

    def insert(self, key, row_ref):
        if key not in self.values:
            # Sorted insert: O(log n) find + O(n) insert
            pos = bisect_left(self.keys, key)
            self.keys.insert(pos, key)
        self.values[key] = row_ref

    def lookup(self, key):
        """O(log n) binary search lookup"""
        pos = bisect_left(self.keys, key)
        if pos < len(self.keys) and self.keys[pos] == key:
            return self.values[key]
        return None

    def range_scan(self, lo, hi):
        """Range query: WHERE id BETWEEN lo AND hi"""
        lo_pos = bisect_left(self.keys, lo)
        hi_pos = bisect_left(self.keys, hi + 1)
        return [self.values[self.keys[i]] for i in range(lo_pos, hi_pos)]

# Usage: Primary Key index তৈরি
idx = SimpleIndex()
for i, row in enumerate([{'id':10,'name':'Alice'},{'id':50,'name':'Bob'},{'id':25, 'name': 'Carol'}]):
    idx.insert(row['id'], row)

print(idx.lookup(50))         # O(log n) — {'id': 50, 'name': 'Bob'}
print(idx.range_scan(10, 50)) # WHERE id BETWEEN 10 AND 50

শিশুর ভাষায়: তোমার কাছে অনেক রঙের বল আছে। সেগুলোকে ৩টি ঝুড়িতে ভাগ করতে হবে যাতে কাছাকাছি রঙের বল একই ঝুড়িতে যায়। প্রথমে এলোমেলো ৩টি জায়গায় ঝুড়ি রাখো। প্রতিটি বল সবচেয়ে কাছের ঝুড়িতে দাও। তারপর ঝুড়িকে তার সব বলের মাঝখানে সরাও। আবার repeat করো — যতক্ষণ না ঝুড়ি আর সরে!

import numpy as np
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

def customer_segmentation_pipeline(fact_table: pd.DataFrame,
                                     n_segments: int = 4) -> pd.DataFrame:
    """
    OLAP + K-Means: Customer segmentation।
    Data Integration context: analytical database → ML clustering।
    এটাই RFM (Recency, Frequency, Monetary) analysis।
    """
    # Step 1: OLAP aggregation (ETL Transform step)
    rfm = fact_table.groupby('customer_id').agg(
        recency    =('order_date', lambda x: (pd.Timestamp.now() - x.max()).days),
        frequency  =('order_id', 'count'),
        monetary   =('amount', 'sum')
    ).reset_index()

    # Step 2: Feature scaling (Field Integrity — same scale)
    scaler = StandardScaler()
    rfm_scaled = scaler.fit_transform(rfm[['recency', 'frequency', 'monetary']])

    # Step 3: K-Means clustering
    kmeans = KMeans(n_clusters=n_segments, random_state=42, n_init=10)
    rfm['segment'] = kmeans.fit_predict(rfm_scaled)

    # Step 4: Segment labeling (business-friendly)
    seg_stats = rfm.groupby('segment')[['recency','frequency','monetary']].mean()
    seg_stats['label'] = ''
    # High frequency + High monetary + Low recency = Champions
    best_seg = seg_stats.sort_values(['monetary', 'frequency'], ascending=False).index
    labels = ['Champions', 'Loyal', 'At Risk', 'Lost'][:n_segments]
    label_map = dict(zip(best_seg[:n_segments], labels))
    rfm['segment_label'] = rfm['segment'].map(label_map)

    print(rfm.groupby('segment_label').agg(
        count=('customer_id', 'count'),
        avg_spend=('monetary', 'mean')
    ))
    return rfm

External Merge Sort — বিশাল CSV Sort করা

RAM-এর চেয়ে বড় file sort করার technique
শিশুর ভাষায়: তোমার কাছে এত বেশি কার্ড আছে যে একসাথে ধরা যায় না। প্রথমে ছোট ছোট ভাগে ভাগ করে প্রতিটি ভাগ sort করো। তারপর দুইটা sorted ভাগ মিলিয়ে বড় sorted ভাগ তৈরি করো। আবার দুইটা বড় sorted ভাগ মিলিয়ে আরও বড়। শেষে সবকিছু sorted!
Time: O(n log n)  |  Space: O(chunk_size) — RAM-independent!
import heapq
import pandas as pd
import os

def external_sort_large_csv(input_path: str,
                               sort_col: str,
                               chunk_size: int = 100_000) -> pd.DataFrame:
    """
    External Merge Sort।
    ১ GB+ CSV file sort করার জন্য।
    ETL pipeline-এ Sort-Merge Join-এর আগে ব্যবহার হয়।
    """
    # Phase 1: Chunk করে read ও sort করো, temp files-এ লেখো
    temp_files = []
    for i, chunk in enumerate(pd.read_csv(input_path, chunksize=chunk_size)):
        sorted_chunk = chunk.sort_values(sort_col)
        temp_path = ff"/tmp/sort_chunk_{i}.parquet"
        sorted_chunk.to_parquet(temp_path, index=False)
        temp_files.append(temp_path)
        print(ff"Sorted chunk {i+1} ({len(sorted_chunk):,} rows)")

    # Phase 2: k-way merge (heap দিয়ে)
    # pandas implementation:
    all_chunks = [pd.read_parquet(f) for f in temp_files]
    result = pd.concat(all_chunks).sort_values(sort_col).reset_index(drop=True)

    # Cleanup temp files
    for f in temp_files:
        if os.path.exists(f): os.remove(f)

    print(ff"✅ Sorted {len(result):,} total rows by '{sort_col}'")
    return result
