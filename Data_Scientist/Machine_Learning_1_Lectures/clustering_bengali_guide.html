চিত্র ১: Supervised vs Unsupervised Learning-এর পার্থক্য
🍎 বাস্তব জীবনের উদাহরণ দিয়ে বুঝি

Supervised (শিক্ষক আছে): তোমার মা তোমাকে ছোটবেলায় বললেন "এটা আপেল, ওটা কমলা।" তুমি শিখলে। পরে নতুন ফল দেখলে বলতে পারলে কোনটা কী। এখানে শিক্ষক (label) আছে।

Unsupervised (নিজেই শেখো): এক বাক্স ফল দেওয়া হলো, কেউ বললো না কোনটা কী। তুমি নিজেই দেখলে — "এগুলো লাল, গোল → এক দল। ওগুলো হলুদ, লম্বা → আরেক দল।" কেউ শেখায়নি — তুমি নিজেই pattern বের করলে। এটাই Clustering!

সবচেয়ে জনপ্রিয় Clustering পদ্ধতি

K-Means কী? — একদম সহজ ভাষায়

🎯 একটা মজার উদাহরণ

মনে করো তোমার ক্লাসে ৩০ জন ছাত্র আছে। তোমাকে বলা হলো তাদের ৩টি দলে ভাগ করো। কীভাবে করবে?

১. প্রথমে ৩ জনকে দলনেতা (centroid) বেছে নাও — যেকোনো ৩ জন

২. বাকি প্রত্যেকে যে দলনেতার কাছে আছে, সেই দলে যাক

৩. এখন প্রতিটি দলের "মাঝখানের মানুষ" (গড় অবস্থান) নতুন দলনেতা হোক

৪. আবার সবাই নতুন দলনেতার কাছে যাক

৫. যতক্ষণ দলনেতা পরিবর্তন না হয়, ততক্ষণ চলো

এটাই K-Means! K = কতগুলো দল চাই।

চিত্র ৩: K-Means এর ধাপ-বধাপ কাজ করার পদ্ধতি

K-Means Algorithm — ধাপে ধাপে

  • ১
    K টি Centroid এলোমেলোভাবে বেছে নাও
    K মানে কতটি দল চাই। K=4 মানে 4টি দলে ভাগ করবো। প্রথমে 4টি random point বেছে নেওয়া হয় centroid হিসেবে।
  • ২
    প্রতিটি Data Point-কে নিকটতম Centroid-এ Assign করো
    প্রতিটি point এবং প্রতিটি centroid-এর মধ্যে distance হিসাব করো। যে centroid সবচেয়ে কাছে, সেই দলে যাও।
  • ৩
    নতুন Centroid হিসাব করো
    প্রতিটি দলের সব point-এর গড় (mean) হিসাব করো। এই গড় অবস্থানই নতুন centroid।
  • ৪
    Convergence পর্যন্ত পুনরাবৃত্তি করো
    ধাপ ২ ও ৩ আবার করো। যখন centroid আর নড়বে না (পরিবর্তন হবে না), তখন থামো। এটাই convergence।

Elbow Method — কতটি Cluster দরকার?

K-Means-এর সবচেয়ে বড় সমস্যা: K কত হবে জানি না। Elbow Method এই সমস্যার সমাধান করে।

⚡ Distortion / Inertia কী?

প্রতিটি point তার centroid থেকে কতটা দূরে — এই দূরত্বের যোগফলকে বলা হয় distortion। Cluster যত ভালো, distortion তত কম।

distortion = Σ distance(xᵢ, cᵢ) / n
যেখানে xᵢ = প্রতিটি data point, cᵢ = তার centroid, n = মোট points
চিত্র ৪: Elbow Method — বাঁকের জায়গায় optimal K পাওয়া যায়
💡 Elbow কীভাবে চেনা যায়?

Distortion vs K এর graph আঁকো। যেখানে curve "কনুইয়ের মতো" বাঁক নেয় — তার আগে খাড়া নামে, পরে ধীরে নামে — সেই K-ই optimal। Ruspini dataset-এ K=4 এ এই বাঁক দেখা যায়।

Python ধাপ ৩: Elbow Method দিয়ে Optimal K খোঁজা 
from scipy.spatial.distance import cdist

range_n_clusters = [2, 3, 4, 5, 6]
distortions = []

for n_clusters in range_n_clusters:
    # প্রতিটি K-এর জন্য KMeans train করা
    cluster = KMeans(n_clusters=n_clusters, random_state=42)
    cluster.fit(df)
    
    # Distortion হিসাব: প্রতিটি point থেকে নিকটতম centroid-এর দূরত্বের গড়
    dist = np.min(cdist(df, cluster.cluster_centers_, 'euclidean'), axis=1)
    distortions.append(np.sum(dist) / np.size(df, axis=0))

# Elbow curve plot
plt.plot(range_n_clusters, distortions, 'gx-')
plt.xlabel('Number of Clusters K')
plt.ylabel('Distortion')
plt.title('Elbow Method')
plt.show()

১ K-Means কেন "non-deterministic"? এটি কোন সমস্যা তৈরি করে এবং কীভাবে সমাধান করা যায়?
ML interview-এ প্রায়ই জিজ্ঞেস করা হয়।
উত্তর
K-Means শুরুতে centroid এলোমেলোভাবে বেছে নেয়। ভিন্ন random initialization → ভিন্ন final cluster। সমস্যা: প্রতিবার run করলে ভিন্ন result পাওয়া যায়। সমাধান: (১) random_state=42 দিলে reproducible result পাওয়া যায়, (২) sklearn-এর KMeans-এ n_init=10 parameter দিলে ১০ বার চালিয়ে সেরাটা রাখে, (৩) KMeans++ initialization ব্যবহার করা।
২ K-Means-এর সীমাবদ্ধতাগুলো কী কী?
উত্তর
১. K আগে থেকে জানতে হয়। ২. Spherical/circular cluster-ই ভালো detect করে — irregular shape-এ কাজ করে না। ৩. Outlier-এর প্রতি sensitive। ৪. Feature scaling না করলে ভুল result। ৫. বড় dataset-এ ধীর।
৩ 🏭 ML Project Task: Customer Segmentation করো
একটি e-commerce company-তে customer-দের RFM (Recency, Frequency, Monetary) feature দিয়ে segment করো। নিচের code complete করো:
Solution Code
Python Customer Segmentation — Real ML Project 
import pandas as pd
import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

# ── ১. Sample Data তৈরি ──
np.random.seed(42)
n = 500
data = {
    'recency': np.random.exponential(30, n),    # শেষ কেনার কতদিন আগে
    'frequency': np.random.poisson(10, n),       # কতবার কিনেছে
    'monetary': np.random.lognormal(6, 1, n)    # মোট কত টাকা খরচ করেছে
}
df = pd.DataFrame(data)

# ── ২. Feature Scaling (অবশ্যই করতে হবে!) ──
# KMeans distance-based, তাই সব feature same scale-এ আনা দরকার
scaler = StandardScaler()
df_scaled = scaler.fit_transform(df)

# ── ৩. Optimal K খোঁজা ──
inertias = []
sil_scores = []
k_range = range(2, 9)

for k in k_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(df_scaled)
    inertias.append(km.inertia_)
    sil_scores.append(silhouette_score(df_scaled, km.labels_))

# ── ৪. Final Model ──
optimal_k = 4  # Elbow + Silhouette দেখে ঠিক করা
final_model = KMeans(n_clusters=optimal_k, random_state=42, n_init=10)
df['segment'] = final_model.fit_predict(df_scaled)

# ── ৫. Segment Analysis ──
segment_profile = df.groupby('segment').agg({
    'recency': 'mean',
    'frequency': 'mean',
    'monetary': 'mean',
    'segment': 'count'
}).rename(columns={'segment': 'count'})

# Segment naming (business interpretation)
segment_names = {0: "Champions 🏆", 1: "At-Risk ⚠️",
                 2: "Potential 🌱", 3: "Lost 😢"}
df['segment_name'] = df['segment'].map(segment_names)

print(segment_profile)
print(f"\nSilhouette Score: {silhouette_score(df_scaled, df['segment']):.3f}")
৪ Inertia এবং Distortion-এর মধ্যে পার্থক্য কী?
উত্তর
Inertia = প্রতিটি point থেকে তার centroid-এর squared distance-এর sum (sklearn এটি দেয়)। Distortion = average distance (normalize করা, squared নয়)। Elbow method উভয় দিয়েই করা যায়, কিন্তু sklearn-এ inertia_ attribute সরাসরি পাওয়া যায়।

HCA কী? — গাছের উপমা দিয়ে বুঝি

🌳 পারিবারিক গাছের মতো

মনে করো একটি পরিবারের গাছ আঁকছো। নিচে সবাই আলাদা। তারপর ধীরে ধীরে ভাই-বোন একসাথে হয়, তারপর চাচাতো ভাই, তারপর পুরো পরিবার।

HCA-ও এভাবে কাজ করে: সব data point আলাদা। তারপর দুটো সবচেয়ে কাছের data মিলিয়ে একটি cluster। তারপর সেই cluster আর কাছের কারো সাথে মিলে বড় cluster। এভাবে একটিমাত্র বড় cluster না হওয়া পর্যন্ত চলে।

এই process-এর diagram-কে বলা হয় Dendrogram বা Hierarchical Tree।

Distance Metrics — দুই Cluster-এর মধ্যে দূরত্ব কীভাবে মাপা হয়?

Method বাংলায় মানে কীভাবে হিসাব হয় কখন ব্যবহার করবে
Single Linkage সর্বনিম্ন দূরত্ব দুই cluster-এর সবচেয়ে কাছের দুটি point-এর দূরত্ব লম্বা, সরু cluster-এর জন্য
Complete Linkage সর্বোচ্চ দূরত্ব দুই cluster-এর সবচেয়ে দূরের দুটি point-এর দূরত্ব গোলাকার, compact cluster-এর জন্য
Average Linkage গড় দূরত্ব দুই cluster-এর সব point জোড়ার গড় দূরত্ব সাধারণত সবচেয়ে robust

চিত্র ৬: বিভিন্ন Linkage পদ্ধতি — হলুদ দাগ দিয়ে distance দেখানো হয়েছে

Silhouette Score — Clustering কতটা ভালো?

📐 Silhouette Score বোঝা

প্রতিটি data point-এর জন্য হিসাব হয়:

s(i) = (b(i) − a(i)) / max(a(i), b(i))
  • a(i) = ওই point থেকে তার নিজের cluster-এর অন্য সব point-এর গড় দূরত্ব (intra-cluster distance)
  • b(i) = ওই point থেকে পরের nearest cluster-এর গড় দূরত্ব (inter-cluster distance)
  • s(i) range: -1 থেকে +1। +1 মানে perfect, 0 মানে border-এ, -1 মানে ভুল cluster-এ আছে
চিত্র ৭: Silhouette Score — নিজের cluster কাছে, পরের cluster দূরে থাকলে score ভালো

Mean Shift কী? — বলের উপমা দিয়ে বুঝি

⚽ একটি বল ছেড়ে দেওয়ার মতো

মনে করো একটি ঘরে অনেক মানুষ আছে কিন্তু কিছু জায়গায় বেশি, কিছু জায়গায় কম। তুমি একটি বল রাখলে — বলটি ধীরে ধীরে যেদিকে বেশি মানুষ, সেদিকে সরে যাবে (ঘনত্বের দিকে)। এই সরে যাওয়াই Mean Shift।

Algorithm একটি window (বৃত্ত) নেয়। সেই বৃত্তের মধ্যে সব point-এর গড় (mean) হিসাব করে। তারপর সেই গড় অবস্থানে shift করে। এটা করতে থাকে যতক্ষণ না বৃত্ত আর নড়ে।

সুবিধা: K আগে থেকে দিতে হয় না — algorithm নিজেই K বের করে!

চিত্র ৮: Mean Shift — Window ঘন জায়গায় shift করে centroid খোঁজে

Bandwidth — Mean Shift-এর সবচেয়ে গুরুত্বপূর্ণ Parameter

⚡ Bandwidth কী?

Bandwidth হলো Window-র আকার (radius)। এটাই ঠিক করে কতগুলো cluster পাওয়া যাবে।

  • বড় bandwidth: বড় window → কম cluster (বেশি দূরের point একসাথে)
  • ছোট bandwidth: ছোট window → বেশি cluster (শুধু কাছের point একসাথে)

estimate_bandwidth(X, quantile=0.1) — sklearn নিজেই data দেখে ভালো bandwidth suggest করে!

চিত্র ৯: Bandwidth ছোট হলে বেশি cluster, বড় হলে কম cluster

Image Compression — Mean Shift-এর অসাধারণ ব্যবহার

🖼️ Image Compression কীভাবে কাজ করে?

একটি ১২৮×১২৮ pixel RGB image-এ মোট ১৬,৩৮৪ টি pixel। প্রতিটি pixel = 3টি সংখ্যা (R, G, B)। মোট ১৬,৩৮৪×৩ = ৪৯,১৫২ টি সংখ্যা।

Mean Shift এই ৪৯,১৫২ সংখ্যাকে K টি রঙে কমিয়ে দেয়। প্রতিটি pixel-কে তার কাছের centroid রঙ দিয়ে replace করা হয়। ফলে image-এ K টি রঙ হয় → file size ছোট হয়।

চিত্র ১০: Mean Shift Image Compression — হাজার রঙকে K টি রঙে কমানো

Python Implementation

Python Mean Shift Image Compression 
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import MeanShift, estimate_bandwidth

# ── ১. Image Load করা ──
img = plt.imread("bird_small.png")
print(f"Image shape: {img.shape}")  # (128, 128, 3)

# ── ২. 3D → 2D reshape ──
# 128×128 pixels, প্রতিটিতে 3 color values (RGB)
# (128, 128, 3) → (16384, 3)
X = img.reshape(img.shape[0] * img.shape[1], img.shape[2])
print(f"Reshaped: {X.shape}")  # (16384, 3)

# ── ৩. Bandwidth Estimate ──
# quantile=0.1 মানে KNN-এর ১০% neighbors দেখে bandwidth ঠিক করবে
# n_samples=300 মানে calculation দ্রুত করতে ৩০০টি sample নেবে
bandwidth = estimate_bandwidth(X, quantile=0.1, n_samples=300)
print(f"Estimated bandwidth: {bandwidth:.3f}")

# ── ৪. Mean Shift ──
ms = MeanShift(bandwidth=bandwidth)
ms.fit(X)

centroids = ms.cluster_centers_  # K টি centroid রঙ
labels = ms.labels_               # প্রতিটি pixel কোন cluster-এ
print(f"Number of clusters found: {len(centroids)}")

# ── ৫. Image Compress করা ──
# প্রতিটি pixel-কে তার cluster-এর centroid রঙ দিয়ে replace
X_recovered = np.zeros(X.shape)
for i in range(len(X)):
    X_recovered[i] = centroids[labels[i]]

# ── ৬. Reshape back to image ──
X_recovered = X_recovered.reshape(img.shape[0], img.shape[1], img.shape[2])

# ── ৭. Original vs Compressed দেখা ──
fig, axes = plt.subplots(1, 2, figsize=(12, 5))
axes[0].imshow(img);  axes[0].set_title('Original Image')
axes[1].imshow(X_recovered); axes[1].set_title('Compressed Image')
plt.show()

# ── ৮. Compression Ratio ──
import imageio, os
imageio.imwrite('recovered.png', (X_recovered * 255).astype(np.uint8))
ratio = os.stat('recovered.png').st_size / os.stat('bird_small.png').st_size
print(f"Compression ratio: {ratio:.2%}")  # 100% এর কম মানে compress হয়েছে

Python Medical Image Segmentation — Real ML Project 
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import MeanShift, estimate_bandwidth
from sklearn.preprocessing import MinMaxScaler

def segment_medical_image(image_path, quantile=0.08, n_samples=500):
    """
    Medical image-কে segment করে।
    image_path: image file path
    quantile: ছোট হলে বেশি segment (বেশি detail)
    n_samples: bandwidth calculation-এ কতটি sample ব্যবহার
    """
    # ── Image Load ──
    img = plt.imread(image_path)
    
    # Float হলে 0-255 scale করা
    if img.max() <= 1.0:
        img_255 = (img * 255).astype(np.uint8)
    else:
        img_255 = img.copy()
    
    # ── Reshape ──
    h, w = img.shape[:2]
    X = img_255[:, :, :3].reshape(-1, 3).astype(float)
    
    # ── Normalization ──
    X_norm = X / 255.0
    
    # ── Bandwidth Estimate ──
    bandwidth = estimate_bandwidth(X_norm, quantile=quantile, 
                                     n_samples=n_samples)
    print(f"Bandwidth: {bandwidth:.4f}")
    
    # ── Mean Shift ──
    ms = MeanShift(bandwidth=bandwidth, bin_seeding=True)
    # bin_seeding=True → faster computation
    ms.fit(X_norm)
    
    n_clusters = len(ms.cluster_centers_)
    print(f"Segments found: {n_clusters}")
    
    # ── Reconstruct Segmented Image ──
    labels = ms.labels_
    segmented = ms.cluster_centers_[labels].reshape(h, w, 3)
    
    # ── Visualization ──
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    axes[0].imshow(img[:, :, :3]); axes[0].set_title('Original')
    axes[1].imshow(segmented); axes[1].set_title(f'Segmented ({n_clusters} regions)')
    
    # Label map
    label_map = labels.reshape(h, w)
    axes[2].imshow(label_map, cmap='tab20')
    axes[2].set_title('Segment Map')
    plt.tight_layout()
    plt.show()
    
    return segmented, label_map, n_clusters

Metric কী মাপে Range ভালো মানে Algorithm
Inertia Intra-cluster distance sum (squared) 0 → ∞ যত কম তত ভালো K-Means
Silhouette Score Intra vs Inter cluster তুলনা -1 → +1 +1 সবচেয়ে ভালো সব algorithm
Distortion Average distance to centroid 0 → ∞ Elbow খোঁজতে K-Means
Davies-Bouldin Cluster separation quality 0 → ∞ যত কম তত ভালো সব algorithm
Python Complete Evaluation Pipeline 
from sklearn.metrics import silhouette_score, davies_bouldin_score
from sklearn.cluster import KMeans, AgglomerativeClustering
import numpy as np

def evaluate_clustering(X, labels, algorithm_name="Algorithm"):
    """সব metric একসাথে calculate করা"""
    results = {}
    
    # Silhouette Score (-1 থেকে +1, বেশি হলে ভালো)
    results['silhouette'] = silhouette_score(X, labels)
    
    # Davies-Bouldin Score (কম হলে ভালো)
    results['davies_bouldin'] = davies_bouldin_score(X, labels)
    
    # Number of clusters
    results['n_clusters'] = len(np.unique(labels))
    
    print(f"\n{'='*40}")
    print(f"  {algorithm_name} Evaluation")
    print(f"{'='*40}")
    print(f"  Clusters found:     {results['n_clusters']}")
    print(f"  Silhouette Score:   {results['silhouette']:.4f}")
    print(f"  Davies-Bouldin:     {results['davies_bouldin']:.4f}")
    
    # Interpretation
    sil = results['silhouette']
    if sil > 0.7: print("  মূল্যায়ন: 🟢 চমৎকার clustering")
    elif sil > 0.5: print("  মূল্যায়ন: 🟡 মোটামুটি ভালো")
    elif sil > 0.25: print("  মূল্যায়ন: 🟠 দুর্বল structure")
    else: print("  মূল্যায়ন: 🔴 কোনো cluster structure নেই")
    
    return results

সব Algorithm — Interview Questions
১ Clustering কি একটি deterministic process?
উত্তর
নির্ভর করে algorithm-এর উপর। HCA এবং Mean Shift deterministic (একই data-তে সবসময় একই result)। K-Means non-deterministic কারণ random initialization — তবে random_state fix করলে reproducible হয়।
২ Feature scaling কেন করতে হয় Clustering-এ?
উত্তর
Clustering distance-based। যদি একটি feature 0-100 (বয়স) এবং আরেকটি 0-100,000 (বেতন) হয়, তাহলে বেতনই distance dominate করবে। StandardScaler বা MinMaxScaler দিয়ে সব feature একই scale-এ আনলে সবাই সমান importance পায়।
৩ একটি dataset-এ Clustering করার পর কীভাবে business value তৈরি করবে?
উত্তর
১. প্রতিটি cluster-এর mean/median দেখো → profile বুঝতে। ২. Human-readable নাম দাও (Champions, At-Risk, etc.)। ৩. প্রতিটি cluster-এর জন্য আলাদা strategy: Champions → loyalty program, At-Risk → winback campaign। ৪. Cluster label নতুন data-তে predict করতে supervised model train করো।
৪ DBSCAN vs Mean Shift — কী পার্থক্য?
উত্তর
উভয়ই density-based এবং K দরকার নেই। পার্থক্য: DBSCAN outlier-কে "noise" হিসেবে mark করে (cluster-এ রাখে না), Mean Shift সব point-কে কোনো না কোনো cluster-এ দেয়। DBSCAN-এ ২টি parameter (eps, min_samples), Mean Shift-এ ১টি (bandwidth)। DBSCAN large data-তে faster।
৫ Production ML system-এ Clustering কীভাবে deploy করবে?
উত্তর
১. Scaler এবং Model একসাথে pickle/joblib দিয়ে save করো। ২. নতুন data আসলে scaler.transform() → model.predict() (KMeans-এ predict আছে, HCA-তে নেই তাই KNN দিয়ে approximate করতে হয়)। ৩. Cluster drift monitor করো — cluster distribution কি সময়ের সাথে পরিবর্তন হচ্ছে? ৪. MLflow/Weights&Biases দিয়ে experiment track করো।

Python Production-Ready Clustering Pipeline 
import numpy as np
import pandas as pd
import joblib
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score, davies_bouldin_score
from sklearn.neighbors import KNeighborsClassifier
import warnings; warnings.filterwarnings('ignore')

class ClusteringPipeline:
    """
    Production-ready Clustering Pipeline
    - Auto optimal K selection
    - Feature scaling
    - Model persistence
    - Prediction on new data
    """
    
    def __init__(self, k_range=(2, 10), algorithm='kmeans'):
        self.k_range = k_range
        self.algorithm = algorithm
        self.scaler = StandardScaler()
        self.model = None
        self.knn = None  # HCA prediction helper
        self.optimal_k = None
        self.metrics = {}
    
    def find_optimal_k(self, X_scaled):
        """Silhouette Score দিয়ে optimal K খোঁজা"""
        best_k, best_score = 2, -1
        scores = []
        
        for k in range(*self.k_range):
            km = KMeans(n_clusters=k, random_state=42, n_init=10)
            labels = km.fit_predict(X_scaled)
            score = silhouette_score(X_scaled, labels)
            scores.append((k, score))
            
            if score > best_score:
                best_k, best_score = k, score
        
        print(f"✓ Optimal K: {best_k} (Silhouette: {best_score:.3f})")
        return best_k
    
    def fit(self, X):
        """Training"""
        # Scale
        X_scaled = self.scaler.fit_transform(X)
        
        # Optimal K
        self.optimal_k = self.find_optimal_k(X_scaled)
        
        # Final model
        self.model = KMeans(n_clusters=self.optimal_k, 
                               random_state=42, n_init=10)
        labels = self.model.fit_predict(X_scaled)
        
        # KNN helper for new data prediction
        self.knn = KNeighborsClassifier(n_neighbors=5)
        self.knn.fit(X_scaled, labels)
        
        # Metrics
        self.metrics = {
            'silhouette': silhouette_score(X_scaled, labels),
            'davies_bouldin': davies_bouldin_score(X_scaled, labels),
            'inertia': self.model.inertia_,
            'n_clusters': self.optimal_k
        }
        
        print(f"✓ Training complete!")
        print(f"  Silhouette: {self.metrics['silhouette']:.3f}")
        print(f"  Davies-Bouldin: {self.metrics['davies_bouldin']:.3f}")
        return self
    
    def predict(self, X_new):
        """নতুন data-তে cluster predict করা"""
        X_scaled = self.scaler.transform(X_new)
        return self.knn.predict(X_scaled)
    
    def save(self, path):
        """Model save করা"""
        joblib.dump(self, path)
        print(f"✓ Model saved to {path}")
    
    @staticmethod
    def load(path):
        """Saved model load করা"""
        return joblib.load(path)
