🤖 Supervised vs Unsupervised Learning

চিত্র ১: Supervised vs Unsupervised Learning
🧠 সহজ কথায় বুঝি

Supervised: ধরো তোমার বাবা তোমাকে গাছ চিনতে শেখাচ্ছেন — "এটা আম গাছ, এটা জাম গাছ"। প্রতিটি উদাহরণের সাথে উত্তর (label) আছে।

Unsupervised: তুমি একা একা মাঠে গেলে, কোনো গাইড নেই। নিজেই গাছগুলোকে গ্রুপ করার চেষ্টা করছ — "এগুলো একরকম দেখতে, ওগুলো আলাদা রকম"।

📊 Classification vs Regression

চিত্র ২: Classification (শ্রেণীবিভাগ) vs Regression (রিগ্রেশন)
✅ আমাদের সমস্যা

আমরা predict করতে চাই: কর্মী চাকরি ছাড়বে কি না? উত্তর হবে ০ (থাকবে) অথবা ১ (ছাড়বে)। এটি একটি Binary Classification সমস্যা।

Exploration, Cleaning ও Preprocessing

ML মডেলকে পরিষ্কার ডেটা দিতে হয়। ময়লা ডেটা দিলে মডেলও ভুল ফলাফল দেবে — "Garbage In, Garbage Out"।

🕳️ Missing Values (অনুপস্থিত মান)

চিত্র ৩: Missing Values (NaN) দেখতে এরকম
⚠️ কেন Missing Values সমস্যা?

ML মডেল গণিত দিয়ে কাজ করে। ফাঁকা ঘরে গণিত করা যায় না! তাই হয় সেই সারি মুছতে হবে, অথবা একটি যুক্তিসঙ্গত মান বসাতে হবে।

কোন সারি মুছে ফেলতে হবে:

  • যেসব সারিতে target variable (left) missing — এগুলো দিয়ে train করা সম্ভব নয়, তাই মুছে দাও।
  • যেসব সারিতে ৩ বা তার বেশি কলামের মান missing — এগুলো অনেক বেশি অসম্পূর্ণ, তাই মুছে দাও।
# target variable 'left' যেখানে missing, সেই সারি মুছো
df = df.dropna(subset=['left'])

# যেসব সারিতে ৩ বা তার বেশি missing value, সেগুলো মুছো
# df.isna().sum(axis=1) → প্রতিটি সারিতে কতটি NaN আছে
df = df.loc[(df.isna().sum(axis=1)) < 3]
python
💜 axis=1 মানে কী?

axis=0 মানে কলাম বরাবর (উপর-নিচ) হিসাব করো।
axis=1 মানে সারি বরাবর (ডানে-বামে) হিসাব করো।
আমরা প্রতিটি সারিতে কতটি NaN আছে গণনা করছি, তাই axis=1।

✂️ Train-Test Split — কেন আগে ভাগ করতে হয়?

চিত্র ৪: Train-Test Split
🚨 Data Leakage কী? (সবচেয়ে বড় ভুল!)

ধরো পরীক্ষার আগে তুমি প্রশ্নপত্র দেখে পড়লে। পরীক্ষায় ভালো করলেও সেটা সত্যিকারের জ্ঞান নয়।

ML-এ data leakage হয় যখন test set-এর তথ্য model training-এ ঢুকে যায়। উদাহরণ: যদি সম্পূর্ণ dataset-এর mean দিয়ে missing value fill করো, তাহলে test data-র mean training-এ ব্যবহার হয়ে যায়। এটা cheating!

from sklearn.model_selection import train_test_split

# X = features (input), y = target (output)
y = df['left']
X = df.drop('left', axis=1)

# ৮০% train, ২০% test
# random_state=48 মানে প্রতিবার একই ভাগ হবে (reproducibility)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, 
    test_size=0.2, 
    random_state=48
)

print("Train Set:", X_train.shape)
print("Test Set:", X_test.shape)
python

🔧 Missing Values পূরণ করা (Imputation)

Split করার পরে এখন missing values পূরণ করব। দুটি কৌশল:

চিত্র ৫: Imputation কৌশল
from sklearn.impute import SimpleImputer

numerical_columns = ['satisfaction_level', 'last_evaluation', 'average_monthly_hours']
categorical_columns = ['number_projects', 'time_spend_company',
                       'work_accident', 'promotion_last_5_years', 
                       'position', 'salary']

# Numerical → median দিয়ে fill করো
numerical_imputer = SimpleImputer(strategy='median')
# Categorical → most frequent (mode) দিয়ে fill করো
categorical_imputer = SimpleImputer(strategy='most_frequent')

# IMPORTANT: fit() শুধু train-এ, transform() দুটোতেই
X_train[numerical_columns] = numerical_imputer.fit_transform(X_train[numerical_columns])
X_test[numerical_columns]  = numerical_imputer.transform(X_test[numerical_columns])

X_train[categorical_columns] = categorical_imputer.fit_transform(X_train[categorical_columns])
X_test[categorical_columns]  = categorical_imputer.transform(X_test[categorical_columns])
python
💡 fit_transform() vs transform() — পার্থক্য কী?

fit() = শেখো (মানে: "train data থেকে median/mode হিসাব করো এবং মনে রাখো")

transform() = প্রয়োগ করো (মানে: "আগে যে median শিখেছিলে সেটা দিয়ে NaN fill করো")

fit_transform() = একসাথে শেখো ও প্রয়োগ করো

Test data-তে কখনো fit() করবে না — সেটা data leakage!

🔢 Categorical Encoding

ML model সংখ্যা বোঝে, "low" বা "high" বোঝে না। তাই text-কে সংখ্যায় রূপান্তর করতে হবে।

চিত্র ৬: Ordinal Encoding vs One-Hot Encoding
from sklearn.preprocessing import OneHotEncoder

# Index reset করতে হবে concat-এর জন্য
X_train = X_train.reset_index(drop=True)
X_test  = X_test.reset_index(drop=True)

# salary → Ordinal (low=0, medium=1, high=2)
# কারণ: low < medium < high — এখানে ক্রম আছে!
X_train['salary'] = X_train['salary'].replace(['low', 'medium', 'high'], [0, 1, 2])
X_test['salary']  = X_test['salary'].replace(['low', 'medium', 'high'], [0, 1, 2])

# position → One-Hot Encoding
# drop='first' → multicollinearity এড়াতে প্রথম column বাদ দেওয়া হয়
encoder = OneHotEncoder(drop='first', sparse=False, handle_unknown='ignore')

encoder.fit(X_train[['position']])

X_train_enc = encoder.transform(X_train[['position']])
X_test_enc  = encoder.transform(X_test[['position']])

# নতুন কলামগুলো DataFrame-এ যোগ করো
train_enc_df = pd.DataFrame(X_train_enc, columns=encoder.get_feature_names_out(['position']))
test_enc_df  = pd.DataFrame(X_test_enc,  columns=encoder.get_feature_names_out(['position']))

X_train = pd.concat([X_train.drop(columns=['position']), train_enc_df], axis=1)
X_test  = pd.concat([X_test.drop(columns=['position']),  test_enc_df],  axis=1)
python

⚖️ Feature Scaling (StandardScaler)

চিত্র ৭: StandardScaler-এর প্রভাব
💡 StandardScaler কী করে?

প্রতিটি মান থেকে mean বিয়োগ করে, তারপর standard deviation দিয়ে ভাগ করে।

সূত্র: z = (x - μ) / σ

ফলাফল: সব feature-এর mean ≈ 0, standard deviation ≈ 1। সবাই একই "ভাষায়" কথা বলে।

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

# fit() শুধু train data-তে
scaler.fit(X_train)

# transform() দুটোতেই
X_train_scaled = scaler.transform(X_train)
X_test_scaled  = scaler.transform(X_test)
python
🎯 ইন্টারভিউ প্র্যাকটিস

সেকশন ৩ — প্র্যাকটিস প্রশ্ন

প্রশ্ন ১: Data Leakage কী? একটি বাস্তব উদাহরণ দিয়ে বুঝাও।

উত্তর দেখো

Data Leakage হয় যখন model training-এ test set-এর তথ্য ব্যবহার হয়। উদাহরণ: যদি পুরো dataset normalize করার পর split করো, তাহলে normalization-এর parameters (mean, std) test data থেকেও প্রভাবিত হয়। সঠিক পদ্ধতি: আগে split করো, তারপর train set থেকে parameters নাও।

প্রশ্ন ২: Salary column-এ Ordinal Encoding করা হলো কিন্তু Position-এ One-Hot Encoding কেন?

উত্তর দেখো

Salary: low < medium < high — এখানে স্বাভাবিক ক্রম আছে। Ordinal encoding এই ক্রম ধরে রাখে।

Position: "engineer", "sales", "hr" — এগুলোর মধ্যে কোনো ক্রম নেই। One-Hot encoding করলে model ভুল ক্রম ধরে নেবে না।

প্রশ্ন ৩ (ML Engineering): নিচের pipeline লিখো — একটি DataFrame থেকে numerical columns median দিয়ে ও categorical columns mode দিয়ে impute করো। তারপর numerical columns StandardScaler দিয়ে scale করো।

উত্তর দেখো 
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
import pandas as pd

num_cols = ['age', 'salary']
cat_cols = ['department']

num_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler',  StandardScaler())
])

preprocessor = ColumnTransformer([
    ('num', num_pipeline, num_cols),
    ('cat', SimpleImputer(strategy='most_frequent'), cat_cols)
])

📏 Classification Metrics

Metric সূত্র বাংলায় অর্থ কখন ব্যবহার
Accuracy (TP+TN)/(TP+TN+FP+FN) মোট সঠিক prediction-এর হার Class balanced হলে
Precision TP/(TP+FP) "ছাড়বে" বললে কতবার সঠিক? False Positive costly হলে
Recall TP/(TP+FN) যারা সত্যিই ছাড়বে তাদের কতজনকে ধরলাম? False Negative costly হলে ⭐
F1-Score 2×(P×R)/(P+R) Precision ও Recall-এর ভারসাম্য উভয়ই গুরুত্বপূর্ণ হলে
⭐ আমাদের সমস্যায় Recall কেন?

যদি কেউ চাকরি ছাড়তে চায় কিন্তু আমরা ধরতে না পারি (FN) → কোম্পানি talent হারায়। এটা বড় ক্ষতি।

কিন্তু যদি কেউ ছাড়বে না অথচ আমরা "ছাড়বে" বলি (FP) → HR একটু বাড়তি attention দেয়। এটা কম ক্ষতি।

তাই Recall maximize করাই লক্ষ্য!

উত্তর দেখো

Recall বেশি গুরুত্বপূর্ণ। যদি একজন সত্যিকারের রোগীকে আমরা ধরতে না পারি (FN), সে অন্যদের সংক্রমিত করতে পারে — বিপদজনক! কিছু false positive (রোগী নয়, কিন্তু positive বললাম) হলেও সেটা কম ক্ষতিকর — শুধু অপ্রয়োজনীয় quarantine হবে।

প্রশ্ন ২ (ML Engineering): Confusion matrix থেকে manually precision, recall ও F1-score হিসাব করো। ধরো: TP=80, TN=600, FP=20, FN=40।

উত্তর দেখো

Precision = TP/(TP+FP) = 80/(80+20) = 0.80

Recall = TP/(TP+FN) = 80/(80+40) = 0.667

F1 = 2×(0.80×0.667)/(0.80+0.667) = 0.727

Accuracy = (80+600)/(80+600+20+40) = 0.919

import pandas as pd

df = pd.read_csv("hr_train_corrupted.csv")

df = df[(df.isna().sum(axis=1)) < 3]

y = df['left']
X = df.drop('left', axis=1)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=48)

# ④ Impute
numerical_columns = ['satisfaction_level', 'last_evaluation', 'average_monthly_hours']
categorical_columns = ['number_projects', 'time_spend_company', 
                       'work_accident', 'promotion_last_5_years', 
                       'position', 'salary']
for col in numerical_columns:

    X_test[col]  = X_test[col].fillna(X_train[col].median())
for col in categorical_columns:

    X_test[col]  = X_test[col].fillna(X_train[col].mode()[0])

X_train = X_train.reset_index(drop=True)
X_test  = X_test.reset_index(drop=True)
X_train['salary'] = X_train['salary'].replace(['low','medium','high'],[0,1,2])

X_test  = pd.get_dummies(X_test)

scaler = StandardScaler()

📐 Penalty Function বোঝা

চিত্র ১৪: Custom Penalty Function
import numpy as np

# α = last_evaluation × number_projects
# ভালো কর্মী যারা অনেক প্রজেক্ট করে তাদের α বেশি
alpha_train = X_train["last_evaluation"] * X_train["number_projects"]
alpha_test  = X_test["last_evaluation"] * X_test["number_projects"]

def compute_score(y, preds, alpha):
    """
    y     = actual labels
    preds = predicted labels  
    alpha = penalty weight (last_eval × num_projects)
    """
    # normalization factor: max possible penalty
    maxi = np.where(alpha > 1, alpha, 1).sum()
    
    # FP penalty: pred=1 কিন্তু actual=0 → penalty=1 প্রতিটির জন্য
    fp_penalty = (preds > y).sum()
    
    # FN penalty: pred=0 কিন্তু actual=1 → penalty=α_i
    fn_penalty = alpha[preds < y].sum()
    
    return 1 - ((fp_penalty + fn_penalty) / maxi)

# Score হিসাব করো
y_pred_train = clf_gs.predict(X_train_scaled)
y_pred_test  = clf_gs.predict(X_test_scaled)

print("Train Score:", compute_score(y_train, y_pred_train, alpha_train))
print("Test Score:",  compute_score(y_test,  y_pred_test,  alpha_test))

উত্তর দেখো 
def weighted_cost_score(y_true, y_pred, transaction_amount):
    import numpy as np
    
    # FP: fraud মনে করলাম, আসলে fraud না → ১ টাকা cost
    fp_mask = (y_pred == 1) & (y_true == 0)
    fp_cost = fp_mask.sum()
    
    # FN: fraud ধরলাম না → transaction amount-এর ১০ গুণ cost
    fn_mask = (y_pred == 0) & (y_true == 1)
    fn_cost = (transaction_amount[fn_mask] * 10).sum()
    
    total_cost = fp_cost + fn_cost
    return total_cost

# কম score = ভালো model
cost = weighted_cost_score(y_test, y_pred_test, transaction_amounts)
print(f"Total Cost: ${cost:,.2f}")

import joblib
import pandas as pd

def predict_new_employee(employee_data: dict) -> int:
    """
    employee_data: dict with raw features
    returns: 0 (stays) or 1 (will leave)
    """
    # Load saved artifacts
    artifacts = joblib.load('full_pipeline.joblib')
    model   = artifacts['model']
    scaler  = artifacts['scaler']
    
    # DataFrame বানাও
    df_new = pd.DataFrame([employee_data])
    
    # Encode salary
    df_new['salary'] = df_new['salary'].replace(['low','medium','high'],[0,1,2])
    df_new = pd.get_dummies(df_new)
    
    # Scale
    df_scaled = scaler.transform(df_new)
    
    # Predict
    return model.predict(df_scaled)[0]

# ব্যবহার:
result = predict_new_employee({
    'satisfaction_level': 0.3,
    'last_evaluation': 0.9,
    'number_projects': 6,
    'salary': 'low',
    'position': 'engineer'
})
print("চাকরি ছাড়বে:" if result == 1 else "থাকবে")

Logistic Regression

লজিস্টিক রিগ্রেশন

👶 বাচ্চাদের মতো বুঝি

ধরো তোমার হাতে একটি ruler (স্কেল)। তুমি ক্লাসের ছাত্রদের লম্বা-বেঁটে দেখে বলতে চাও কে basketball খেলে কি না। একটা সরল রেখা (line) টানো — যারা রেখার উপরে তারা "হ্যাঁ", যারা নিচে তারা "না"।

Logistic Regression ঠিক এটাই করে, তবে output-কে ০ থেকে ১ এর মধ্যে একটি probability হিসেবে দেয় (Sigmoid function ব্যবহার করে)।

চিত্র ১৬: Sigmoid Function — output সবসময় ০ এবং ১-এর মধ্যে

💻 Python Implementation

from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, classification_report

# Model তৈরি ও train
lr = LogisticRegression(
    C=1.0,           # regularization strength (বড় C → কম regularization)
    max_iter=1000,  # convergence-এর জন্য iteration সংখ্যা
    random_state=42
)
lr.fit(X_train_scaled, y_train)

# Predict
y_pred = lr.predict(X_test_scaled)
y_prob = lr.predict_proba(X_test_scaled)[:, 1]  # class 1-এর probability

print("Accuracy:", accuracy_score(y_test, y_pred))
print(classification_report(y_test, y_pred))

# Coefficient দেখো (কোন feature কতটা প্রভাবশালী)
print("Coefficients:", lr.coef_)

Logistic Regression — ML Engineering

Logistic Regression-এ threshold পরিবর্তন করে precision ও recall-এর trade-off দেখাও।

উত্তর দেখো 
import numpy as np
from sklearn.metrics import precision_score, recall_score

# Default threshold = 0.5
y_prob = lr.predict_proba(X_test_scaled)[:, 1]

for threshold in [0.3, 0.4, 0.5, 0.6, 0.7]:
    y_pred_t = (y_prob >= threshold).astype(int)
    p = precision_score(y_test, y_pred_t)
    r = recall_score(y_test, y_pred_t)
    print(f"Threshold={threshold:.1f} | Precision={p:.3f} | Recall={r:.3f}")

Decision Tree

সিদ্ধান্ত বৃক্ষ

👶 বাচ্চাদের মতো বুঝি

ভাবো তুমি "২০ প্রশ্নের খেলা" খেলছ। কেউ একটা জিনিস ভেবেছে, তুমি হ্যাঁ/না প্রশ্ন করে বের করবে। "কি প্রাণী?", "কি ৪ পা আছে?", "কি বনে থাকে?"...

Decision Tree ঠিক এটাই করে! প্রতিটি node-এ একটি প্রশ্ন জিজ্ঞেস করে, উত্তরের উপর ভিত্তি করে পরের দিকে যায়, শেষে leaf node-এ সিদ্ধান্ত দেয়।

চিত্র ১৭: একটি সরল Decision Tree

💻 Python Implementation

from sklearn.tree import DecisionTreeClassifier, plot_tree
import matplotlib.pyplot as plt

dt = DecisionTreeClassifier(
    criterion='gini',   # split criterion: 'gini' বা 'entropy'
    max_depth=5,        # গাছ কতটা গভীর হবে (বেশি = overfitting)
    min_samples_split=20, # split করতে কমপক্ষে কতটি sample লাগবে
    min_samples_leaf=10,  # leaf-এ কমপক্ষে কতটি sample থাকবে
    random_state=42
)
dt.fit(X_train_scaled, y_train)

print("Train Acc:", dt.score(X_train_scaled, y_train))
print("Test Acc:",  dt.score(X_test_scaled,  y_test))

# গাছ visualize করো (ছোট max_depth-এর জন্য ভালো)
plt.figure(figsize=(20, 8))
plot_tree(dt, max_depth=3, feature_names=X_train.columns,
           class_names=['Stay', 'Leave'], filled=True)
plt.show()

Random Forest

র‍্যান্ডম ফরেস্ট — Ensemble Learning

👶 বাচ্চাদের মতো বুঝি

ধরো তোমাকে একটা কঠিন প্রশ্নের উত্তর দিতে হবে। তুমি একা জানো না, তাই ১০০ জন বিশেষজ্ঞকে জিজ্ঞেস করলে। যে উত্তর বেশি লোক দিল, সেটাই সঠিক — এটাই voting।

Random Forest: অনেকগুলো Decision Tree তৈরি করো (প্রতিটি random ডেটা ও random features নিয়ে), তারপর সবার prediction-এর majority vote নাও।

চিত্র ১৮: Random Forest — Majority Voting

💻 Python Implementation

from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(
    n_estimators=100,   # কতটি Decision Tree তৈরি হবে

    min_samples_split=5, # split করতে minimum samples

    criterion='gini',   # split criterion
    n_jobs=-1,           # সব CPU core ব্যবহার করো
    random_state=42
)

rf.fit(X_train_scaled, y_train)

# Feature importance
importances = rf.feature_importances_
feature_names = X_train.columns
sorted_idx = importances.argsort()[::-1]

print("Top 5 Features:")
for i in sorted_idx[:5]:
    print(f"  {feature_names[i]}: {importances[i]:.3f}")

GridSearchCV

Hyperparameter Grid Search + Cross Validation

👶 বাচ্চাদের মতো বুঝি

ভাবো তুমি নতুন জুতো কিনতে গেছ। তোমাকে বিভিন্ন সাইজ (৮, ৯, ১০) এবং বিভিন্ন রঙ (লাল, নীল, সাদা) পরীক্ষা করতে হবে। প্রতিটি combination পরো, দেখো কোনটা সবচেয়ে ভালো ফিট করে। Grid Search ঠিক এটাই করে — সব combination পরীক্ষা করে।

চিত্র ১৯: GridSearchCV — সেরা combination খুঁজে বের করা

💻 Complete Implementation

from sklearn.model_selection import GridSearchCV, cross_val_score
from sklearn.ensemble import RandomForestClassifier
import numpy as np

# Step 1: Parameter grid define করো
param_grid = {
    'criterion': ['gini', 'entropy'],
    'max_depth': np.arange(3, 16, 2),   # 3,5,7,9,11,13,15
    'n_estimators': [50, 100, 200]
}

# Step 2: GridSearchCV তৈরি করো
grid_search = GridSearchCV(
    estimator=RandomForestClassifier(random_state=42),
    param_grid=param_grid,
    cv=5,                    # 5-fold cross validation
    scoring='recall',       # optimize করার metric
    n_jobs=-1,               # parallel processing
    verbose=2,               # progress দেখাও
    return_train_score=True  # train score-ও রাখো
)

# Step 3: Fit
grid_search.fit(X_train_scaled, y_train)

# Step 4: Results দেখো
print("Best Parameters:", grid_search.best_params_)
print("Best CV Recall:",   grid_search.best_score_)

# Results DataFrame-এ দেখো
results = pd.DataFrame(grid_search.cv_results_)
results.sort_values('rank_test_score')[[
    'param_criterion', 'param_max_depth', 
    'mean_test_score', 'std_test_score'
]].head(10)

End-to-End HR Analytics Pipeline

একটি সম্পূর্ণ ML pipeline তৈরি করো নিচের requirements নিয়ে:

  • HR dataset load ও clean করো
  • Train-test split (stratified — class balance বজায় রাখতে)
  • Preprocessing pipeline (SimpleImputer + StandardScaler)
  • তিনটি model compare করো (LR, DT, RF)
  • GridSearchCV দিয়ে RF optimize করো
  • Final model evaluate করো (classification report + confusion matrix)
  • Model ও pipeline সেভ করো
সম্পূর্ণ উত্তর দেখো 
# ════════════════════════════════════
# Complete HR Attrition ML Pipeline
# ════════════════════════════════════
import pandas as pd
import numpy as np
import joblib
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report
from sklearn.pipeline import Pipeline

# ── 1. Load & Clean ──────────────────────
df = pd.read_csv("hr_train_corrupted.csv")
df = df.dropna(subset=['left'])
df = df[(df.isna().sum(axis=1)) < 3]

# ── 2. Split (stratified) ────────────────
y = df['left']
X = df.drop('left', axis=1)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)
# stratify=y → train ও test-এ class ratio একই থাকবে

# ── 3. Preprocess ────────────────────────
num_cols = ['satisfaction_level', 'last_evaluation', 'average_monthly_hours']
cat_cols = ['number_projects', 'time_spend_company', 
            'work_accident', 'promotion_last_5_years', 'salary']

X_train = X_train.reset_index(drop=True)
X_test  = X_test.reset_index(drop=True)

for col in num_cols:
    X_train[col] = X_train[col].fillna(X_train[col].median())
    X_test[col]  = X_test[col].fillna(X_train[col].median())
for col in cat_cols:
    X_train[col] = X_train[col].fillna(X_train[col].mode()[0])
    X_test[col]  = X_test[col].fillna(X_train[col].mode()[0])

X_train['salary'] = X_train['salary'].replace(['low','medium','high'],[0,1,2])
X_test['salary']  = X_test['salary'].replace(['low','medium','high'],[0,1,2])
X_train = pd.get_dummies(X_train)
X_test  = pd.get_dummies(X_test)

scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s  = scaler.transform(X_test)

# ── 4. Model Comparison ──────────────────
models = {
    'LR': LogisticRegression(max_iter=1000),
    'DT': DecisionTreeClassifier(random_state=42),
    'RF': RandomForestClassifier(random_state=42)
}
for name, m in models.items():
    m.fit(X_train_s, y_train)
    print(f"{name}: {m.score(X_test_s, y_test):.4f}")

# ── 5. GridSearchCV ───────────────────────
param_grid = {
    'criterion': ['gini', 'entropy'],
    'max_depth': [5, 10, 15]
}
gs = GridSearchCV(RandomForestClassifier(), 
                   param_grid, cv=5, scoring='recall')
gs.fit(X_train_s, y_train)
print("Best:", gs.best_params_)

# ── 6. Evaluate ──────────────────────────
print(classification_report(y_test, gs.predict(X_test_s)))

# ── 7. Save ──────────────────────────────
joblib.dump({'model': gs, 'scaler': scaler}, 'hr_pipeline.joblib')
print("Pipeline saved!")
