Simple Linear Regression — তত্ত্ব ও সূত্র

Simple Linear Regression-এ মাত্র একটি explanatory variable (X) দিয়ে target variable (y) predict করা হয়। এটা হলো সবচেয়ে সহজ regression model।

মনে করো তুমি দেখতে চাও — একটা ছাত্র যত ঘণ্টা পড়াশোনা করে, তার নম্বর কত হয়। এখানে: পড়ার ঘণ্টা = X, নম্বর = y।

y = β₀ + β₁ × x + ε
y
Target variable — যা predict করতে চাই (যেমন: গাড়ির দাম, পয়েন্ট)
x
Explanatory variable — যা দিয়ে predict করব (যেমন: গাড়ির ওজন, মিনিট)
β₀
Intercept — রেখাটা y-axis কোথায় কাটে (x=0 হলে y কত)
β₁
Slope — x একটু বাড়লে y কতটা বাড়ে/কমে
ε
Error term — model পুরোপুরি perfect না, এই পার্থক্যটাই error
β₀ (Intercept) ও β₁ (Slope) — চাক্ষুষ বোঝা

Least Squares Method — কিভাবে β₀ আর β₁ বের করা হয়?

আমরা চাই residuals (actual - predicted) যতটা সম্ভব কম হোক। Least Squares Method-এ সব residuals² এর যোগফল minimize করা হয়।

Minimize করতে হবে:
RSS = Σ(yᵢ - ŷᵢ)² = Σ(yᵢ - β₀ - β₁xᵢ)²

Simple Linear Regression — Cars Dataset দিয়ে বাস্তবায়ন

Cars Dataset-এ ১৫৯টি গাড়ির তথ্য আছে। আমরা curb-weight (গাড়ির ওজন) দিয়ে price (দাম) predict করব।

PythonSimple Linear Regression — সম্পূর্ণ কোড
# ━━━ ডেটা লোড করি ━━━
df = pd.read_csv("cars.csv")

# ━━━ X এবং y আলাদা করি ━━━
y = df['price']           # target: গাড়ির দাম
X = df[['curb-weight']]   # [[]] ব্যবহার করছি কারণ DataFrame দরকার, Series নয়

# ━━━ মডেল তৈরি ও train করা ━━━

# ━━━ Coefficients দেখি ━━━
print(f"Intercept (β₀): {slr.intercept_:.2f}")
print(f"Slope (β₁): {slr.coef_[0]:.2f}")
Intercept (β₀): -15378.23 Slope (β₁): 10.90
🔢
এই সংখ্যাগুলোর মানে কী?

সমীকরণটা হলো: price = -15378.23 + 10.90 × curb-weight
অর্থাৎ — গাড়ির ওজন ১ unit বাড়লে দাম প্রায় ১০.৯ টাকা বাড়ে। তবে সতর্কতা: এটা দুটো variable-এর সম্পর্ক দেখায়, causality (কারণ-ফল) নয়!

Model Evaluation — R² এবং RMSE

Model বানানোর পর সবচেয়ে গুরুত্বপূর্ণ প্রশ্ন — এটা কতটা ভালো?

R² এবং RMSE — দুটো মূল Metric
PythonCross-Validation ও RMSE
# ━━━ Cross-Validation দিয়ে R² দেখি ━━━
cv_results = cross_validate(slr, X, y, return_train_score=True, cv=4)
print("Test R² (average):", cv_results['test_score'].mean())    # ~0.75
print("Train R² (average):", cv_results['train_score'].mean())  # ~0.80

# ━━━ RMSE বের করি ━━━
def rmse(predictions, targets):
    return np.sqrt(((predictions - targets) ** 2).mean())

pred_price = slr.predict(X)
print(f"RMSE: {rmse(pred_price, y):.2f}")     # ~2629

PythonProduction-Ready ML Pipeline
from sklearn.pipeline import Pipeline
from sklearn.feature_selection import SelectKBest, f_regression
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score
from sklearn.metrics import mean_squared_error
import numpy as np

def build_regression_pipeline(X_train, y_train, X_test, y_test, k=5):
    """
    Complete ML regression pipeline.
    
    Parameters:
        X_train, y_train: Training data
        X_test, y_test: Test data  
        k: Number of features to select
    
    Returns:
        dict: pipeline, metrics, selected features
    """
    
    # Pipeline বানাও — সব ধাপ একসাথে
    pipeline = Pipeline([
        ('scaler', StandardScaler()),           # Step 1: Scale
        ('selector', SelectKBest(f_regression, k=k)),  # Step 2: Select
        ('model', LinearRegression())            # Step 3: Model
    ])
    
    # Train করো
    pipeline.fit(X_train, y_train)
    
    # Metrics বের করো
    y_pred = pipeline.predict(X_test)
    train_r2 = pipeline.score(X_train, y_train)
    test_r2  = pipeline.score(X_test,  y_test)
    rmse = np.sqrt(mean_squared_error(y_test, y_pred))
    
    # CV score
    cv_scores = cross_val_score(pipeline, X_train, y_train, cv=5)
    
    # Selected features
    selector = pipeline.named_steps['selector']
    selected_features = X_train.columns[selector.get_support()].tolist()
    
    results = {
        'pipeline': pipeline,
        'train_r2': train_r2,
        'test_r2': test_r2,
        'rmse': rmse,
        'cv_mean': cv_scores.mean(),
        'cv_std': cv_scores.std(),
        'selected_features': selected_features,
        'overfitting_gap': train_r2 - test_r2
    }
    
    print(f"Train R²: {train_r2:.4f}")
    print(f"Test R²:  {test_r2:.4f}")
    print(f"RMSE:     {rmse:.2f}")
    print(f"CV R² (mean±std): {cv_scores.mean():.3f}±{cv_scores.std():.3f}")
    print(f"Overfitting gap: {train_r2 - test_r2:.4f}")
    print(f"Selected: {selected_features}")
    
    return results

Ridge Regression (L2 Regularization)

Ridge Regression সাধারণ Linear Regression-এর মতোই, শুধু extra penalty যোগ হয়। এই penalty হলো coefficients-এর বর্গের যোগফল (L2 norm)।

Minimize: ||Y - Xβ||² + α||β||²
||Y - Xβ||²
Prediction error (সাধারণ regression-এর মতো) — যত কম তত ভালো
α||β||²
Penalty term — β² এর যোগফল × α। বড় coefficient-কে "শাস্তি" দেয়
α (alpha)
Penalty strength। বড় α = বেশি শাস্তি = ছোট coefficient। ছোট α = কম শাস্তি = সাধারণ regression-এর কাছাকাছি
🏏
Ridge-এর সহজ উপমা

ধরো তুমি একটা দলের ব্যাটসম্যান বাছছ। সাধারণ regression শুধু past average দেখে — হয়তো একজনের average অনেক বেশি কিন্তু সে শুধু weak bowling-এর বিরুদ্ধে run করেছে। Ridge বলে: "সবাইকে কিছুটা সমান গুরুত্ব দাও, কারো over-dependence নয়।"

• Overfitting কমাতে চাও কিন্তু সব coefficient থাকুক (Ridge কোনো coefficient ০ করে না)

Lasso Regression (L1 Regularization)

Lasso হলো Ridge-এর মতোই — কিন্তু penalty হলো coefficients-এর absolute value-এর যোগফল (L1 norm)। এই ছোট পার্থক্যের বিশাল ফলাফল: Lasso কিছু coefficient-কে একদম শূন্য করে দিতে পারে। মানে Lasso নিজে নিজেই Feature Selection করে!

Minimize: ||Y - Xβ||² + α||β||₁
||β||₁
L1 Norm = |β₁| + |β₂| + ... + |βₚ| (absolute values-এর যোগফল)
Ridge vs Lasso
Ridge: β² penalty → কোনো coefficient ০ হয় না। Lasso: |β| penalty → কিছু coefficient ০ হয়ে যায়!
Ridge vs Lasso — Coefficient Path (alpha বাড়লে কী হয়)

def compare_regression_models(X_train, y_train, X_test, y_test):
    """সব regression model তুলনা করো।"""
    
    # Scale করো (Ridge/Lasso/EN-এর জন্য দরকার)
    scaler = StandardScaler()
    X_tr_sc = scaler.fit_transform(X_train)
    X_te_sc = scaler.transform(X_test)
    
    models = {
        'Linear Regression': LinearRegression(),
        'Ridge (CV)': RidgeCV(alphas=np.logspace(-3, 3, 20)),
        'Lasso (CV)': LassoCV(cv=5, max_iter=5000),
        'Elastic Net (CV)': ElasticNetCV(
            cv=5,
            l1_ratio=[0.1, 0.5, 0.7, 0.9, 0.99],
            max_iter=5000
        )
    }
    
    results = []
    
    for name, model in models.items():
        # Linear Regression unscaled data-তেও চলে
        if name == 'Linear Regression':
            model.fit(X_train, y_train)
            y_pred = model.predict(X_test)
            train_r2 = model.score(X_train, y_train)
            test_r2  = model.score(X_test, y_test)
        else:
            model.fit(X_tr_sc, y_train)
            y_pred = model.predict(X_te_sc)
            train_r2 = model.score(X_tr_sc, y_train)
            test_r2  = model.score(X_te_sc, y_test)
        
        rmse = np.sqrt(mean_squared_error(y_test, y_pred))
        
        results.append({
            'Model': name,
            'Train R²': round(train_r2, 4),
            'Test R²': round(test_r2, 4),
            'RMSE': round(rmse, 2),
            'Overfit Gap': round(train_r2 - test_r2, 4)
        })
    
    results_df = pd.DataFrame(results).sort_values('Test R²', ascending=False)
    print(results_df.to_string(index=False))
    
    best_model_name = results_df.iloc[0]['Model']
    print(f"\n🏆 সেরা model: {best_model_name}")
    
    return results_df

from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import mean_squared_error, r2_score
import numpy as np
import pandas as pd

class LinearRegressionWrapper:
    """
    Production-ready Linear Regression wrapper.
    Real ML projects-এ এভাবে code organize করা হয়।
    """
    
    def __init__(self, random_state=42):
        self.model = LinearRegression()
        self.random_state = random_state
        self.is_fitted = False
    
    def fit(self, X_train, y_train):
        self.model.fit(X_train, y_train)
        self.is_fitted = True
        self.feature_names = (
            X_train.columns.tolist() 
            if hasattr(X_train, 'columns') 
            else [f"x{i}" for i in range(X_train.shape[1])]
        )
        return self
    
    def predict(self, X):
        return self.model.predict(X)
    
    def evaluate(self, X_train, y_train, X_test, y_test):
        y_pred_train = self.predict(X_train)
        y_pred_test  = self.predict(X_test)
        
        return {
            'train_r2'  : r2_score(y_train, y_pred_train),
            'test_r2'   : r2_score(y_test,  y_pred_test),
            'train_rmse': np.sqrt(mean_squared_error(y_train, y_pred_train)),
            'test_rmse' : np.sqrt(mean_squared_error(y_test,  y_pred_test)),
            'intercept' : self.model.intercept_,
            'coefficients': dict(zip(self.feature_names, self.model.coef_))
        }
    
    def cross_validate(self, X, y, cv=5):
        scores = cross_val_score(self.model, X, y, cv=cv)
        return {'mean': scores.mean(), 'std': scores.std(), 'scores': scores}

def lasso_feature_selection(X_train, y_train, X_test, y_test, feature_names=None):
    """Lasso regression with automatic feature selection."""
    
    from sklearn.preprocessing import StandardScaler
    scaler = StandardScaler()
    X_tr = scaler.fit_transform(X_train)
    X_te = scaler.transform(X_test)
    
    # Feature names বের করো
    if feature_names is None:
        feature_names = (

            if hasattr(X_train, 'columns') 
            else [f"feature_{i}" for i in range(X_train.shape[1])]
        )

        '|Coefficient|': np.abs(lasso_cv.coef_),
        'Selected': lasso_cv.coef_ != 0
    }).sort_values('|Coefficient|', ascending=False)
    
    selected = coef_df[coef_df['Selected']]['Feature'].tolist()

    print(f"❌ Removed features ({len(removed)}): {removed}")
    print(f"\nCoefficients:\n{coef_df.to_string(index=False)}")
    
    return lasso_cv, scaler, selected

    # Numeric columns শুধু রাখো (simple version)
    numeric_cols = df.select_dtypes('number').columns.tolist()
    
    X = df[numeric_cols].drop(target_col, axis=1)
    y = df[target_col]
    
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=test_size, random_state=random_state
    )
    
    print(f"\n✂️ Split: {len(X_train)} train, {len(X_test)} test")
    return X_train, X_test, y_train, y_test

def train_and_compare(X_train, y_train, X_test, y_test):
    """সব model train করো ও compare করো।"""
    
    # Pipeline with scaler (Ridge/Lasso/EN-এর জন্য)
    models = {
        'Linear Regression': Pipeline([
            ('model', LinearRegression())
        ]),
        'Ridge (CV)': Pipeline([
            ('scaler', StandardScaler()),
            ('model', RidgeCV(alphas=np.logspace(-3, 3, 20)))
        ]),
        'Lasso (CV)': Pipeline([
            ('scaler', StandardScaler()),
            ('model', LassoCV(cv=5, max_iter=5000))
        ]),
        'Elastic Net (CV)': Pipeline([
            ('scaler', StandardScaler()),
            ('model', ElasticNetCV(
                cv=5,
                l1_ratio=[0.1, 0.5, 0.9],
                max_iter=5000
            ))
        ])
    }
    
    results = []
    trained_models = {}
    
    print("\n" + "="*60)
    print("🏋️ TRAINING AND EVALUATION")
    print("="*60)
    
    for name, pipeline in models.items():
        pipeline.fit(X_train, y_train)
        
        y_pred = pipeline.predict(X_test)
        train_r2 = pipeline.score(X_train, y_train)
        test_r2  = pipeline.score(X_test,  y_test)
        rmse = np.sqrt(mean_squared_error(y_test, y_pred))
        
        cv_scores = cross_val_score(pipeline, X_train, y_train, cv=5)
        
        results.append({
            'Model': name,
            'Train R²': round(train_r2, 4),
            'Test R²':  round(test_r2, 4),
            'RMSE': round(rmse, 2),
            'CV Mean': round(cv_scores.mean(), 4),
            'Overfit': round(train_r2 - test_r2, 4)
        })
        trained_models[name] = pipeline
    
    results_df = pd.DataFrame(results).sort_values('Test R²', ascending=False)
    print(results_df.to_string(index=False))
    
    best_name = results_df.iloc[0]['Model']
    print(f"\n🏆 সেরা Model: {best_name}")
    
    return trained_models[best_name], results_df

Elastic Net — Ridge + Lasso এক জায়গায়

Ridge = L2 penalty | Lasso = L1 penalty | Elastic Net = দুটো মিশিয়ে

🔢 Elastic Net-এর সূত্র:
min β: Σ(yᵢ - Σβⱼxᵢⱼ)² + α·[λ·Σ|βⱼ| + (1-λ)·Σβⱼ²]

α (alpha) = কতটা penalty — বড় হলে বেশি regularization
λ (l1_ratio) = 1 হলে pure Lasso, 0 হলে pure Ridge, মাঝে হলে mix

Q1
Elastic Net-কে "Ridge + Lasso-র মিশ্রণ" বলা হয় কেন? l1_ratio=1 মানে কী?

Elastic Net-এর penalty = α·[λ·Σ|βⱼ| + (1-λ)·Σβⱼ²]

l1_ratio (λ) = 1 → (1-λ)=0 → Ridge term বাদ → pure Lasso

l1_ratio (λ) = 0 → λ=0 → Lasso term বাদ → pure Ridge

l1_ratio = 0.5 → দুটো সমান ভাগে mix

Elastic Net-এর সুবিধা: correlated variable গুলোর weight share করে — Lasso যেমন arbitrarily একটা বেছে নেয়, তা না করে দুটোতেই ভালো coefficient রাখে।

Q2
One-Hot Encoding-এ pos_SG বাদ দিলাম কেন? Dummy Variable Trap explain করো।

যদি C, PF, PG, SF, SG সব রাখি: pos_C + pos_PF + pos_PG + pos_SF + pos_SG = 1 (সবসময়)

এর মানে এই ৫টা column linearly dependent → multicollinearity → XᵀX matrix invertible থাকে না → model unstable।

Solution: k categories থেকে k-1 টা রাখো। বাদ দেওয়াটা "reference category" হয় — এর বিপরীতে বাকিগুলো interpret করা হয়।

Q3
Simple LR (R²=0.85) vs ElasticNet (R²=0.93) — কোনটা production-এ ব্যবহার করব? Justify করো।

ElasticNet ব্যবহার করব কারণ:

  • R² অনেক বেশি: 0.85 → 0.93 (8% improvement)
  • RMSE কম: 211 → 145 (গড় error 66 পয়েন্ট কমেছে)
  • Train ও Test score প্রায় সমান (0.928 vs 0.928) → overfitting নেই
  • regularization আছে, production data-তে generalize করবে

Simple LR শুধু তখনই যদি real-time inference দরকার হয় (latency <1ms) অথবা model explainability stakeholder-দের কাছে critical।

    rmse   = np.sqrt(mean_squared_error(y_test, m.predict(Xte)))
    gap    = r2_tr - r2_te
    print(f"{name:<20} {r2_tr:>9.4f} {r2_te:>9.4f} {rmse:>10.2f} {gap:>8.4f}")

গণিতের ভিত্তি — OLS Estimator কীভাবে জন্ম নেয়? 📐

Linear Regression-এর পুরো গাণিতিক রূপ

এতক্ষণ আমরা দেখেছি model কীভাবে ব্যবহার করতে হয়। এখন দেখব — sklearn আসলে ভেতরে ভেতরে কী করছে?

📐 Linear Regression Model (একটা observation i-এর জন্য):
yᵢ = β₀ + β₁xᵢ₁ + β₂xᵢ₂ + ... + βₚxᵢₚ + εᵢ

yᵢ = predict করতে চাই (pts)
xᵢⱼ = input features (mp, age, ...)
βⱼ = coefficient — এগুলোই model শিখে
εᵢ = error — যা predict করা গেল না

Matrix Form — সব n জনের সমীকরণ একসাথে

২৮

Error Term ε — চারটি গুরুত্বপূর্ণ Assumption

Linear Regression সঠিকভাবে কাজ করতে হলে error গুলোকে কিছু শর্ত মানতে হবে। এগুলো না মানলে model-এর prediction ও p-value সব ভুল হয়ে যায়।

১. Centered — গড় শূন্য
E(εᵢ) = 0

Error গুলো systematically positive বা negative না। কখনো বেশি predict, কখনো কম — কিন্তু গড়ে ঠিকঠাক।

২. Homoscedastic — সমান Variance
Var(εᵢ) = σ² (সবার জন্য)

ছোট player বা বড় player — সবার জন্য error-এর ছড়ানো একই। Heteroscedasticity থাকলে residual plot-এ funnel দেখা যায়।

৩. Independent — স্বাধীন
Cov(εᵢ, εⱼ) = 0, i≠j

একজনের prediction error আরেকজনের উপর নির্ভর করে না। Time series data-তে এটা সবসময় ভাঙে।

৪. Gaussian — Normal Distribution
εᵢ ~ N(0, σ²)

Error গুলো normal distribution follow করে। দরকার confidence interval ও hypothesis testing-এর জন্য।

২৯

OLS ও Ridge — সমাধান কীভাবে বের হয়?

পদক্ষেপে পদক্ষেপে OLS সমাধান

ধাপ ১: Loss Function লেখো
f(β) = ||Y - Xᵀβ||² = Σᵢ(yᵢ - Σⱼβⱼxᵢⱼ)²

এটা "actual - predicted"-এর square সব যোগ করা। যত কম, model তত ভালো।

ধাপ ২: Gradient = 0 সেট করো

কেন gradient = 0? কারণ function-এর minimum-এ slope = 0 হয় — ঠিক পাহাড়ের নিচে যেমন flat।

∇f(β) = 0 -2(XᵀY - XᵀXβ) = 0 XᵀXβ = XᵀY
ধাপ ৩: Solve করো → OLS Estimator
β_OLS = (XᵀX)⁻¹ · XᵀY

এটাই Ordinary Least Squares (OLS) Estimator — sklearn LinearRegression ভেতরে এটাই করে! শর্ত: XᵀX invertible হতে হবে।

Ridge — কখন OLS কাজ করে না?

যখন p ≥ n (বেশি feature, কম data), তখন XᵀX invertible না — সমাধান নেই! Ridge এই সমস্যা সমাধান করে একটা L2 penalty যোগ করে।

Ridge Loss Function:
g(β) = ||Y - Xᵀβ||² + α||β||²
∇g(β) = 0 করে solve:
-2(XᵀY - XᵀXβ) + 2αβ = 0 (XᵀX + nαI)β = XᵀY
β_Ridge = (XᵀX + nαI)⁻¹ · XᵀY

কেন সবসময় invertible? (XᵀX + nαI)-এ diagonal-এ nα যোগ হয়েছে। α > 0 হলে এই matrix সবসময় positive definite → সবসময় invertible!

🧠 OLS vs Ridge তুলনা:
বিষয়OLSRidge
Penaltyনেইα||β||²
BiasUnbiased ✓Biased (0-এর দিকে টানে)
Varianceবেশি (overfit prone)কম ✓
InvertibilityXᵀX full rank লাগবেসবসময় ✓
Variable Selectionনানা (Lasso করে)
৩০

Lasso — L1 Norm ও Variable Selection-এর রহস্য

L1 Norm কেন Differentiable না?

h(β) = ||Y - Xᵀβ||² + α·Σ|βⱼ|

|β| (absolute value) এর derivative β=0-তে exist করে না (বাম থেকে -1, ডান থেকে +1)। তাই OLS বা Ridge-এর মতো simple formula বের করা যায় না।

L1 penalty (Lasso)-র "হীরা" আকৃতির constraint region-এর কোণে β=0 হওয়ার সম্ভাবনা বেশি। তাই Lasso automatically কিছু coefficient 0 করে — variable selection হয়।

Sklearn কীভাবে Lasso solve করে?

Coordinate Descent

একবারে একটা βⱼ update করো, বাকিগুলো fix রেখে। ঘুরতে থাকো যতক্ষণ converge না হয়।

Soft Thresholding

|β̂ⱼ| < α/(2n) হলে সেই βⱼ = 0 করে দাও। এটাই Lasso-র variable selection-এর আসল কারণ।

৩১

Bias-Variance Tradeoff — কেন Regularization Overfitting কমায়?

Model-এর মোট Error দুই ভাগে ভাগ হয়

Total Error = Variance(β_esti) + Bias²(β_esti)
Variance

Training data বদলালে model কতটা বদলায়।
বেশি → Overfitting
Test score অনেক কম train score-এর চেয়ে।

Bias

Average prediction-এ systematic error।
বেশি → Underfitting
Train score-ই কম।

Ridge ও Lasso কেন Overfitting কমায়?

Mathematical proof: penalized estimator-এর variance < OLS-এর variance। α বাড়লে variance আরো কমে — কিন্তু bias বাড়ে। CV দিয়ে optimal α খুঁজি যেখানে total error সবচেয়ে কম।

গণিত ও Advanced Models — Interview Exercise 🎓

Mathematical Background ও Advanced Model প্রশ্নোত্তর

Q1
OLS estimator β = (XᵀX)⁻¹XᵀY কোন condition-এ কাজ করে না? তখন কী করবে?

কাজ করে না যখন:

  • p ≥ n: বেশি features, কম samples (genomics, text data)
  • XᵀX invertible না — X full rank না
  • Perfect multicollinearity — columns linearly dependent

Solution: Ridge (L2 penalty → XᵀX + nαI সবসময় invertible), অথবা Lasso/ElasticNet।

Q2
"OLS unbiased কিন্তু high variance" — explain করো। Ridge কীভাবে সমাধান করে?

OLS unbiased: E(β_OLS) = β — average-এ সঠিক। কিন্তু training data একটু বদলালেই β অনেক বদলে যায় (high variance) → overfitting।

Ridge: α penalty β-কে 0-এর দিকে টানে → biased হয়, কিন্তু Var(β_Ridge) < Var(β_OLS)।

Bias-Variance tradeoff: কিছু bias accept করে variance কমাই → overall test error কমে।

Q3
Lasso কীভাবে variable selection করে? Geometric ও mathematical explanation দাও।

Geometric: L1 constraint region হলো diamond shape — coordinate axis-এ কোণ আছে। OLS-এর loss function (ellipse) এই diamond-এর কোণে intersect করলে সেই coefficient = 0।

Mathematical: Soft-thresholding — |β̂ⱼ| < α/(2n) হলে βⱼ = 0 set করা হয়।

L2 (Ridge) circle-এর কোনো কোণ নেই → কখনো exactly 0 হয় না, শুধু ছোট হয়।

Q4
Random Forest কেন Linear Regression-এর চেয়ে ভালো হতে পারে? কখন LR বেশি উপযুক্ত?

RF ভালো যখন: non-linear relationship, interaction effects, outlier/missing values আছে, large dataset।

LR ভালো যখন: interpretability দরকার (coefficient explain করতে হবে), data সত্যিই linear, small dataset, statistical inference দরকার (p-value, CI)।

Practical rule: প্রথমে LR দিয়ে baseline তৈরি করো। তারপর RF/XGBoost দিয়ে দেখো improvement হয় কিনা।

    'Linear Regression': (LinearRegression(), True),
    'RidgeCV':           (RidgeCV(alphas=np.logspace(-3,3,50)), True),
    'LassoCV':           (LassoCV(cv=8), True),
    'ElasticNetCV':      (ElasticNetCV(cv=8, l1_ratio=[0.5,0.9,0.99]), True),

    'KNN':               (KNeighborsRegressor(n_neighbors=7), True),
    'SVR':               (SVR(kernel='rbf', C=100, epsilon=10), True),
}

results = []
for name, (model, use_scaled) in models.items():
    Xtr = X_train_s if use_scaled else X_train
    Xte = X_test_s  if use_scaled else X_test
    model.fit(Xtr, y_train)
    pred = model.predict(Xte)
    results.append({
        'Model':       name,
        'R² Train':    round(model.score(Xtr, y_train), 4),
        'R² Test':     round(r2_score(y_test, pred), 4),
        'RMSE Test':   round(np.sqrt(mean_squared_error(y_test, pred)), 2),
        'Overfit Gap': round(model.score(Xtr, y_train) - r2_score(y_test, pred), 4)
    })

df_r = pd.DataFrame(results).sort_values('R² Test', ascending=False)
print(df_r.to_string(index=False))
print(f"\n🏆 সেরা: {df_r.iloc[0]['Model']} | R²={df_r.iloc[0]['R² Test']}")
