🧠 সহজ ভাষায় মেশিন লার্নিং

ধরো তুমি ছোটবেলায় হাজারবার বিড়াল আর কুকুর দেখেছো। এখন কেউ নতুন একটি ছবি দেখালে তুমি বলতে পারো — "এটা বিড়াল!" — তুমি কিন্তু কাউকে শেখাওনি কোনো নিয়ম। তুমি উদাহরণ থেকে শিখেছো।


মেশিন লার্নিং ঠিক এটাই করে। কম্পিউটারকে অনেক উদাহরণ (data) দেওয়া হয়, সে নিজে নিজে প্যাটার্ন খুঁজে বের করে এবং ভবিষ্যতে নতুন তথ্য দিলে সিদ্ধান্ত নিতে পারে।

উদাহরণ: ছবি দেওয়া আছে এবং বলা আছে "বিড়াল" বা "কুকুর"। মডেল শিখে তারপর নতুন ছবিতে বলতে পারে।

✂️ Train-Test Split কী এবং কেন প্রয়োজন?

কল্পনা করো তুমি পরীক্ষার প্রস্তুতি নিচ্ছো। তুমি বইয়ের সব প্রশ্ন দেখলে এবং উত্তর মুখস্থ করলে। পরীক্ষায় ঠিক সেই প্রশ্নই এলো — তুমি ১০০% পেলে!


কিন্তু এতে কি তোমার সত্যিকারের জ্ঞান প্রমাণ হলো? না! একই কথা ML মডেলের ক্ষেত্রে প্রযোজ্য।

চিত্র: ডেটাসেটকে Train এবং Test অংশে ভাগ করা
PYTHON — train_test_split
from sklearn.model_selection import train_test_split import pandas as pd # ডেটা লোড করা df = pd.read_csv('base.csv') # ব্যাখ্যামূলক চলরাশি (X) এবং লক্ষ্য চলরাশি (y) আলাদা করা X = df.drop("Response", axis=1) # Response বাদে বাকি সব y = df["Response"] # শুধু Response # Train-Test Split # stratify=y মানে: train এবং test উভয়েই ০ ও ১-এর অনুপাত একই থাকবে # (Class Imbalance থাকলে এটা জরুরি!) X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.25, # ২৫% test-এর জন্য stratify=y, # ← এটা খুব গুরুত্বপূর্ণ! random_state=42 # ফলাফল পুনরুৎপাদনযোগ্য করতে ) print(f"Train size: {X_train.shape}") print(f"Test size: {X_test.shape}")
⚠️ stratify=y কেন দিলাম?

ধরো আমাদের ডেটায় মাত্র ১২% গ্রাহক বীমা নেবে। যদি random split করি, তাহলে হয়তো test set-এ ৫% বা ২০% হয়ে যেতে পারে — এতে ফলাফল ভুল হবে। stratify=y দিলে train ও test উভয়েই একই অনুপাতে ক্লাস থাকবে।

তাই আমাদের ব্যবহার করতে হবে F1 Score — যা উভয় ক্লাসের পারফরম্যান্স মাপে।

🔄 Cross-Validation কী?

Hold-out পদ্ধতিতে একটি সমস্যা আছে: যে ২৫% test set বেছে নেওয়া হয়েছে সেটা যদি "সহজ" হয় তাহলে মডেল ভালো দেখাবে, যদি "কঠিন" হয় তাহলে খারাপ দেখাবে। এটা দূর করতে Cross-Validation ব্যবহার হয়।

প্রতিটি Fold-এ ভিন্ন অংশ Test হিসেবে ব্যবহার হয়। সব Fold-এর গড় স্কোরই চূড়ান্ত পারফরম্যান্স।

১. Supervised এবং Unsupervised Learning-এর পার্থক্য কী? দুটি করে উদাহরণ দাও।
উত্তর দেখো

Supervised: ডেটার সাথে লেবেল/উত্তর দেওয়া থাকে। অ্যালগরিদম ইনপুট ও আউটপুটের মধ্যে সম্পর্ক শেখে।
উদাহরণ: Email spam detection (spam/not spam লেবেল আছে), বীমা নেওয়া পূর্বাভাস।

Unsupervised: কোনো লেবেল নেই। অ্যালগরিদম নিজে প্যাটার্ন বা গ্রুপ খোঁজে।
উদাহরণ: Customer segmentation, Market basket analysis।

২. Classification এবং Regression-এর মধ্যে পার্থক্য ব্যাখ্যা করো।
উত্তর দেখো

Classification: আউটপুট হলো একটি ক্লাস/বিভাগ (discrete)। যেমন: হ্যাঁ/না, বিড়াল/কুকুর/পাখি।

Regression: আউটপুট হলো একটি সংখ্যা (continuous)। যেমন: বাড়ির দাম = ৩৫,০০,০০০ টাকা।

সহজ নিয়ম: "কতটা?" → Regression | "কোন ধরনের?" → Classification

৩. Overfitting কী? এটা কীভাবে detect করা যায়?
উত্তর দেখো

Overfitting: মডেল training data এত ভালো মুখস্থ করে যে নতুন data-তে ভালো করতে পারে না।

Detection: Train accuracy >> Test accuracy হলে overfitting। যেমন: Train = 98%, Test = 65%।

সমাধান: More data, Regularization, Cross-validation, Simpler model

৪. Class imbalance কী? Accuracy কেন এক্ষেত্রে ভালো metric নয়?
উত্তর দেখো

Class Imbalance: Target variable-এর ক্লাসগুলোর মধ্যে বড় পার্থক্য। যেমন: ৯৫% না, ৫% হ্যাঁ।

Accuracy সমস্যা: মডেল সবাইকে "না" বললেও accuracy = 95%! কিন্তু minority class (হ্যাঁ) সম্পূর্ণ miss করছে।

ভালো metrics: F1-Score, Precision, Recall, AUC-ROC

৫. stratify=y কেন train_test_split-এ ব্যবহার করা হয়?
উত্তর দেখো

Class imbalance থাকলে random split-এ train ও test set-এ class distribution ভিন্ন হয়ে যেতে পারে। stratify=y নিশ্চিত করে যে উভয় set-এই প্রতিটি class একই অনুপাতে থাকবে।

📐 IQR পদ্ধতি — Outlier range বের করা

IQR (Interquartile Range) = Q3 - Q1

Valid Range = [Q1 - 1.5×IQR, Q3 + 1.5×IQR]

এর বাইরে মান = সম্ভাব্য Outlier

IQR = Q3 − Q1   |   Range = [Q1 − 1.5·IQR, Q3 + 1.5·IQR]
PYTHON — IQR দিয়ে Outlier খোঁজা
# Age variable-এর outlier বের করা Q1 = train["Age"].quantile(0.25) # নিচের ২৫% সীমা Q3 = train["Age"].quantile(0.75) # উপরের ২৫% সীমা IQR = Q3 - Q1 lower_bound = Q1 - 1.5 * IQR # নিম্ন সীমা upper_bound = Q3 + 1.5 * IQR # উর্ধ্ব সীমা print(f"IQR: {IQR}") print(f"Range: [{lower_bound:.1f}, {upper_bound:.1f}]") # Output: Range: [-11.0, 85.0] # বয়স ১৮-র কম হওয়া সম্ভব না, তাই lower_bound = 18 ধরি outliers = train.loc[(train['Age'] < 18) | (train['Age'] > 85), 'Age'] print(outliers) # কিছু উদাহরণ পাবো যেমন: 2, 2022, 3 # Outlier ঠিক করা (ধারণামূলক সংশোধন) train.loc[97970, 'Age'] = 22 # 2 → 22 (সম্ভবত টাইপো) train.loc[103535, 'Age'] = 64 # 640 → 64 train.loc[147203, 'Age'] = 20 train.loc[240237, 'Age'] = 80 train.loc[352885, 'Age'] = 57

১. IQR পদ্ধতিতে Outlier কীভাবে বের করা হয়? Q1, Q3 কী?
উত্তর দেখো

Q1 (1st Quartile) = ডেটার নিচের ২৫% এর সীমা। Q3 (3rd Quartile) = উপরের ২৫% এর সীমা।

IQR = Q3 - Q1 (মাঝের ৫০% ডেটার বিস্তার)

Outlier = Q1 - 1.5×IQR এর নিচে বা Q3 + 1.5×IQR এর উপরে

এই পদ্ধতি extreme values-এর প্রতি robust কারণ এটি mean বা std ব্যবহার করে না।

কৌশল: যে channel ১২%+ গ্রাহককে আগ্রহী করে → ১ (কার্যকর), বাকি → ০ (অকার্যকর)

📊 Chi-Square Test ও Cramer's V বোঝা

Chi-Square Test: দুটি categorical variable স্বাধীন কিনা পরীক্ষা করে।

H₀: Variables স্বাধীন | H₁: Variables নির্ভরশীল

p-value < 0.05 → H₀ বাতিল → Variables নির্ভরশীল (ভালো!)


Cramer's V: নির্ভরতার শক্তি মাপে (0 থেকে 1):

• ~0.1 → দুর্বল | ~0.3 → মাঝারি | ~0.5+ → শক্তিশালী

V = √( χ² / N × (min(a,b) - 1) )

১. One Hot Encoding (OHE) কী? কেন N-1 column রাখতে হয়?
উত্তর দেখো

OHE categorical variable-কে binary columns-এ রূপান্তরিত করে। N category থেকে N টি columns তৈরি হয়।

N-1 রাখতে হয় কারণ শেষ category অন্যগুলো থেকে predict করা যায় (perfect multicollinearity)। এটা "dummy variable trap" বলে।

উদাহরণ: [Red, Green, Blue] → is_Red, is_Green (Blue drop করো)

২. Min-Max Normalization ও Z-Score Standardization কখন কোনটি ব্যবহার করবে?
উত্তর দেখো

Min-Max: Data normal distribution follow করে না, neural network বা KNN ব্যবহার করছো, fixed range দরকার।

Z-Score: Data normal/Gaussian distribution follow করে, Linear models (Logistic Regression, SVM) ব্যবহার করছো।

Robust: Outlier আছে — median ও IQR ব্যবহার করে বলে outlier-এর প্রভাব কম।

৩. কেন scaler.fit_transform() শুধু train data-তে করতে হয়?
উত্তর দেখো

Scaler fit করার মানে mean, std, min, max ইত্যাদি হিসেব করা। যদি test data দিয়ে fit করা হয়, তাহলে test data-র তথ্য (future information) training-এ ঢুকে যায় → Data Leakage।

সঠিক পদ্ধতি: scaler.fit_transform(X_train) তারপর scaler.transform(X_test)

৪. Cramer's V কীভাবে variable selection-এ সাহায্য করে?
উত্তর দেখো

Cramer's V দুটি categorical variable-এর মধ্যে association strength পরিমাপ করে। একটি variable ও target variable-এর মধ্যে Cramer's V বেশি হলে সেই feature model-এর জন্য বেশি তথ্যপূর্ণ।

Rule of thumb: 0.1+ হলে variable রাখো।

📐 ধাপ (f): Odds Ratio — সহজ ব্যাখ্যা

Coefficient সরাসরি বোঝা কঠিন। Odds Ratio (OR) হলো coefficient-এর exponential — এটা বলে কোনো variable কত গুণ সম্ভাবনা পরিবর্তন করে।

🧮 Formula: OR = e^(coefficient)

যদি OR = 7 হয়, মানে সেই variable থাকলে সম্ভাবনা 7 গুণ বেড়ে যায়।
যদি negative coefficient হয়: -1/OR ব্যবহার করি — যেমন -52 মানে 52 গুণ কমে।

def crossvalidation_resample(X, y, model):
    for name, resample in {
        "Smote": SMOTE(),
        "Oversampling": RandomOverSampler(sampling_strategy='not majority'),
        "Undersampling": RandomUnderSampler(sampling_strategy='majority')
    }.items():
        skf = StratifiedKFold(n_splits=5)
        f_score = []

        for tr_idx, te_idx in skf.split(X_train, y_train):
            X_tr, y_tr = X_train.loc[tr_idx], y_train.loc[tr_idx]
            X_te, y_te = X_train.loc[te_idx], y_train.loc[te_idx]

            # ⚠️ শুধু TRAIN PART-এ resampling! Test-এ নয়!
            X_res, y_res = resample.fit_resample(X_tr, y_tr)

            model.fit(X_res, y_res)
            y_pred = model.predict(X_te)
            f_score.append(f1_score(y_pred, y_te))

        print(f"{name}: avg F1 = {np.mean(f_score):.5f}")

class InferencePipeline:
    def __init__(self, model, scaler, threshold=0.68, low=0.40, high=0.75):
        self.model = model
        self.scaler = scaler
        self.threshold = threshold
        self.low = low
        self.high = high

    def preprocess(self, df):
        # transform only — never fit on new data!
        return self.scaler.transform(df)

    def predict_proba(self, df):
        return self.model.predict_proba(self.preprocess(df))[:, 1]

    def predict_batch(self, df):
        proba = self.predict_proba(df)
        result = df.copy()
        result['subscription_probability'] = proba
        result['contact_recommended'] = (proba >= self.low) & (proba <= self.high)
        result['predicted_class'] = (proba >= self.threshold).astype(int)
        return result[['subscription_probability', 'contact_recommended', 'predicted_class']]

"""
Complete ML Engineering Pipeline
Insurance Cross-Sell Prediction
"""
import pandas as pd
import numpy as np
from sklearn.model_selection import StratifiedKFold, train_test_split
from sklearn.preprocessing import MinMaxScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import f1_score, classification_report
from imblearn.over_sampling import SMOTE
import warnings; warnings.filterwarnings('ignore')

# ===== STEP 1: Simulated Insurance Data =====
np.random.seed(42)
n = 5000
data = pd.DataFrame({
    'Vehicle_Damage'    : np.random.choice([0,1], n, p=[0.5,0.5]),
    'Previously_Insured': np.random.choice([0,1], n, p=[0.54,0.46]),
    'Age'               : np.random.uniform(20, 85, n),
    'Annual_Premium'    : np.random.uniform(24421, 39411, n),
    'Driving_License'   : np.random.choice([0,1], n, p=[0.03,0.97]),
})
log_odds = (-2.0 + 2.5*data['Vehicle_Damage']
            - 3.8*data['Previously_Insured']
            + 0.02*(data['Age']-40)
            + 0.5*data['Driving_License'])
prob = 1/(1+np.exp(-log_odds))
data['Response'] = (np.random.uniform(0,1,n) < prob).astype(int)
print(f"Class dist: {data['Response'].value_counts(normalize=True).round(2).to_dict()}")

# ===== STEP 2: Preprocessing =====
X = data.drop('Response', axis=1)
y = data['Response']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)

scaler = MinMaxScaler()
X_tr_s = pd.DataFrame(scaler.fit_transform(X_train), columns=X.columns, index=X_train.index)
X_te_s = pd.DataFrame(scaler.transform(X_test),      columns=X.columns, index=X_test.index)

# ===== STEP 3: Threshold Optimization via CV =====
def find_optimal_threshold(X_tr, y_tr, model_cls):
    skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
    thresholds_cv = []
    for tr_i, va_i in skf.split(X_tr, y_tr):
        Xtr, ytr = X_tr.iloc[tr_i], y_tr.iloc[tr_i]
        Xva, yva = X_tr.iloc[va_i], y_tr.iloc[va_i]
        Xr, yr = SMOTE(random_state=42).fit_resample(Xtr, ytr)
        m = model_cls().fit(Xr, yr)
        probs = m.predict_proba(Xva)[:, 1]
        ts = np.arange(0.01, 0.99, 0.01)
        scores = [f1_score(yva, (probs>=t).astype(int), zero_division=0) for t in ts]
        thresholds_cv.append(ts[np.argmax(scores)])
    return round(float(np.mean(thresholds_cv)), 3)

opt_t = find_optimal_threshold(X_tr_s, y_train, LogisticRegression)
print(f"Optimal threshold: {opt_t}")

# ===== STEP 4: Final Training =====
Xr, yr = SMOTE(random_state=42).fit_resample(X_tr_s, y_train)
final_model = LogisticRegression(max_iter=1000, random_state=42).fit(Xr, yr)

# ===== STEP 5: Evaluation =====
y_probs = final_model.predict_proba(X_te_s)[:, 1]
y_pred  = (y_probs >= opt_t).astype(int)
print(classification_report(y_test, y_pred))

# ===== STEP 6: Business Recommendation =====
contact_mask = (y_probs >= 0.40) & (y_probs <= 0.75)
pct = contact_mask.mean()
savings = 10000 * (0.43 - pct) * 30
print(f"Contact: {pct:.1%} | Savings (10K): €{savings:,.0f}")

১. Bias-Variance Tradeoff কী? এটা ML-এর মূল সমস্যার সাথে কীভাবে সম্পর্কিত?
বিস্তারিত উত্তর দেখো

Bias: মডেল কতটা সরলীকৃত ধারণা নিয়ে কাজ করে। বেশি bias = Underfitting।

Variance: Training data পরিবর্তন হলে মডেল কতটা পরিবর্তিত হয়। বেশি variance = Overfitting।

Tradeoff: Bias কমালে variance বাড়ে এবং উল্টো। সর্বোত্তম মডেল দুটির মধ্যে সামঞ্জস্য রাখে।

সমাধান: Cross-validation, Regularization (L1/L2), Ensemble methods

২. L1 (Lasso) এবং L2 (Ridge) Regularization-এর পার্থক্য কী? কখন কোনটি?
বিস্তারিত উত্তর দেখো

L1 (Lasso): |weights| যোগ করে loss-এ। কিছু weights শূন্য করে দেয় → automatic feature selection।

L2 (Ridge): weights² যোগ করে। সব weights ছোট করে কিন্তু শূন্য করে না।

L1 ব্যবহার করো: অনেক irrelevant features থাকলে, sparse model চাইলে।

L2 ব্যবহার করো: সব features কম-বেশি গুরুত্বপূর্ণ, multicollinearity থাকলে।

ElasticNet = L1 + L2 মিলিয়ে।

৩. Bagging vs Boosting কী? Random Forest কোন ধরনের?
বিস্তারিত উত্তর দেখো

Bagging (Bootstrap Aggregating): সমান্তরালে অনেক model train করে, vote নেয়। Variance কমায়। Random Forest = Bagging + random feature selection।

Boosting: ক্রমানুসারে model train করে, আগের model-এর ভুল শেখায়। Bias কমায়। XGBoost, AdaBoost, LightGBM = Boosting।

Stacking = Meta-learning — দুটোর prediction কে নতুন features হিসেবে ব্যবহার।

৪. Hyperparameter tuning-এর কৌশলগুলো কী কী? GridSearch vs RandomSearch?
বিস্তারিত উত্তর দেখো

GridSearchCV: সব parameter combination চেষ্টা করে। ছোট search space-এর জন্য ভালো।

RandomizedSearchCV: Random combination চেষ্টা করে। বড় search space-এর জন্য efficient।

Bayesian Optimization (Optuna/Hyperopt): আগের ফলাফল থেকে শিখে smart search করে। সবচেয়ে efficient।

সাধারণ নিয়ম: প্রথমে RandomSearch দিয়ে promising range খোঁজো, তারপর GridSearch দিয়ে fine-tune করো।

৫. AUC-ROC কী? ০.৫ এবং ১.০ মানে কী?
বিস্তারিত উত্তর দেখো

ROC Curve: True Positive Rate (Recall) vs False Positive Rate-এর curve। AUC = এই curve-এর নিচের ক্ষেত্রফল।

AUC = 0.5 → মডেল random guess-এর মতোই (worst)

AUC = 1.0 → নিখুঁত মডেল (সব সঠিক)

AUC = 0.7+ → মোটামুটি ভালো

AUC = 0.9+ → খুব ভালো

Class Imbalance থাকলে AUC-ROC বরং PR-AUC (Precision-Recall) বেশি informative।

# ============================================= # প্রজেক্ট ১: সম্পূর্ণ ML Pipeline # ============================================= import pandas as pd import numpy as np import matplotlib.pyplot as plt import seaborn as sns from sklearn.model_selection import train_test_split, cross_val_score from sklearn.pipeline import Pipeline from sklearn.preprocessing import RobustScaler from sklearn.impute import SimpleImputer from sklearn.compose import ColumnTransformer from sklearn.ensemble import RandomForestClassifier from sklearn.metrics import classification_report, roc_auc_score import warnings warnings.filterwarnings('ignore') # ---- ধাপ ১: ডেটা লোড ও প্রাথমিক পরিদর্শন ---- df = pd.read_csv('base.csv') print("ডেটার আকার:", df.shape) print("\nMissing values:\n", df.isna().sum()) # ---- ধাপ ২: Feature Engineering ---- # Date conversion df['Vehicle_Date'] = pd.to_datetime(df['Vehicle_Date'], unit='s') df['Vehicle_Age_Years'] = 2019 - df['Vehicle_Date'].dt.year # Signature_Date মুছে দাও (data leakage) df = df.drop(['Signature_Date', 'Vehicle_Date', 'id'], axis=1) # ---- ধাপ ৩: X, y বিভাজন ও Train-Test Split ---- X = df.drop('Response', axis=1) y = df['Response'] X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, stratify=y, random_state=42 ) print(f"Train: {X_train.shape}, Test: {X_test.shape}") # ---- ধাপ ৪: Preprocessing Pipeline ---- numeric_features = ['Age', 'Annual_Premium', 'Vintage', 'Vehicle_Age_Years'] categorical_features = ['Gender', 'Driving_License', 'Previously_Insured', 'Vehicle_Damage', 'Region_Code', 'Policy_Sales_Channel'] # Numeric transformer numeric_transformer = Pipeline([ ('imputer', SimpleImputer(strategy='median')), ('scaler', RobustScaler()) ]) # Categorical transformer categorical_transformer = Pipeline([ ('imputer', SimpleImputer(strategy='most_frequent')) ]) # ColumnTransformer — দুটো এক সাথে preprocessor = ColumnTransformer([ ('num', numeric_transformer, numeric_features), ('cat', categorical_transformer, categorical_features) ]) # ---- ধাপ ৫: Full Pipeline ---- full_pipeline = Pipeline([ ('preprocessor', preprocessor), ('classifier', RandomForestClassifier( n_estimators=200, max_depth=15, class_weight='balanced', n_jobs=-1, random_state=42 )) ]) # ---- ধাপ ৬: Train ও Evaluate ---- full_pipeline.fit(X_train, y_train) y_pred = full_pipeline.predict(X_test) y_proba = full_pipeline.predict_proba(X_test)[:, 1] print("\n=== চূড়ান্ত মূল্যায়ন ===") print(classification_report(y_test, y_pred)) print(f"AUC-ROC: {roc_auc_score(y_test, y_proba):.4f}")

from sklearn.model_selection import RandomizedSearchCV from scipy.stats import randint, uniform import time # Search space সংজ্ঞায়িত করা param_distributions = { 'classifier__n_estimators': randint(100, 500), 'classifier__max_depth': [5, 10, 15, 20, None], 'classifier__min_samples_leaf': randint(1, 50), 'classifier__max_features': ['sqrt', 'log2', 0.5], } # RandomizedSearchCV তৈরি random_search = RandomizedSearchCV( full_pipeline, param_distributions=param_distributions, n_iter=30, # ৩০টি random combination চেষ্টা cv=5, # 5-Fold Cross-Validation scoring='f1', # F1 maximize করো n_jobs=-1, random_state=42, verbose=1 ) # Search চালানো start = time.time() random_search.fit(X_train, y_train) elapsed = time.time() - start print(f"সময় লেগেছে: {elapsed:.1f} সেকেন্ড") print(f"সেরা CV F1: {random_search.best_score_:.4f}") print(f"সেরা parameters: {random_search.best_params_}") # Final evaluation best_model = random_search.best_estimator_ y_pred_best = best_model.predict(X_test) print("\nSolution Classification Report:") print(classification_report(y_test, y_pred_best))

from sklearn.linear_model import LogisticRegression from sklearn.tree import DecisionTreeClassifier from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier from sklearn.metrics import f1_score, roc_auc_score, precision_score, recall_score # সব মডেলের dictionary models = { 'Logistic Regression': LogisticRegression(class_weight='balanced', max_iter=1000), 'Decision Tree': DecisionTreeClassifier(max_depth=8, class_weight='balanced'), 'Random Forest': RandomForestClassifier(n_estimators=100, class_weight='balanced', n_jobs=-1), 'Gradient Boosting': GradientBoostingClassifier(n_estimators=100), } # প্রতিটি মডেলের জন্য pipeline তৈরি ও evaluation results = [] for name, clf in models.items(): # Pipeline তৈরি pipe = Pipeline([ ('preprocessor', preprocessor), ('classifier', clf) ]) # Train pipe.fit(X_train, y_train) y_pred = pipe.predict(X_test) # Metrics results.append({ 'Model': name, 'F1 Score': f1_score(y_test, y_pred), 'Precision': precision_score(y_test, y_pred), 'Recall': recall_score(y_test, y_pred), 'AUC-ROC': roc_auc_score(y_test, pipe.predict_proba(X_test)[:, 1]) }) print(f"{name}: F1={results[-1]['F1 Score']:.4f}, AUC={results[-1]['AUC-ROC']:.4f}") # DataFrame এ রূপান্তর ও সাজানো results_df = pd.DataFrame(results).sort_values('F1 Score', ascending=False) print("\n=== মডেল তুলনা ===") print(results_df.to_string(index=False)) # Visualization results_df.set_index('Model')[['F1 Score', 'Precision', 'Recall']].plot( kind='bar', figsize=(10, 5), color=['#00d4ff', '#06d6a0', '#ff6b9d'] ) plt.title('মডেল পারফরম্যান্স তুলনা', fontsize=14) plt.xticks(rotation=45) plt.tight_layout() plt.savefig('model_comparison.png', dpi=200) plt.show()
