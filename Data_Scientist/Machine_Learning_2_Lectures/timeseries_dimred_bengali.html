সময়ের সাথে সংগ্রহ করা ডেটা বিশ্লেষণের সম্পূর্ণ পদ্ধতি

// ০১

টাইম সিরিজের ৩টি উপাদান

যেকোনো টাইম সিরিজকে তিনটি অংশে ভাগ করা যায়। এই তিনটি অংশ মিলিয়েই পুরো সিরিজ তৈরি হয়।

📈 ট্রেন্ড

ডেটার দীর্ঘমেয়াদী গতিবিধি। ধীরে ধীরে ওপরে যাচ্ছে নাকি নিচে নামছে?

উদাহরণ: বাংলাদেশের জনসংখ্যা প্রতি বছর বাড়ছে — এটা ঊর্ধ্বমুখী ট্রেন্ড।

f(x) = -2.2x + 5

🔄 সিজনালিটি

নির্দিষ্ট সময় পরপর একই ধরনের পরিবর্তন। এটা পূর্বাভাসযোগ্য।

উদাহরণ: রমজান মাসে খাবারের দোকানের বিক্রি সন্ধ্যায় অনেক বেড়ে যায়।

sin(2πx/365) · cos(...)

🎲 নয়েজ

সম্পূর্ণ এলোমেলো পরিবর্তন। কোনো নিয়ম নেই, পূর্বাভাস দেওয়া সম্ভব নয়।

উদাহরণ: কোনো একদিন হঠাৎ ঝড়ের কারণে বিক্রি কমে গেল।

Normal(μ=3, σ=2)
💡
মজার বিষয়!

সূর্যের কলঙ্ক (Sunspots) গণনার ডেটা দিয়ে এই মাস্টারক্লাসে প্র্যাকটিস করা হয়েছে। ১৭০০ সাল থেকে এই ডেটা সংগ্রহ হচ্ছে! এটা একটা প্রাকৃতিক টাইম সিরিজের চমৎকার উদাহরণ।

// ০২

Additive বনাম Multiplicative মডেল

দুটো ভিন্ন ধরনের মডেল আছে। কোনটা ব্যবহার করব সেটা ডেটার চেহারা দেখে বুঝতে পারব।

➕
Additive — যখন ব্যবহার করব

যখন সিজনালিটির তরঙ্গের উচ্চতা সময়ের সাথে একই থাকে। তাপমাত্রার ডেটায় সাধারণত এটাই দেখা যায়।

✖️
Multiplicative — যখন ব্যবহার করব

যখন সিজনালিটির তরঙ্গ সময়ের সাথে বড় হতে থাকে। শেয়ার বাজারের ডেটায় প্রায়ই এটা দেখা যায়।

Python — টাইম সিরিজ তৈরি করা 
# প্রয়োজনীয় লাইব্রেরি আমদানি করি
import numpy as np
import matplotlib.pyplot as plt

# ① ট্রেন্ড তৈরি — একটা সরল রেখার সমীকরণ f(x) = -2.2x + 5
# 1095 মানে ৩ বছরের দিন (৩×৩৬৫)
trend = -2.2 * np.array(range(1095)) + 5

# ② সিজনালিটি তৈরি — সাইন ও কোসাইন দিয়ে
# /365 দিলে বার্ষিক চক্র পাওয়া যায়
period = np.array([
    160 * np.sin(2 * np.pi / 365 * x) + 80 * np.cos(2 * np.pi / 100 * x)
    for x in range(0, 1095)
])

# ③ নয়েজ তৈরি — র্যান্ডম সংখ্যা (গড়=৩, স্ট্যান্ডার্ড ডেভিয়েশন=২)
white_noise = np.random.normal(3, 2, size=1095)

# Additive মডেল: সব কিছু যোগ করি
series_additive = trend + period + white_noise

# Multiplicative মডেল: গুণ করি
series_multiplicative = trend * (1 + period) * (1 + white_noise)
🤔
সহজ মনে রাখার উপায়

যদি তরঙ্গের উচ্চতা সব জায়গায় সমান হয় → Additive। যদি ডানদিকে গেলে তরঙ্গ বড় হয় → Multiplicative। একটা পাখা বন্ধ (Additive) বনাম পাখা খোলা (Multiplicative) — এভাবে মনে রাখো!

// ০৩

স্থিতিশীলতা (Stationarity)

টাইম সিরিজ বিশ্লেষণের সবচেয়ে গুরুত্বপূর্ণ ধারণা। মডেল তৈরির আগে এটা বুঝতেই হবে।

🎯 Stationarity মানে কী?

একটা টাইম সিরিজ স্থিতিশীল (stationary) তখন বলা হয় যখন:

  • ১
    ডেটার গড় (mean) সময়ের সাথে একই থাকে — বাড়ে না, কমে না
  • ২
    ডেটার বিচ্ছুরণ (variance) সময়ের সাথে একই থাকে
  • ৩
    দুটো সময়ের মধ্যে সম্পর্ক (covariance) শুধু তাদের মাঝের ব্যবধানের উপর নির্ভর করে

🧪 ADF Test — স্থিতিশীলতা পরীক্ষা করার উপায়

Augmented Dickey-Fuller (ADF) Test হলো একটি পরিসংখ্যানগত পরীক্ষা যা বলে দেয় সিরিজটি stationary কিনা।

নিয়ম
p-value < ০.০৫ → Stationary ✅  |  p-value ≥ ০.০৫ → Non-Stationary ❌
Python — ADF Test 
from statsmodels.tsa.stattools import adfuller

# ADF test চালাই
_, p_value, _, _, _, _ = adfuller(sunspots)
print(p_value)  # যদি > 0.05 হয়, মানে Non-Stationary

# সমাধান: Differencing — পার্থক্য বের করা
# X_t - X_(t-1) = Z_t (নতুন স্থিতিশীল সিরিজ)
sunspots_diff = sunspots.diff().dropna()

_, p_value, _, _, _, _ = adfuller(sunspots_diff)
print(p_value)  # এখন < 0.05, মানে Stationary ✅
💡
Differencing কী?

প্রতিটি মান থেকে আগের মান বিয়োগ করলে ট্রেন্ড দূর হয়ে যায় এবং সিরিজ স্থিতিশীল হয়। যেমন: সোমবার ১০০, মঙ্গলবার ১০৫ → পার্থক্য = ৫। এভাবে সব মানের পার্থক্য নিলে নতুন সিরিজ পাওয়া যায়।

// ০৪

AR, MA, ARMA, এবং ARIMA মডেল

এই মডেলগুলো টাইম সিরিজের ভবিষ্যৎ মান পূর্বাভাস দিতে পারে। একটা একটা করে বুঝি।

🔁 AR (Autoregressive) মডেল

AR মানে নিজের উপর নিজের রিগ্রেশন। সহজ কথায়: আজকের মান নির্ধারিত হয় আগের কিছু মানের উপর ভিত্তি করে।

🏠
বাস্তব উদাহরণ

কাল আবহাওয়া কেমন হবে? সম্ভবত আজকের আবহাওয়ার মতোই, হয়তো একটু কম বা বেশি। অর্থাৎ আগের দিনের তাপমাত্রা থেকে আগামী দিনের পূর্বাভাস দেওয়া যায়।

AR(p) — p টি আগের মান ব্যবহার করে
X_t = φ₀ + φ₁·X_{t-1} + φ₂·X_{t-2} + ... + φ_p·X_{t-p} + ε_t

ব্যাখ্যা:

  • φ
    φ (phi) হলো গুণাংক — কতটুকু প্রভাব আছে আগের মানের
  • p
    p হলো কতটি আগের মান ব্যবহার করব। AR(1) মানে শুধু ১টি আগের মান।
  • ε
    ε (epsilon) হলো নয়েজ — যা ব্যাখ্যা করা যায় না
AR(1) — শুধু ১টি আগের মান
X_t = φ₀ + φ₁·X_{t-1} + ε_t

📊 MA (Moving Average) মডেল

MA মানে ত্রুটির (error) উপর রিগ্রেশন। আগের পূর্বাভাসের ভুল থেকে শিক্ষা নিয়ে পরবর্তী মান বের করা।

🎯
বাস্তব উদাহরণ

মনে করো তুমি প্রতিদিন বিক্রির পূর্বাভাস দাও। যদি গতকাল তোমার পূর্বাভাস ৫০টি বেশি ছিল, তাহলে আজ তুমি সেই ভুল মাথায় রেখে পূর্বাভাস দেবে।

MA(q) — q টি আগের ত্রুটি ব্যবহার করে
X_t = ε_t + θ₁·ε_{t-1} + θ₂·ε_{t-2} + ... + θ_q·ε_{t-q}

ব্যাখ্যা:

  • θ
    θ (theta) হলো ত্রুটির গুণাংক
  • q
    q হলো কতটি আগের ত্রুটি ব্যবহার করব
  • ε
    ε = আসল মান − পূর্বাভাসিত মান (ত্রুটি)

🔗 ARMA মডেল — AR + MA একসাথে

ARMA হলো AR এবং MA মডেলের মিশ্রণ। Stationary সিরিজের জন্য ব্যবহার করা হয়।

ARMA(p, q)
X_t = φ₀ + φ₁X_{t-1} + ... + φ_pX_{t-p} + ε_t + θ₁ε_{t-1} + ... + θ_qε_{t-q}
📝
ARMA(1,1) উদাহরণ

X_t = φ₀ + φ₁X_{t-1} + ε_t + θ₁ε_{t-1} — এখানে ১টি আগের মান এবং ১টি আগের ত্রুটি ব্যবহার হচ্ছে।

⚠️
সতর্কতা

ARMA শুধুমাত্র Stationary সিরিজে কাজ করে। যদি সিরিজে ট্রেন্ড থাকে (non-stationary), তাহলে ARIMA ব্যবহার করতে হবে।

⚡ ARIMA মডেল — Non-Stationary সিরিজের সমাধান

ARIMA = AR + I + MA। "I" মানে Integration — Differencing কতবার করা হয়েছে।

ARIMA(p, d, q) — তিনটি প্যারামিটার
p = AR অর্ডার  |  d = Differencing সংখ্যা  |  q = MA অর্ডার
  • p
    কতটি আগের মান ব্যবহার করব। PACF গ্রাফ দেখে নির্ধারণ করা হয়।
  • d
    কতবার Differencing করতে হয়েছে Stationary করতে। সাধারণত ১ বা ২।
  • q
    কতটি আগের ত্রুটি ব্যবহার করব। ACF গ্রাফ দেখে নির্ধারণ করা হয়।
Python — ARIMA মডেল তৈরি 
import itertools
from statsmodels.tsa.arima.model import ARIMA

# সম্ভাব্য p ও q এর মান
p = range(0, 6)   # ০ থেকে ৫
q = range(0, 6)   # ০ থেকে ৫
d = [1]          # ১ বার differencing করা হয়েছিল

# সব সম্ভাব্য কম্বিনেশন
pdq = list(itertools.product(p, d, q))

# সেরা মডেল খোঁজা (BIC দিয়ে)
best_bic = float("inf")
for order in pdq:
    model = ARIMA(sunspots['SUNACTIVITY'], order=order).fit()
    if model.bic < best_bic:
        best_bic = model.bic
        best_order = order

print(f"সেরা মডেল: ARIMA{best_order}")
# ফলাফল: ARIMA(2, 1, 2) — BIC অনুযায়ী
📊
কোন Information Criterion ব্যবহার করব?

BIC — ব্যাখ্যামূলক মডেলের জন্য (Explanatory) — সহজ মডেল পছন্দ করে
AIC — পূর্বাভাসের জন্য (Predictive) — জটিল মডেলও নেয়
HQIC — দুটোর মাঝামাঝি
সংখ্যা যত কম, মডেল তত ভালো!

// ০৫

ACF ও PACF গ্রাফ

p ও q এর মান নির্ধারণ করতে এই দুটি গ্রাফ ব্যবহার করা হয়।

📉 ACF — Autocorrelation Function

ACF দেখায় একটি সিরিজের বর্তমান মানের সাথে তার বিভিন্ন আগের মানের সম্পর্ক (correlation) কতটুকু।

এটা q (MA অর্ডার) নির্ধারণে সাহায্য করে।

📏

যদি ACF গ্রাফে lag x এর পর হঠাৎ শূন্যের কাছাকাছি চলে আসে → q = x−1

📉 PACF — Partial Autocorrelation

PACF দেখায় বর্তমান মানের সাথে একটি নির্দিষ্ট আগের মানের সরাসরি সম্পর্ক (মাঝের প্রভাব বাদ দিয়ে)।

এটা p (AR অর্ডার) নির্ধারণে সাহায্য করে।

📏

যদি PACF গ্রাফে lag x এর পর হঠাৎ শূন্যের কাছাকাছি চলে আসে → p = x−1

Python — ACF ও PACF প্লট 
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

plt.figure(figsize=(12, 6))

# ACF প্লট — MA অর্ডার (q) নির্ধারণের জন্য
plt.subplot(1, 2, 1)
plot_acf(sunspots_diff, lags=40, ax=plt.gca())
plt.title('ACF')

# PACF প্লট — AR অর্ডার (p) নির্ধারণের জন্য
plt.subplot(1, 2, 2)
plot_pacf(sunspots_diff, lags=40, ax=plt.gca())
plt.title('PACF')

plt.tight_layout()
plt.show()

PCA — Principal Component Analysis

সবচেয়ে জনপ্রিয় ডাইমেনশনালিটি রিডাকশন পদ্ধতি। তথ্য না হারিয়ে মাত্রা কমানো।

🧮 PCA কীভাবে কাজ করে?

PCA নতুন অক্ষ খুঁজে বের করে যেগুলো ডেটার মধ্যে সবচেয়ে বেশি বৈচিত্র্য ধারণ করে।

📐 Principal Component (PC) কী?

PC হলো নতুন অক্ষ যা PCA তৈরি করে।

  • PC1
    প্রথম অক্ষ — সবচেয়ে বেশি variance ধারণ করে
  • PC2
    দ্বিতীয় অক্ষ — PC1 এর লম্ব (orthogonal), দ্বিতীয় সর্বোচ্চ variance
  • ...
    এভাবে চলতে থাকে

🎯 PCA কী সংরক্ষণ করে?

PCA মূল ডেটার দূরত্ব সম্পর্ক যতটা সম্ভব বজায় রাখে।

কাছের পয়েন্ট → নতুন স্থানেও কাছে থাকে।

দূরের পয়েন্ট → নতুন স্থানেও দূরে থাকে।

Variance ব্যাখ্যা = ব্যবহৃত PC এর eigenvalue / মোট eigenvalue
Python — Prince লাইব্রেরি দিয়ে PCA 
import prince

# PCA তৈরি করি — ২টি principal component দিয়ে
# n_components=2 মানে ১৪ মাত্রা → ২ মাত্রায় নামাব
pca = prince.PCA(n_components=2)
pca = pca.fit(choco)  # চকোলেট ডেটায় PCA শেখাই

# ব্যক্তি গ্রাফ (Individuals graph) — প্রতিটি চকোলেট নতুন স্থানে
row_coords = pca.row_coordinates(choco)

# গ্রাফে দেখাই
fig, ax = plt.subplots()
ax.scatter(row_coords[0], row_coords[1])

# চকোলেটের নাম লেবেল হিসেবে যোগ করি
for i, label in enumerate(choco.index):
    ax.annotate(label, (row_coords.iloc[i, 0], row_coords.iloc[i, 1]))

plt.show()

🔵 Correlation Circle — কোন বৈশিষ্ট্য কোন দিকে টানছে?

Correlation Circle দেখায় প্রতিটি বৈশিষ্ট্য (attribute) PC1 ও PC2 এর সাথে কতটা সম্পর্কিত।

🔍
কীভাবে পড়বে?

বাম দিকের তীর → চকোলেট ডার্ক ধরনের (বেশি কোকো, তিক্ততা)। ডান দিকের তীর → মিল্ক ধরনের (মিষ্টি, দুধ)। দুটো তীর কাছাকাছি থাকলে সেই দুটো বৈশিষ্ট্য একসাথে বাড়ে/কমে।

Python — Correlation Circle 
# প্রতিটি বৈশিষ্ট্যের PC1 ও PC2 এর সাথে correlation
corr = pca.column_correlations
display(corr)

# Correlation Circle আঁকা
fig, axes = plt.subplots(figsize=(10, 10))
axes.set_xlim(-1, 1)
axes.set_ylim(-1, 1)

for j in choco.columns:
    # প্রতিটি বৈশিষ্ট্যের জন্য তীর আঁকি
    plt.annotate(j, (corr.loc[j, 0], corr.loc[j, 1]))
    plt.arrow(0, 0, corr.loc[j, 0]*0.95, corr.loc[j, 1]*0.95,
             head_width=0.03, color='b')

# বৃত্ত যোগ করি
cercle = plt.Circle((0, 0), 1, color='cyan', fill=False)
axes.add_artist(cercle)
plt.show()

PCA এর সীমাবদ্ধতা

PCA ধরে নেয় সব সম্পর্ক রৈখিক (linear)। যদি ডেটায় জটিল, অরৈখিক সম্পর্ক থাকে — PCA ঠিকমতো কাজ করে না। তখন UMAP বা t-SNE ব্যবহার করতে হয়।

// ০৮

UMAP — আরও শক্তিশালী পদ্ধতি

যখন PCA কাজ করে না, তখন UMAP ব্যবহার করা হয়।

🗺️ UMAP কী?

Uniform Manifold Approximation and Projection — একটি শক্তিশালী ডাইমেনশনালিটি রিডাকশন পদ্ধতি।

🧩
সহজ ব্যাখ্যা

কল্পনা করো তুমি পৃথিবীর একটা ম্যাপ আঁকছ। পৃথিবী গোলাকার (৩D), কিন্তু ম্যাপ সমতল (২D)। UMAP ঠিক এই কাজটাই করে — উচ্চ মাত্রার ডেটাকে কম মাত্রায় "ম্যাপ" করে।

⚙️ UMAP এর গুরুত্বপূর্ণ প্যারামিটার

👥
n_neighbors

প্রতিটি পয়েন্ট কতটি প্রতিবেশী দেখে। বেশি হলে → global structure। কম হলে → local structure।

📏
min_dist

প্রজেকশন স্থানে পয়েন্টগুলোর ন্যূনতম দূরত্ব। কম মান → ঘন ক্লাস্টার। বেশি মান → বিস্তৃত।

Python — UMAP on Fashion MNIST 
import umap
import pandas as pd

# Zalando Fashion MNIST ডেটাসেট লোড করি
# ৬০,০০০টি পোশাকের ছবি, প্রতিটি ২৮×২৮ পিক্সেল = ৭৮৪ বৈশিষ্ট্য!
df = pd.read_csv('fashion-mnist_train.csv')

target = df['label']           # ০-৯: পোশাকের ধরন
data = df.drop('label', axis=1)  # ৭৮৪ পিক্সেল বৈশিষ্ট্য

# UMAP মডেল তৈরি
umap_model = umap.UMAP(
    n_neighbors=15,   # ১৫ প্রতিবেশী দেখবে
    min_dist=0.1,     # কাছাকাছি পয়েন্ট আরও কাছে
    n_components=2   # ৭৮৪ মাত্রা → ২ মাত্রা
)

# ৭৮৪ মাত্রা থেকে ২ মাত্রায় নামানো
embedding = umap_model.fit_transform(data)

# ফলাফল দেখাই — রঙ দিয়ে পোশাকের ধরন বোঝাব
plt.figure(figsize=(10, 8))
plt.scatter(embedding[:, 0], embedding[:, 1], c=target)
plt.title("UMAP — ৭৮৪ মাত্রা থেকে ২ মাত্রায়")
plt.show()
