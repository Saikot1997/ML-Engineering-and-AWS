📘 বইয়ের উদাহরণ — Alice ও The Hobbit

Alice কে জিজ্ঞেস করা হলো সে কী ধরনের বই পছন্দ করে। সে বলল — Adventure পছন্দ না, Romance পছন্দ। তার পছন্দ লেখা যায়:

Alice = (Adventure: 0, Romance: 4) → ভেক্টর: [0, 4]

এখন The Hobbit বইটা দেখি — এতে Romance নেই, কিন্তু Adventure প্রচুর:

The Hobbit = (Adventure: 5, Romance: 0) → ভেক্টর: [5, 0]

এখন হিসাব করি — Alice কি The Hobbit পছন্দ করবে? Dot Product ব্যবহার করি:

(0 × 5) + (4 × 0) = 0 + 0 = 0

Score = 0 মানে Alice-এর The Hobbit পছন্দ হওয়ার সম্ভাবনা খুবই কম! এটাই Content-Based Filtering।

🔍
TF-IDF কী? — সহজ ভাষায়

TF (Term Frequency): একটি শব্দ একটি বইয়ে কতবার আছে।
IDF (Inverse Document Frequency): শব্দটি কতটা বিরল। সব বইয়ে থাকলে কম গুরুত্বপূর্ণ।
TF-IDF = TF × IDF: যে শব্দটি একটি বইয়ে বেশি কিন্তু অন্যত্র কম — সেটা সেই বইয়ের পরিচায়ক।
যেমন "magic" শব্দটি Harry Potter-এ বেশি — এটা Harry Potter-এর বৈশিষ্ট্য।

Python ধাপ ৪: Recommendation Function 
from tabulate import tabulate

def recommendations(title, mat_sim, num_recommendations=10):
    """
    একটি বইয়ের জন্য সবচেয়ে মিলে যাওয়া বইগুলো খুঁজে বের করা
    
    Parameters:
        title: যে বইয়ের সাথে মিলাবো
        mat_sim: similarity matrix (cosine বা euclidean)
        num_recommendations: কতটি সুপারিশ চাই
    """
    # ১. বইটির index বের করা
    idx = indices[title]
    
    # ২. এই বইয়ের সাথে অন্য সব বইয়ের similarity score সংগ্রহ
    # enumerate ব্যবহার করি যাতে (index, score) tuple পাই
    similarity_scores = list(enumerate(mat_sim[idx]))
    
    # ৩. Score অনুযায়ী সাজানো (বেশি থেকে কম)
    similarity_scores = sorted(similarity_scores, key=lambda x: x[1], reverse=True)
    
    # ৪. প্রথম বাদ দিচ্ছি — কারণ সেটা নিজেই (score = 1.0)
    # পরের num_recommendations টা নেওয়া হচ্ছে
    top_similar = similarity_scores[1:num_recommendations+1]
    
    # ৫. Index থেকে Title বের করা
    res = [(indices.index[idx], score) for idx, score in top_similar]
    
    return tabulate(res, headers=["বইয়ের নাম", "Similarity Score"], tablefmt="pretty")

# পরীক্ষা করি
print(recommendations('The Queen\'s Gambit', sim_cosine))

Similarity Measures
মিল মাপার তিনটি পদ্ধতি
চিত্র: তিনটি Similarity Measure-এর তুলনামূলক চিত্র
পদ্ধতি সূত্র মান পরিসীমা কখন ব্যবহার সমস্যা
Cosine Similarity cos(x,y) = (x·y) / (|x||y|) -১ থেকে ১ (text-এ ০ থেকে ১) Text, NLP, Sparse data মাত্রা (magnitude) বিবেচনা করে না
Dot Product Σ xᵢyᵢ যেকোনো মান Normalized vectors, Neural nets Scale সমস্যা আছে
Euclidean Distance ||x-y|| = √Σ(xᵢ-yᵢ)² ০ থেকে ∞ Low-dimensional, Image উচ্চ মাত্রায় কাজ করে না (Curse of Dimensionality)
Python সব Similarity Measure Implement করা 
import numpy as np

def cosine_sim(x, y):
    """Cosine Similarity — ০ হলে কোনো মিল নেই, ১ হলে একদম একই"""
    dot = np.dot(x, y)
    norm_x = np.linalg.norm(x)
    norm_y = np.linalg.norm(y)
    if norm_x == 0 or norm_y == 0:
        return 0  # শূন্য ভেক্টর হলে ০ ফেরত
    return dot / (norm_x * norm_y)

def euclidean_sim(x, y):
    """Euclidean Similarity — দূরত্বকে similarity-তে রূপান্তর"""
    dist = np.sqrt(np.sum((x - y)**2))
    return 1 / (1 + dist)  # ১/(১+d) — দূরত্ব বাড়লে মিল কমে

# উদাহরণ: Alice আর The Hobbit
alice = np.array([0, 4])      # adventure=0, romance=4
hobbit = np.array([5, 0])     # adventure=5, romance=0

print(f"Cosine Similarity: {cosine_sim(alice, hobbit):.4f}")
print(f"Euclidean Similarity: {euclidean_sim(alice, hobbit):.4f}")
# আউটপুট: Cosine = 0.0000, Euclidean = 0.1716

Bayesian Average — কেন দরকার?

⚖️ সাধারণ Average-এর সমস্যা

ধরো একটি বই শুধু একজন পড়েছে এবং ৫ দিয়েছে। আরেকটি বই ১০০০ জন পড়েছে এবং গড় ৪.৯ পেয়েছে। সাধারণ average-এ প্রথমটি জিতবে — কিন্তু এটা কি ঠিক?

Bayesian Average = (C × M + S) / (C + n)

যেখানে: M = সব বইয়ের গড় রেটিং, C = গড় রেটিং সংখ্যা, S = রেটিংগুলোর যোগফল, n = মোট রেটিং সংখ্যা

এই পদ্ধতি কম রেটিংের বইকে global average-এর দিকে টেনে আনে — ফলে বেশি ন্যায্য তুলনা হয়।

Python Bayesian Average — কোড Implementation 
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv('ratings_flrd.csv')

# প্রতিটি বইয়ের রেটিং সংখ্যা ও গড় রেটিং
book_stats = df.groupby('title')['rating'].agg(['count', 'mean']).reset_index()

# C = সব বইয়ের গড় রেটিং সংখ্যা
# M = সব বইয়ের গড় রেটিং মান
C = book_stats['count'].mean()
M = book_stats['mean'].mean()

def bayesian_avg(ratings_series):
    """
    Bayesian Average = (C × M + S) / (C + n)
    
    বাংলায়: কম রেটিংওয়ালা বইকে global average-এর দিকে টেনে আনে।
    ফলে ১টি রেটিং পাওয়া বই ১০০০টি রেটিং পাওয়া বইয়ের সাথে
    ন্যায্যভাবে তুলনা হয়।
    """
    n = ratings_series.count()   # এই বইয়ের মোট রেটিং সংখ্যা
    S = ratings_series.sum()    # এই বইয়ের রেটিংয়ের যোগফল
    return (C * M + S) / (C + n)

# প্রতিটি বইয়ের Bayesian Average হিসাব
bayesian_avg_ratings = df.groupby('title')['rating'].agg(bayesian_avg).reset_index()
bayesian_avg_ratings.columns = ['title', 'bayesian_avg']

# book_stats-এর সাথে merge করা
book_stats = book_stats.merge(bayesian_avg_ratings, on='title').sort_values(
    'bayesian_avg', ascending=False
)

# Top 10 সেরা বই দেখানো (Bayesian Average অনুযায়ী)
best_rated = book_stats[['title', 'count', 'mean', 'bayesian_avg']].head(10)
sns.barplot(y='title', x='bayesian_avg', data=best_rated, orient='h')
plt.title('Top 10 Books — Bayesian Average Rating')
plt.tight_layout()
plt.show()

Python User-Based Filtering — Prediction Function 
# User Similarity Matrix তৈরি
user_similarity = dist.cosine_similarity(sparse_ratings)
user_similarity = pd.DataFrame(user_similarity, 
                                  index=user_ids, columns=user_ids)

def pred_user(mat_ratings, user_similarity, k, user_id):
    """
    একজন ব্যবহারকারীর জন্য অনুমানিত রেটিং হিসাব করা
    
    সূত্র: r̂ᵤᵢ = Σ sim(u,v) * rᵥᵢ / Σ |sim(u,v)|
    যেখানে v = k জন সবচেয়ে মিলে যাওয়া ব্যবহারকারী
    """
    # এই ব্যবহারকারী কোন বইগুলো পড়েননি (rating=0)
    to_predict = mat_ratings.loc[user_id][mat_ratings.loc[user_id]==0]
    
    # k জন সবচেয়ে মিলে যাওয়া ব্যবহারকারী খোঁজা (নিজেকে বাদ দিয়ে)
    similar_users = user_similarity.loc[user_id].sort_values(ascending=False)[1:k+1]
    
    # Denominator: similarity-এর যোগফল (স্বাভাবিকীকরণের জন্য)
    norm = np.sum(np.abs(similar_users))
    
    for i in to_predict.index:
        # i বইটির জন্য similar users-দের রেটিং
        ratings = mat_ratings[i].loc[similar_users.index]
        
        # Weighted sum: similarity * rating
        scalar_prod = np.dot(ratings, similar_users)
        
        # অনুমানিত রেটিং
        pred = scalar_prod / norm
        to_predict[i] = pred
    
    return to_predict

# একজন ব্যবহারকারীর জন্য ১০টি সুপারিশ
userId = '004d5e96c8a318aeb006af50f8cc949c'
reco = pred_user(mat_ratings, user_similarity, k=3, user_id=userId)
print(reco.sort_values(ascending=False).head(10))
Python Item-Based Filtering — Prediction Function 
# Item Similarity — বইয়ের মধ্যে মিল (transpose করে)
# কেন transpose? কারণ এখন বই = সারি, ব্যবহারকারী = কলাম
item_similarity = dist.cosine_similarity(sparse_ratings.T)
item_similarity = pd.DataFrame(item_similarity, index=titles, columns=titles)

def pred_item(mat_ratings, item_similarity, k, user_id):
    """
    একজন ব্যবহারকারীর না পড়া বইয়ের রেটিং অনুমান করা
    Item-Based পদ্ধতিতে
    """
    to_predict = mat_ratings.loc[user_id][mat_ratings.loc[user_id]==0]
    
    for i in to_predict.index:
        # i বইটির সাথে সবচেয়ে মিলে যাওয়া k টি বই
        similar_items = item_similarity.loc[i].sort_values(ascending=False)[1:k+1]
        norm = np.sum(np.abs(similar_items))
        
        # ব্যবহারকারী সেই similar বইগুলোকে কী রেটিং দিয়েছে
        ratings = mat_ratings[similar_items.index].loc[user_id]
        
        scalar_prod = np.dot(ratings, similar_items)
        pred = scalar_prod / norm
        to_predict[i] = pred
    
    return to_predict

মূল ধারণা — ছোটদের মতো বোঝানো

ধরো একটা বড় ধাঁধা (puzzle) আছে ১০০০ টুকরার। সেটা দেখে বোঝা কঠিন। কিন্তু যদি সেই ধাঁধাকে কয়েকটি ছোট ধাঁধায় ভাগ করা যায়? Matrix Factorization ঠিক এটাই করে — বড় Rating Matrix কে দুটো ছোট Matrix-এ ভাঙে। তারপর সেই দুটো ছোট Matrix গুণ করলে মূল Matrix পাওয়া যায়, কিন্তু এবার "?" জায়গাগুলোও পূরণ হয়ে যায়!

চিত্র: A (sparse) = U × Vᵀ → R (dense). d হলো latent factors সংখ্যা, এটাই আমরা optimize করি।
📐 SVD — Singular Value Decomposition
A = U Σ Vᵀ

U = User-Latent Factor Matrix (ব্যবহারকারী কোন বিষয় পছন্দ করে)
Σ = Diagonal Matrix (কতটা গুরুত্বপূর্ণ প্রতিটি factor)
V = Item-Latent Factor Matrix (বই কোন বিষয়ের)

Truncated SVD: শুধু সবচেয়ে গুরুত্বপূর্ণ d টি singular value রাখা হয় → মাত্রা কমে।

➕ NMF — Non-Negative Matrix Factorization
R = W × H

W = User matrix (m × d) — সব মান ≥ ০
H = Item matrix (d × n) — সব মান ≥ ০

সুবিধা: সব মান positive হওয়ায় ব্যাখ্যা করা সহজ। SVD-র চেয়ে দ্রুত হিসাব করা যায়।

Latent Variables মানে অজানা বৈশিষ্ট্য — হয়তো "গোয়েন্দা" বা "রোমান্টিক" কিন্তু আমরা সেটা জানি না।

Python Truncated SVD দিয়ে Hybrid Recommendation 
from sklearn.decomposition import TruncatedSVD
import sklearn.metrics.pairwise as dist

# SVD তৈরি — n_components = latent factors সংখ্যা
# কম factors = সাধারণ patterns, বেশি factors = সূক্ষ্ম patterns
# কিন্তু বেশি হলে overfitting এর ঝুঁকি!
svd = TruncatedSVD(n_components=12)

# Sparse matrix transpose করে fit করা
# transpose কারণ: বই = সারি হওয়া দরকার (বইয়ের similarity চাই)
ratings_red = svd.fit_transform(sparse_ratings.T)
print(ratings_red.shape)  # (১৮৩৮, ১২) — ১৮৩৮ বই, ১২ latent factor

# পদ্ধতি ১: Reduced matrix দিয়ে similarity
# দ্রুত কিন্তু missing values fill করে না
item_similarity = dist.cosine_similarity(ratings_red)
item_similarity = pd.DataFrame(item_similarity, index=titles, columns=titles)

# পদ্ধতি ২: Original matrix reconstruct করে similarity
# ধীর কিন্তু missing values অনুমান করে fill করে
new_ratings_red = svd.inverse_transform(ratings_red)
item_similarity2 = dist.cosine_similarity(new_ratings_red)
item_similarity2 = pd.DataFrame(item_similarity2, index=titles, columns=titles)

# Recommendation করা
reco1 = pred_item(mat_ratings, item_similarity, 3, userId).sort_values(ascending=False).head(10)
reco2 = pred_item(mat_ratings, item_similarity2, 3, userId).sort_values(ascending=False).head(10)

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
import pandas as pd

class ContentBasedRecommender:
    def __init__(self, text_column='description'):
        self.tfidf = TfidfVectorizer(stop_words='english', max_features=50000)
        self.text_column = text_column
        self.sim_matrix = None
        self.indices = None

    def fit(self, df):
        tfidf_matrix = self.tfidf.fit_transform(df[self.text_column].fillna(''))
        self.sim_matrix = cosine_similarity(tfidf_matrix)
        self.indices = pd.Series(df.index, index=df['title'])
        return self

    def recommend(self, title, n=10):
        idx = self.indices[title]
        scores = list(enumerate(self.sim_matrix[idx]))
        scores = sorted(scores, key=lambda x: x[1], reverse=True)[1:n+1]
        book_indices = [i[0] for i in scores]
        return self.indices.index[book_indices].tolist()

from sklearn.metrics.pairwise import cosine_similarity
from scipy.sparse import csr_matrix
import numpy as np

class UserBasedCF:
    def __init__(self, k=10):
        self.k = k  # k = সবচেয়ে মিলে যাওয়া ব্যবহারকারী সংখ্যা

    def fit(self, ratings_df):
        self.ratings = ratings_df + 1  # ০ = পড়েনি
        self.ratings.fillna(0, inplace=True)
        sparse = csr_matrix(self.ratings)
        sim = cosine_similarity(sparse)
        self.user_sim = pd.DataFrame(sim, 
                                      index=ratings_df.index, 
                                      columns=ratings_df.index)
        return self

    def recommend(self, user_id, n=10):
        # না পড়া বইগুলো
        unread = self.ratings.loc[user_id][self.ratings.loc[user_id] == 0]
        # k জন সবচেয়ে মিলে যাওয়া ব্যবহারকারী
        similar = self.user_sim.loc[user_id].sort_values(ascending=False)[1:self.k+1]
        norm = np.sum(np.abs(similar))
        preds = {}
        for book in unread.index:
            r = self.ratings[book].loc[similar.index]
            preds[book] = np.dot(r, similar) / norm
        return pd.Series(preds).sort_values(ascending=False).head(n)

class ItemBasedCF:
    def __init__(self, k=10):
        self.k = k

    def fit(self, ratings_df):
        self.ratings = ratings_df + 1
        self.ratings.fillna(0, inplace=True)
        sparse = csr_matrix(self.ratings)
        # Transpose! কারণ বইয়ের মধ্যে similarity চাই
        sim = cosine_similarity(sparse.T)
        self.item_sim = pd.DataFrame(sim,
                                      index=ratings_df.columns,
                                      columns=ratings_df.columns)
        return self

    def recommend(self, user_id, n=10):
        unread = self.ratings.loc[user_id][self.ratings.loc[user_id] == 0]
        preds = {}
        for book in unread.index:
            similar = self.item_sim.loc[book].sort_values(ascending=False)[1:self.k+1]
            norm = np.sum(np.abs(similar))
            if norm == 0:
                continue
            r = self.ratings[similar.index].loc[user_id]
            preds[book] = np.dot(r, similar) / norm
        return pd.Series(preds).sort_values(ascending=False).head(n)

from surprise import SVD, Reader, Dataset
from surprise.model_selection import cross_validate, GridSearchCV
import pandas as pd

class SVDRecommender:
    def __init__(self, n_factors=100, n_epochs=20, lr_all=0.005, reg_all=0.02):
        self.model = SVD(n_factors=n_factors, n_epochs=n_epochs,
                         lr_all=lr_all, reg_all=reg_all)
        self.reader = Reader(rating_scale=(1, 5))

    def fit(self, df, user_col='user_id', item_col='title', rating_col='rating'):
        data = Dataset.load_from_df(df[[user_col, item_col, rating_col]], 
                                      self.reader)
        trainset = data.build_full_trainset()
        self.model.fit(trainset)
        self.trainset = trainset
        return self

    def recommend(self, user_id, all_items, rated_items, n=10):
        # না দেখা আইটেমের জন্য prediction
        unrated = [i for i in all_items if i not in rated_items]
        predictions = [(item, self.model.predict(user_id, item).est) 
                       for item in unrated]
        predictions.sort(key=lambda x: x[1], reverse=True)
        return predictions[:n]

    def tune(self, df, user_col, item_col, rating_col):
        # Hyperparameter Tuning
        data = Dataset.load_from_df(df[[user_col, item_col, rating_col]], self.reader)
        param_grid = {
            'n_factors': [50, 100, 150],
            'n_epochs': [20, 30],

        }

        path = self._get_cache_path(model_name)

        with open(path, 'rb') as f:
            model = pickle.load(f)
        logger.info(f"Model '{model_name}' loaded from cache")
        return model

⚖️ Bayesian Average — কেন দরকার?

ধরো একটি বই শুধু একজন পড়েছে এবং ৫ দিয়েছে। আরেকটি বই ১০০০ জন পড়েছে এবং গড় ৪.৯ পেয়েছে। সাধারণ average-এ প্রথমটি জিতবে — কিন্তু এটা কি ন্যায়সঙ্গত?

Bayesian Average = (C × M + S) / (C + n)

যেখানে: M = সব বইয়ের গড় রেটিং  |  C = গড় রেটিং সংখ্যা  |  S = রেটিংগুলোর যোগফল  |  n = মোট রেটিং সংখ্যা

কম রেটিং পাওয়া বই → global average-এর কাছাকাছি থাকবে। বেশি রেটিং পাওয়া বই → নিজের average প্রতিফলিত হবে।

book_stats = df.groupby('title')['rating'].agg(['count', 'mean']).reset_index()

C = book_stats['count'].mean()   # গড় রেটিং সংখ্যা
M = book_stats['mean'].mean()    # গড় রেটিং মান

def bayesian_avg(series):
    """
    কম রেটিংওয়ালা বইকে global average-এর দিকে টানে।
    ফলে ১ রেটিংওয়ালা বই ও ১০০০ রেটিংওয়ালা বই
    ন্যায্যভাবে তুলনা হয়।
    """
    n = series.count()
    S = series.sum()
    return (C * M + S) / (C + n)

# প্রতিটি বইয়ের Bayesian Average

    bayesian_avg_ratings, on='title'

Tokenization কী?

বড় text → ছোট শব্দ-টুকরায় ভাগ করা।
"Harry loves magic" → ["Harry", "loves", "magic"]

TF (Term Frequency)

TF(t,d) = count(t in d) / total words in d

একটি বইয়ে "magic" শব্দ কতবার আছে, মোট শব্দ দিয়ে ভাগ।

IDF (Inverse Document Frequency)

IDF(t) = log(N / df(t))

N = মোট বই। "horcrux" শুধু HP-এ → IDF বড় → বিরল ও গুরুত্বপূর্ণ।

TF-IDF(t,d) = TF(t,d) × IDF(t)
✅

"the" — সব বইয়ে → IDF ≈ 0 → TF-IDF ≈ 0 (গুরুত্বহীন)
"horcrux" — শুধু HP বইয়ে → IDF বড় → TF-IDF বড় (HP-এর পরিচায়ক)

import math
from collections import Counter

documents = [
    "magic dragon adventure quest",
    "romance love adventure passion",
    "magic wizard spell dragon"
]

def tf(word, doc):
    words = doc.split()
    return words.count(word) / len(words)

def idf(word, docs):
    N  = len(docs)
    df = sum(1 for d in docs if word in d.split())
    return math.log(N / df) if df > 0 else 0

def tfidf(word, doc, docs):
    return tf(word, doc) * idf(word, docs)

for i, doc in enumerate(documents):
    score = tfidf("magic", doc, documents)
    print(f"Doc {i+1}: TF-IDF('magic') = {score:.4f}")
# Doc 1: 0.1014  Doc 2: 0.0000  Doc 3: 0.1014

import numpy as np
from typing import List

def compute_rmse(actual: List[float], predicted: List[float]) -> float:
    """বড় ভুলে বেশি penalty — বড় error সহ্য করে না।"""
    a, p = np.array(actual), np.array(predicted)
    return float(np.sqrt(np.mean((a - p) ** 2)))

def compute_mae(actual: List[float], predicted: List[float]) -> float:
    """সব ভুলকে সমান গুরুত্ব — "গড়ে X star ভুল"।"""
    a, p = np.array(actual), np.array(predicted)
    return float(np.mean(np.abs(a - p)))

def precision_at_k(recommended: List[str],
                    relevant: List[str], k: int) -> float:
    """K টা দিলাম, কতটা সত্যিই পছন্দের?"""
    hits = sum(1 for i in recommended[:k] if i in set(relevant))
    return hits / k if k > 0 else 0.0

def recall_at_k(recommended: List[str],
                 relevant: List[str], k: int) -> float:
    """সব পছন্দের মধ্যে কতটা ধরলাম?"""
    if not relevant: return 0.0
    hits = sum(1 for i in recommended[:k] if i in set(relevant))
    return hits / len(relevant)

def ndcg_at_k(recommended: List[str],
               relevant: List[str], k: int) -> float:
    """আগে relevant দিলে বেশি পুরস্কার — position গুরুত্বপূর্ণ।"""
    rel_set = set(relevant)
    dcg  = sum(1/np.log2(i+2)
               for i, item in enumerate(recommended[:k])
               if item in rel_set)
    idcg = sum(1/np.log2(i+2)
               for i in range(min(len(rel_set), k)))
    return dcg / idcg if idcg > 0 else 0.0

import pandas as pd, numpy as np
import logging, pickle
from typing import List, Optional
from scipy.sparse import csr_matrix
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
from sklearn.decomposition import TruncatedSVD

logger = logging.getLogger(__name__)

class HybridRecommender:
    """
    Hybrid Recommendation System
    ─────────────────────────────
    নতুন user (< min_ratings) → Content-Based Only
    পুরনো user  → alpha*CF + (1-alpha)*CB

    Cold Start সমস্যা সমাধান করে এবং
    দুটো system-এর সেরা দিক একসাথে নেয়।
    """

    def __init__(self, alpha=0.7, min_ratings=5,
                 n_components=12, k=10):
        self.alpha, self.min_ratings = alpha, min_ratings
        self.n_components, self.k   = n_components, k
        self._fitted = False

    def fit(self, ratings_df, items_df,
            user_col='user_id', item_col='title',
            rating_col='rating', desc_col='description'):
        # Content-Based component
        self.tfidf  = TfidfVectorizer(stop_words='english', max_features=30000)
        cb_mat      = self.tfidf.fit_transform(items_df[desc_col].fillna(''))
        self.cb_df  = pd.DataFrame(cosine_similarity(cb_mat),
                                    index=items_df[item_col], columns=items_df[item_col])

        # Collaborative Filtering (SVD + Item-Based)
        self.mat    = (ratings_df.pivot_table(
            columns=item_col, index=user_col, values=rating_col
        ) + 1).fillna(0)
        self.user_ids = self.mat.index.tolist()
        self.titles   = self.mat.columns.tolist()
        red         = TruncatedSVD(n_components=self.n_components,
                                     random_state=42).fit_transform(
                          csr_matrix(self.mat).T)
        self.cf_df  = pd.DataFrame(cosine_similarity(red),
                                    index=self.titles, columns=self.titles)
        self._fitted = True
        logger.info(f"Fitted: {len(self.user_ids)} users, {len(self.titles)} items")
        return self

    def _is_cold(self, uid):
        if uid not in self.mat.index: return True
        return (self.mat.loc[uid] > 0).sum() < self.min_ratings

    def _cf_pred(self, uid):
        unread = self.mat.loc[uid][self.mat.loc[uid] == 0]
        preds  = {}
        for book in unread.index:
            sim  = self.cf_df.loc[book].sort_values(ascending=False)[1:self.k+1]
            norm = np.sum(np.abs(sim))
            if norm == 0: continue
            preds[book] = np.dot(self.mat[sim.index].loc[uid], sim) / norm
        return pd.Series(preds)

    def _cb_pred(self, uid, liked):
        candidates = (self.mat.loc[uid][self.mat.loc[uid] == 0].index
                      if uid in self.mat.index else self.titles)
        preds = {}
        for book in candidates:
            if book not in self.cb_df.columns: continue
            scores = [self.cb_df.loc[lb, book]
                      for lb in liked if lb in self.cb_df.index]
            if scores: preds[book] = np.mean(scores)
        return pd.Series(preds)

    def recommend(self, uid: str,
                   liked: Optional[List[str]] = None,
                   n: int = 10) -> pd.Series:
        """
        uid   : user ID
        liked : পছন্দের বই (Content-Based এর জন্য)
        n     : কতটি সুপারিশ চাই
        """
        assert self._fitted, "আগে fit() call করো!"
        liked = liked or []
        if self._is_cold(uid):
            logger.info(f"{uid}: cold → Content-Based")
            return self._cb_pred(uid, liked).sort_values(ascending=False).head(n)
        cf = self._cf_pred(uid)
        cb = self._cb_pred(uid, liked)
        if cf.max() > 0: cf /= cf.max()
        if len(cb) and cb.max() > 0: cb /= cb.max()
        combined = self.alpha * cf + (1 - self.alpha) * cb.reindex(cf.index, fill_value=0)
        logger.info(f"{uid}: hybrid α={self.alpha}")
        return combined.sort_values(ascending=False).head(n)

    def save(self, path): pickle.dump(self, open(path, 'wb')); logger.info(f"Saved → {path}")

    @staticmethod
    def load(path): return pickle.load(open(path, 'rb'))

Q1. নতুন platform-এ প্রথম দিন থেকে Recommendation চালু করবে কীভাবে — কোনো user data নেই?
✅

(১) Content-Based দিয়ে শুরু — item description ব্যবহার করো। (২) Popularity fallback রাখো। (৩) Onboarding-এ কয়েকটি পছন্দ জিজ্ঞেস করো। (৪) ডেটা জমলে CF যোগ করো। (৫) শেষে Hybrid বানাও।

Q2. Production-এ হঠাৎ RMSE বেড়ে গেছে। কীভাবে debug করবে?
✅

Data drift চেক, নতুন cold item, model staleness (শেষ retrain কবে?), specific user segment সমস্যা, feature pipeline-এ bug কিনা দেখো।

Q3. "Popularity Bias" কী? সমাধান?
✅

জনপ্রিয় আইটেম সবসময় recommend হয়, বিরল ভালো আইটেম বাদ পড়ে। সমাধান: IPS, Diversity metric, Exploration-Exploitation (epsilon-greedy)।

Q4. SVD-তে n_factors কীভাবে বেছে নেবে?
✅

Validation RMSE দেখে cross-validation করো। Elbow method ব্যবহার করো। বেশি → overfitting, কম → underfitting।

Q5. Real-time vs Batch recommendation — কখন কোনটা?
✅

Batch: রাতে retrain, সকালে ready, সস্তা (Netflix homepage)।
Real-time: তাৎক্ষণিক, ব্যয়বহুল (Amazon "also bought")।
Hybrid approach: Base = batch, context adjustment = real-time।
