০ পরিচয় — কেন Pipeline দরকার?

Machine Learning project এ আমরা সাধারণত এরকম code লিখি:

সমস্যাযুক্ত code — Data Leakage!Python
# ❌ এইভাবে করলে বড় ভুল হয়
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

# পুরো data normalize করলাম
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)  # ⚠️ পুরো dataset — test data সহ!

# এখন train-test split
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y)

# Model train
model = LogisticRegression()
model.fit(X_train, y_train)
model.score(X_test, y_test)  # এই score টা বাস্তবের চেয়ে ভালো দেখাবে!
⚠️ সমস্যা: Data Leakage!

উপরের code এ StandardScaler পুরো dataset (X_train + X_test) দেখে mean ও standard deviation শিখেছে। এর মানে model পরোক্ষভাবে test data দেখে ফেলেছে। এটাকে বলে Data Leakage — যেন পরীক্ষার আগেই answer sheet দেখে নেওয়া। বাস্তব deployment এ এই পার্থক্য বিপজ্জনক হতে পারে।

✅ সমাধান: Pipeline!

Pipeline ব্যবহার করলে প্রতিটি cross-validation fold এ শুধু training data দিয়ে transformer fit হয়। Test data কখনো "দেখা" যায় না।

GridSearchCV দিয়ে একসাথে সব transformer ও model এর optimal parameters খোঁজা যায়।
৩
Isolation — Data Leakage রোধ
Cross-validation এ প্রতিটি fold এ transformer শুধু training portion থেকে fit হয়।

১ Estimators — সবকিছুর Base Class

Scikit-learn এ সব object — classifier, regressor, transformer — একটাই base class থেকে আসে: Estimator। এই একটা concept বুঝলে বাকি সব সহজ।

💡 সহজ ভাষায়: Estimator হল একজন "শিক্ষার্থী"। সে data দেখে শেখে (fit) এবং তারপর কাজ করে।

from sklearn.preprocessing import StandardScaler
from numpy.random import rand

# 3 জন মানুষের 4টা feature — একটা ছোট dataset
X = rand(3, 4)
print("Original X:\n", X)

# Scaler তৈরি
scaler = StandardScaler()

# fit() — training data দেখে mean ও std শেখা
scaler.fit(X)

# fit এর পর এই attributes পাওয়া যায়
print("প্রতিটি column এর mean:", scaler.mean_)
print("প্রতিটি column এর std:",  scaler.scale_)
print("প্রতিটি column এর var:",  scaler.var_)

Y = scaler.transform(X)
print("Normalized Y:\n", Y)

# Verify: Y এর প্রতিটি column এর mean ≈ 0, var ≈ 1
scaler2 = StandardScaler()

print("Y এর var  (≈ 1):", scaler2.var_)

🎯 Interview প্রশ্ন — Estimators

প্রশ্ন ১: fit() কেন শুধু training data তে call করতে হয়? ★★★▶
fit() method data এর statistics (mean, variance ইত্যাদি) calculate করে। Test data দিয়ে fit করলে model পরোক্ষভাবে test data "দেখে ফেলে" — এটা Data Leakage। বাস্তব deployment এ test/production data আগে থেকে দেখা সম্ভব না। তাই শুধু training data থেকে fit করলে model এর evaluation সৎ হয়।
প্রশ্ন ২: fit() এবং fit_transform() এর পার্থক্য কী?▶
fit() শুধু parameter শেখে, data পরিবর্তন করে না। transform() শেখা parameter দিয়ে data বদলায়। fit_transform() দুটো একসাথে — transformer.fit(X).transform(X) এর সমতুল্য। Training data তে fit_transform(), test data তে শুধু transform() ব্যবহার করো।
প্রশ্ন ৩: Scikit-learn এর common interface কী? এটা কেন important?▶
সব Estimator এ fit(X, y) আছে। Transformer এ আছে transform(X)। Model এ আছে predict(X), score(X, y)। এই uniform interface এর কারণেই Pipeline যেকোনো Estimator নিতে পারে — আলাদা code লেখা লাগে না।

২ Transformers — Data রূপান্তরকারী

Transformer হল Estimator এর বিশেষ উপশ্রেণী। এরা fit() করে parameter শেখে এবং transform() করে data বদলায়।

📐 StandardScaler Formula
X_new[i,j] = (X[i,j] − μ[j]) / σ[j]

μ = column এর mean, σ = column এর standard deviation

ফলাফল: প্রতিটি column এর mean = 0, std = 1

কেন Standardization দরকার?

💡 Real Example

ধরো dataset এ: বয়স (20–80) এবং বেতন (10,000–10,00,000)। বেতনের সংখ্যা অনেক বড়, তাই gradient descent এর সময় model বেতনকে অনেক বেশি গুরুত্ব দেবে। Standardization করলে দুটো feature একই scale এ আসে, model নিরপেক্ষভাবে শিখতে পারে।

StandardScaler সম্পূর্ণ উদাহরণPython
from sklearn.preprocessing import StandardScaler
import numpy as np

X = np.array([[10, 500],
               [20, 1000],
               [30, 750]])

scaler = StandardScaler()

# fit_transform = fit() তারপর transform()
Y = scaler.fit_transform(X)
print("Normalized:\n", Y)

# Test data তে শুধু transform() — fit() নয়!
X_test = np.array([[25, 800]])
Y_test = scaler.transform(X_test)  # training এর mean/std ব্যবহার করে
print("Test normalized:", Y_test)

নিজের Transformer বানানো

Scikit-learn এ custom Transformer বানাতে দুটো class inherit করতে হয়:

  • BaseEstimator — get_params() ও set_params() দেয় (GridSearchCV এর জন্য দরকার)
  • TransformerMixin — fit_transform() দেয় (শুধু fit ও transform লিখলেই কাজ হয়)
⚠️ Custom Transformer এর ৩টি অবশ্য মেনে চলার নিয়ম
  • fit() অবশ্যই return self করতে হবে — নইলে fit_transform() কাজ করে না
  • transform() original matrix modify না করে নতুন data return করতে হবে
  • Pipeline এ আগের step এর output পরের step এর input — তাই original নষ্ট করা যাবে না
Inverter2x2 — 2x2 Matrix Inverse TransformerPython
import numpy as np
from sklearn.base import BaseEstimator, TransformerMixin
from numpy.random import rand

class Inverter2x2(TransformerMixin):
    """2x2 matrix এর mathematical inverse বের করা।
    
    det(A) = ad - bc
    A_inv = (1/det) * [[d, -b], [-c, a]]
    """
    
    def __init__(self):
        self.det = 0  # determinant শুরুতে 0
    
    def fit(self, X):
        # "শেখার" ধাপ — determinant calculate করে store করা
        if X.shape != (2, 2):
            print("এই matrix 2x2 নয়!")
            return self
        # det = a*d - b*c
        self.det = X[0,0]*X[1,1] - X[0,1]*X[1,0]
        return self  # ⚠️ অবশ্যই self return করতে হবে!
    
    def transform(self, X):
        # "প্রয়োগের" ধাপ — inverse calculate করা
        if self.det == 0:
            print("Matrix invertible নয় (det=0)!")
            return
        # নতুন matrix তৈরি — original X modify করছি না!
        Y = np.zeros((2, 2))
        Y[0,0] =  X[1,1]
        Y[1,1] =  X[0,0]
        Y[0,1] = -X[0,1]
        Y[1,0] = -X[1,0]
        return (1/self.det) * Y

# ব্যবহার
inverter = Inverter2x2()
X = rand(2, 2)

# fit_transform = fit() তারপর transform()
Y = inverter.fit_transform(X)
print("Original X:\n", X)
print("Inverse Y:\n", Y)

# Verify: X @ Y ≈ Identity matrix I
print("X @ Y (≈ [[1,0],[0,1]]):\n", X @ Y)

নিজের MinMaxScaler বানাও

  1. MyMinMaxScaler class বানাও (BaseEstimator, TransformerMixin inherit করে)।
  2. fit() এ: প্রতিটি column এর min ও max calculate করে self.min_, self.max_ এ store করো।
  3. transform() এ: formula প্রয়োগ করো: (X - min) / (max - min) — কিন্তু original X modify করো না।
  4. Check করো: transformed data এর min ≈ 0, max ≈ 1।
▶ Solution দেখো
MyMinMaxScaler SolutionPython
from sklearn.base import BaseEstimator, TransformerMixin
import numpy as np

class MyMinMaxScaler(BaseEstimator, TransformerMixin):
    def __init__(self):
        self.min_ = None
        self.max_ = None
    
    def fit(self, X, y=None):
        self.min_ = X.min(axis=0)  # প্রতিটি column এর min
        self.max_ = X.max(axis=0)  # প্রতিটি column এর max
        return self  # অবশ্যই self return করো!
    
    def transform(self, X):
        # copy() করে নাও — original modify না করতে
        return (X - self.min_) / (self.max_ - self.min_)

# Test করো
X = np.array([[10, 200], [20, 400], [30, 100]])
sc = MyMinMaxScaler()
result = sc.fit_transform(X)
print(result)
print("Min (should be 0):", result.min(axis=0))
print("Max (should be 1):", result.max(axis=0))

৩ FeatureUnion — সমান্তরাল Transformation

Pipeline এ transformation sequential (একটার পর একটা)। কিন্তু FeatureUnion এ transformation parallel — সব transformer একই input পায়, outputs concatenate হয়।

চিত্র ৩: FeatureUnion — parallel transformation, তারপর concatenation

FeatureUnion উদাহরণPython
from sklearn.pipeline import FeatureUnion
from sklearn.preprocessing import PolynomialFeatures, StandardScaler, MinMaxScaler
import numpy as np

# তিনটি transformer আলাদাভাবে তৈরি
poly       = PolynomialFeatures(2)
std_scaler = StandardScaler()
mm_scaler  = MinMaxScaler()

# FeatureUnion — ('নাম', transformer) pairs এর list
union = FeatureUnion([
    ('poly', poly),
    ('std',  std_scaler),
    ('mm',   mm_scaler)
])

# একটা single transformer হিসেবে ব্যবহার
X = np.array([[1, 2], [3, 4], [5, 6]])
result = union.fit_transform(X)
print(f"Output shape: {result.shape}")
# poly: 6 col, std: 2 col, mm: 2 col = মোট 10 columns
🔵 Pipeline

Sequential। Step N এর output → Step N+1 এর input। Preprocessing chain + model এর জন্য।

🟣 FeatureUnion

Parallel। সব transformer একই input, outputs concatenate। একই data থেকে বিভিন্ন ধরনের feature।

৪ Pipeline তৈরি — হাতে-কলমে

📋 Pipeline তৈরির নিয়ম
  • Pipeline(steps=[('নাম', estimator), ...]) format এ দাও
  • Last step ছাড়া সব step কে Transformer হতে হবে
  • Last step: Model (predict করবে) বা Transformer (transform করবে)
  • Name গুলো unique হতে হবে — GridSearch এ কাজে লাগবে
Diabetes Dataset — LinearRegression PipelinePython
import pandas as pd
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler, PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import Pipeline

# ১. Data load
X = pd.DataFrame(load_diabetes().data)
y = load_diabetes().target

# ২. Train-test split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=1
)

# ৩. Pipeline তৈরি — steps এর list
linreg_pipe = Pipeline(steps=[
    ('standardization',  StandardScaler()),     # Step 1
    ('poly_features',    PolynomialFeatures(2)), # Step 2
    ('linear_regression', LinearRegression())    # Step 3: model
])

# ৪. একটাই fit() — সব steps automatically run হবে
linreg_pipe.fit(X_train, y_train)
score_pipe = linreg_pipe.score(X_test, y_test)

# তুলনার জন্য: basic LinearRegression (without pipeline)
lr = LinearRegression()
lr.fit(X_train, y_train)
score_basic = lr.score(X_test, y_test)

print(f"Pipeline score:  {score_pipe:.4f}")
print(f"Basic LR score:  {score_basic:.4f}")
# Pipeline এর score বেশি — polynomial features এর কারণে!

🎯 Interview প্রশ্ন — Pipeline

প্রশ্ন ১: Pipeline এর last step এ model না দিলে কী হয়?▶
Pipeline টা Transformer হিসেবে কাজ করে। তখন fit(), transform(), fit_transform() পাওয়া যাবে — কিন্তু predict() বা score() পাওয়া যাবে না। এটা useful যখন preprocessing pipeline আলাদা করে রাখতে চাও।
প্রশ্ন ২: Pipeline ছাড়া cross-validation এ কী data leakage হয়?▶
Pipeline ছাড়া StandardScaler দিয়ে পুরো dataset normalize করলে, mean ও std পুরো dataset থেকে calculate হয় (test fold সহ)। Pipeline ব্যবহার করলে প্রতিটি CV fold এ শুধু training portion থেকে mean ও std calculate হয় — এটাই সঠিক।
প্রশ্ন ৩: Production এ Pipeline কেন এত valuable?▶
(১) একটাই object joblib দিয়ে save/load করতে হয়। (২) নতুন data তে pipeline.predict(X_new) — আলাদাভাবে preprocess করতে হয় না। (৩) Data leakage automatically prevent হয়। (৪) Code readable ও maintainable। (৫) A/B testing সহজ।

৫ GridSearchCV — সেরা Parameters খোঁজা

Model এর hyperparameters manually tune করা কঠিন। GridSearchCV সব combination automatically test করে সেরাটা বের করে।

💡 সহজ ভাষায়: GridSearchCV হল একজন রাঁধুনি যে সব combination চেষ্টা করে (কম নুন-কম চিনি, কম নুন-বেশি চিনি...) এবং কোনটা সেরা রান্না হয়েছে তা বলে দেয়।
⚠️ Pipeline এ Parameter naming — দুটো underscore!
'step_name__param_name'

দুটো underscore (__) দিয়ে step name এবং parameter name আলাদা করো

GridSearchCV + Pipeline — Digits DatasetPython
import pandas as pd
import numpy as np
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
from sklearn.feature_selection import SelectKBest
from sklearn.svm import SVC
from sklearn.pipeline import Pipeline
from sklearn.model_selection import GridSearchCV

X = pd.DataFrame(load_digits().data)
y = load_digits().target
X = X.drop([0,24,31,32,39,56], axis=1)

# Pipeline — step names মনে রাখো!
svc_pipe = Pipeline([
    ('scaling',   StandardScaler()),  # step name: 'scaling'
    ('selection', SelectKBest()),     # step name: 'selection'
    ('model',     SVC())               # step name: 'model'
])

# Parameter grid — 'step_name__param_name' format!
param_grid = {
    'selection__k'   : [10, 20, 30, 40, 50, 'all'],
    'model__kernel'  : ['poly', 'linear', 'rbf']
}
# মোট: 6 × 3 = 18 combinations × 5 folds = 90 fits!

grid = GridSearchCV(svc_pipe, param_grid, cv=5, n_jobs=-1)
grid.fit(X, y)

print("সেরা Parameters:", grid.best_params_)
print("সেরা Score:     ", grid.best_score_)

from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.pipeline import Pipeline
from sklearn.linear_model import BayesianRidge
from sklearn.model_selection import GridSearchCV
import numpy as np

class ColumnBucketer(BaseEstimator, TransformerMixin):
    """Numeric column কে equal-width buckets এ ভাগ করে।
    
    Example: age=25, bucket_size=10 → age_bucket=20 (bucket [20,30))
    Formula: (X // bucket_size) * bucket_size
    """
    def __init__(self, column_name, bucket_size):
        # BaseEstimator এর requirement: __init__ এ সব params store করো
        self.column_name = column_name
        self.bucket_size  = bucket_size
    
    def fit(self, X, y=None):
        return self  # কিছু শেখার নেই
    
    def transform(self, X):
        X = X.copy()  # original modify না করতে copy করো
        X[self.column_name + "_bucket"] = (
            X[self.column_name] // self.bucket_size
        ) * self.bucket_size
        return X


class ColumnDrop(BaseEstimator, TransformerMixin):
    """DataFrame থেকে একটি column সরায়।"""
    def __init__(self, column_to_drop):
        self.column_to_drop = column_to_drop
    def fit(self, X, y=None):
        return self
    def transform(self, X):
        return X.drop(self.column_to_drop, axis=1)


# Pipeline তৈরি — custom transformers সহ
pipe = Pipeline([
    ('bucket_age',  ColumnBucketer('AGE',  bucket_size=5)),
    ('bucket_crim', ColumnBucketer('CRIM', bucket_size=5)),
    ('drop_age',    ColumnDrop('AGE')),
    ('drop_crim',   ColumnDrop('CRIM')),
    ('model',       BayesianRidge())
])

# GridSearch এ custom transformer এর parameter ব্যবহার!
params = {
    'bucket_age__bucket_size'  : [3, 5, 10],  # 'bucket_age' step এর 'bucket_size'
    'bucket_crim__bucket_size' : [3, 5, 10],
    'model__alpha_1'           : np.logspace(-3, 2, 5),
    'model__alpha_2'           : np.logspace(-3, 2, 5)
}

grid = GridSearchCV(pipe, params, cv=5)
# grid.fit(X, y)  # Boston dataset দরকার

SplitName — নাম থেকে Surname, Title, FirstnamePython
import re

def spliter(series):
    """regex দিয়ে "Braund, Mr. Owen" → ['Braund', ' Mr', ' Owen']"""
    chain = series.apply(lambda x: re.split(r"[.,\((.*?)\)]", x))
    for elt in chain:
        if elt[-1] == '': del elt[-1]
    return chain

class SplitName(BaseEstimator, TransformerMixin):
    """Name column কে Surname, Title, Firstname(s) এ ভাগ করে।"""
    def __init__(self, column_name): self.column_name = column_name
    def fit(self, X, y=None): return self
    def transform(self, X):
        X = X.copy()
        chain = spliter(X[self.column_name])
        X['Surname']     = chain.apply(lambda x: x[0].strip())
        X['Title']       = chain.apply(lambda x: x[1][1:])  # space remove
        X['Firstname(s)'] = chain.apply(lambda x: x[2])
        return X
CategorizeTitle + SplitCabin TransformersPython
class CategorizeTitle(BaseEstimator, TransformerMixin):
    """Title → 5 categories: Miss, Mrs, Mr, Master, Special"""
    def __init__(self, column_name): self.column_name = column_name
    def fit(self, X, y=None): return self
    def transform(self, X):
        X = X.copy()
        special = ["Dr","Don","Mme","Major","Lady","Sir",
                    "Mlle","Col","Capt","the Countess","Jonkheer","Dona"]
        X[self.column_name] = X[self.column_name].replace(special, 'Special')
        X[self.column_name] = X[self.column_name].replace(['Rev'], 'Mr')
        X[self.column_name] = X[self.column_name].replace(['Ms'], 'Miss')
        return X[[self.column_name]]

def babtri(x):
    """Cabin number → 'Port' (even) বা 'Starboard' (odd)"""
    if x % 2 == 0.0: return 'Port'
    if x % 2 == 1.0: return 'Starboard'
    return np.nan

class SplitCabin(BaseEstimator, TransformerMixin):
    """Cabin string → letter (deck) এবং parity (port/starboard)"""
    def __init__(self, column_name): self.column_name = column_name
    def fit(self, X, y=None): return self
    def transform(self, X):
        new_X = pd.DataFrame()
        new_X[self.column_name+'_letter'] = X[self.column_name].str.slice(0,1)
        var = X[self.column_name].str.slice(1,5).str.extract("([0-9]+)").astype('float')
        new_X[self.column_name+'_parite'] = var.iloc[:,0].apply(babtri)
        return new_X

Credit Risk Prediction Pipeline

📋 Problem

একটা bank এর credit risk assessment system বানাতে হবে। Dataset: age, income, loan_amount, credit_history, employment_type, num_dependents, has_property → predict: loan_default (1/0)।

  1. Synthetic data তৈরি করো (নিচে দেওয়া code দিয়ে)।
  2. Custom Transformer: DebtToIncomeRatio — loan_amount/income নামে নতুন feature তৈরি করে।
  3. ColumnTransformer: Numerical → StandardScaler, Categorical (employment_type) → OneHotEncoder, Binary (credit_history, has_property) → passthrough।
  4. Full Pipeline: DebtToIncomeRatio → ColumnTransformer → RandomForestClassifier।
  5. GridSearchCV: n_estimators [50,100,200] এবং max_depth [3,5,None] test করো।
  6. Report: Best parameters, accuracy, precision, recall, f1-score।
▶ Solution দেখো
Credit Risk Full SolutionPython
import numpy as np
import pandas as pd
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.metrics import classification_report

# ══ Step 1: Synthetic Data ══
np.random.seed(42)
n = 1000
df = pd.DataFrame({
    'age'             : np.random.randint(22, 65, n),
    'income'          : np.random.lognormal(10, 0.8, n),
    'loan_amount'     : np.random.lognormal(10, 1.2, n),
    'credit_history'  : np.random.randint(0, 2, n),
    'employment_type' : np.random.choice(['salaried','self_employed','business'], n),
    'num_dependents'  : np.random.randint(0, 5, n),
    'has_property'    : np.random.randint(0, 2, n),
})
dti = df['loan_amount'] / df['income']
prob = (0.3 * (dti > 3) + 0.4 * (1 - df['credit_history'])).clip(0, 1)
df['loan_default'] = (np.random.random(n) < prob).astype(int)
df.loc[df.sample(50).index, 'income'] = np.nan  # missing values
X = df.drop('loan_default', axis=1)
y = df['loan_default']

# ══ Step 2: Custom Transformer ══
class DebtToIncomeRatio(BaseEstimator, TransformerMixin):
    def fit(self, X, y=None): return self
    def transform(self, X):
        X = X.copy()
        income_safe = X['income'].fillna(X['income'].median())
        X['dti_ratio'] = X['loan_amount'] / income_safe
        return X

# ══ Step 3: Column groups ══
num_cols  = ['age', 'income', 'loan_amount', 'num_dependents', 'dti_ratio']
cat_cols  = ['employment_type']
pass_cols = ['credit_history', 'has_property']

num_pipe = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler',  StandardScaler())
])

preprocessor = ColumnTransformer([
    ('num',  num_pipe,                                           num_cols),
    ('cat',  OneHotEncoder(handle_unknown='ignore'),             cat_cols),
    ('pass', 'passthrough',                                       pass_cols)
])

# ══ Step 4: Full Pipeline ══
full_pipe = Pipeline([
    ('feature_eng',  DebtToIncomeRatio()),
    ('preprocessor', preprocessor),
    ('model',        RandomForestClassifier(random_state=42))
])

# ══ Step 5: GridSearchCV ══
X_tr, X_te, y_tr, y_te = train_test_split(X, y, random_state=42)

param_grid = {
    'model__n_estimators' : [50, 100, 200],
    'model__max_depth'    : [3, 5, None],
}
grid = GridSearchCV(full_pipe, param_grid, cv=5, scoring='f1', n_jobs=-1)
grid.fit(X_tr, y_tr)

print("Best params:", grid.best_params_)
print("Best CV F1: ", grid.best_score_)

# ══ Step 6: Final Report ══
y_pred = grid.best_estimator_.predict(X_te)
print(classification_report(y_te, y_pred))

Model Comparison Framework

📋 Problem

একই preprocessor দিয়ে multiple models automatically compare করার reusable function বানাও। Output: DataFrame with model name, mean CV score, std।

  1. যেকোনো preprocessor তৈরি করো।
  2. Models dict: {'LogisticRegression': lr, 'RandomForest': rf, 'GradientBoosting': gb, 'SVC': svc}।
  3. প্রতিটির জন্য Pipeline তৈরি করে 5-fold CV score বের করো।
  4. Results DataFrame এ organize করো, best model identify করো।
▶ Solution দেখো
Model Comparison FrameworkPython
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.svm import SVC
import pandas as pd

def compare_models(preprocessor, X, y, cv=5, scoring='accuracy'):
    """একই preprocessor দিয়ে multiple models compare করো।
    
    Returns: DataFrame sorted by mean_score (best first)
    """
    models = {
        'LogisticRegression'  : LogisticRegression(max_iter=1000),
        'RandomForest'        : RandomForestClassifier(random_state=42),
        'GradientBoosting'    : GradientBoostingClassifier(random_state=42),
        'SVC'                 : SVC(),
    }
    results = []
    for name, model in models.items():
        pipe = Pipeline([
            ('preprocessor', preprocessor),
            ('model',        model)
        ])
        scores = cross_val_score(pipe, X, y, cv=cv, scoring=scoring, n_jobs=-1)
        results.append({
            'model'      : name,
            'mean_score' : scores.mean(),
            'std'        : scores.std(),
            'min'        : scores.min(),
            'max'        : scores.max(),
        })
        print(f"{name}: {scores.mean():.4f} ± {scores.std():.4f}")
    df = pd.DataFrame(results).sort_values('mean_score', ascending=False)
    print(f"\n🏆 Best Model: {df.iloc[0]['model']} ({df.iloc[0]['mean_score']:.4f})")
    return df

        'safe_prob'     : round(float(proba[0]), 4),

    }

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.pipeline import Pipeline, FeatureUnion
from sklearn.preprocessing import StandardScaler

from sklearn.base import BaseEstimator, TransformerMixin

# DataFrame থেকে আলাদা অংশ বের করার extractors
class TextExtractor(BaseEstimator, TransformerMixin):
    def fit(self, X, y=None): return self
    def transform(self, X):
        return X['review_text'].values  # TfidfVectorizer এর জন্য 1D

class NumericExtractor(BaseEstimator, TransformerMixin):
    def fit(self, X, y=None): return self

# Pipelines
text_pipe = Pipeline([

    ('extract', NumericExtractor()),
    ('scale',   StandardScaler())
])

# FeatureUnion দিয়ে text + numeric combine
combined = FeatureUnion([
    ('text',    text_pipe),
    ('numeric', num_pipe)
])

# Full pipeline
pipeline = Pipeline([
    ('features', combined),
    ('clf',      LogisticRegression(max_iter=1000, C=1.0))
])
