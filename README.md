## 🗺️ Learning Tracks

### ☁️ AWS Cloud Practitioner (CCP)
Foundational AWS concepts across 9 sessions — cloud models, core services, billing, security, and global infrastructure.

### 🏗️ AWS Solutions Architect Associate (SAA)
Architecture best practices, 4 core modules, and 3 hands-on labs covering compute, storage, networking, and databases on AWS.

### 📊 Data Scientist Track
End-to-end data science curriculum including:
- **Python for Data Science** — NumPy, Pandas, OOP, loops, EDA, data quality
- **Machine Learning 1–4** — Regression, Classification, Clustering, Feature Engineering, Pipelines, Anomaly Detection, Time Series, Dimensionality Reduction, NLP, RL
- **Deep Learning** — TensorFlow, PyTorch, CNN, OpenCV
- **Data Engineering** — SQL, PySpark, Streamlit, data integration
- **Data Visualisation** — Matplotlib, Seaborn, Plotly
- **MLOps (DS)** — MLflow, model tracking
- **Programming Tools** — Linux/Bash, unit testing, virtual machines

### ⚙️ MLOps Track
Production ML engineering stack:
- **Containerisation:** Docker, Kubernetes
- **Orchestration:** Apache Airflow, ZenML
- **Experiment Tracking:** MLflow, Weights & Biases
- **APIs & Serving:** FastAPI, BentoML
- **Data Versioning:** DVC
- **Databases:** SQL, MongoDB, Elasticsearch
- **Streaming:** Apache Kafka
- **Monitoring:** Prometheus, Grafana, Drift Monitoring
- **CI/CD:** Git/GitHub, Jenkins
- **LLM & RAG:** RAG-LLM pipeline
- **Security:** API security (Part 1 & 2), unit testing, TDD
