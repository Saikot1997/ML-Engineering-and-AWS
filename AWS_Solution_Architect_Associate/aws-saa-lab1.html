Lab 1: AWS Management Console & AWS CLI

AWS Management Console navigate করো, S3 bucket তৈরি করো, এবং AWS CLI দিয়ে S3 তে files upload করো। Session Manager ব্যবহার করে EC2 তে connect করো।

OBJECTIVES

AWS Console explore করো
Console দিয়ে S3 bucket তৈরি
S3 তে object upload করো
AWS CLI explore করো
CLI দিয়ে S3 bucket তৈরি
🌐
AWS Management Console
Web-based GUI। সব AWS services access করার সহজ উপায়। Search bar, Favorites, Widgets সব customize করা যায়।
💻
AWS CLI
Command Line Interface। Terminal থেকে AWS services control করো। Console এর বিকল্প — automation এর জন্য ideal।
🪣
Amazon S3
Object storage service। Unlimited storage। Globally unique bucket names। HTTP দিয়ে access।
🔐
Session Manager
SSM capability। SSH port open না করেই EC2 তে browser-based shell। IAM দিয়ে access control। Audit trail।
⚡
AWS API
Console এবং CLI উভয়ই AWS API call করে। সব interaction → API → AWS service। একই কাজ, দুটো interface।
🏷️
Regions
AWS resources geographical area তে থাকে। Region selector দিয়ে correct region বেছে নাও। Lab এ eu-west-2।

🔑 KEY COMMANDS — Lab এ ব্যবহৃত CLI Commands

# S3 buckets list করো aws s3 ls # নতুন S3 bucket তৈরি করো aws s3 mb s3://labclibucket-NUMBER # File S3 তে copy করো aws s3 cp /home/ssm-user/HappyFace.jpg s3://labclibucket-NUMBER # Bucket contents list করো aws s3 ls s3://labclibucket-NUMBER

💡 Lab থেকে মূল শিক্ষা

Console ও CLI উভয়ই একই AWS API call করে। Console = human-friendly GUI। CLI = automation-friendly। যেকোনো একটি দিয়ে same resource তৈরি করা যায়। Session Manager = SSH ছাড়া secure EC2 access।

T1
Task 1: Explore the AWS Management Console
Region, widgets, search, favorites সব explore করো
STEP 3
On the navigation bar, choose the Region selector at the top-right corner.
বাংলা
Console এর উপরে ডানদিকে Region selector আছে। এখানে click করলে সব AWS Regions দেখাবে। তোমার Lab এর জন্য eu-west-2 (London) select করো।
STEP 4-8
Open General Settings → See all user settings → Edit Localization → Choose Default Region → Save settings.
বাংলা
Gear icon → See all user settings → Localization and default Region section → Edit → Default Region বেছে নাও → Save। এটা তোমার browser এ default region set করে।
STEP 12-15
Search box → type cloud → choose AWS Cloud Map service from Services section → return home.
বাংলা
Search box এ "cloud" লিখলে ফলাফল আসে। Services, Features, Documentation — সব দেখায়। AWS Cloud Map select করো। AWS logo click করে home এ ফিরো।
STEP 16-21
Add favorites: Services → All services → click ★ star. Remove: Favorites list → deselect star.
বাংলা
Favorites = top navigation এ pin করা services। Services menu → তোমার দরকারী service এর পাশে ★ star click করো। Remove করতে Favorites এ গিয়ে star deselect করো।
STEP 25-29
Add widgets: + Add widgets button. Drag title bar to rearrange. Drag bottom-right to resize. Ellipsis icon → Remove widget.
বাংলা
Console home এর Widgets = quick access shortcuts। + Add widgets দিয়ে নতুন widget যোগ করো। Title bar drag করে সরাও। Corner drag করে resize করো। ⋮ (ellipsis) → Remove widget।
T2
Task 2: Create S3 Bucket via Console
AWS Management Console দিয়ে S3 bucket তৈরি করো
📍
Caution: Correct region এ আছো কিনা নিশ্চিত করো (Lab এর বাম পাশে LabRegion দেখো)।
STEP 30-32
Services menu → All Services → Storage → S3. Or search S3 in search bar.
বাংলা
Services → Storage → S3 অথবা search bar এ "S3" type করো। S3 console খুলবে যেখানে তোমার সব buckets দেখাবে।
STEP 33-38
Buckets → Create bucket → Name: labbucket-NUMBER → AWS Region matches LabRegion → Leave all defaults → Create bucket.
বাংলা
Create bucket click করো। Bucket name: labbucket-987987 (NUMBER = random)। Globally unique নাম দিতে হবে। Region = LabRegion। বাকি সব default রাখো → Create bucket।
T3
Task 3: Upload Object to S3 via Console
S3 console দিয়ে image upload করো
STEP 39-45
Right-click the image link → Save as HappyFace.jpg → S3 → choose labbucket-xxxxx → Upload → Add files → Browse → HappyFace.jpg → Upload → Close.
বাংলা
Lab এ image link এ right-click → Save as → HappyFace.jpg save করো। তারপর S3 bucket এ → Upload → Add files → Browse → HappyFace.jpg select → Upload। "Upload succeeded" দেখবে।
T4
Task 4: Create S3 Bucket & Upload using AWS CLI
Session Manager → EC2 → CLI commands
STEP 46-51
Search → EC2 → Instances → Select Command Host → Connect → Session Manager tab → Connect.
বাংলা
EC2 console → Instances → Command Host select → Connect → Session Manager → Connect। Browser এ terminal window খুলবে। এটাই তোমার CLI environment। SSH port open নেই কিন্তু SSM দিয়ে connect হলো।
STEP 52-55
List buckets: aws s3 ls. Create bucket: aws s3 mb s3://labclibucket-NUMBER. List again to see new bucket.
বাংলা
aws s3 ls = সব buckets দেখো। mb = make bucket। aws s3 mb s3://labclibucket-123 চালাও। Expected output: make_bucket: labclibucket-xxxxx। আবার aws s3 ls চালিয়ে নতুন bucket দেখো।
STEP 56-58
Copy file: aws s3 cp /home/ssm-user/HappyFace.jpg s3://labclibucket-NUMBER. List bucket to confirm.
বাংলা
cp = copy। Local file → S3 তে copy করো। Expected output: upload: ../../home/ssm-user/HappyFace.jpg to s3://labclibucket-xxxxx/HappyFace.jpg। তারপর aws s3 ls s3://labclibucket-NUMBER দিয়ে confirm করো।
