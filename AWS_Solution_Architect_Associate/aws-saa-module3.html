🎭 IAM Roles — সবচেয়ে গুরুত্বপূর্ণ IAM concept
Role = temporary credentials। AWS services, users, external identities assume করতে পারে।
EC2 Instance Profile — EC2 তে Role attach। S3/DynamoDB access। Hardcoded credentials নয়।
Cross-Account Role — Account A থেকে Account B তে access। STS AssumeRole।
Service-Linked Role — AWS service নিজেই create করে। e.g., AWSServiceRoleForEC2Spot।
📌 Exam: "EC2 needs S3 access without storing credentials" → IAM Role + Instance Profile

🏢 AWS Organizations & SCPs

  • AWS Organizations — Multiple accounts centrally manage করো। Consolidated billing।
  • SCP (Service Control Policy) — Maximum permissions define করে। Root/OU/account এ apply। Allow এবং Deny উভয়।
  • OU (Organizational Unit) — Accounts group করো। SCP inherit হয়।
  • SCP Deny — SCP deny করলে IAM policy allow থাকলেও কাজ করে না।
  • Management Account — SCP প্রযোজ্য নয়। Full admin।

🔐 VPC Endpoints — Private connectivity to AWS services

  • Gateway Endpoint — S3 ও DynamoDB। Free। VPC Route table এ add করো। Internet নয়।
  • Interface Endpoint (PrivateLink) — ENI with private IP। Most AWS services। Hourly charge।
  • VPC PrivateLink — Expose your service privately to other VPCs। NLB required।
  • VPC Flow Logs — IP traffic log। CloudWatch বা S3 তে store। Security analysis।
  • VPC Peering — Two VPCs connect। Non-transitive। CIDR overlap হলে কাজ করে না।
🔒 Bastion Host vs Session Manager
Bastion Host — Public subnet এ EC2। SSH gateway to private instances। Port 22 open দরকার।
AWS Systems Manager Session Manager — No SSH, no Bastion। Browser-based shell। IAM policy দিয়ে control। Audit trail CloudTrail তে।
📌 Exam: "Secure EC2 access without SSH or open ports" → SSM Session Manager
💡

Exam Tip: SG = Stateful (1টি rule allow করলে response auto)। NACL = Stateless (inbound + outbound আলাদা rules)। Block specific IP → NACL। VPC Endpoint = private S3/DynamoDB access।

🔑 KMS Key Types EXAM HOT
AWS Managed Keys — AWS automatically creates, manages। Service এর জন্য (aws/s3)। Free।
Customer Managed Keys (CMK) — You create ও control। Key policy আপনি লেখেন। Rotation optional।
AWS Owned Keys — AWS internally uses। আপনি দেখতে বা manage করতে পারেন না।
KMS Key Rotation — CMK: automatic rotation every year (optional)। AWS Managed: auto every year।
📌 Exam: "FIPS 140-2 Level 3, dedicated hardware" → CloudHSM। "Managed keys, audit trail" → KMS
🤫 Secrets Manager vs Parameter Store
Secrets Manager: DB passwords, API keys। Automatic rotation (Lambda function)। Native RDS/Redshift integration। Monthly charge।
SSM Parameter Store: Configuration values। Hierarchical (/app/prod/db-url)। Free Standard tier। SecureString = KMS encrypted। No auto-rotation।
📌 Exam: "Auto rotate RDS password" → Secrets Manager। "Store app config, free" → Parameter Store
💡

Exam Tip: KMS = AWS manages HSM, multi-tenant। CloudHSM = dedicated hardware, you manage। Secrets Manager = rotation। Parameter Store = config + free tier। ACM = free SSL for ALB/CloudFront।

🔐 Amazon Cognito — User Pool vs Identity Pool
User Pool — Authentication। Sign-in, sign-up। JWT tokens। MFA। Social login (Google, Facebook)।
  → "কে তুমি?" → Login → JWT

Identity Pool (Federated Identity) — Authorization। Temporary AWS credentials।
  → "তুমি এখন S3/DynamoDB access করতে পারবে" → STS AssumeRole

Combined flow: User Pool (login) → Identity Pool (AWS creds) → S3/DynamoDB
📌 Exam: "Mobile app users AWS services access করবে" → User Pool + Identity Pool

🛡️ WAF Rules — কোথায় কাজ করে?

  • WAF — CloudFront, ALB, API Gateway, AppSync। Layer 7।
  • WAF Rules: IP-based, Rate limiting, SQL injection, XSS, Geo-match, Custom regex।
  • AWS Managed Rules — Pre-built rule groups। OWASP Top 10, Bot Control।
  • Shield Standard — Automatic। All customers। Layer 3/4 DDoS।
  • Shield Advanced — $3000/month। 24/7 DRT support। Layer 7। Cost protection।
💡

Exam Tip: WAF = Layer 7 web attacks। Shield Standard = free DDoS। GuardDuty = threat detection (no setup needed)। Macie = PII in S3। Inspector = EC2 CVE scanning। Cognito User Pool = auth, Identity Pool = AWS access।
