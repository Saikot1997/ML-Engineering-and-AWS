🌟 Amazon Aurora — SAA এ সবচেয়ে বেশি আসে
MySQL এর ৫x faster, PostgreSQL এর ৩x faster। Storage auto-grows (10GB→128TB)।

Aurora Serverless v2 — variable workloads, per-second billing, zero management।
Aurora Global Database — 1 primary region + up to 5 secondary regions। Cross-region DR।
📌 Exam: "MySQL compatible, highly available, auto-scaling storage" → Aurora
🔑 DynamoDB Advanced Features
DAX (DynamoDB Accelerator) — In-memory cache। ms → microseconds। No app code change।
Global Tables — Multi-region active-active। Automatic replication। Low-latency globally।
DynamoDB Streams — Item changes → Lambda trigger। Event-driven architecture।
TTL — Items auto-expire। Session data, temp data। No extra cost।
PITR — Point-in-Time Recovery। Last 35 days এর যেকোনো মুহূর্তে restore।
💡

Exam Tips: Multi-AZ standby = HA শুধু, reads নয়। Aurora Multi-Master = multiple write nodes। Athena = serverless S3 query (Glue Data Catalog দিয়ে)। Redshift = OLAP analytics, not OLTP।

🔐 S3 Security & Features EXAM
Bucket Policy — Resource-based JSON policy। Bucket level। Cross-account access দেওয়া যায়।
ACL (Access Control Lists) — Object level। Legacy। Block Public Access দিয়ে override।
Server-Side Encryption (SSE):
  • SSE-S3 — AWS managed keys। Default। Free।
  • SSE-KMS — KMS keys। Audit trail। Key rotation। কিছুটা বেশি cost।
  • SSE-C — Customer-provided keys। AWS key store করে না।
S3 Versioning — Delete marker রাখে। Accidental delete থেকে protect। MFA Delete enable করা যায়।
Replication — CRR (Cross-Region) বা SRR (Same-Region)। Versioning required।

✅ S3 vs EBS vs EFS — সঠিক Storage বেছে নাও

  • S3 — Object storage। Unlimited। Static websites, backups, ML datasets। HTTP access।
  • EBS — Block storage। EC2 এর hard drive। একটি EC2 এ attach (io1/io2 Multi-Attach exception)।
  • EFS — NFS। Multiple EC2 across AZs। Linux only। Pay per use।
  • FSx for Windows — SMB। Windows apps, Active Directory। Microsoft workloads।
  • FSx for Lustre — High-performance। HPC, ML training। S3 integrate।
💡

Exam Tip: S3 = object, unlimited। EBS = block, one EC2। EFS = NFS, multiple EC2, Linux। Glacier Deep Archive = cheapest, 12h retrieval, compliance 7+ years। S3 Lifecycle = automatic tier transition।

λ AWS Lambda — Serverless Compute
Max execution time: 15 minutes। Memory: 128MB–10GB। Ephemeral storage: /tmp 512MB–10GB।
Pricing: Number of requests + duration। Always Free: 1M requests/month + 400,000 GB-sec।
Triggers: API Gateway, S3 events, DynamoDB Streams, SQS, SNS, EventBridge, CloudWatch।
Lambda@Edge — CloudFront এর Edge Locations এ run। Geolocation-based routing।
📌 Exam: "No server management, event-driven, short tasks" → Lambda

✅ Messaging Services — SQS vs SNS vs EventBridge

  • SQS — Queue (1:1)। Pull model। Async decoupling। Standard (at-least-once) বা FIFO (exactly-once, ordered)।
  • SNS — Topic (1:many)। Push model। Fan-out। Email, SMS, Lambda, SQS triggers।
  • EventBridge — Event bus। Rule-based routing। SaaS events, AWS service events।
  • Kinesis Data Streams — Real-time data streaming। Multiple consumers। Retention 1-365 days।
  • SNS + SQS fan-out — SNS → multiple SQS। Most resilient async pattern।
💡

Exam Tip: SQS = queue/decouple। SNS = notification/fan-out। SQS FIFO = ordered messages, exactly-once। Kinesis = real-time streaming/analytics। Step Functions = orchestrate Lambda workflows।

🌐 CloudFront vs Global Accelerator
CloudFront — CDN। Static ও dynamic content cache করে। Edge Locations (450+)। HTTP/HTTPS।
  • Origin: S3, ALB, EC2, Custom HTTP
  • Signed URLs/Cookies — Paid content protect
  • OAC (Origin Access Control) — S3 direct access block, only via CloudFront

AWS Global Accelerator — Layer 4। AWS global network ব্যবহার করে। Static IPs (anycast)। TCP/UDP।
  • Gaming, VoIP, non-HTTP apps
  • Failover instantly, no DNS TTL wait

📌 Exam: "HTTP caching, static content" → CloudFront। "Static IP, global TCP/UDP" → Global Accelerator
💡

Exam Tip: Redis = persistence, pub/sub, Multi-AZ — session management best। Memcached = simple caching, multi-thread। CloudFront = HTTP CDN। Global Accelerator = non-HTTP or static IP needed।
