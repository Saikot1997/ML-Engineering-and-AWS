🌐
Amazon VPC
Logically isolated network। তোমার নিজের private cloud। IP range, subnets, routes — সব তুমি define করো। CIDR: 10.0.0.0/16
📦
Public Subnet
Internet-facing resources। CIDR: 10.0.0.0/24। Internet Gateway route আছে। Public IP auto-assign।
🔒
Private Subnet
Internet থেকে isolated। CIDR: 10.0.2.0/23। NAT Gateway দিয়ে outbound internet। No direct inbound।
🚪
Internet Gateway
VPC ↔ Internet সংযোগ। Public subnet route এ attach। NAT করে public ↔ private IP।
🔀
NAT Gateway
Private instances → internet outbound। Public subnet এ থাকে। Internet থেকে direct access নেই।
🛡️
Security Groups
Instance-level firewall। Public SG: HTTP (80) allow। Private SG: Public SG থেকে HTTP।

💡 Lab থেকে মূল শিক্ষা

Public subnet = Internet Gateway route আছে। Private subnet = Internet থেকে directly accessible নয়, কিন্তু NAT Gateway দিয়ে outbound access আছে। Security Group = stateful, allow only। NACL = stateless, subnet level।

T1
Task 1: Create Amazon VPC
Lab VPC with CIDR 10.0.0.0/16
STEP 3-6
Search → VPC → Your VPCs → Create VPC → Resources: VPC only → Name: Lab VPC → CIDR: 10.0.0.0/16 → Create VPC.
বাংলা
Console এ VPC search করো → Your VPCs → Create VPC। Name: Lab VPC। IPv4 CIDR: 10.0.0.0/16। এই range এ 65,000+ IP addresses আছে।
STEP 8-10
Actions → Edit VPC settings → DNS settings → Enable DNS hostnames → Save.
বাংলা
DNS hostnames enable করলে EC2 instances automatically DNS name পাবে (e.g., ec2-52-42-133-255.compute.amazonaws.com)। Route 53 এ readable name ও দেওয়া যাবে।
T2
Task 2: Create Public & Private Subnets
Two subnets in same Availability Zone
STEP 11-18
Subnets → Create subnet → VPC: Lab VPC → Name: Public Subnet → First AZ → CIDR: 10.0.0.0/24 → Create → Actions → Edit subnet settings → Enable auto-assign public IPv4.
বাংলা
Public Subnet: CIDR 10.0.0.0/24 = 256 IPs। Auto-assign public IP enable করো — এই subnet এ launch হওয়া EC2 automatically public IP পাবে। এখনো "public" না — IGW route দরকার।
STEP 19-21
Create subnet → VPC: Lab VPC → Name: Private Subnet → First AZ → CIDR: 10.0.2.0/23 → Create subnet.
বাংলা
Private Subnet: CIDR 10.0.2.0/23 = 512 IPs। Public এর চেয়ে double size — কারণ বেশিরভাগ resources private থাকা উচিত। Internet থেকে directly accessible নয়।
T3
Task 3: Create Internet Gateway
VPC কে internet এর সাথে connect করো
STEP 22-27
Internet gateways → Create internet gateway → Name: Lab IGW → Create → Actions → Attach to VPC → Select Lab VPC → Attach.
বাংলা
IGW তৈরি করে Lab VPC তে attach করো। IGW state: Attached দেখাবে। IGW attach হলেও public access হয়নি — Route Table update দরকার।
T4
Task 4: Configure Public Route Table
Internet traffic → IGW route যোগ করো
STEP 29-35
Route tables → Create route table → Name: Public Route Table → Lab VPC → Create → Routes tab → Edit routes → Add route → Destination: 0.0.0.0/0 → Target: Internet Gateway → Save.
বাংলা
0.0.0.0/0 মানে সব internet traffic। Target = IGW। এই route যোগ করলে subnet টি public হয়ে যায়। 10.0.0.0/16 → local (VPC internal) route already আছে।
STEP 36-39
Subnet associations tab → Edit subnet associations → Select Public Subnet → Save associations.
বাংলা
Route table কে Public Subnet এ associate করো। এখন Public Subnet সত্যিকারের public — Internet Gateway route আছে।
T5-6
Task 5-6: Security Group & Launch Public EC2
Public SG তৈরি এবং EC2 launch
STEP 40-44
Security groups → Create security group → Name: Public SG → VPC: Lab VPC → Inbound rules: HTTP (80), Source: Anywhere-IPv4 → Create.
বাংলা
Public SG: Port 80 (HTTP) যেকোনো IP থেকে allow। Web server access এর জন্য দরকার। Security best practice: HTTPS ব্যবহার করা উচিত — এই lab এ HTTP শুধু simplicity এর জন্য।
STEP 45-68
EC2 → Launch instances → Name: Public Instance → Amazon Linux 2023 → t3.micro → No key pair → VPC: Lab VPC → Subnet: Public Subnet → Auto-assign IP: Enable → Security: Public SG → IAM: EC2InstProfile → User data: Apache script → Launch.
বাংলা
EC2 launch করো। Key pair লাগবে না — Session Manager দিয়ে connect করবো। User data script automatically Apache web server install করবে। Public subnet + Public SG + Public IP = internet accessible।
T9
Task 9: NAT Gateway & Private Route Table
Private instances এর outbound internet access
STEP 84-86
NAT gateways → Create NAT gateway → Name: Lab NGW → Subnet: Public Subnet → Allocate Elastic IP → Create.
বাংলা
NAT Gateway = Public subnet এ থাকে। Elastic IP নেয়। Private instances এর outbound traffic এখান দিয়ে যাবে। Internet থেকে direct connection initiate করা যাবে না।
STEP 87-97
Route tables → Create route table → Name: Private Route Table → Lab VPC → Routes → Add: 0.0.0.0/0 → NAT Gateway → Subnet associations → Private Subnet → Save.
বাংলা
Private route table এ 0.0.0.0/0 → NAT Gateway route। Private subnet associate করো। এখন private instances internet access পাবে কিন্তু internet থেকে directly reach করা যাবে না।
T10-11
Task 10-11: Private SG & Launch Private EC2
Private instance isolate করো
STEP 98-102
Security groups → Create → Name: Private SG → Inbound: HTTP, Source: Custom → type sg → choose Public SG → Create.
বাংলা
Private SG: Source = Public SG (specific IP নয়, Security Group)। মানে শুধু Public SG তে assigned resources HTTP access পাবে। Multi-tier architecture এর best practice।
STEP 103-126
EC2 → Launch → Name: Private Instance → Linux 2023 → t3.micro → No key pair → VPC: Lab VPC → Subnet: Private Subnet → Auto-assign IP: Disable → Security: Private SG → Launch.
বাংলা
Private Instance: Auto-assign public IP: Disable। Private subnet। Private SG। Internet থেকে directly access করা যাবে না। Public Instance → Private Instance এ HTTP access হবে (same security group rule)।
