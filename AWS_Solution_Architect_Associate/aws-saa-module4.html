🌍 Route 53 Routing Policies — SAA এ সবচেয়ে বেশি আসে
Simple — একটি resource। Random multiple IPs।
Weighted — Traffic distribution (70% A, 30% B)। A/B testing।
Latency — Lowest latency region তে route। Global users।
Failover — Primary healthy? Route to primary। Unhealthy? Route to secondary। Health Check।
Geolocation — User এর location based। Country/continent।
Geo-proximity — Location + bias। Traffic flow adjust।
Multi-Value — Multiple IPs + health checks। Random selection।
📌 Exam: "DR failover" → Failover। "A/B test" → Weighted। "Nearest server" → Latency
💡

Exam Tip: DX = private dedicated, consistent, expensive। VPN = internet, encrypted, quick। TGW = hub-and-spoke, thousands VPCs। VPC Peering = non-transitive, just 2 VPCs।

🔄 DMS — Database Migration হোমোজিনিয়াস vs হেটেরোজিনিয়াস
Homogeneous — Same engine (MySQL → MySQL)। DMS directly।
Heterogeneous — Different engine (Oracle → Aurora)। SCT (Schema Conversion Tool) আগে run করো, তারপর DMS।
CDC (Change Data Capture) — Continuous replication। Source থেকে target এ real-time sync।
📌 Exam: "Oracle → PostgreSQL migration" → SCT + DMS

❄️ Snow Family — কতটুকু data, কোনটা বেছে নেবে?

  • Snowcone — 8TB (HDD) বা 14TB (SSD)। Smallest। IoT, edge computing।
  • Snowball Edge Storage — 80TB। Bulk data transfer। 10-100TB range।
  • Snowball Edge Compute — 42TB + EC2 compute। Edge processing।
  • Snowmobile — 100PB। 10PB এর বেশি হলে Snowmobile।
  • Rule of thumb — 1Gbps connection এ 10TB upload করতে ~1 day, 1PB ~3 years → Snow family use করো।
💡

Exam Tip: DataSync = online file transfer (scheduled)। Snow family = offline bulk। Storage Gateway = hybrid (on-prem apps use S3)। DMS = DB migration। Snowmobile = >10PB।

📊 CloudWatch — Metrics vs Logs vs Alarms
Metrics — Numeric data। EC2 CPU%, network, disk। Custom metrics (memory RAM — default নেই!)।
Logs — Text data। Application logs, Lambda logs। Log Groups → Log Streams।
Alarms — Metric threshold পার হলে action। SNS notification, EC2 action, Auto Scaling।
Log Insights — Query language for logs। Pattern, filter, aggregate।
CloudWatch Agent — EC2 এ install। Memory, disk utilization, custom metrics।
📌 Exam: "EC2 memory metrics" → CloudWatch Agent চাই (default নেই)
🔍 CloudTrail vs CloudWatch vs Config — পার্থক্য
CloudWatch — "কী হচ্ছে?" Performance monitoring। Metrics, logs, alarms।
CloudTrail — "কে করেছে?" API audit trail। Security, compliance। Who called DeleteBucket?
AWS Config — "কীভাবে আছে?" Configuration state। Compliance rules। "S3 bucket কি public?"
📌 Exam: "Who changed Security Group?" → CloudTrail। "Is S3 compliant?" → Config। "CPU high" → CloudWatch
💡

Exam Tip: EC2 default metrics = CPU, Network, Disk I/O। Memory = CloudWatch Agent। CloudTrail = API audit (default 90d, store S3 permanently)। Config = compliance drift। X-Ray = distributed tracing।

💰 Savings Plans — Reserved Instances এর চেয়ে ভালো কেন?
Reserved Instances — Specific instance type + region + OS। Up to 72% off।
Compute Savings Plans — Any instance family, region, OS, tenancy। Up to 66% off। Most flexible।
EC2 Instance Savings Plans — Specific family + region। Up to 72% off। OS flexible।
SageMaker Savings Plans — ML workloads।
📌 Exam: "Maximum discount, flexible instance type" → Compute Savings Plans
💡

Exam Tip: Spot = cheapest (90% off) কিন্তু interruption। Batch jobs, stateless apps। Reserved = steady 1-3 year। Savings Plans = RI এর flexible version। Trusted Advisor = best practice check (5 pillars)।
