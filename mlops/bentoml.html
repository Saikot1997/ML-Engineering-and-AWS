01

ML Production কী এবং কেন দরকার?

ধরো, তুমি একটি ML model তৈরি করলে যে ছবি দেখে রোগ বলতে পারে। তুমি Python-এ চমৎকারভাবে তৈরি করলে। কিন্তু এটা শুধু তোমার কম্পিউটারে চলে। অন্য কেউ এটা ব্যবহার করতে পারছে না। এটাই মূল সমস্যা।

Production মানে হলো — তোমার model-কে এমন একটি জায়গায় রাখা যেখানে যে কেউ, যেকোনো সময়, ইন্টারনেটের মাধ্যমে এটা ব্যবহার করতে পারবে। ঠিক যেমন Google বা Facebook তাদের AI features সবার জন্য উপলব্ধ রাখে।

💡 সহজ উপমা

তুমি রান্না করতে পারো — এটা তোমার "Model তৈরি"। কিন্তু রেস্তোরাঁ খুললে সবাই তোমার রান্না খেতে পারবে — এটা "Production Deployment"।

Development থেকে Production — যাত্রা

BentoML কী? — বিস্তারিত ব্যাখ্যা

BentoML হলো একটি open-source Python library যা ML model deploy করাকে অনেক সহজ করে দেয়। এটি framework-agnostic — মানে তুমি scikit-learn, TensorFlow, PyTorch, XGBoost — যেকোনো library দিয়ে তৈরি model ব্যবহার করতে পারবে।

🍱 "Bento" নামটা কোথা থেকে?

জাপানে "Bento" মানে হলো একটি বাক্স যাতে একসাথে পুরো খাবার থাকে — ভাত, তরকারি, সব কিছু। BentoML-এ "Bento" মানে একটি প্যাকেজ যাতে তোমার ML model, code, dependencies — সব কিছু একসাথে থাকে।

একটি Bento-এর ভেতরে কী থাকে?
🔧

Installation ও প্রাথমিক Setup

BentoML install করার আগে একটি virtual environment বানানো উচিত। এটা কেন? কারণ বিভিন্ন project-এ বিভিন্ন version-এর library লাগে। Virtual environment আলাদা "বাক্স" তৈরি করে — একটা project অন্যটাকে নষ্ট করতে পারে না।

💡 Virtual Environment কী?

ধরো তোমার একটা project-এ numpy 1.23 লাগে, আরেকটাতে numpy 2.0 লাগে। দুটো একসাথে install করলে conflict হবে। Virtual environment প্রতিটা project-এর জন্য আলাদা Python environment তৈরি করে — সমস্যা নেই।

ধাপ ১: Python চেক করো

# Terminal-এ এই command চালাও:
python3 --version

# Output হবে যেমন:
Python 3.11.5bash

ধাপ ২: Virtual Environment তৈরি করো (uv দিয়ে)

uv হলো Python-এর একটি নতুন, খুব দ্রুত package manager। এটা pip-এর চেয়ে অনেক দ্রুত কাজ করে।

# Virtual environment তৈরি করো
uv venv

# Dependencies install করো (requirements.txt থেকে)
uv sync

# Virtual environment activate করো (Linux/Mac)
source .venv/bin/activate

# এখন তুমি virtual env-এ আছো। Terminal-এ দেখবে:
(.venv) $ bash

ধাপ ৩: BentoML install করো

# pip দিয়ে install
pip install bentoml

# সঠিকভাবে install হয়েছে কিনা দেখো
bentoml --version

# Output:
bentoml, version 1.4.26bash
⚠️ মনে রাখো

প্রতিবার নতুন terminal খুললে source .venv/bin/activate চালাতে হবে। না হলে তোমার install করা packages পাওয়া যাবে না।

05

Model Store — মডেল সংরক্ষণ ব্যবস্থা

সাধারণত মানুষ তাদের trained model model.pkl নামের ফাইলে save করে। কিন্তু এর সমস্যা হলো — কোন version কোনটা? কখন train হয়েছিল? BentoML এর সমাধান দিয়েছে Model Store দিয়ে।

📦 Model Store কী?

এটা হলো তোমার হার্ড ডিস্কে একটি বিশেষ folder (সাধারণত ~/bentoml/models/) যেখানে BentoML তোমার সব model automatically সংরক্ষণ করে — প্রতিটা version-এর জন্য আলাদা unique tag সহ।

Model Store-এর ভেতরের ফাইল কাঠামো

Model Save করার Command

import bentoml
from sklearn import ensemble

# Model train করলাম (ধরে নিলাম)
rf_classifier = ensemble.RandomForestClassifier(n_jobs=-1)
rf_classifier.fit(X_train, y_train)

# এখন BentoML-এ save করো
# "accidents_rf" হলো model-এর নাম — তুমি যেকোনো নাম দিতে পারো
model_ref = bentoml.sklearn.save_model("accidents_rf", rf_classifier)

print(f"Model saved as: {model_ref}")
# Output: Model saved as: accidents_rf:y22glzfi3om7jinxpython

Model দেখার ও মুছার Commands

# সব saved model-এর list দেখো
bentoml models list

# Output এরকম দেখাবে:
# Tag                          Module          Size       Creation Time

# একটি model load করো (Python script-এ)
model = bentoml.sklearn.load_model("accidents_rf:latest")

# একটি model মুছো (tag দিয়ে)

✅ "latest" এর সুবিধা

তুমি model-এর tag মনে না রাখলেও accidents_rf:latest দিলেই সবচেয়ে নতুন version load হবে। BentoML নিজেই track করে কোনটা latest।

import sklearn
import pandas as pd
from sklearn import ensemble
import numpy as np
import bentoml

# ধাপ ১: Preprocessed data load করো
X_train = pd.read_csv('data/preprocessed/X_train.csv')
X_test  = pd.read_csv('data/preprocessed/X_test.csv')
y_train = pd.read_csv('data/preprocessed/y_train.csv')
y_test  = pd.read_csv('data/preprocessed/y_test.csv')

# y_train 2D array — 1D করো
y_train = np.ravel(y_train)
y_test  = np.ravel(y_test)

# ধাপ ২: Random Forest model তৈরি ও train
# n_jobs=-1 মানে সব CPU core ব্যবহার করো (দ্রুত train হবে)
rf_classifier = ensemble.RandomForestClassifier(n_jobs=-1)
rf_classifier.fit(X_train, y_train)

# ধাপ ৩: Accuracy পরীক্ষা করো
accuracy = rf_classifier.score(X_test, y_test)
print(f"Model accuracy: {accuracy}")
# Output: Model accuracy: 0.776  (77.6% ✓)

# ধাপ ৪: BentoML Model Store-এ save করো
# প্রথম argument: model-এর নাম
# দ্বিতীয় argument: actual model object
model_ref = bentoml.sklearn.save_model("accidents_rf", rf_classifier)
print(f"Model saved: {model_ref}")python
✅ এই output দেখলে সফল

Model accuracy: 0.7762949421084705 — মানে model 77% ক্ষেত্রে সঠিক prediction করতে পারে।

07

API ও Serving — মডেলকে সার্ভিস বানানো

API কী? — সহজ ভাষায়

API (Application Programming Interface) হলো দুটো software-এর মধ্যে কথা বলার নিয়ম। ধরো তোমার model একটি "রেস্তোরাঁ"। API হলো "মেনু কার্ড" — customer বলে কী চায়, রেস্তোরাঁ দেয়।

ML API-এর কাজের ধারা

সহজ API Service তৈরি (simple_service.py)

import bentoml
from pydantic import BaseModel
from bentoml.io import JSON

# ধাপ ১: Model Store থেকে model load করো
# "latest" মানে সবচেয়ে নতুন version
model_runner = bentoml.sklearn.get("accidents_rf:latest").to_runner()

# ধাপ ২: Input data-এর সব fields define করো (Pydantic model)
# Pydantic মানে — ভুল type দিলে API নিজেই error ফেরত দেবে
class InputModel(BaseModel):
    place: int           # দুর্ঘটনার স্থান code
    catu: int            # ব্যক্তির category (1=চালক, 2=যাত্রী...)
    sexe: int            # লিঙ্গ (1=পুরুষ, 2=মহিলা)
    secu1: float         # নিরাপত্তা সরঞ্জাম
    year_acc: int        # দুর্ঘটনার বছর
    victim_age: int      # আহত ব্যক্তির বয়স
    catv: int            # যানবাহনের category
    obsm: int            # চলমান বাধা
    motor: int           # engine type
    catr: int            # রাস্তার category
    circ: int            # traffic direction
    surf: int            # রাস্তার surface অবস্থা
    situ: int            # দুর্ঘটনার স্থান পরিস্থিতি
    vma: int             # সর্বোচ্চ অনুমোদিত গতি
    jour: int            # সপ্তাহের দিন
    mois: int            # মাস
    lum: int             # আলোর পরিস্থিতি
    dep: int             # department code
    com: int             # commune code
    agg_: int            # শহর এলাকা কিনা
    int: int             # intersection type
    atm: int             # আবহাওয়া
    col: int             # collision type
    lat: float           # latitude (GPS)
    long: float          # longitude (GPS)
    hour: int            # ঘণ্টা
    nb_victim: int       # আহতের সংখ্যা
    nb_vehicules: int    # যানবাহনের সংখ্যা

# ধাপ ৩: Service তৈরি করো — নামটা গুরুত্বপূর্ণ, এটাই Bento-র নাম হবে
svc = bentoml.Service("rf_clf_service", runners=[model_runner])

# ধাপ ৪: Endpoint define করো
# POST /classify → এই function চলবে
@svc.api(input=JSON(pydantic_model=InputModel), output=JSON())
async def classify(input_data: InputModel):
    # Pydantic model → list of values → model-এ দাও
    data = [[
        input_data.place, input_data.catu, input_data.sexe,
        input_data.secu1, input_data.year_acc, input_data.victim_age,
        # ... বাকি সব fields
    ]]
    prediction = await model_runner.predict.async_run(data)
    return {"prediction": prediction.tolist()}python

Service চালু করো

# project root থেকে চালালে এই format:
# "src.simple_service" মানে src/ folder-এর simple_service.py ফাইল
# ":svc" মানে ওই ফাইলে "svc" নামের variable
bentoml serve src.simple_service:svc --port 3001 --reload

# অথবা src/ folder-এর ভেতরে থেকে চালালে:

# --reload মানে: code change হলে auto restart করবে (development-এ কাজের)

🌐 Swagger UI — Browser-এ API Test

Service চালু হলে browser-এ http://localhost:3001 যাও। স্বয়ংক্রিয়ভাবে তৈরি Swagger UI দেখবে — সেখানে input দিয়ে সরাসরি API test করা যায়, কোনো extra tool ছাড়াই। প্রতিটা endpoint-এর documentation ও example দেখা যায়।

💡 দুটো Terminal লাগবে

প্রথম terminal-এ service চালু রাখো (এটা বন্ধ করলে API বন্ধ হবে)। দ্বিতীয় terminal খুলে সেখান থেকে curl বা test script চালাও।

curl দিয়ে API Test করো

# Terminal থেকে API test করা

  -H "Content-Type: application/json" \

# Response পাবে:

💡 curl কী?

curl হলো command line থেকে HTTP request পাঠানোর tool। Postman-এর মতো, কিন্তু terminal-এ। -X মানে HTTP method (POST), -H মানে Header, -d মানে Data।

Prometheus Metrics — Performance Monitor করো

API Security — JWT Authentication

সমস্যা হলো যে কেউ তোমার API call করতে পারছে। এটা নিরাপদ না। সমাধান হলো JWT (JSON Web Token) দিয়ে authentication।

🔑 JWT কী?

ধরো তুমি concert-এ ঢুকলে — gate-এ ticket দেখালে, তারা তোমাকে wristband দিলো। এরপর ভেতরে যেখানেই যাও, wristband দেখালেই ঢুকতে দেবে — আবার ticket দেখাতে হবে না। JWT ঠিক এরকম। Login করলে একটা "token" পাবে — সেটা দিয়েই সব API call করতে পারবে।

JWT Authentication Flow

Middleware কী এবং কেন দরকার?

Middleware হলো একটি "দারোয়ান" যে প্রতিটা request আসার আগেই সেটা চেক করে। BentoML নিজে কোনো security দেয় না — তাই আমাদের নিজেই এই দারোয়ান বসাতে হয়।

কারণব্যাখ্যা

Rate Limitingএকজন user বেশি বার request করতে পারবে না

JWT Authentication-সহ Service (service.py)

import jwt
from datetime import datetime, timedelta
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.responses import JSONResponse

# User database (real project-এ database থেকে আসবে)
USERS = {
    "user123": "password123",
    "admin": "admin123"
}
SECRET_KEY = "my-secret-key"  # Real project-এ .env file-এ রাখো

# JWT Middleware — দারোয়ান
class JWTAuthMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        # Login endpoint-এ token লাগে না
        if request.url.path == "/login":
            return await call_next(request)
        
        # Authorization header থেকে token নাও
        token = request.headers.get("Authorization", "").replace("Bearer ", "")
        
        try:
            # Token verify করো
            payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
            request.state.user = payload["sub"]
        except jwt.ExpiredSignatureError:
            return JSONResponse({"error": "Token expired"}, status_code=401)
        except jwt.InvalidTokenError:
            return JSONResponse({"error": "Invalid token"}, status_code=401)
        
        return await call_next(request)

# Service তৈরি করো
svc = bentoml.Service("rf_clf_service", runners=[model_runner])
svc.add_asgi_middleware(JWTAuthMiddleware)

# Login endpoint
@svc.api(input=JSON(), output=JSON())
async def login(credentials: dict):
    username = credentials.get("username")
    password = credentials.get("password")
    
    if USERS.get(username) == password:
        # Token তৈরি করো — 1 ঘণ্টা valid
        token = jwt.encode({
            "sub": username,
            "exp": datetime.utcnow() + timedelta(hours=1)
        }, SECRET_KEY, algorithm="HS256")
        return {"token": token}
    return JSONResponse({"error": "Invalid credentials"}, status_code=401)python

# random_state=42 মানে প্রতিবার একই split (reproducible)
X_train, X_test, y_train, y_test = train_test_split(
    X_scaled, y, test_size=0.2, random_state=42
)

# ধাপ ৭: Processed folder তৈরি করো (না থাকলে)
os.makedirs('data/processed', exist_ok=True)

# ধাপ ৮: CSV-তে save করো
pd.DataFrame(X_train).to_csv('data/processed/X_train.csv', index=False)
pd.DataFrame(X_test).to_csv('data/processed/X_test.csv', index=False)
pd.DataFrame(y_train).to_csv('data/processed/y_train.csv', index=False)
pd.DataFrame(y_test).to_csv('data/processed/y_test.csv', index=False)
print("Data saved successfully!")python

# tests/test_api.py
import pytest
import requests

BASE_URL = "http://localhost:3001"

# ১. সঠিক credentials দিলে token পাওয়া যায়
def test_login_success():
    response = requests.post(f"{BASE_URL}/login", json={
        "username": "user123",
        "password": "password123"
    })
    assert response.status_code == 200
    assert "token" in response.json()

# ২. ভুল credentials দিলে 401 error আসে
def test_login_failure():
    response = requests.post(f"{BASE_URL}/login", json={
        "username": "wrong",
        "password": "wrong"
    })
    assert response.status_code == 401

# ৩. Token ছাড়া predict করলে 401 আসে
def test_predict_without_token():
    response = requests.post(f"{BASE_URL}/predict", json={"GRE Score": 320})
    assert response.status_code == 401

# ৪. Token দিয়ে predict করলে সঠিক ফলাফল আসে
def test_predict_success():
    # আগে login করো
    login_res = requests.post(f"{BASE_URL}/login", json={
        "username": "user123", "password": "password123"
    })
    token = login_res.json()["token"]
    
    # তারপর predict করো
    response = requests.post(
        f"{BASE_URL}/predict",
        json={"GRE Score": 320, "TOEFL Score": 110, "CGPA": 8.5},
        headers={"Authorization": f"Bearer {token}"}
    )
    assert response.status_code == 200
    assert "prediction" in response.json()

# Test চালাও:
# pytest tests/test_api.py -vpython
