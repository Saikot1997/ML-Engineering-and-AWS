LLM (Large Language Model)

🧒 স্তর ১ — সহজ গল্প

কল্পনা করো তুমি জন্মের পর থেকে প্রতিদিন ১ লক্ষ বই পড়ছ — পত্রিকা, উপন্যাস, বিজ্ঞান, রেসিপি, ইতিহাস, কোড, সব। ১০ বছর পর তোমার মাথায় কোটি কোটি প্যাটার্ন জমে গেছে।


LLM ঠিক এটাই। ইন্টারনেটের কোটি পাতা পড়ে শেখা AI — যেটা ভাষা বোঝে এবং উত্তর তৈরি করে।

💡 সহজ উদাহরণতুমি যখন ChatGPT বা Claude এর সাথে কথা বলো — সেটাই LLM। আমি প্রশ্ন পেলে কোটি প্যাটার্ন থেকে সেরা উত্তর বানাই।

🔬 স্তর ২ — থিওরি

Token ও Next Token Prediction:


LLM ভাষাকে Token এ ভাগ করে — শব্দের টুকরো। তারপর পরের token কী হবে তা predict করে।


Transformer Architecture (Google, ২০১৭):


👁️
Self-Attention

পুরো বাক্যের সব শব্দ একসাথে দেখে। "সে গান গাইল কারণ সে খুশি" — দুটো "সে" আলাদা করে বোঝে।

🔢
Parameters

মডেলের "জ্ঞান" সংরক্ষণের জায়গা। GPT-3 = ১৭৫ বিলিয়ন numbers। এই numbers মিলেই মস্তিষ্ক।


Temperature ও Max Tokens:

Temperature (0–2)

0 = সবসময় একই উত্তর  ·  1 = ভারসাম্য  ·  2 = অনেক creative

Max Tokens

উত্তরের দৈর্ঘ্য। ১ token ≈ ০.৭৫ শব্দ। কোড লিখলে temperature=0, গল্প লিখলে =0.9।


Training — ৩টা ধাপ:

১
Pre-training: Wikipedia, বই, কোড সহ ~১ trillion শব্দ। মাসের পর মাস GPU তে।
২
Supervised Fine-tuning (SFT): মানুষের লেখা "ভালো উত্তর" এর উদাহরণ দিয়ে সমন্বয়।
৩
RLHF: মানুষ দুটো উত্তরের মধ্যে ভালোটা বেছে দেয়, মডেল শেখে। ChatGPT, Claude এভাবেই তৈরি।

⚠️ Hallucination — সবচেয়ে বড় সমস্যা

LLM মাঝে মাঝে ভুল তথ্য অনেক আত্মবিশ্বাসের সাথে দেয়। কারণ সে "সত্যি বলতে" শেখেনি — শুধু "কোন শব্দের পরে কোন শব্দ আসে" শিখেছে।

Hallucination কমাতে RAG ব্যবহার করো — পরের অধ্যায়ে শেখাবো।

RAG (Retrieval-Augmented Generation)

🧒 স্তর ১ — সহজ গল্প

তোমার একজন বুদ্ধিমান বন্ধু (LLM) অনেক কিছু জানে। কিন্তু সে তোমার অফিসের নতুন নীতি বা আজকের খবর জানে না।


তুমি তাকে সব document দিয়ে বললে: "এগুলো পড়ে আমার প্রশ্নের উত্তর দাও।"


এটাই RAG! LLM এর বুদ্ধি + তোমার তথ্য = কম hallucination, সঠিক উত্তর।

💡 উদাহরণOpen book পরীক্ষা মনে আছে? RAG হলো LLM এর open book পরীক্ষা।

🔬 স্তর ২ — RAG Pipeline (৬ ধাপ)

১
Document Loading: PDF, Word, web page — সব লোড করো।
২
Chunking: বড় document কে ছোট ছোট টুকরোয় ভাগ করো (৩০০–৬০০ অক্ষর)।
৩
Embedding: প্রতিটা টুকরোকে সংখ্যার vector এ বদলাও। কাছাকাছি অর্থ = গণিতেও কাছাকাছি।
৪
Vector Store: FAISS / ChromaDB তে index করো।
৫
Retrieval: প্রশ্ন এলে সবচেয়ে সংশ্লিষ্ট K টা chunk খুঁজে বের করো।
৬
Generation: LLM সেই chunks দিয়ে উত্তর তৈরি করে।

Embedding কী? — "রাজা" − "পুরুষ" + "নারী" ≈ "রানী" এই গণিত embedding দিয়ে কাজ করে।


Vector DB তুলনা:

DBকখন ব্যবহার করবেCost

💻 স্তর ৩ — RAG কোড

rag_example.py
# pip install langchain langchain-openai faiss-cpu sentence-transformers pypdf

from langchain_community.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_community.vectorstores import FAISS
from langchain.chains import RetrievalQA

# ধাপ ১: PDF লোড
docs = PyPDFLoader("document.pdf").load()

# ধাপ ২: Chunk করো
chunks = RecursiveCharacterTextSplitter(
    chunk_size=500, chunk_overlap=60,
    separators=["\n\n", "\n", "।", " "]  # বাংলার জন্য "।" যোগ করো
).split_documents(docs)

# ধাপ ৩+৪: Embed ও Index করো
db = FAISS.from_documents(chunks, OpenAIEmbeddings())
db.save_local("my_index")  # disk এ save

# ধাপ ৫+৬: QA Chain
qa = RetrievalQA.from_chain_type(
    llm=ChatOpenAI(temperature=0),
    retriever=db.as_retriever(search_kwargs={"k": 4})
)
print(qa.invoke("এই নথিতে মূল বিষয় কী?")["result"])

💻 স্তর ৩ — Agent কোড (OpenAI Function Calling)

agent_basic.py
# pip install openai duckduckgo-search
import os, json
from openai import OpenAI
from duckduckgo_search import DDGS

client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])

def web_search(query):
    with DDGS() as d:
        return str([r["body"][:200] for r in d.text(query, max_results=3)])

def calculator(expr):
    return str(eval(expr))

TOOLS = [
    {"type": "function", "function": {
        "name": "web_search",
        "description": "ওয়েবে তথ্য খোঁজে",
        "parameters": {"type": "object",
          "properties": {"query": {"type": "string"}},
          "required": ["query"]}}},
    {"type": "function", "function": {
        "name": "calculator",
        "description": "গণিত হিসাব করে",
        "parameters": {"type": "object",
          "properties": {"expr": {"type": "string"}},
          "required": ["expr"]}}}
]
TOOL_MAP = {"web_search": web_search, "calculator": calculator}
msgs = [{"role": "system", "content": "তুমি একজন Research Agent।"}]

def run(task):
    msgs.append({"role": "user", "content": task})
    for _ in range(8):
        r = client.chat.completions.create(model="gpt-4o", messages=msgs, tools=TOOLS)
        m = r.choices[0].message
        msgs.append(m)
        if not m.tool_calls: return m.content
        for tc in m.tool_calls:
            result = TOOL_MAP[tc.function.name](**json.loads(tc.function.arguments))
            msgs.append({"role": "tool", "tool_call_id": tc.id, "content": result})

print(run("বাংলাদেশের জনসংখ্যা খোঁজো এবং সেটার ৭৫% হিসাব করো।"))

💻 স্তর ৩ — MCP Server কোড

simple_mcp_server.py
# pip install mcp[cli]
from mcp.server.fastmcp import FastMCP
import datetime

mcp = FastMCP("আমার প্রথম MCP Server")

@mcp.tool()
def get_time() -> str:
    """বর্তমান সময় ও তারিখ দেয়"""
    return datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")

@mcp.tool()
def add(a: float, b: float) -> str:
    """দুটো সংখ্যা যোগ করে"""
    return f"{a} + {b} = {a + b}"

if __name__ == "__main__":
    mcp.run()  # python simple_mcp_server.py

import pandas as pd

def load_examples(path="data/SentNoB_dataset.csv", n=3) -> str:
    """
    CSV থেকে few-shot examples বানাও।
    প্রতি sentiment class থেকে n টা নমুনা নেবে।
    """
    try:
        df = pd.read_csv(path)
        print(f"✅ Dataset: {len(df)} rows | columns: {list(df.columns)}")
        # column নাম খুঁজে বের করো
        tc = next((c for c in ['text','sentence','Text'] if c in df.columns), df.columns[0])
        lc = next((c for c in ['sentiment','label','Sentiment'] if c in df.columns), df.columns[1])
        rows = []
        for lbl in ['Positive','Negative','Neutral']:
            sub = df[df[lc].str.lower()==lbl.lower()].sample(min(n,len(sub)) if len(sub)>0 else 0)
            for _,r in sub.iterrows():
                rows.append(f"বাক্য: {r[tc]}\nঅনুভূতি: {lbl}")
        return "\n\n".join(rows)
    except FileNotFoundError:
        print("⚠️  Dataset নেই — sample data ব্যবহার হচ্ছে")
        return """বাক্য: আজকের দিনটা অসাধারণ ছিল!
অনুভূতি: Positive

বাক্য: এই সিনেমাটা একদম বাজে।
অনুভূতি: Negative

বাক্য: আগামীকাল বৃষ্টি হতে পারে।
অনুভূতি: Neutral"""

chatbot.py
import os
from openai import OpenAI
from loader import load_examples
from rich.console import Console
from rich.panel import Panel

console = Console()
client  = OpenAI(api_key=os.environ["OPENAI_API_KEY"])
SHOTS   = load_examples()

SYSTEM = f"""তুমি একজন সহানুভূতিশীল বাংলা chatbot।
প্রতিটা উত্তরের শুরুতে [SENTIMENT: Positive/Negative/Neutral] লেখো।
তারপর সেই sentiment অনুযায়ী উত্তর দাও।

Examples:
{SHOTS}"""

history = [{"role": "system", "content": SYSTEM}]

def chat(msg):
    history.append({"role":"user","content":msg})
    r = client.chat.completions.create(
        model="gpt-4o-mini", messages=history,
        temperature=0.7, max_tokens=300)
    reply = r.choices[0].message.content
    history.append({"role":"assistant","content":reply})
    return reply

def parse(reply):
    colors = {"Positive":"green","Negative":"red","Neutral":"yellow"}
    for s,c in colors.items():
        tag = f"[SENTIMENT: {s}]"
        if tag in reply:
            return reply.replace(tag,"").strip(), f"😊 {s}" if s=="Positive" else f"😔 {s}" if s=="Negative" else f"😐 {s}", c
    return reply, "Unknown", "white"

if __name__=="__main__":
    console.print(Panel("[bold yellow]🧠 বাংলা Sentiment Chatbot[/]\n[dim]exit লিখলে বন্ধ হবে[/]",border_style="yellow"))
    while True:
        u = input("\n[তুমি]: ").strip()
        if u.lower() in ["exit","quit"]: break
        if not u: continue
        with console.status("[dim]ভাবছি...[/]"):
            reply = chat(u)
        text,label,color = parse(reply)
        console.print(f"\n[{color}]{label}[/]")
        console.print(Panel(text,border_style=color))

build_index.py — Vector Index তৈরি করো (একবার)

build_index.py
"""
Dataset লোড → Chunk → Embed → FAISS index তৈরি করে disk এ save।
একবার চালালেই হবে। তারপর rag_qa.py লোড করবে।
"""
import os, pickle
import pandas as pd
import numpy as np
import faiss
from sentence_transformers import SentenceTransformer
from tqdm import tqdm

IDX_DIR = "vectorstore"
os.makedirs(IDX_DIR, exist_ok=True)

print("📰 Dataset লোড হচ্ছে...")
df = pd.read_csv("data/bangla_news.csv")
print(f"   Columns: {list(df.columns)}")

# text column খুঁজো
tc = next((c for c in ['content','text','article','news','body'] if c in df.columns), df.columns[0])
print(f"   Text column: {tc}")

df = df.dropna(subset=[tc])
df[tc] = df[tc].astype(str).str.strip()
texts = df[df[tc].str.len()>50][tc].tolist()
print(f"   পরিষ্কার সংবাদ: {len(texts)}")

print("\n✂️  Chunking হচ্ছে...")
chunks = []
for i,t in enumerate(texts):
    for j in range(0,len(t),280):
        c=t[j:j+300].strip()
        if len(c)>30: chunks.append({"text":c,"src":i})
print(f"   মোট chunks: {len(chunks)}")

print("\n🤖 Embedding model লোড হচ্ছে (প্রথমবার ~400MB download)...")
model = SentenceTransformer("sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2")

print("\n🔢 Embeddings তৈরি হচ্ছে...")
vecs = model.encode(
    [c["text"] for c in chunks],
    batch_size=64, show_progress_bar=True, convert_to_numpy=True
).astype("float32")

print("\n📦 FAISS index তৈরি হচ্ছে...")
idx = faiss.IndexFlatIP(vecs.shape[1])
faiss.normalize_L2(vecs)
idx.add(vecs)
faiss.write_index(idx, f"{IDX_DIR}/news.index")
with open(f"{IDX_DIR}/chunks.pkl","wb") as f: pickle.dump(chunks,f)
print(f"✅ Done! Index: {idx.ntotal} vectors → vectorstore/ এ save।")
print("এখন python3 rag_qa.py চালাও!")

rag_qa.py — Q&A System

rag_qa.py
import os, pickle
import numpy as np
import faiss
from openai import OpenAI
from sentence_transformers import SentenceTransformer
from rich.console import Console
from rich.panel import Panel
from rich.table import Table

console = Console()
client  = OpenAI(api_key=os.environ["OPENAI_API_KEY"])

print("📦 Index লোড হচ্ছে...")
idx    = faiss.read_index("vectorstore/news.index")
chunks = pickle.load(open("vectorstore/chunks.pkl","rb"))
embed  = SentenceTransformer("sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2")
print(f"✅ Ready — {idx.ntotal} chunks")

def retrieve(q, k=4):
    v = embed.encode([q], convert_to_numpy=True).astype("float32")
    faiss.normalize_L2(v)
    sc,ids = idx.search(v,k)
    return [{"text":chunks[i]["text"],"score":float(sc[0][j])} for j,i in enumerate(ids[0]) if i<len(chunks)]

def answer(q, hits):
    ctx = "\n\n".join(f"[সংবাদ {i+1}]: {h['text']}" for i,h in enumerate(hits))
    r = client.chat.completions.create(
        model="gpt-4o-mini", temperature=0, max_tokens=400,
        messages=[{"role":"user","content":f"""নিচের সংবাদ থেকে উত্তর দাও। Context এ না থাকলে বলো "এই তথ্য সংবাদে নেই।"

Context:
{ctx}

প্রশ্ন: {q}
উত্তর (বাংলায়):"""}])
    return r.choices[0].message.content

if __name__=="__main__":
    console.print(Panel("[bold green]📚 বাংলা News Q&A[/]\n[dim]exit দিয়ে বন্ধ[/]",border_style="green"))
    while True:
        q = input("\n❓ প্রশ্ন: ").strip()
        if q.lower()=="exit": break
        if not q: continue
        with console.status("[dim]খোঁজা হচ্ছে...[/]"): hits=retrieve(q)
        t=Table(title="সংশ্লিষ্ট সংবাদ")
        t.add_column("#",width=3); t.add_column("Score",width=6); t.add_column("সংবাদ")
        [t.add_row(str(i+1),f"{h['score']:.2f}",h["text"][:100]+"...") for i,h in enumerate(hits)]
        console.print(t)
        with console.status("[dim]উত্তর তৈরি হচ্ছে...[/]"): a=answer(q,hits)
        console.print(Panel(a,title="[bold green]উত্তর[/]",border_style="green"))

agent.py
"""
বাংলাদেশ Research Agent — OpenAI Function Calling
Tools: web_search, calculator, get_wikipedia, save_report
"""
import os, json, math
from datetime import datetime
from openai import OpenAI
from duckduckgo_search import DDGS
import wikipediaapi
from rich.console import Console
from rich.panel import Panel

console = Console()
client  = OpenAI(api_key=os.environ["OPENAI_API_KEY"])
wiki    = wikipediaapi.Wikipedia("ResearchAgent/1.0", "bn")
os.makedirs("reports", exist_ok=True)

# ── Tool Functions ──
def web_search(query: str, max_results: int = 4) -> str:
    console.print(f"  🔍 [dim]{query}[/]")
    try:
        with DDGS() as d:
            res = list(d.text(query, max_results=max_results))
        return json.dumps([{"title":r["title"],"snippet":r["body"][:250]} for r in res], ensure_ascii=False)
    except Exception as e: return f"Error: {e}"

def calculator(expression: str) -> str:
    console.print(f"  🔢 [dim]{expression}[/]")
    try: return f"ফলাফল: {eval(expression, {}, {'math': math}):,}"
    except Exception as e: return f"Error: {e}"

def get_wikipedia(topic: str) -> str:
    console.print(f"  📖 Wikipedia: [dim]{topic}[/]")
    p = wiki.page(topic)
    if p.exists(): return p.summary[:1000]
    wiki_en = wikipediaapi.Wikipedia("ResearchAgent/1.0","en")
    pe = wiki_en.page(topic)
    return pe.summary[:1000] if pe.exists() else f"'{topic}' পাওয়া গেল না।"

def save_report(filename: str, content: str) -> str:
    console.print(f"  💾 Save: [dim]{filename}[/]")
    path = f"reports/{filename}"
    with open(path,"w",encoding="utf-8") as f:
        f.write(f"# {filename}\nতৈরি: {datetime.now().strftime('%Y-%m-%d %H:%M')}\n\n{content}")
    return f"✅ '{path}' এ save হয়েছে।"

# ── OpenAI Tool Definitions ──
TOOLS = [
    {"type":"function","function":{"name":"web_search","description":"ওয়েবে তথ্য খোঁজে। সাম্প্রতিক ঘটনা বা statistics এর জন্য।","parameters":{"type":"object","properties":{"query":{"type":"string"},"max_results":{"type":"integer","default":4}},"required":["query"]}}},
    {"type":"function","function":{"name":"calculator","description":"গণিত হিসাব করে।","parameters":{"type":"object","properties":{"expression":{"type":"string"}},"required":["expression"]}}},
    {"type":"function","function":{"name":"get_wikipedia","description":"Wikipedia থেকে বিস্তারিত তথ্য আনে।","parameters":{"type":"object","properties":{"topic":{"type":"string"}},"required":["topic"]}}},
    {"type":"function","function":{"name":"save_report","description":"রিপোর্ট ফাইলে save করে।","parameters":{"type":"object","properties":{"filename":{"type":"string"},"content":{"type":"string"}},"required":["filename","content"]}}}
]
TOOL_MAP = {"web_search":web_search,"calculator":calculator,"get_wikipedia":get_wikipedia,"save_report":save_report}

# ── Agent Loop ──
def run_agent(task: str, max_steps=10):
    console.print(Panel(f"[bold]Task:[/] {task}",border_style="blue"))
    msgs = [
        {"role":"system","content":"তুমি একজন বাংলাদেশ বিশেষজ্ঞ Research Agent। প্রয়োজনীয় tools ব্যবহার করো। সব কাজ শেষে বাংলায় রিপোর্ট save করো।"},
        {"role":"user","content":task}
    ]
    for step in range(max_steps):
        console.print(f"\n[blue]── ধাপ {step+1} ──[/]")
        r = client.chat.completions.create(model="gpt-4o",messages=msgs,tools=TOOLS,tool_choice="auto")
        m = r.choices[0].message
        msgs.append(m)
        if not m.tool_calls:
            console.print("\n[green]✅ Done![/]")
            return m.content
        for tc in m.tool_calls:
            console.print(f"  [yellow]Tool: {tc.function.name}[/]")
            res = TOOL_MAP[tc.function.name](**json.loads(tc.function.arguments))
            msgs.append({"role":"tool","tool_call_id":tc.id,"content":str(res)})
    return "সর্বোচ্চ ধাপে পৌঁছে গেছি।"

if __name__=="__main__":
    console.print(Panel("[bold blue]🤖 Bangladesh Research Agent[/]\n[dim]exit দিয়ে বন্ধ[/]\n\nউদাহরণ:\n→ বাংলাদেশের GDP ও জনসংখ্যা সম্পর্কে রিপোর্ট তৈরি করো।\n→ ঢাকার জনসংখ্যা জানো এবং বাংলাদেশের মোট জনসংখ্যার % হিসাব করো।",border_style="blue"))
    while True:
        task=input("\n📋 Task: ").strip()
        if task.lower()=="exit": break
        if not task: continue
        run_agent(task)

file_server.py — MCP Server

file_server.py
"""
File Manager MCP Server
Claude Desktop এর সাথে connect হবে।
Claude এই server এর tools দিয়ে files পড়তে/লিখতে/খুঁজতে পারবে।
"""
import os, json
from datetime import datetime
from pathlib import Path
from mcp.server.fastmcp import FastMCP

WORKSPACE = Path("workspace").resolve()
WORKSPACE.mkdir(exist_ok=True)

mcp = FastMCP("বাংলা ফাইল ম্যানেজার",
    instructions=f"Workspace: {WORKSPACE}. শুধু .txt .md .py .json এ কাজ করো।")

def _safe(name):
    p = (WORKSPACE/name).resolve()
    if not str(p).startswith(str(WORKSPACE)): raise ValueError("Access denied!")
    return p

@mcp.tool()
def list_files() -> str:
    """Workspace এর সব files ও folders দেখায়"""
    items = []
    for p in sorted(WORKSPACE.iterdir()):
        s = p.stat()
        items.append({
            "নাম": p.name,
            "ধরন": "📁 Folder" if p.is_dir() else f"📄 File ({s.st_size}B)",
            "পরিবর্তন": datetime.fromtimestamp(s.st_mtime).strftime("%Y-%m-%d %H:%M")
        })
    return json.dumps(items, ensure_ascii=False, indent=2)

@mcp.tool()
def read_file(filename: str) -> str:
    """File এর content পড়ে। filename: ফাইলের নাম যেমন notes.txt"""
    try:
        p = _safe(filename)
        if not p.exists(): return f"'{filename}' পাওয়া গেল না।"
        return p.read_text(encoding="utf-8")
    except Exception as e: return f"Error: {e}"

@mcp.tool()
def write_file(filename: str, content: str, append: bool = False) -> str:
    """File এ লেখে। append=True হলে পুরনো content এর পরে যোগ হয়।"""
    try:
        p = _safe(filename)
        mode = "a" if append else "w"
        with open(p, mode, encoding="utf-8") as f: f.write(content)
        return f"✅ '{filename}' এ {'যোগ' if append else 'লেখা'} হয়েছে।"
    except Exception as e: return f"Error: {e}"

@mcp.tool()
def search_in_files(keyword: str) -> str:
    """সব text file এর ভেতরে keyword খোঁজে।"""
    found = []
    for p in WORKSPACE.rglob("*.txt"):
        try:
            txt = p.read_text(encoding="utf-8")
            if keyword.lower() in txt.lower():
                lines = [l for l in txt.splitlines() if keyword.lower() in l.lower()]
                found.append({"file":p.name,"lines":lines[:3]})
        except: pass
    return json.dumps(found or [{"result":ff"'{keyword}' পাওয়া গেল না।"}], ensure_ascii=False)

@mcp.tool()
def create_note(title: str, content: str) -> str:
    """দ্রুত note তৈরি করো — title ও content দিলেই হবে।"""
    safe = "_".join(c for c in title.split() if c.isalnum() or ord(c)>127)
    fname = f"note_{datetime.now().strftime('%Y%m%d_%H%M')}_{safe[:20]}.txt"
    p = _safe(fname)
    p.write_text(f"# {title}\n{datetime.now().strftime('%Y-%m-%d %H:%M')}\n\n{content}", encoding="utf-8")
    return f"✅ Note তৈরি: {fname}"

@mcp.resource("workspace://overview")
def overview() -> str:
    """Workspace এর সংক্ষিপ্ত overview"""
    files = [p.name for p in WORKSPACE.iterdir() if p.is_file()]
    return f"Workspace: {WORKSPACE}\nFiles: {', '.join(files)}"

if __name__=="__main__":
    print(f"🚀 MCP Server চালু — Workspace: {WORKSPACE}")
    mcp.run()
