📖 DIAGRAM পড়ো — বাংলায়
১
Multi-AZ — Primary DB এবং Standby Replica দুটো আলাদা AZ তে। Synchronous replication। Primary fail হলে automatic failover — Standby Primary হয়। উদ্দেশ্য: High Availability।
২
Read Replica — Primary DB থেকে Asynchronous copy। Read queries serve করে। Primary fail হলে auto failover নেই (manually promote করতে হয়)। উদ্দেশ্য: Read Scalability।
৩
গুরুত্বপূর্ণ: Multi-AZ Standby read serve করতে পারে না। শুধু failover এর জন্য। Read করতে চাইলে Read Replica।
💡
Exam most common question: Multi-AZ = HA (failover), Read Replica = Performance (reads)। "Disaster recovery" → Multi-AZ। "Read-heavy" → Read Replica।
